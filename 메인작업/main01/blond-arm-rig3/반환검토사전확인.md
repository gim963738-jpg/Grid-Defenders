# A안 반환 검토·B안 연결 전 확인

2026-11-10 main01. A안의 실제 worker_done 성공 회신과 결과 파일을 확인한 뒤 검토용 독립 플레이어를 제공한다. 사용자 합격이나 게임 반영으로 기록하지 않는다. 이미 승인된 B안은 A안 반환으로 브랜치 점유가 해제된 다음 기존 캐릭터 담당에게 발송한다.

이번에 본문을 확인한 공통 규정 A, 메인 운영, 팀장 운영, main01 작업진행방법, 메인보고형식, 진행승인규칙, 작업대장/사용법, 분야 characters 규정·작업진행방법을 적용한다. 자료 분류는 세계관/캐릭터, 제작 책임은 characters다. 역할 연결·조직·파일담당표 및 A/B 사용자 확인과 B 전문 지시를 대조했다. main01/규정.md는 존재하지 않아 main01 작업진행방법과 메인운영규정을 따른다. 다른 팀의 원본이나 공통 규정은 수정하지 않는다.

확인 범위: 파츠 펼침, 원본/재조립 비교, 연속 동작 화면, 보고·검수, 실제 플레이어의 재생/정지/스크럽, 배포 사본의 HTTP 응답과 SHA. 공개 사본은 게임/public/dev-previews 아래 새 독립 경로에 필요한 파일만 복사하며 게임 코드·화면·설정은 변경하지 않는다. 원본 A 및 준비된 B 전문 지시의 해시는 유지한다. 검토용 파츠의 거친 경계, 큰 회전의 천 겹침, 전신 체중 이동이 없는 한계를 보고한다. 커밋·푸시는 하지 않는다.
