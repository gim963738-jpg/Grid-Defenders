- Orca account list의 비밀값 제외 상태: codex ok. 구독 요금제/혜택 활성화/잔액 정보는 제공되지 않음.
- 현재 내장 imagegen 스키마에는 model 또는 과금 조직/크레딧 계정 선택 필드 없음. 특정 모델·크레딧 사용을 검증 완료로 보고할 수 없음.
- 기존 미디어 로컬 resolve: OpenAI API key 없음. 실제 생성/편집 호출 아님. 기존 로컬 경로의 기본 모델 표기는2.5여서2.6으로 자동 간주하면 안 됨.
- 공식 https://developers.openai.com/api/docs/models/gpt-image-2.6-sunburst 확인: 요청 모델 실존, Images 생성·편집 지원.
- 공식 https://developers.openai.com/api/docs/guides/chatgpt-api-credits 확인: 자격 있는 Pro/Business 구독은 소유 API 조직에 구독 혜택 크레딧을 연결해 Images API 사용 가능. 소유/동일 이메일 등 조건과 사용자 본인 혜택 활성화가 필요. 현재 사용자 요금제/자격/연결 여부 미확인. ChatGPT 또는 signed-in Codex 한도를 API 크레딧과 혼동하지 않음.

현재 상태: 경로 조사 완료, 새 모델/크레딧 연결 미완료. 사용자 본인 계정의 혜택 활성화와 안전한 인증 연결이 남음. 원격 로그인 토큰/브라우저 쿠키 추출 없음, 화면/결제 설정 변경 없음, 키 값 조회·출력·소스 저장 없음. 이미지 생성·과금 호출/새 크레딧 구매/자동충전/전역도구 수정/기존 진행중 작업 중단 없음.

후속: 계정에 구독 API 크레딧 혜택이 표시되는지 확인. 표시·활성화됐다면 해당 조직의 인증을 별도 안전한 사용자 입력 경로로 연결하고 먼저 무료 인증/모델 접근 검사. 순수 ChatGPT 내 이미지 사용 한도만 의미한다면 현재 도구에서 특정2.6과 차감계정을 직접 지정하는 연결이 확인되지 않았다고 명확히 안내. API 구매 잔액으로 임의 대체하지 않음.
