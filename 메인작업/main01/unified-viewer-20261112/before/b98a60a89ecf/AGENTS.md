v23은 도시·왕국 삽화의 상대적 비중을 줄이고 내륙과 도시 사이 공간을 넓힌 1536×1024 가로형 생성 원본이다. 다섯 대륙을 각각 북·남·서·동 4구역으로 나누며 중앙은 중앙북부·중앙남부·중앙서부·중앙동부다. 나머지는 북대륙북부·서대륙북부 같은 형식이다. 실선은 대륙 구획, 점선은 내부 구획이며 이 지리 구분을 새 국가나 종속 관계로 간주하지 않는다. `regional_divisions`에 20구역, `minor_impact_sites`에 이름 없는 소규모 운석 오염지 4곳을 기록한다. 기존 서부·중앙·남부 세 곳에 v24에서 동대륙 호수 동쪽·진월국 북쪽 내륙 한 곳을 추가했다. v24도 1536×1024 생성 원본이며 확대·축소하지 않는다. 작은 충돌지는 기존 대형 충돌지 가로폭의 약 1/4이며 지도 지명과 번호 표식은 추가하지 않는다. 이미지 폭·높이와 표식 위치는 실제 새 원본에 맞춘다.
중앙은 황제가 통치하는 아스테른 제국, 큰 수도는 발레시온, 작은 마법 수도의 표준명은 **아르케리온**이다. 아르케리온에는 독립 세력인 **마탑**이 있으며 중앙대륙 마법사의 기본 소속은 마탑이다. 왕국 소속 네 마법가문은 마탑을 떠나 왕국에 몸을 맡긴 마법사들이 세운 계보이며 현재 마탑 소속과 별도로 분류한다. 에르디안·칼레도르는 친왕파 봉신가문, 벨사르는 귀족파, **오르딘은 중립**이다. 에르디안은 화염마법, 칼레도르는 공간마법, 벨사르는 물속성 마법의 대가이며 오르딘은 특정 한 마법에 국한되지 않고 종합적으로 잘 다룬다. 작은 수도의 대외적 충의와 실제 협력, 마탑의 독립성, 가문의 왕국 소속과 궁정 입장을 구분한다. 두 봉신가문을 제외한 마법사들의 활동 자유를 유지한다. 친왕파는 황제를 지지하는 세력이라는 사용자 호칭을 유지한다.
서부 발트레인 왕국(사용자 표기 발레트레인 왕국)의 내부 정치는 **친왕파·반왕파**로 나뉜다. 친왕파는 국왕을 지지하고 반왕파는 국왕에 반대한다. 중앙 제국의 친왕파·귀족파와 별도 세력이며 지도자·구성 가문·세부 대립 사유는 미정이다. 서부와 중앙은 성휘 대교회의 중재로 휴전 중이며 이계의 적에 공동 대응한다. 남부 사하리드 왕국과 동부 진월국은 우호 관계다. 진월국은 **가문이 아닌 문파 중심**으로 운영하며 **검법 문파 4개·도법 문파 2개**, 총 6개 문파가 있다. 문파 이름·지도자·개별 특성은 미정이다. 북부 스카르가드 요새는 하르반·우르칸 두 부족으로 구성되고, 1대3~4의 전력 우위는 **북방 설산** 조건이다. 북부는 신 대신 전승을 신성시한다. 성휘 대교회의 창조신은 에르하온, 남부의 사막신은 나하르다. 성휘 대교회는 **성직자·성기사로 구성된 자체 무력**을 보유한다. 병력 규모·지휘 체계·구체적인 전투 능력은 미정이다.
사용자 최신 요청에 따라 **첨부자료와 모든 이전 작업물은 현재 세계관에 배치하지 않는다**. 기존 아르케리온 수석 빛 마법사 시안도 포함해 출신·소속을 미지정으로 보관하고 **신규 캐릭터부터 배치**한다. 중앙대륙·아르케리온·마탑의 기존 시안 연결을 해제하며 제작 당시 제목·프롬프트·원본 입력은 과거 기록으로 보존한다. 마탑 기본 소속 규칙은 앞으로 중앙대륙에 배치하는 신규 캐릭터에 적용한다. 위 네 가문의 전문 마법 외 세부 학파·추가 지도자·새 스킬·수치 밸런스를 임의 확정하지 않는다.

엘프와 드워프는 소수민족이며, 각 민족 전체의 국력은 북방민족보다 작은 편이다. 엘프 민족은 타국과의 교류가 매우 적다. 드워프 민족은 사하리드 왕국과 교류가 잦고 탐구심이 깊다. 드워프족의 평균 키는 **140cm**, 종족 체형은 **땅딸막한 체형**이다. 드워프 캐릭터 제작에는 이 체격을 적용하며 평균값과 개별 인물의 키를 구분한다. 소수민족 설정은 구조화 설정의 `peoples`와 각 거점의 `people_id`에 연결하며, 드워프와 사하리드의 빈번한 교류를 종속·동맹 관계로 바꾸지 않는다.

# 캐릭터 그림체 참조 (사용자 요청, 2026-11-06)

**2026-11-08 사용자 재지정 · C3~C6 8장 전체 작화:** [작화고정기준](자료/캐릭터그림체/GC9/작화고정기준.json), [완성본 8장·실행 프롬프트](자료/캐릭터그림체/GC9/완성작화기준8장.json), [대화 대조 보고서](output/gc9-style-standard-20261108/report.md)를 우선한다. 기준 집합은 **C3·C4·C5·C6 정면·사선 8장 전체**다. **C4 전체·얼굴 최우선, C3 금속 최우선**을 유지하며 C5·C6의 남성형도 같은 작화 집합에 포함한다. C3도 전체 작화 기준이며 C4 얼굴+C3 금속만으로 전체를 축약하지 않는다. 발로르를 C6에만 고정하던 이전 복구 규칙은 해제한다. C5는 Bram+Ronan으로 성공했으므로 참조 이름의 조합을 실패 원인으로 단정하지 않는다. C5는 투구로 얼굴이 가려져 얼굴 기준으로 쓰지 않는다. 대상별 전체 작화 대표 1~2장과 필요한 보조 원본을 실제 첨부하며 총 5장 한도를 지킨다. 8장 전부를 한 호출에 넣는 규칙이 아니다. 원대화의 구성 참조/주 작화/재질/구도 역할 분리와 정면 마스터→동일 인물 사선 원리를 유지한다. 원본 16장은 분석 라이브러리, 8장은 생성 후 평가된 기준으로 수량을 합치지 않는다. 후속 금발 전사·장검·단검은 파생 작업 확인 자료이며 이번 원기준을 대체하지 않는다. 전체 작화 실패본을 편집·화풍 마스터로 쓰거나 그 얼굴·선·명암을 고정한 부분 편집을 반복하지 않는다. 발로르 v09·v10 등 실패 이력과 v11 미검증 후보는 기준에서 제외한다. 기존 SD 선택·디자인 선택과 그림체 통과는 별개다. 전체 작화 확인 전 다음 방향을 연속 생성하지 않는다. preflight는 입력 일관성 검사이며 출력 화풍 판정/내장 도구 강제 차단 기능이 아니다. 이번 기준 정리는 이미지 생성 없이 진행한다.

## 생성 결과에 대한 사용자 피드백

이후 같은 제작에서는 [사용자 피드백과 C1 수정 기준](output/character-redesign-6x2/revisions/c01-v2/피드백.md)을 적용한다. 가까이에서도 얼굴선·금속 면·장식 연결이 읽혀야 하며, 저해상도 JPEG 축소본 확대를 원본 품질 검수로 사용하지 않는다.
