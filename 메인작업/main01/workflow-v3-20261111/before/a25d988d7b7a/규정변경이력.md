# 규정 변경 이력

## OPS-005 모델 기본값 — 2026-11-09

사용자 직접 요청으로 GPT-6.1 Sol / medium을 기본값으로 기록했다. Codex config.toml 두 키와 메인운영규정의 다음 실행 옵션을 갱신했다. 기존 Orca 세션 GUI의 일괄 전환은 미검증이며 설정 저장과 구분한다.

## A-1.1.0 — 2026-11-08 / OPS-002

사용자가 제시한 세계관 → 몬스터/캐릭터 → 세부 객체별 도메인 계층으로 실제 작업 목록을 재배치했다. 기존 역할 ID·Git 브랜치·폴더·전문 제작 기준·이력을 유지하고4개 부족한 분류/작업 공간과 원본 색인을 추가했다. 캐릭터와 몬스터의 제작·검수 기준을 통합하지 않는다. 이전 A-1.0.0의 사용자 이해 확인·병행 작업·검수·통합 절차는 유지한다.

## A-1.0.0 — 2026-11-08

근거: 본 대화에서 사용자가 요청한 새 운영 방식과 이번 사전 준비 요청.

- 메인3개에서 병행 요청·시안 제작·부분 조합·전문 지시·검수를 수행한다.
- 최초 지시와 수정 지시 모두 메인의 이해를 사용자에게 확인받은 후 전달한다.
- 담당 브랜치는 기존 작업 기준을 이어받아 결과물과 규정 보완 내용을 함께 만든다.
- 사용자 피드백·판정·실패 사례를 작업번호·결과 차수·규정 버전에 연결한다.
- 작업대장으로 담당·확인·브랜치 점유를 구분하고 실제 전달·제작·검증·사용자 합격·통합·커밋·푸시를 분리한다.

기존 분야별 그림체·색·방향·프레임 수·게임 밸런스 등을 이번 운영 변경으로 재확정하지 않는다. 추가 기준은 [개정 양식](양식/규정개정.md)으로 제안과 사용자 확인을 구분해 누적한다.


## OPS-003 팀장 체계 적용 — 2026-11-09

현재 조직은 [조직.json](조직.json), 운영은 [팀장운영규정.md](팀장운영규정.md), 공유 파일 책임은 [파일담당표.md](파일담당표.md)를 따른다. 기존 5담당을 팀장으로 이어받고 게임개발 팀장·독립 테스터를 신설한다. 총 6개 팀장과 독립 테스터이며 메인3개 역할을 유지한다. 자료의 세계관 계층과 원본 위치는 보존한다. 실제 조직 관계는 조직.json이 우선한다. 원본 완성 시트의 불필요한 분해·재조립은 기본 공정에서 제외한다. 사용자 확인 근거는 OPS-003 대화기록이며 새 게임 콘텐츠 지시0건이다.


## OPS-004 매 작업 하달 후 필독 — 2026-11-09

규정 A 및 팀장 운영 규정 v2.0.0 → v2.1.0. 각 역할 작업진행방법 v1.0.0 추가. 사용자의 매 작업 필독 요청을 근거로 적용했으며 사용자 추가 승인 단계를 만들지 않았다.

사용자 요청으로 모든 역할의 작업진행방법.md와 requiredReadings를 연결했다. 작업을 받은 에이전트는 본문 읽기 → 작업별 적용 요약 → start 착수 확인 후 작업한다. 전문지시와 하위위임에 실제 필독 경로/버전을 포함하며, 목록만 복사하거나 과거 초기화 응답으로 대신하지 않는다. read-pack/start 절차는 [작업대장 사용법](도구/사용법.md)을 따른다. 사용자 추가 승인 절차가 아니다.
