# 세계관 중심 도메인 트리

현재 실제 담당 조직은 [조직 안내](../조직안내.md)와 조직.json을 따른다. 아래 세계관 트리는 자료 분류이며 실제 AI 조직의 표시·부모 관계와는 구분한다. OPS-001/002의 인원·동일 계층 설명은 당시 기록이다.


운영 분류를 제작 공정에서 기획 대상 중심으로 정리했다. 이 폴더의 색인과 실제 Orca 작업 목록의 부모/자식 관계를 함께 관리한다.

```text
세계관
├─ 몬스터
│  └─ 몬스터 스프라이트
└─ 캐릭터
   ├─ 캐릭터 일러스트
   ├─ 캐릭터 스프라이트
   │  └─ 영상·모션 소스
   ├─ 캐릭터 능력치
   └─ 캐릭터 스킬
      └─ 이펙트·제작도구
```

영상과 이펙트는 기존 자료를 보존하기 위해 관련 작업 아래에 남겼다. 이펙트 도구의 공용 재료 성격은 유지하며 몬스터 작업에서도 참조할 수 있다. 메인3개는 이 도메인 트리를 공통으로 사용한다. UI·아이템 작업의 기존 위치는 유지한다.

## 분류와 제작 규정

부모/자식 관계는 기획 소속을 나타낸다. 몬스터와 캐릭터의 제작·검수 기준을 하나로 합치는 뜻이 아니다. 공통 [규정 A](../규정A.md)와 각 분야의 기존 규정을 이어 사용한다. 최초·수정 지시는 계속 사용자 이해 확인 후 전달한다.

## 데이터 원본과 색인

각 노드의 index.json에 담당 역할·실제 Git 작업 공간·원본 참조 위치·자료 상태를 기록한다. 기존 원본을 옮기거나 기존 경로를 끊지 않았다. 새 작업 공간에 Git 기준선으로 들어 있는 오래된 자료를 최신 원본으로 가정하지 말고 **색인이 지정하는 기존 소스**를 읽는다.

세계관 자료 중 기존 캐릭터·세계관 작업 공간에 저장된 원본은 그 위치를 보존하며, 세계관 노드에서 공통 소스로 연결한다. 새 세계관 변경은 확인된 원본과 승인 범위로 작업하고, 사용자 합격 후 정확한 변경 범위와 소스 색인을 함께 갱신한다. 단순 분류 변경으로 미확정 수치·스킬·화풍을 확정하지 않는다.

분류가 바뀌어도 기존 역할 ID와 Git 브랜치·원래 채팅 이력은 유지한다. 실제 작업 전달은 [브랜치목록](../브랜치목록.json)의 selector로 수행하며, 표시 이름만 보고 다른 작업에 보내지 않는다. 새로 추가된 관리·작업 공간에는 이번에 새 제작 AI나 제작 지시를 시작하지 않았다.
