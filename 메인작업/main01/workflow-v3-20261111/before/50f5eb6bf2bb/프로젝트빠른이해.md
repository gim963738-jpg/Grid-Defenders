# 새 메인용 프로젝트 인계

프로젝트: Grid Defenders. 순환 길목을 방어하는 웨이브전과 이동하며 싸우는 보스전, 전투 중 상점·가방·장비 조합을 가진 웹 게임 시제품이다. 현재 구현과 기획을 구분한다.

- 현재 구현의 근거는 [현재 구현 현황](../문서/05_프로젝트정의/현재구현현황.md), [큰기획](../문서/01_큰기획/큰기획.md), [게임 실행 안내](../게임/README.md)다. 전체 보고서의 과거 스냅샷을 최신 구현으로 오해하지 않는다.
- 실제 가로 UI는800×360, 전장 배치5×4/20칸이다. 영웅 최대3명, 공용 가방7×3, 판매 상품5개 등은 현재 시제품 값이다. 보스 진형 편집은7×6이다.
- 최신 가로 길목은 직사각형이며 관련 코드가 UI 작업 공간으로 복제되어 있다. 새 시안 선택으로 바꿀 수 있는 현재 구현이지 영구 디자인 제약은 아니다.
- 사용자의 'UI2배수'는 확대가 아니라 짝수 치수를 뜻한다. [모바일 UI 규격](../문서/00_개발규칙/모바일UI규격.md)을 읽는다.
- 사용자는 메인에서 실제 분석·비교 시안을 보고 부분별 선택을 원한다. 'UI4번·필드6번'처럼 조합하고 통합 시안을 확인한 뒤 구현으로 이어간다.
- 기술 검증과 사용자 시각적 합격은 다르다. 합격·개선됐으나 미달·수정 요청·실패를 구분한다. 사용자 확인 없이 AI가 합격시키거나 실패본을 기준으로 채택하지 않는다.
- 디자인 UI를 먼저 별도 사본으로 만들고 단계별 연결해 온 프로젝트다. 로비 영웅 데이터 연결·새 전투 기능 등은 별도 요청 범위로 확인한다.
- 캐릭터·몬스터·이펙트의 최신 기준은 [분야 목록](기준/README.md)에서 실제 제작 브랜치 원본을 읽는다. GC9 일러스트 비율, SD 원본 프레이밍, 게임 내 표시 크기, 논리 사거리 R을 하나의 픽셀 기준으로 합치지 않는다.
- main의 기존 미커밋 변경과 별도 분야 작업은 보존 중이다. 공통 소스·자산을 정리한다며 이동·삭제·자동 병합하지 않는다. 현재 UI 구현 원본과 작업 사본의 연결은 [브랜치목록](브랜치목록.json)을 따른다.

이번 준비에서는 실제 슬라임·시안10종 제작 지시를 발송하지 않았다. 새 요청을 받으면 규정 A의 이해 확인 단계를 적용한다.


## OPS-003 팀장 체계 적용 — 2026-11-09

현재 조직은 [조직.json](조직.json), 운영은 [팀장운영규정.md](팀장운영규정.md), 공유 파일 책임은 [파일담당표.md](파일담당표.md)를 따른다. 기존 5담당을 팀장으로 이어받고 게임개발 팀장·독립 테스터를 신설한다. 총 6개 팀장과 독립 테스터이며 메인3개 역할을 유지한다. 자료의 세계관 계층과 원본 위치는 보존한다. 실제 조직 관계는 조직.json이 우선한다. 원본 완성 시트의 불필요한 분해·재조립은 기본 공정에서 제외한다. 사용자 확인 근거는 OPS-003 대화기록이며 새 게임 콘텐츠 지시0건이다.
