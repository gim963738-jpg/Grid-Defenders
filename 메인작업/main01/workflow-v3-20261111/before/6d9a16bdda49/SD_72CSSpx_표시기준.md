## 제작에서 표시까지

1. 승인된 캐릭터 디자인으로 고해상도 투명 원본을 제작·보존한다. 이번 선택은 새 그림체·체형 채택이나 기존 미합격 디자인의 합격이 아니다.
2. 원본의 본체 높이·발점·전체 PNG 범위를 기록한 뒤, 기본 표시 본체 높이를 **72 CSSpx**로 맞춘다. 검·방패·망토의 돌출과 투명 여백을 본체 키로 계산하지 않는다. PNG 캔버스 전체를72픽셀로 강제 축소하거나 파츠 원본을72픽셀로 만드는 지시가 아니다. 기존 금발 전사 비교 메타의 bodyHeight1123은 그 이미지의 기준이며 다른 캐릭터에 복사하지 않는다.
3. 표시 방식은 기존 교전 비교 도구의 **3번: 고품질 축소 + 경계 정리**를 기준으로 한다. 원본 바이트는 바꾸지 않고 파생 표시 버퍼에 적용한다. 단계 축소와 Canvas high 보간 후 바깥 투명 영역에 연결된 극저알파(1~8) 비초록 픽셀만 알파를1단계 낮추는 현재 처리다. 과도한 블러·샤프닝·얼굴/무기 재생성으로 대체하지 않는다. 경계 정리는2번 대비 차이가 매우 작은 보수적 처리이며 큰 개선 효과를 약속하지 않는다.
4. CSS 표시 크기와 PNG 실제 픽셀을 구분한다. 본체72 CSSpx는 DPR1에서는 본체72 물리픽셀, DPR2에서는144 물리픽셀에 대응한다. 전체 PNG는 장비/여백에 따라 더 클 수 있다. 원본 해상도·표시 본체 CSSpx·DPR·발점 정보를 함께 기록한다.
5. 밝은/어두운 배경과 실제 필드의72 CSSpx에서 얼굴·실루엣·손과 장비 연결·유색 외곽·발선을 확인한다. 확대 화면만으로 작은 표시 품질을 합격 처리하지 않는다. 장비 길이·비율·색상·방향·재생 속도·피해 판정은 이 처리로 변경하지 않는다.
