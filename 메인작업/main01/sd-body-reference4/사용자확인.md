# 사용자 확정 요청과 진행 근거
사용자는 코드 도형 마네킹으로는 판단할 수 없다고 했으며 SD 금발 전사를 기준으로 머리카락·갑옷·장비를 제거하고 민머리, 몸에 딱 붙는 검은 티와 반바지를 입힌 외형을 요청했다. 맨몸 비율 확인 목적이며 실제 나체를 제작하는 것이 아니다.

사용자: “이거 나체 뽑을때 남여 한장씩 2장뽑을건데 이때 이미지GPT2.6 사용해서 여기서 2장 2.6두장 총 4장 뽑아오자”.
메인 이해 확인: 내장 이미지 생성으로 남녀 각1장 + GPT Image2.6으로 남녀 각1장, 총4장. 동일 우측3/4뷰·동일 기본 자세·민머리·밀착 검은 반팔 티·짧은 반바지. 우선 정지 이미지 비교 후 외형 선택, 움직임 연결은 후속.
사용자 조건 보완: “서있는기준으로 뽑아줘 이때 신체에서 실루엣에서 여성형과 남성형이 차이가 나게끔 뽑아줘야한다 이해했지?”
메인 최종 이해: 두 발로 자연스럽게 서 있는 동일 우측3/4뷰. 어깨폭/몸통/허리선/골반폭/팔다리 두께에서 남녀 차이, 과장 피하기. SD 금발 전사 그림체·비율 기준, 총4장.
사용자 실제 최종 승인: “진행”.

유료 GPT Image2.6은 이미지2장 제작에만 사용하고 기존 캐릭터 프로젝트의 승인된 API/구독혜택 연결 경로를 재사용한다. 텍스트/영상 API·리깅·게임적용·커밋/푸시는 승인 범위 밖이다. 직전 코드 전용 지시는 직전 이동시제품 범위이며 이번은 사용자가 명시한 두 이미지 생성 경로 비교다.
