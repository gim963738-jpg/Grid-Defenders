# 스킬 문서 표 정리 — 사용자 확인

2026-11-11 / main01.

사용자 요청: “스킬문서 보기 어렵게정리되어있네 스킬아이콘 스킬명 스킬 종류[1스킬,2스킬 이런식]스킬설명 표형식으로 정리해놔”.

main01 확인: 현재 스킬 기획 문서 ‘임시영웅.md’를 영웅별로 ‘스킬 아이콘 | 스킬명 | 스킬 종류(패시브·1스킬·2스킬·궁극기 등) | 스킬 설명’ 표로 정리. 기존 설명·수치·쿨타임·붉은 보스전용 표시 보존. 기존 아이콘 연결, 없는 것은 ‘미등록’ 표시.

사용자는 위 확인 내용을 인용하고 “이 내용으로 진행”이라고 직접 답했다. 이 범위의 문서 편집 승인이다. 게임 구현·스킬 수치 변경·새 아이콘 생성·이미지 API·GitHub 저장 요청은 아니다.
