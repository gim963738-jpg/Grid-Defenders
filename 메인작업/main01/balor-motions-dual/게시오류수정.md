# 비교 페이지 공개파일 로딩 오류 수정

사용자 게임 화면에 `/dev-previews/balor-motions-dual-v001/data.js` ERR_LOAD_PUBLIC_URL 개발 서버 오류창이 표시됐다. 게시 도구의 초기 확인 중 같은 URL HTTP500이 발생했던 기록이 있고 이후 원본과 동일한200응답이 확인됐다. 현재 HTML은 원래부터 일반 script 태그였으므로 게임 소스가 해당 파일을 import했다고 단정하지 않는다. Vite 정적 공개파일 목록 갱신 전에 확인 요청이 들어간 경합으로 추정하며, 확인된 사실과 구분한다.

게임 페이지는 새로고침하지 않고 해당 경로의 오류창만 제거했다. 동기식 전후 확인은 같은 URL·WAVE73, 오류창1→0이었다. 저장·전투 초기화·서버 재시작·HMR 오류창 설정 비활성화는 하지 않았다.

재발 방지: 게시 페이지에서 data.js와 player.js를 별도 요청하지 않도록 실제 데이터/재생 코드를 HTML에 포함했다. 원본 제작 폴더의 HTML/JS 및 모든 원본 PNG는 그대로 보존했다. 공개 사본만 기술적으로 묶었으며 게시 도구도 같은 변환·원본/게시 해시 기록·원자적 파일 교체·파일 전체 준비 후 검증을 적용한다. 공개JS 직접 HTTP프로브는 없앴다.

실제 격리 Edge/HTTP 검증: 게시오류검증.json. HTTP200,ready=true,26시트로드,외부data/player요청0,페이지예외0,HTTP실패0,오류창0. 사용자 브라우저로 검증 페이지를 열지 않았다. 공개파일56개는 게시검증.json에 소스/게시 해시와 검증 방법을 구분했다. 발로르 원화·모션 품질 미달 판정은 변경하지 않는다.
