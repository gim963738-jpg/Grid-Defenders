# 금발 전사 사거리100·기존 스프라이트 적용 — 확인 대기

사용자 원문:
> 금발전사 사거리 100 조정후 스프라이트 작업한거 적용한다
> 스킬없이 평타만

현재 분석 범위는 읽기 전용이다. 해당 신규 적용의 '진행'은 아직 받지 않았으므로 코드 수정/적용 지시는 발송하지 않았다.

확인 사실:
- root 게임/src/defenseConfig.ts blond: 기본 사거리130,공격력85,공속1.1. bossBattle.ts에서 근접 blond는 일반 사거리값을 사용한다.
- 현재 blondArt.ts는 blond-warrior-v1의8방향 정지 이미지와60프레임 우측 걷기만 읽는다. 새 제작 시트가 연결돼 있지 않다.
- 기존8모션 결과는 sprites/output/characters/blond_motions_MAIN02-20261111-8D69415B_v002의 A_builtin/B_image26에 각각 있다. native시트/animation.json/납품보고/시각WARN 보존. 일반 미적합격·게임통합 여부를 제작완료로 추정하지 않는다.
- 별도 발로르 캐릭터 제작과 effects 공방은 서로 다른 파일 책임으로 진행 중. 게임 적용 책임은 gameplay이며 아직 신규 발송 전이다.

적용 제안:
웨이브·보스 공통 기본 사거리130→100. 현재 공격력/공격속도는 유지. 기존 완성 스프라이트의 전투대기·달리기·기본공격·피격·사망을 해당 게임 상태에 연결한다. 스킬을 새로 부여하지 않고 공격은 평타로만 처리한다. 공격 동작과 실제 피해 확정 시점을 스킬구현규약에 맞게 분리·연결하고 타격 중복을 검증한다. 본체/발점·모션 크기·원본 영역은 기존 제작 메타와72CSS 표시 기준을 읽어 조정한다.

현재 확인할 선택: 내장 또는2.6 완성 시트 중 적용 대상. 이는 기존 파일 사용 선택이며 새2.6 API 호출 허가/이미지 생성 요청이 아니다. 네이티브 선택 '2.6 시트로 진행' 또는 '내장 시트로 진행' 제출은 해당 범위의 실제 진행 승인으로 기록한다. 침묵/사전 선택은 승인 아니다.
