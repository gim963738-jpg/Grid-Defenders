# 선택안 기본자세6장 제작 확인

사용자: “1,4번 적용 기준으로 정면 3/4측면 우측면 이렇게 뽑아봐 거기서 최종결정하자”.
이후 자세 정정: “기본자세로 뽑아봐”.
메인이 확인한 범위: “1번·4번을 각각 양발로 서서 장검·단검을 자연스럽게 내려 든 기본 대기 자세로 제작할까요? 정면·오른쪽 45°·90°로 총 6장이며, 최종 채택·게임 적용은 비교 후 결정합니다.”
