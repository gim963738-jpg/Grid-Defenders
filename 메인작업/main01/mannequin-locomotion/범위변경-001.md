# 진행 중 작업의 최신 사용자 변경 지시 — 001

대상: MAIN01-20261110-B87520F7 / main01 / characters / 차수1 진행 중 보충지시.

사용자 원문:
> 여성체 남성체 따로 구분해서 만들어야해서 이것도 같이 작업시켜줘
> 3안제작하지말고 남 1안 여 1안 으로 가져오고 내가 보면서 피드백 줄께

앞서 사용자가 “GPT2.6은 사용하지않고 진행하자 / Idle 기본 대기 / 시작/ Walk / Run / 정지”로 승인한 진행 중 작업에 대한 직접적인 대상·납품 구성 교체 지시다. 실제 원문을 보존하며 새로 ‘진행’이라고 말했다고 바꾸어 기록하지 않는다. 원래 제작 3안 지시는 이번 “3안제작하지말고”에 의해 대체된다. 새 부서·별도 생성 경로·게임 통합으로 확장하지 않는다.

## 최신 납품 범위
1. 남성형 기본 마네킹 1개와 여성형 기본 마네킹 1개, 합계 2개만 제작한다. 체형별 모션 3안이나 총6안은 만들지 않는다.
2. 두 마네킹 모두 Idle / Start / Walk / Run / Stop을 제공한다. 동일한 기본 동작 구성·주기·시점·비교 크기를 사용해 체형과 연결 상태를 볼 수 있게 한다. 체형 차이로 필요한 관절 위치·발 접지 보정은 가능하되 변경값과 이유를 설명한다. 남녀별 성격·행동·속도를 임의로 다르게 만들지 않는다.
3. 남성체는 기존 금발 전사의 머리/신체 비율을 기준으로 삼는다. 여성체는 같은 SD 계열의 기본 체형 초안으로 어깨·상체·허리·골반 등 신체 폭과 관절 배치를 별도 데이터로 조정한다. 몸 전체를 가로로 눌러 여성체라고 부르거나 색상/속눈썹만 바꾸지 않는다. 과도한 신체 강조 없이 매끈한 비해부학적 단색 인체 모형으로 제작한다. 여성 체형의 세부 비율은 미확정 초안이며 모든 여성 캐릭터의 영구 표준으로 확정하지 않는다.
4. 우측3/4뷰, 머리 유지/머리카락·옷·갑옷·장비 없음, 눈은 방향 확인용 표시, 전신+뼈대 토글, 코드 전용, 모든 이미지/영상 생성/API 금지, 사용자 화면 조작/커밋·푸시/게임 적용 금지는 유지한다.
5. 두 체형을 나란히 재생·정지·스크럽하고 자동 순환과 개별 Idle/Start/Walk/Run/Stop을 확인할 수 있게 한다. 기존3안 선택/표기/설명은 최종 제출에서 남성체/여성체2개로 바꾸며 임시 작업물은 삭제하지 않고 이력으로 보존한다.
6. 사용자 검수는 전신 움직임과 체형을 보고 진행한다. 내부에서는 각 체형의 관절/길이불변/접지/지면 미끄러짐/앞뒤 겹침/상태 연결을 검사하고 문제 부분만 확대자료로 제공한다. 미적 합격과 최종속도는 사용자가 결정한다.
