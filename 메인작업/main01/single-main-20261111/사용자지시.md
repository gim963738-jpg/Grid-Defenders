# 단일 메인 운영 전환 — 사용자 직접 지시

> 메인그냥 1번만 쓰는걸로하고 2번 3번 없애자 없애기전에 자료가지고있는 메인있으면 자료만 가지고오고 정리해줘

승인 범위: 메인01만 활성 총괄로 유지. 메인02/03 고유자료·작업기록·진행상태를 인수하고 검증한 뒤 해당 두 메인의 운영/Orca 작업공간을 정리한다. 분야별 팀장/전문 작업은 유지한다. 원본·미커밋 변경·기존 커밋/브랜치 이력은 보존하며 코드를 무검증 통합하지 않는다. 기존 제작 요청의 권한은 그대로 보존하되 새 작업 발송과 사용자 확인은 메인01로 모은다.

GitHub 저장 요청은 아니므로 커밋/푸시는 하지 않는다. 자격증명/브라우저 프로필을 공개자료에 넣지 않는다. 실제 파일·작업 인수 확인 전 삭제하지 않는다. 사용자 브라우저/패널은 조작하지 않는다.
