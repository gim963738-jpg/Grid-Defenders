사용자가 직전 개선 설명에 실제로 “진행”이라고 승인했다. 같은 범위의 허락을 반복 요구하지 말고 아래 내용을 제작한다. 기존 통합/maintenance 시안은 사용자 불합격이다.

## 목표와 원인
기존 실패: 정비를 큰 상점으로만 해석했고 병사·영웅 선택을 전장 배치로 착각했다. 작은 전장 미리보기와 과다 패널로 플레이 흐름이 보이지 않았다. 이번에는 초기 자금으로 병사·영웅과 장비를 준비하고 전장에 배치 → 자동 웨이브 전투 → 정비하는 게임 흐름을 이미지로 명료하게 보여준다.
D3의 시각 언어(둥근 짙은 유리판, 절제된 밝은 테두리, 선형 아이콘)와 배경 분위기는 유지한다. 실패한 화면 배치는 폐기하고 새 정보 위계로 구성한다. 상단 정보판은 이전 선택대로 뒤 배경이 더 보이는 alpha .74, 글자 불투명. 필드 아트는 기존 자산을 재사용할 수 있다.

## 두 정비 작업 화면
상단 혹은 하단의 명료한 2개 내비게이션: 병력·배치 / 장비. 둘을 동시에 펼쳐 화면을 가득 채우지 않는다. 정비 맥락과 준비 상태는 공통으로 유지한다. 가장 중요한 다음 행동은 하나만 강조한다.

A 병력·배치:
- 실제 전장 배치판을 주인공으로 크게 쓴다. 작은 썸네일을 배치 UI라고 제출하지 않는다. 왼쪽 아군 방어·오른쪽 적 진입 방향을 읽을 수 있어야 한다.
- 병사/영웅 선택 구분을 두고 선택 목록은 화면에 최소5칸. 영웅 후보 최소8명 이상을 페이지/스크롤로 탐색하는 모습을 포함한다. 동시 출전 정원 변경 승인과 혼동하지 않는다. 없는 병과/영웅의 수치·스킬을 새 규칙으로 확정하지 않는다. 필요한 후보 자리는 시안 샘플임을 보고서에 명시한다.
- 병력 선택→가능한 배치 칸 강조→실제 전장에 놓인 모습, 기존 유닛 선택→이동/교환이 읽히는 상태를 보여준다. 선택 카드와 전장 캐릭터는 동일한 개체로 연결돼야 한다.
- 구매 비용·잔액은 필요한 순간에 간명하게. 영웅 선택 상세는 능력치와 스킬 요약을 한 패널 안에서 동시에 확인하되 항상 열린 대형 패널로 전장을 가리지 않는다.
- 이것은 웨이브용 실제 배치 화면이다. 사용자가 제거한 별도 보스 진형 메뉴/7x6 보스 편집판을 복구하지 않는다.
- 준비 완료 상태에서 전투 시작 버튼을 명확히 둔다.

B 장비:
- 상품 / 작은 다음 웨이브 이월 창고 / 선택 영웅 인벤을 같은 화면에서 넓고 명확하게 구분한다. 병력 배치판과 영웅 상세를 동시에 또 펼치지 않는다.
- 큰 아이템을 과도하게 축소하지 않도록 셀을 크게. 1x1 재료와 여러 칸 조합 장비를 같은 축척으로 보여준다. 창고 칸 수는 제안으로 표시하고 수용 검증을 한다. 빈칸1개에 2칸 장비가 들어간다고 표시하지 않는다.
- 상점→창고, 상점→영웅 인벤, 영웅 인벤↔창고 이동/착용을 선택 목적지 또는 드래그 상태로 제시한다. 상품 상세는 선택했을 때만 표시한다. 구매/착용/이동 완료 상태가 구별돼야 한다.
- 별도 가방 버튼 없음. 다음 보스 정보는 간결한 버튼과 선택시 펼침으로 제공한다. 영웅 능력치+스킬 요약 동시 보기 요구는 유지한다.

## 전투와 진행
자동전투 화면에서는 전장/진행 정보/필수 조작 중심. 편집용 상점·창고·후보 목록은 닫힌다.
흐름: 초기 준비 → 일반4웨이브 → 정비 → 중보스가 중간에 포함된4웨이브 → 정비 → 일반4웨이브 → 정비 → 최종 보스. 중보스는 추가 별도전이 아니다. 정확한 중보스 웨이브/초기 자금 등 미확정 수치는 샘플 제안이며 확정 규칙으로 적지 않는다.
