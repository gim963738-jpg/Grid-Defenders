# 장르 UI 조사와 이번 작업 적용
main02 분석. 아래 적용점은 메인의 설계 제안이며 타게임의 실제 UI와 우리게임 구현을 혼동하지 않는다. 인기순위 조사나 현행 PC화면의 모바일 적합성 검증을 했다고 주장하지 않는다.
1 Mechabellum 공식 https://store.steampowered.com/app/669330/Mechabellum/ : 병력모집/배치/자동전투 흐름. 적용: 배치판 중심, 후보선택과 실제배치 분리, 상세는 선택맥락에만.
2 The Last Spell 개발진 https://lastspell.com/new-features-1/ : 2021년 단계개편 설명. 다음적 진입방향을 준비중 보여주고 방어도구를 같은 준비단계에 모아 배치를 최종점검으로 연결. 현행 UI좌표를 증명하는 문서가 아님. 적용: 다음적/보스정보를 정비맥락에서 접근, 병력과장비간 상태연속성, 의무적다단계마법사 대신 바로 전환.
3 Backpack Battles 공식 https://store.steampowered.com/app/2427700/Backpack_Battles/ : 구매/모양이다른아이템배치/조합으로 자동전투 준비. 적용: 상점과보유격자를같이보고 직접이동, 같은셀척도, 선택할때정보노출. 타게임 PC화면 밀도·단축키·미술장식 복제안함.
우리게임 제안: 병력·배치/장비의 두 정비작업과 편집조작닫힌자동전투. 장비는 상점→영웅→창고3열. 같은내용을큰캡슐버튼으로모두강조하지않고 배경/본문/조작의역할구분. D3의차콜유리/얇은테두리/제한된강조색 유지. 큰설명판·상시완료문구·디버그ID 제거. 본문14/보조12/터치48이상/여백12 기준을유지하며정보노출을줄여해결.
셀크기·컬럼비율은도구배치검사로맞추되게임상의창고크기·출전정원·가격은새로확정하지않는다.
