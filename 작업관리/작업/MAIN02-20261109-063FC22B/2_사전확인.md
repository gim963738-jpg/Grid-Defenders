# 사전확인
실제 생성 전 작성. 담당 main02 / ui. 허용 변경은 신규 output 시안과 이 작업 기록만. 기존 게임·규정·아트 원본·다른 메인 기록 수정 제외.
적용 기준: AGENTS의 공통 모바일 크기 보존, main02 작업진행방법의 요청확인/필독/회신검수, 규정A v2.1.0의 실제 사용자 확인과 선택 미확정 구분, 메인운영규정 OPS-004의 공식 위임/영수증/read-pack/start, 팀장규정 v2.1.0의 원본 보존과 실제 제작 담당, 파일담당표의 UI 표시/입력 경계와 게임코드 제외, 조직 v2.0.0의 main02 요청 소유/ui 실행, 도메인 README/트리의 ui 외부역할 분류와 원본 위치 보존, UI규정의800×360·공통 터치/글자 기준. 작업연결의 requiredReadings를 이번 작업 본문으로 재확인. 작업대장상 UI 동시 제작 없음. Orca runtime UI 기존 채팅 done, worker-list에 UI 배정 없음. 기존 채팅/원본은 보존하고 동일 UI 작업 공간에 별도 감독 실행을 시작한다. 새 콘텐츠 원본이 아닌 독립 이미지 시안만 소유한다.
사용자 확인: 직전 이해문에 대한 진행. 단일 디자인 선택/합격/구현 승인은 없음.
검증: 16개 PNG 개별 확인, 방향·버튼 매핑·펼침 상태·한글 가독성·보스전 구분·공통 규격·참고 출처. 팀장 결과를 main02가 검토하고 사용자 판정 대기로 제출한다.
