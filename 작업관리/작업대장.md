# 공유 작업대장

OPS-001 초기 준비 이후 실제 제작 작업을 운영 중이다. 현재 작업 수·진행 상태는 아래 기준 데이터에서 조회하며, 초기 준비 당시의 0건 표기를 현재 상태로 사용하지 않는다.

작업의 기준 데이터는 `작업/<작업번호>/task.json`이다. 목록은 `python 작업관리/도구/작업대장.py list`로 확인한다. 이 문서에 별도 진행 상태를 중복 수기 입력하지 않는다.

GitHub 저장은 [사용자 요청 시 저장 규칙](저장운영규정.md)을 따른다. 사용자 저장 요청 때 작업 기록을 먼저 작성한 뒤 커밋·업로드하고 원격 해시를 확인한다. 요청 없는 자동 커밋·푸시는 하지 않는다.

메인별 시안·피드백·전문 지시와 송신 영수증을 작업번호로 연결한다. 규정만 준비한 상태를 제작 완료로, 발송 준비를 실제 발송으로 표시하지 않는다.


OPS-003: 팀장 조직·독립 테스터 세팅. 실제 상태와 전달 영수증은 `기록/OPS-003/`에 기록한다. 운영 안내는 콘텐츠 제작 작업과 구분한다.

OPS-004: 매 작업 하달 후 역할별 작업진행방법·적용 기준 필독 연결 완료. 설정/검사 근거는 `기록/OPS-004/`, 실제 착수 확인은 각 작업의 차수별 읽기확인 기록으로 구분한다. [작업대장 사용법](도구/사용법.md)을 따른다.
