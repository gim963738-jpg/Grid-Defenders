# OPS-005 기본 모델 설정

사용자 원문: “작업 끝나면 추론강도는 6.1sor 중간을 기본값으로 세팅해줘”. 모델 표기는 GPT-6.1 Sol(`gpt-6.1-sol`), 추론 강도는 중간(`medium`)으로 해석해 알렸다.

대상은 Codex의 모델·추론 기본값과 향후 프로젝트 지시의 실행 옵션이다. 게임 파일·이미지 생성 모델·외부 서비스·권한·실행 중인 작업 내용은 바꾸지 않는다. 기존 설정은 백업하고 이 두 값 이외에는 보존한다.

Orca 공식 CLI 도움말과 UI에서 새 에이전트 기본값 및 현재 대화의 선택이 구분됨을 확인했다. 설정 화면이 여러 번 대화 화면으로 되돌아와 GUI 저장은 아직 검증하지 못했다. UI 자동화의 성공 응답만으로 실제 저장 완료를 주장하지 않는다.

필독: main01 작업진행방법, 규정A v2.1.0, 메인운영규정 OPS-004, 팀장운영규정 v2.1.0 및 최신 사용자 요청. 이번 요청은 이미 허용된 운영 설정이며 제작 지시 승인을 추가 요구하지 않는다.
