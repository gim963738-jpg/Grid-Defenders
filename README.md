# Grid Defenders

OPS-003 (2026-11-09): 6개 팀장과 독립 테스터를 배치하고 신규 게임개발/테스터 채팅의 규정 읽기를 확인했다. 기존 채팅 직접 알림은 CLI 제한으로 대기하며 시작 지침·공유규정은 연결했다. [현재 조직과 준비 상태](작업관리/조직안내.md).

새 작업 방식: [메인3개·분야별 작업 공간 시작 안내](작업관리/README.md). 메인은 실제 시안 제작과 이해 확인·전문 지시·검수를 맡고, 분야별 담당은 기존 기준 정교화와 제작을 수행합니다.


병사·영웅을 배치하고 전투 중 장비를 구매·배열·조합하며 웨이브와 보스에 대응하는 모바일 지향 2D 디펜스 게임이다. 현재는 **로컬 웹 시제품**이며 상용 출시·앱 패키지·계정·결제가 완성된 상태는 아니다.

| 위치 | 용도 |
|---|---|
| 게임/src, 게임/tests | 실제 게임 코드와 검증 |
| 게임/public/assets | 게임에 배포하는 리소스 |
| 자료/아트원본 | 재가공 가능한 원본과 출처. 게임 빌드에 포함하지 않음 |
| 자료/기획원본 | 초기 HWP와 검색용 본문 |
| 자료/세계관, output/world | 설정 데이터·열람 페이지·현재 지도 |
| output/imagegen 등 | 제작·검토 산출물. 존재만으로 채택·전투 적용 완료를 뜻하지 않음 |
| 문서 | 규칙·기획·현재 정의·역사 작업 기록·사업 보고서 |

기준 브랜치는 main이다. 분리된 제작 워크트리는 원본을 보존하며 검증된 결과물만 단계적으로 통합한다.
