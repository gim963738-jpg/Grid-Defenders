캐릭터 그림체 참조 16장으로 확장

새 캐릭터에도 유지할 것은 선화·얼굴의 생략 방식·큰 형태·재질별 명암입니다. 머리색·의상·무기·체형은 새 캐릭터의 설정을 따릅니다.

선과 얼굴가늘고 선명한 선, 강한 윗눈꺼풀, 짧은 코와 입. 인물마다 눈매·턱·볼은 다르게.
큰 형태머리카락·천·장비의 큰 묶음을 먼저. 날카로운 끝과 길게 휘는 곡선을 함께 사용.
셀 명암과 재질읽히는 그림자 경계. 피부는 부드럽게, 천은 넓은 면, 금속은 날카로운 반사.
정체성 유지나이·체형·피부·복장·색을 보존. 백발·금장·장발·날개는 필수 조건이 아님.

누적 16종 비교 · 새 참조 7종

7종 표시

추가분에서 전신 판금·옅은 흰 겹옷·검붉은 장비·밝은 웃음·큰 원호와 날개의 층 분리를 보완했습니다. 기본 셀 경계는 유지하면서 재질별 대비를 조절합니다. 큰 장식과 효과는 새 캐릭터 설정에 있을 때만 적용합니다.

다음 캐릭터에 적용하는 순서

  1. 새 인물의 얼굴·나이·체형·피부·머리·복장·장비를 먼저 정의합니다.
  2. 화풍 참조 2~3장을 선택하고 각 이미지의 역할을 정합니다. 기존 캐릭터 이미지가 있다면 정체성 참조로 구분합니다.
  3. 고정 화풍 블록에 새 설정을 붙입니다. 색·복장·체형은 새 설정을 우선합니다.
  4. 생성 결과를 원본과 나란히 비교합니다. 얼굴, 선, 셀 명암, 재질, 손발·프레임을 점검합니다.

현재는 분석과 제작 준비 단계입니다. 모델 추가 학습이나 신규 생성 일치도 검증을 마친 상태는 아닙니다. 원본 JFIF 16장은 흰 배경이며 알파가 없습니다. 화면의 축소 미리보기는 분석용이고, 제작 참조에는 보관한 원본을 사용합니다.

그림체 기준 · 생성 프롬프트 · 입력 양식 · 원본 목록과 분석
분류·수치: 초기 9장(사용자 지정 남성 5종·여성 4종) + 추가 7장(성별 그룹 미지정) = 총 16장. A01·A06은 외형으로 식별합니다. 등신의 실측값이나 공식 캐릭터 설정을 추정한 보고서가 아닙니다.
