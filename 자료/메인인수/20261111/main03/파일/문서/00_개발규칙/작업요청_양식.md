# 작업 요청 양식

## 필수 — 간단한 작업은 이것만
- 제목:
- 원하는 내용: 현재 상태 → 변경 후 상태
- 대상: 화면·기능·파일·이미지 라벨 중 아는 것으로
- 완료 기준:

모르면 `확인 필요`라고 적는다. AI는 관련 자료를 읽고 꼭 필요한 누락만 질문한다.

## 선택 — 중요도 높음
- 유지할 부분 / 제외할 부분:
- 참고 자료:
- 정확한 수치·크기·문구:
- 예외 상황:
- 순서·우선순위:

## 선택 — 상세 제작
- 입력·실행 조건 / 처리 순서:
- 반복·동시 실행 처리:
- 저장·불러오기:
- 화면 크기별 동작:
- 기술 제한 / 수정 허용·금지 파일:
- 검증 방법:

선택 항목 공란은 기능 추가 허용이 아니다.

## AI 작업 전 승인 보고서
- 상위 큰기획 / 세부 문서:
- 작업 ID / 제목 / 전체 순서 중 위치:
- 현재 상태와 이번 목표:
- 어려운 설명 바로 아래 같은 의미의 쉬운 풀이:
- 생성·수정 파일별 변경 내용과 이유:
- 유지할 부분 / 제외 범위:
- 상세 동작·미정 사항:
- 완료 조건 / 검증 방법:
- 영향과 필요한 복구 방법:
- 승인 요청: 위 범위의 구현·검증·로컬 저장.

큰기획 → 단계 개요 → 세부 기능 문서 → 현재 작업 보고서 순으로 연결한다. 승인 범위가 달라지면 변경분을 다시 확인받는다.
