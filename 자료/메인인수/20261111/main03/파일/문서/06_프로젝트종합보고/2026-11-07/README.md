PDF는 로컬 서버 없이 읽을 수 있다. 외부 출처 링크는 유지하고 로컬 코드·원본 참조는 읽을 수 있는 표기로 남겼다. 코드·원본 파일로 이동하려면 저장소 안의 HTML/Markdown 링크를 이용한다. HTML의 인쇄/PDF 버튼으로도 출력할 수 있다.

발표 요약에는 발표 메모와 근거를 함께 넣었다. 외부 발표에서 작업 원본의 절대 경로나 내부 상태 JSON을 공개할 필요는 없다. 파일 수·검사 수·원본 통합 수를 출시 콘텐츠 수나 전체 진행률로 발표하지 않는다.

보고서출력.py는 표준 Python만으로 HTML을 재생성한다. PDF검증.py는 QA용 임시 폴더의 PyMuPDF를 사용한다. 게임의 package.json이나 잠금 파일에 보고서 제작 의존성을 추가하지 않았다. 검증 환경을 다시 만들 때는 임시 폴더에만 설치한다.

```powershell
python -m pip install --target "$env:TEMP/grid-defenders-pdf-qa" pymupdf
python 보고서출력.py
python PDF검증.py
```

게임 브라우저 검사는 Vite의 /tests/browser-check.html에서만 실행한다. 실제 게임 탭을 검사 화면으로 바꾸지 않는다. 물리 모바일 기기·전체 캠페인·4개 육안 연출 갤러리는 이번 자동 검증 범위 밖이다.
