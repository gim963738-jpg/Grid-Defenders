# 4_정의문서.md

기본탭 웨이브전, 사용자가 탭을 선택하면 실제 전장을 바꾸지 않고 미터기 내용만 교체. 보스진행중은실시간표시, 종료후는최근완료기록(웨이브·승패·시간·유닛피해/DPS·당시최고) 유지. 새 보스시험중 최근결과 버튼으로 이전완료기록 조회.
진행중 중단은 완료기록이없을때만 임시보관. 이미완료된승패기록은 새시험중단으로 덮어쓰지 않음. 새시험완료시최근완료기록교체. 스냅샷은 현재미터와분리되어 재시험초기화 영향을받지 않음. 게임리셋시기록삭제, 브라우저재시작간영구저장은미구현.
10단위보스진행중 웨이브탭은보스진입전 마지막일반웨이브결과를 표시. 다음일반웨이브가시작되면현재웨이브집계표시. 최근결과의최고DPS는기록당시값으로표기.
