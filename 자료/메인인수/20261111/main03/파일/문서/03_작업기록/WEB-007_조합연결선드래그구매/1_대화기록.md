# WEB-007 — 대화 기록

- 참고 이미지: 붙은 조합 재료의 노란 연결선, 짚거나 드래그한 재료와 상대의 파란 점선.
- 후속 확정: 노란색은 조합식이 맞는 아이템의 변이 붙었을 때, 파란색은 아이템을 짚었을 때.
- 조합 결과 이름·모양·능력치는 조합 전 표시하지 않음. 도감 UI는 별도 후속 작업 예정.
- 여러 조합 실행 시 횟수만큼 모루 소비.
- 상점 상품은 짚거나 드래그할 때 상대만 표시. 공용 가방에 내려놓으면 구매.
- 영웅 장비칸 오른쪽 회전·해제 버튼 대신 조합 영역.
- 유저의 후속 규칙으로 기존 보고 범위를 보완·승인하여 진행. 구현·검증 완료, 시각 피드백 대기.
