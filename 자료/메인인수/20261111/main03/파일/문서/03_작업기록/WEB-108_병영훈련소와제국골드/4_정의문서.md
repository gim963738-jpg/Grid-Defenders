# WEB-108 정의문서
TrainingProgress: gold/rank/levels(attack,health,normal,boss). 최초 제국 골드0·1등급(내부rank0)·모든레벨0. 비용100×(rank+1)×(level+1). 누적레벨rank×10+현재레벨, 공격/HP2%·일반/보스피해3%씩 가산. 승급 시4종레벨0으로 초기화하면서 누적효과 유지. 일반전 종료 보상=처치(웨이브+보스합산)×10+(현재웨이브-1)×25. 기존 GameRun.finish가 정상전에서1회만 성공하므로 중복/무한테스트보상 없음. 비용/효과/보상은 임시이며 training.ts의상수로 변경. 공격/HP는장비적용후동일배율, 피해는기존치명/타격배율/방어계수에대상계수1회 적용. 실제 보스(kind boss)에는보스피해, 친위대 및웨이브는일반피해. 저장키grid-defenders.training.v1. 브라우저별저장이며GitHub/계정클라우드동기화는미구현. 독립로비의영웅카드와전투시작은기존시안상태, 실제전투/훈련계산연결과구분.
