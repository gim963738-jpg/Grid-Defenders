# 작업 일지 — 2026-11-07
- 웨이브의 병사·영웅·임시 도형 캐릭터·몬스터를 하나의 발 위치 정렬 레이어로 묶었다. 화면 아래쪽의 발이 앞에 오고 같은 행에서는 기존 안정적인 순서를 유지한다.
- 몸체와 이름표·쿨타임, 몬스터의 체력/유형 라벨을 소속 표시 그룹에 함께 넣어 뒤쪽 정보가 앞 캐릭터 얼굴을 뚫고 나오지 않게 했다. 그림자는 모든 몸체 뒤, 공격선/명중 이펙트/피해 숫자는 앞에 유지한다.
- 유닛 이동 시 몸체가 현재 칸 그룹으로 이동한다. 몬스터 처치/초기화 시 해당 그룹 전체를 제거하고 동일 ID 재사용 시 새 표시를 만든다. 공유 원본 텍스처는 유지한다.
- 보스는 캐릭터 전용 z-index2 stacking context 안에서 발 높이로 정렬한다. 명중 SVG의 z-index4와 하단/공통 HUD는 기존 우선순위를 유지한다.
