# 발 기준 표시 순서
## 웨이브
`actor-depth-layer`는 `sortableChildren`을 사용하는 공통 표시 레이어다. 각 배치칸의 유닛 그룹은 `SLOTS[i].y + 12`, 몬스터 그룹은 `enemy.y + enemyRadius(enemy)`를 깊이 값으로 사용한다. 큰 값이 나중에 그려진다. 그룹은 추가 좌표 이동/축소/클리핑을 하지 않는다.

유닛 그룹은 몸체 Sprite 또는 임시 Graphics, 이름표, 쿨타임 막대/텍스트를 포함한다. 실제 이동 후 Sprite를 현재 칸 그룹으로 재배치한다. 몬스터 그룹은 몸체·체력바·유형 라벨을 포함하고 제거 시 함께 정리한다. 기존 독립 Sprite 및 공유 프레임 텍스처 캐시는 유지한다.
↳ 쉽게 말하면: 뒤에 선 캐릭터의 발이나 글자가 앞 캐릭터 얼굴 위로 올라오지 않도록 한 덩어리로 앞뒤를 정한다.

그림자는 공통 하단 Graphics에, 공격선은 `attack-effects`에 표시한다. 기존 화염/검격/명중 Sprite·피해 숫자는 캐릭터 레이어보다 앞에 유지한다. 캐릭터 원본 크기·발 pivot·정면 소환·8방향/60프레임 걷기·슬라임2~24프레임 재생은 그대로다.

## 보스
`.boss-actor-layer`는 절대 위치 inset0/z-index2/isolation:isolate/pointer-events:none이다. 캐릭터 자식의 z-index는 발 y좌표×100을 반올림한 값이다. 발 기준은 일반 유닛 y+32, 친위대 y+40.5, 보스 y+55.6875로 기존 표시 발 위치를 사용한다. 부모 안에서만 정렬하므로 큰 자식 z-index가 명중 효과 z-index4나 HUD를 덮지 않는다. 기존 전장 좌표·이미지 비율·CSS 캐릭터 영역은 유지한다.
