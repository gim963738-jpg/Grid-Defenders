# 원인과 범위
웨이브에서 병사는 영웅보다 뒤에 생성되는 별도 레이어에 있었고, 이름표도 모든 몸체 위에 그려졌다. 위쪽 병사가 아래쪽 영웅보다 앞에 표시되는 원인이다. 보스도 모든 캐릭터가 같은 z-index를 사용해 생성 순서에 영향을 받았다.

대상은 `게임/src/defenseView.ts`, `bossBattleView.ts`, `style.css`, 관련 표시 검사다. 발 기준 공통 정렬·이름표/체력/쿨타임 소속·그림자/명중 효과 순서를 수정한다. 모델 위치·사거리·피해·타격 시점·크기·PNG/프레임 원본·장비/소환/로비 연결은 변경하지 않는다.

AGENTS.md·스킬 구현 규약을 읽고 원본/기준점/피해 판정 분리 기준을 적용한다. 밀집 배치의 전장 이름표와 쿨타임은 소속 캐릭터와 함께 가려지도록 사용자의 겹침 수정 요청을 적용한다. 상세 능력치와 스킬 조작 UI는 그대로이며 피해 숫자/명중 효과는 상단 레이어를 유지한다.
