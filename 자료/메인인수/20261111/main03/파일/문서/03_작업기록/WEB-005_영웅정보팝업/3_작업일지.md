# WEB-005 — 작업 일지

- 날짜: 2026-11-02.
- 영웅 카드: 아이콘·이름·소환 상태 중심 약62px, 기존 공격력·공속 상시 줄 제거.
- 클릭 팝업: 어두운 바탕·금색 테두리·색상 아이콘·2열 수치. 최대 체력·공격력·방어력·공속·재생·골드 증가 표시.
- 배치 전은 기본값, 배치 후는 game.stats의 장비 적용값. 이미 배치된 카드로도 해당 영웅 선택 가능.
- 정원이 가득한 카드도 정보 클릭 가능하게 변경했으나 소환 대기 선택과 모델의3명 제한은 유지.
- 장비창 영웅 버튼·능력치 줄 제거. 현재 영웅 이름·번호를 제목으로 표시.
- 영웅 선택 정보 큰 카드 숨김, 병사 정보·강화·판매 유지.
- 팝업은 클릭한 카드/전장 영웅 근처에 배치하고 게임 영역·viewport 안으로 보정. 닫기/외부 클릭/Escape/탭 전환 지원.
- 전투 로직·수치 변경 없음.

## 검증
- TypeScript 검사·Vite 빌드 통과.
- 브라우저18개 확인: 배치 전 체력2000/공격40, 작은 카드 높이, 중복 DOM 없음, 닫기, 소환 선택 유지, 배치 후 자동 장비 연결, 제목 일치, 팝업 경계, 장비 적용 공격55, Escape·외부 클릭, 정원 가득 정보 열람·소환 제한, 기존 카드 연결, 중복 큰 정보 숨김·가로 넘침 없음.
- 추가 네이티브 카드 클릭으로 정보 열림 확인. 실제 카드 높이61.99px.
- 추가 회귀: 탭 전환 후 팝업 재등장 안 함, 병사 선택 정보와 강화·판매 버튼 유지.
- 320px 모바일 에뮬레이션에서 팝업300px·높이181px로 화면 안 표시. 콘솔 오류 없음.
- 배치 후 화면과 카드 발췌 캡처를 열어 확인. 별도 QA 탭은 종료하고 원래 게임 탭으로 복귀.
- 실제 휴대폰 하드웨어·최종 아트는 미검증.
