# WEB-014 — 대화 기록

- 요청: 테스트용 몬스터·네임드, 물리/마법 공격과 방어 구분, 일반/물리 방어/마법 방어 타입.
- 임시 피해: 물리→물리 방어형·마법→마법 방어형0.75배, 반대 계열/일반형1배. 유저 승인.
- 시험 무한 웨이브: 일정 시간 종료 시 다음 시작. 미처치 패배 대신 일반 몬스터를 정리.
- 현상금은3웨이브마다 기존 수동 버튼 기회 적립. 후속 답변으로 대기 최대3회, 활성1마리 유지.
- 네임드는5웨이브마다1마리. 살아남은 네임드와 현상금은 다음 웨이브에도 유지하도록 유저 지정.
- 보고한 시험값: 웨이브30초·일반10마리. 네임드·전투 수치는 임시 권한으로 설정.
- 구현·검증 완료, 유저 시각 피드백 대기.
