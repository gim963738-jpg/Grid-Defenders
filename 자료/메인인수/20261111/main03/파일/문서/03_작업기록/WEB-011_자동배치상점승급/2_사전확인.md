# WEB-011 — 사전 확인

- 대상: defenseConfig.ts(확률), defense.ts(자동 배치·상품 가격), main.ts(드롭 분기·승급·안내·잔상), index.html/style.css(UI) 및 관련 문서/화면.
- 경계 밖 이동·회전·조합 결과는 현재 방향을 유지하여 같은 격자에서 가장 가까운 비충돌 위치 탐색. 없으면 원상태/재료·재화 보존.
- 상점 판매 영역 우선, 공용 가방→전장 영웅 자동 장착 다음, 나머지는 격자 드롭. 격자 밖에는 가장 가까운 보이는 격자의 좌표로 보정.
- 상품 생성(초기·리롤·리셋) 시 각각20% 확률로50% 할인, 표기/버튼/드래그 구매 공통 가격. 판매는 실제 누적 구매 원가의 절반 버림.
- 자동 영웅 장착은 현재 방향, 빈칸 없으면 중앙에 ‘영웅 장비칸에 빈칸이 없습니다.’ 안내.
- 전장 선택 병사 아래 승급 버튼, 소환 패널 같은 종류 카드 아래 동일 병사 번호 승급 버튼. 기존 승급 비용/레벨 상한 유지.
- 제외: 종류 전체 동시 승급·새 등급 체계·자동 회전·오염 시스템·영구 저장.
- 완료 조건: 잔상/실제 보정 일치·거래가/환급 일치·빈칸 실패 보존·선택 병사만 승급·모바일·빌드 검증.
