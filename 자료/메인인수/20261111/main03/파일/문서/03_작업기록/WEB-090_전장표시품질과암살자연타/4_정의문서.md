# WEB-090 정의문서
평타 총3타35%씩·6/8/10프레임 완료 유지. 최초 공격 우선순위대로 최대3대상을 잡고, 부족하면 마지막 대상을 반복. 공격 도중 대상이 사망/사거리 이탈하면 현재 범위 안의 우선순위 목록으로 대체하며 빈 범위에는 허공 피해 없음. 스킬로 캔슬한 미래 타격을 보충하지 않음.
화질: 전장 물리 해상도 최소2배/최대3배, 선형 필터+밉맵 축소, 어두운 의상을 보존하는 외곽 연결 배경 제거.
검격: 원본 시트 경계의 잔광을 완만하게 투명화하고 칸 폭을 넘는 반투명 곡선 잔광으로 연장. 실제 피해 범위와 칸 배치는 그대로. 상세 치수는 구현 후 갱신.

WEB-089의 부족 타수 생략 규칙을 이 정의로 대체. 총타수·데미지 프레임·스킬 쿨타임은 변경하지 않음.
renderQuality: battleResolution은2~3 범위, smoothTexture는선형+밉맵. removeSheetBackground는외곽 연결 네이비 배경과 이펙트 빈 공간을 분리 처리하며 의상의 암부 보존. 이펙트 셀 외곽2px 테두리 잔상 제거, 평타 잔광 경계9px 완화.
assassinBasicTrail:3~11프레임 구간에만 표시, 최대 불투명도0.58·전방 도달46px(슬롯 가로간격64px). 잔광 레이어는유닛 뒤, 시트 본체 크기65px 유지. 사거리/실제 피해 범위는그대로이며 시각 확장만 적용. 캔슬 시 잔광 즉시 중단.
assassinBasicTarget: 최초 우선 대상이 살아있고 현재 사거리 안이면 해당 타격에 사용, 부족한 타수는 마지막 대상 반복. 해당 대상이 없으면 현재 범위 안 우선순위 목록의 해당 타수 또는 마지막 대상으로 대체. 범위 내 적0이면 피해 없음. 보스는 같은 프레임에 이미 누적된 치명 피해 대상도 제외.
