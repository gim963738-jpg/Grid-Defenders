# 정의문서
- unitDragImage(kind): 병사·영웅의 드래그용 이미지 HTML 반환. 이름 텍스트 없음. 실제 배치/이동 규칙 변경 없음.
- unit-drag-ghost: 소환·전장 이동 공통 이미지 미리보기 스타일.
- inventory-hero-stats: 현재 선택 영웅의 능력치 버튼. 영웅이 없으면 비활성화.
- heroInfo.anchor=inventory: 기존 hero-info 창을 장비 헤더의 버튼에 맞춰 배치. 실제 영웅 ID로 장비 반영 수치를 조회.
확정 범위: 사용자 요청 기능. 새 능력치·전투 효과 추가 없음. 최종 외관 확인 대기.
