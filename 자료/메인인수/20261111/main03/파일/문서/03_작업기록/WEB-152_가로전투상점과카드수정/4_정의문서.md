# 표시와 판정 계약
InventoryPick: 소유 장비ID 또는 상점 슬롯.
inventoryPlacement: 위치/회전/점유 셀/가능 여부/겹침 경고를 계산하는 읽기 전용 함수. commitInventoryPlacement는 최신 모델로 다시 확인한 뒤 기존 구매·장착·가방 이동 함수를 호출한다.
가방: 가로5칸, 최소3행. 미리보기 확장 행은 아이템 외곽 표시용이며 드래그 중 새 앵커가 되어 무한히 늘어나지 않는다. 놓으면 모델 행 수로 확정하며 스크롤 위치를 유지한다.
연결선: 기존 recipeForTypes/adjacentPairs/combinationPlan으로 판단. 파랑은 선택·누른·드래그 재료의 가능한 상대. 노랑은 같은 가방에서 변이 맞닿은 조합. 조합 버튼은 선택 영웅과 공용 가방 계획 및 모루 잔액을 사용한다.
그림과 판정: 아이템은 전체 그림/전체 도형으로 렌더하고 각 점유 칸마다 분할하지 않는다. 그림은 그 장비판 외곽을 넘지 않도록 제한한다. 유닛·스킬 레이어는 기존 렌더러를 유지한다.
카드:72×72, 간격2, 영웅 한 번에5장/총9개 표시. 이름은 하단18px, 선택은Y=-6px. 병사 클래스는20×20 엠블럼과 접근성 이름으로 제공. 초상화 표시명은 UI 표본이며 별도 로비 상태를 가져오지 않는다.
