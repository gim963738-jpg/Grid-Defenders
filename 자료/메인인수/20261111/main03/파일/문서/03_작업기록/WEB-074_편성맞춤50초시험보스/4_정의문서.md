# 정의문서
수동 시험 목표:50초 이상, 최대 화력 기준 약60초. 게임 시간 기준이므로5배속에서는50초가 실제 약10초. 자동 스킬을 사용하지 않거나 실제 치명타가 줄면 더 길어질 수 있음.
보정은 입장/재시험 시의 유닛 종류·레벨·배치·장비 적용 공격력/공속/체력/재생을 반영. 실제 게임의 재화·유닛·장비·DPS 최고 기록과 RNG를 바꾸지 않는 별도 인스턴스 사용.
기준 시뮬레이션: 자동 스킬ON, 치명타 가능 공격은 최대 치명타. 체력 배율 상한 탐색 후12회 이분 탐색, 목표60초. 공격 배율은 총 아군 체력×0.35/(기본 적 합산DPS196×60). 보스와 친위대에 함께 적용. HP는 올림, 공격은 내림하되 최소1.
기본12명 검증 예: 친위대 각HP15136/공격8, 보스HP50452/공격14, 기준 전투 약60.05초. 편성이 바뀌면 수치는 달라짐.
일반 BossBattle reset 기본 튜닝은HP/공격 배율1. 개발자 수동 시험에만 프로필 전달. 자동10웨이브 및 게임 리셋은 수동 프로필 해제.
