# WEB-094 작업일지
criticalAttack 공통 함수로 생성된 공격/시전 객체에 치명타 결과와 배율 적용 공격력 저장. 화염/검격/암살자 스킬 및 근접/원거리/암살자 지연 평타를 연결. 모든 영웅 기본 공격 포함. 히트는 저장된 값만 읽어 재판정/이중 배율 없음. 보스 피해 숫자 치명 강조, 영웅 능력치 필드 표시. 기존 피해 기대값 검사는 주입한 비치명 RNG로 고정해 불규칙 실패 제거. 빌드 통과, 기존468개 및 신규 치명타35개 검사 통과(503개). 신규 검사는 스킬3종×2모드의 시전당 RNG1회·모든 타격/피해비율과 영웅6종×2모드 평타를 검증. 별도 화면 캡처 검증은 미실시.
