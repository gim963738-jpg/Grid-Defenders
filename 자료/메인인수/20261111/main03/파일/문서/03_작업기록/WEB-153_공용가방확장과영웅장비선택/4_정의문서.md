# 현재 정의
- `BAG_GRID`: 가로 전투7×3, 기존 세로 전투5×3. 가득 차면 기존 규칙대로 아래 확장.
- 영웅 장비: 가로5×4(20칸), 표시 칸26×26px. 공용 가방도26×26px.
- 전장 영웅 클릭: 기존 선택 처리 후 가로 모드에서 `landscape-hero-selected` 이벤트에 영웅ID 전달. UI는 상점을 열고 같은 영웅 장비칸을 강조한다.
- `pendingHeroFocus`: 숨김 상태의 패널이 열린 뒤 해당 영웅 장비칸으로 스크롤. 이미 열린 상점에서는 선택만 즉시 갱신.
- 클릭 전파 보호는 방금 선택된 영웅을 누른 경우에만 적용하며 빈 전장을 누르면 원래처럼 닫힌다.

26px/패널 높이는 현재800×360 가로 화면에 맞춘 표시값이다. 구매·판매·장착·회전·조합은 기존 모델을 사용한다. 구현·관련 검증 완료, 사용자 최종 확인 대기.
