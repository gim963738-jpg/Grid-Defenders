# 노란 슬라임 오른쪽 재생 범위
`SLIME_RIPPLE.count=30`은 원본 시트의 프레임 수다. `firstFrame=2`, `lastFrame=24`는1부터 세는 재생 범위다.

오른쪽으로 이동 중인 노랑의 원본0기준 인덱스는 `1 + floor(game.elapsed × 30) % 23`이다. 구현은 부동소수점 경계 안정용 작은 오차를 더한다. 순서는2→3→…→24→2이며1번과25~30번은 표시하지 않는다.

기존30fps와 게임 시간 사용을 유지해 배속/일시정지에 함께 반응한다. 범위가 줄어 반복 주기는1초에서23/30초로 바뀐다. 원본 셀256×256/6열5행·발 기준점(128,228)·표시 폭28·피해 판정은 그대로다. WEB-169의 전체30장 반복 정의를 이번 요청으로 대체한다.
