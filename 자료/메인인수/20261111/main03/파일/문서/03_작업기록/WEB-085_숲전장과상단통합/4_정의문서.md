# 정의문서
- DEFENSE_FIELD: 전체 렌더390×430,전투 원점 y=100. RULES의 전투 로컬 크기390×330과 구분.
- fieldToScreen/screenToField: 화면 확대/축소·스크롤 위치를 포함한 전투 좌표 왕복 변환. 상단 숲 좌표는 배치 영역 바깥으로 판정.
- forest-clearing-v1.png: 내장 imagegen으로 만든 숲 원화. 상단과 전투 보드에 걸친 단일 배경. 제공 캐릭터 및 스킬 시트는 수정하지 않음.
- PATH: 둥근 흙길의 몬스터 순환 중심선. 모서리 반경28, 여러 직선 구간 보간. pathPoint는 PATH 길이에 따라 반복.
- 배치 표시: 빈 위치를 가리킬 때만 원형 바닥 빛/점 표시, 선택 유닛에는 바닥 타원과 기존 사거리 표시.
- wave-info: 배경 구분 카드 없이 숲 상단에 겹치는 정보 UI. 배속/일시정지는 클릭 가능, 나머지 정보 바탕은 포인터 통과.
기획 상태: 사용자 요청 디자인/구조 구현 완료. 최종 외관 승인 대기.
