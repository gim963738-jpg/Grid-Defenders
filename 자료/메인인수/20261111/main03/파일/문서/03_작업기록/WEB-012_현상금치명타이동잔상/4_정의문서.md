# WEB-012 — 정의

## 현상금
- normalKills: 일반 몬스터 처치 누적. kills는 현상금 포함 전체 처치.
- bountySummons: 사용한 현상금 소환 횟수.
- bountyCredits(): floor(normalKills/50)-bountySummons. 대기 기회 누적, 자동 소환하지 않음.
- Enemy.bounty: 현상금 구분. 일반 몬스터 최대30과 별도로1마리, 황금색·큰 몸·뿔 표현.
- summonBounty: 기회1회 소비 후 기존 경로 시작점에 즉시 생성. 살아 있는 현상금이 있으면 소비 없이 거부.
- 임시 HP1600, 이동32 논리px/초, 모루1·기본100G. 골드에 기존 영웅 장착 골드 보너스 적용, 모루는 고정.
- bounty-summon: 전장 논리 좌측81.5%·상단14.5% 기준 오른쪽 위 버튼. 기회가 없으면 숨김, 기회가 남아도 활성 현상금이 있으면 비활성.

## 치명타·피해 숫자
- RULES.soldierCritChance=0.1, critMultiplier=1.5. 병사3종에만 적용. 공격마다1회 추첨, 범위 안 대상끼리 같은 판정 공유.
- 피해=기본 공격값×치명 배율 반올림. 기록의 attack은 이 공격값, damage는 실제 체력 감소량.
- DamageNumber: 적 타격 위치·실제 감소량·치명 여부·수명0.75초. 실제 시간 기준으로 표시하여 배속에서도 읽을 수 있음. 최대80개.
- 일반 숫자는 밝은14px, 치명은 노란18px·‘치명’ 표시. 소멸하며 이동. 전장 위쪽은 아래 방향으로 흘려 가장자리 겹침 완화.
- 텍스트 풀을 재사용, 장면 종료 시 함께 정리. 게임 리셋으로 데이터와 표시 초기화.

## 병사 이동 잔상
- view.draw의 movement: 드래그 개체ID·마우스 아래 목표 slot. 실제 모델 좌표는 놓기 전까지 유지.
- 이동 병사가 대상 칸 위에 있을 때 반투명 몸체·머리·칸 테두리. 자기 자리/전장 밖/드래그 종료는 표시하지 않음.
- 점유 칸도 자리교체 예상 위치 표시. 실제 이동·교체 규칙은 기존 유지. 영웅 이동 잔상은 이번 요청 범위 제외.
