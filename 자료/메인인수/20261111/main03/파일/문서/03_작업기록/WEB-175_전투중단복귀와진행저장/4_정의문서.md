# 전투 중단·복귀
진행 중 페이지 숨김/이탈/동결 시 전투를 일시정지하고 임시 드래그를 취소한다. 돌아와도 자동 재개하지 않는다. 실행 중 이탈했다면 전투 재개/정지 유지 안내창을 표시한다. 기존 수동 정지는 그대로 유지한다. 장면 전환이나 로비 복귀 확인창이 열려 있으면 안내창을 뒤로 미룬다.

자동 진입 URL의 normal/infinite-test에서 저장된 전투가 있으면 정지 복원 후 이어하기/새 전투를 제공한다. 계속하기는 같은 runId를 사용한다. 새 전투, 명시적인 중도 로비 복귀, 정상 종료는 해당 저장을 지운다. 로비 확인 취소는 지우지 않는다. 기존 개발용 battle=manual은 자동 복원하지 않는다.

# 저장
브라우저 localStorage 키: grid-defenders.battle-save.v1.{landscape|portrait}.{normal|infinite-test}. 입력 완료, 장면 전환 완료, 2초 주기, 페이지 이탈에 저장한다. 비정상 강제 종료는 마지막 성공한 체크포인트부터 복원한다. 서버/계정 저장이나 여러 탭 동시 실행의 저장 병합은 포함하지 않는다.

재화·상품·장비 좌표/회전/소유자·배치 유닛·적·웨이브·보스 체력/좌표/시간·쿨타임·공격 진행·피해 집계·ID 카운터·전투 모드/ID를 복원한다. 벽시계 경과 시간은 시뮬레이션에 반영하지 않는다. 일시적인 선택/드래그/툴팁은 초기화한다. 모델 메서드와 RNG/훈련 콜백은 보존한다. 공격 원본은 기존 모델과 같이 스냅샷이며 실시간 유닛 참조로 바꾸지 않는다.

버전/레이아웃/모드/데이터 형식이 잘못되면 복원을 거절하고 새 전투를 시작한다. 저장 실패 시 현재 메모리 전투는 계속 사용할 수 있다. 개발용 보스 프로필은 실제 적용된 healthScale/attackScale만 저장한다.

# 보상
training 저장의 battleRewards에 runId와 지급액을 함께 보관한다. 재화와 영수증은 한 번의 setItem으로 저장한다. 같은 ID에는 다시 지급하지 않으며 읽기/쓰기 실패 시 완료 처리하지 않고 정지·재시도를 제공한다. 캠프 기록에 이미 끝난 ID가 있으면 남은 체크포인트도 재생하지 않는다. 기존 보상 공식은 유지한다.

# 복귀창
양 전투 화면이 같은 대화창을 사용한다. 최대400px/좌우12px 이상, 제목20px·본문14px·버튼48px 이상·간격8px. 모달이므로 기존 전장 배치를 밀지 않는다. 이번 요청에 따라 전체 모바일 배치/크기 조절은 별도로 보류한다.
