# WEB-004 — 작업 일지

- 날짜: 2026-11-02.
- 이동: 유닛 드래그로 빈 칸 이동, 모든 조합 자리교체. 위치 외 상태 불변, 비용 없음.
- 범위: 영웅 선택 원 내부0.16·테두리2px/0.95. 실제 사거리 변경 없음.
- 메뉴: 전장 영웅 단순 클릭 시 해당 장비창 자동 선택. 이동 드래그는 자동 전환과 구분.
- 공격: 보병90도 부채꼴·기존 사거리130, 마법병 주 대상 중심 반경48의 다수 타격. 동일 영역 데이터로 판정·이펙트.
- 가방:5열 격자·자동 빈 공간 배치·행 확장, 아이템 위치/방향 공유. 장착·해제·가방 이동에서 충돌 검증.
- 회전: 두 가방 더블클릭/두 번 탭 즉시90도, 회전 버튼도 동일 동작. 실패 상태 유지.
- 드래그: 블록의 집은 칸 오프셋 유지, 포인터 취소·영역 밖 드롭에서 원상 유지.

## 검증
- TypeScript 검사·Vite 빌드 통과.
- 모델23개: 영웅/병사의 빈 칸 이동·모든 교체 조합·장비/강화/대기시간/골드 보존·잘못된 위치 취소.
- 두 가방 회전·장착·경계/겹침 실패 원자성·해제 자동 배치 확인.
- 장비52개에서 공용28행 확장 및 칸 중복 없음.
- 보병 이펙트 내2명 처치·보상2회, 영역 밖 미피해. 마법병 반경 경계 포함3명 타격, 경계 밖 미피해. 궁병 단일 유지, 같은 적 중복 보상 방지.
- 실제 UI: 영웅 클릭 자동 연결, 병사 이동·혼합/영웅 교체, 상점 유지, 장착·더블클릭 회전 확인.
- Orca 네이티브 dblclick 입력으로 영웅칸 가로2칸→세로2칸, 공용 가방 세로2칸→가로2칸 확인. 합성 연속 클릭·두 번 탭도 확인.
- 터치 PointerEvent로 이동 및 장착 해제 드래그, 집은 두 번째 칸 오프셋 보존·공격 수치 원복·잔여 드래그 표시0.
- 별도 QA 탭320px 폭에서 터치 이동·두 번 탭·가로 넘침 없음 확인. 원래 게임 탭의 고정 크기 설정은 변경하지 않음.
- 새 QA 탭 콘솔 오류 없음. 실제 휴대폰 하드웨어 미검증.
- 영웅 범위·격자 가방 캡처를 열어 확인. 가방 이미지는 설명용 영역 발췌. QA 탭은 종료 후 원래 게임 탭 복귀.
