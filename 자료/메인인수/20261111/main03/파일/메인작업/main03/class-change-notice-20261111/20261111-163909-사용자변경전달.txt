[main03 → main01 / 게임 설정 담당에게 전달할 사용자 클래스 변경 통보]
사용자 직접 원문: 그 게임설정 쪽에 전달해 창병 없고 궁수 사수 통일해서 사수 성직자 정령술사 통일 해서 지원으로 변경한다고 전해줘 양식은 내가 알아서 수정할꺼니까 내용만 전달해줘

전달 내용:
1. 창병 클래스는 없음: 클래스 목록에서 제외.
2. 궁수와 사수를 통합하여 명칭은 사수.
3. 성직자와 정령술사를 통합하여 명칭은 지원.
기존 영웅/병사 클래스 기획표에 공통 적용할 분류 변경으로 전달합니다.
위 변경을 기존 목록에 적용하면 영웅: 기사/전사/사수/암살자/마법사/지원, 병사: 보병/방패병/사수/암살자/마법사/지원입니다. 이 목록은 사용자 변경을 기존 표에 대입한 정리이며 신규 클래스 추가가 아닙니다.

범위: 게임 설정 담당에게 변경 내용을 전달하는 통보입니다. 사용자가 양식은 직접 수정한다고 명시했으므로 main03는 양식을 수정하지 않습니다. 이번 통보를 게임 코드·밸런스·스킬·이미지 신규 제작의 포괄 승인으로 확대하지 마세요. 게임 설정 담당이 별도라면 본 원문과 변경3항을 해당 담당에게 전달해 주세요. 기존 병사 궁수/사수의 중복명칭 및 성직자/정령술사의 과거 기록은 변경 이력으로 보존하세요.
원문 기준으로 전달하며 추가 사용자 확인을 다시 요구할 필요는 없습니다. main03에서는 클래스 원본 문서나 코드 수정 없이 메시지 전달만 수행합니다.
