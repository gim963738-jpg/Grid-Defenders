# 사용자 직접 지시: 2.6 이미지 사용 제한
사용자 원문: 추가로 2.6 이미지는 내가 허가해서 진행하는게 아니면 사용할수없다고 전달해줘
적용: 사용자가 2.6 이미지 사용을 명시적으로 허가한 작업에서만 사용 가능. 일반적인 제작 진행 승인/기존 사용 이력/담당 판단을 별도 사용 허가로 간주하지 않는다. 허가 없이 자동 대체 모델로 선택하지 않는다.
이번 전달은 제한 공지이며 금발 전사 모션 제작은 아직 진행 승인 대기. 신규 제작·API 호출·기존 작업 수정 하달이 아니다. 기존 원본과 타 작업은 보존한다.
캐릭터 팀장 공간 terminal list 결과 현재 수신 가능한 터미널 없음. 총괄 main01 공식 run으로 제한 원문 및 전문 담당 전파 요청을 전달한다. 전달과 각 담당 읽기 확인은 구분한다.
