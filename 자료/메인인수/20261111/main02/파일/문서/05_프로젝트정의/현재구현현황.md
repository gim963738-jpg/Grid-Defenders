# Grid Defenders — 현재 구현 현황

기준일: 2026-11-07. 검토 대상은 기준 프로젝트의 `게임/src`, `게임/tests`, 설정 및 WEB-178까지의 작업 기록이다. 이번 정리 이후의 변경은 해당 작업 기록과 코드를 다시 확인한다. 사업 판단·전체 작업 영역·자원 통합 내역은 [프로젝트 종합 보고서](../06_프로젝트종합보고/2026-11-07/프로젝트종합보고서.md)에 정리한다.

이 문서는 초기 기획과 현재 구현을 구분하기 위한 현황표다. **‘완료’는 명시한 시제품 기능의 구현 범위에 한정하며, 정식 출시·밸런스 확정·모바일 전체 기기 검증을 뜻하지 않는다.** 전체 진행률은 확정된 출시 범위와 분모가 없어 산정하지 않는다. 과거 문서의 ‘현재’, ‘최신’, ‘미구현’은 그 문서 작성 당시의 상태다.

2026-11-07 정리에서는 기존 테스트를 재사용하는 공통 실행 명령을 추가했다. `게임` 폴더에서 `npm test`는 소스·테스트 전체 타입 검사 후 실제 Vite 모듈 로딩으로 세로·가로 모델을 분리해 검사한다. **27개 모델 테스트 파일, 두 화면 조건에서 53회 실행, 1,242개 확인 항목이 통과했다.** 세로 전용 배치 검사 1개는 가로에서 적용 대상이 아님을 출력한다.

## 다음 작업의 목적과 완료 기준

1. **가로 전투 진형 기준 정리(P0):** 20칸 웨이브 배치를 보스전의 전열·중열·후열과 일관되게 연결한다. 조작 방식·간격 범위·적용 시점을 먼저 정하고, 저장·재진입 후 동일 진형이 유지되며 유닛이 겹치거나 필드 밖에 놓이지 않을 때 완료로 본다. 현재 진형 버튼을 편집 완료로 계산하지 않는다.
2. **모바일 조작·중단 복귀 검증(P0):** 확정된 배치를 공통 모바일 규격에 맞춰 점검한다. 대표 가로 기기에서 구매·배치·회전·조합·일시정지·페이지 이탈·복귀·보상 중복 방지를 직접 검증하고 재현 가능한 결함을 정리한다.
3. **첫 플레이와 완주 흐름(P1):** 강제 튜토리얼과 40웨이브 최종 승리 조건을 각기 설계·구현한다. 새 사용자가 기본 조작을 완료할 수 있고 일반 모드에서 패배/완주 모두 결과·보상·로비로 이어질 때 완료로 본다.
4. **영웅·성장 데이터 통합(P1):** 로비 시안과 전투 모델의 영웅 식별자·소유·성장·장비를 일치시킨다. 같은 영웅의 표시와 실제 능력치가 출전·귀환 후에도 일치할 때 완료로 본다. 힐러의 새 역할과 스킬은 콘셉트 확정까지 보류한다.
5. **출시·사업 범위 결정(P2):** 앱 포장, 수익 모델, 계정·서버 필요 범위, 최종 콘텐츠 분량을 결정한다. 기능 목록·비용 전제·검증 기준이 문서화되기 전에는 출시 일정이나 사업 전체 진행률을 확정하지 않는다.

진행 중인 다른 작업 영역의 원본은 유지한다. 여기의 ‘완료’나 작업명만으로 다른 브랜치 전체를 병합·삭제하지 않으며, 통합된 자료와 연결을 기다리는 자료의 세부 구분은 종합 보고서의 작업별 정리표를 따른다.
