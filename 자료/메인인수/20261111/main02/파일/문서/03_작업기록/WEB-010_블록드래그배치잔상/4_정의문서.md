# WEB-010 — 정의

- gear-drag-layer: 화면 고정·입력 비차단·화면 밖 클립 레이어.
- gear-drag-ghost: 회전된 실제 블록을 대상 격자 셀 크기로 표시. 이름 카드 없음, 불투명도0.8.
- drop-preview: 실제 배치 예상 칸의 반투명 잔상, 불투명도0.45. 원본 아이템은 드래그 중 변경하지 않음.
- drop-warning/drag-warning: 가방 배치 불가 또는 영웅 장착 비활성 예상 위치의 붉은 표시. 실제 영웅 겹침 허용 규칙 유지.
- updateGearDrag: 매 이동·스크롤·리사이즈 시 원래 잔상을 지우고 새 칸에 표시. 놓기·취소·blur·HMR 시 제거.
- purchasePosition: 상점 상품의 구매 후 가방 위치를 계산하는 읽기 전용 함수. 구매와 미리보기에서 공유.
- canPlace: 기존 배치 검사 공개, 상태 변경 없음. 구매 가격 부족도 잔상 경고에 포함.
- 유닛(병사·영웅) 드래그 표시는 이번 대상이 아님.
