# WEB-010 — 사전 확인

- 대상: main.ts 드래그 시각화·정리, defense.ts 읽기 전용 배치 판정/구매 위치 공유, style.css 반투명 블록·잔상, index.html 드래그 레이어, 관련 문서.
- 실제 모양·색·회전 방향과 집은 칸을 반영한 블록이 따라옴. 대상 칸에는 반투명 배치 잔상.
- 배치 불가/영웅 비활성 위치는 붉게 표시. 상점 구매 시 기존 빈 칸 대체 배치 위치도 반영.
- 제외: 아이템 배치·회전·구매·겹침 규칙 변경, 유닛 드래그 외형 변경.
- 완료 조건: 잔상과 실제 결과 일치, 회전/집은 칸 반영, 놓기/취소/창 전환 잔상 제거, 모바일·빌드 확인.
