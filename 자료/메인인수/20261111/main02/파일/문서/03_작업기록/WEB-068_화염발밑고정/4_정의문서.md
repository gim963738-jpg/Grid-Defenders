# 정의문서
투사체는 비행 중 목표 몸 중앙(tx,ty)을 추적. 도착 후 좌표가 고정되어 마법진/화염은 적을 따라가지 않는다. 피해 범위는 고정된 원래 몸 중앙을 사용. 범위를 벗어난 적은 후속 범위 피해를 받지 않음.
표시 위치만 발밑으로 분리: 일반 +8, 현상금 +12, 네임드 +14. 웨이브의 실제 사각형 크기와 같은 enemyRadius 사용. 보스 친위대 +40.5, 시험 보스 +55.6875는 현재 캐릭터 사각형의 하단 기준.
각 화염 프레임의 마법진 중심을 개별 측정해 한 좌표에 정렬. 화염 단계는 원본 픽셀당 0.75 배율을 유지해 칸 크기에 따른 움직임을 방지. 투사체·피해 타이밍과 3회 피해·4초 쿨타임은 유지.
