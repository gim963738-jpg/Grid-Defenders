# 정면 소환 정의
방향0은 `idle-8.png`의 첫 정면 전신 컷이다. `blondFrame()`의 기본값도0이다.

웨이브 `Unit.facing`은 금발 전사에만 소환 시0으로 생성하는 선택적 표시 값이다. 실제 일반 공격의 유효 대상이 결정됐을 때8방향을 기록한다. 표시 코드는 `blondFrame(unit.facing ?? 0)`을 사용하고 주변 적을 탐색해 소환 방향을 바꾸지 않는다. 첫 공격 이후에는 마지막 공격 방향을 유지한다. 피해/쿨타임/사거리 계산은 그대로다.

보스 `BossActor.walk.direction`의 초기값과 초기화 값은0이다. 실제 이동량이 양수이거나 평타가 시작되는 순간에만 방향을 갱신한다. 정지/첫 행동 대기 중에는 초기 정면을 유지하며 오른쪽 이동 때 기존60프레임과 게임 시간 연동을 사용한다. WEB-170의 초기 오른쪽 방향/주변 대상 추적 표시를 이번 요청으로 대체한다.
