# 정의문서
대상 melee 검 영웅 평타. 패턴은 유닛 ID별로 ⑤ 대각베기 → ④ 반대 대각베기 → ③ 수평베기를 반복. 한 평타에 세 베기를 동시 재생하지 않음. C ①·②와 B의 X자 효과는 사용하지 않음.
검빛은 A 8프레임의 검 주변 밝은 영역만 기존 전장 캐릭터에 표시하며 전체 인물 자세를 교체하지 않음.
공격당 전체 모션 시간 min(0.5초, 공격 주기×0.9). 검빛은 모션의 앞 80%, 피해는 모션 30% 지점(기본 0.15초), 타격 시트 10프레임은 남은 70%에 재생. 평타마다 기존 공격력의 물리 피해 1회, 프레임 수로 피해가 늘어나지 않음.
타격 직전까지 목표 중심을 따라가고 타격 후 베기 위치 고정. 목표가 이미 사망했으면 추가 타격 없음. 공격자가 제거/사망하면 미발동 평타 취소. 웨이브 전환 시 미완료 평타 삭제, 번호는 같은 영웅 기준 유지. 게임 초기화/보스 재시작 시 번호도 초기화.
출처: 사용자 첨부 시트. 이미지 생성 없이 원본 프레임을 코드에서 분할.
