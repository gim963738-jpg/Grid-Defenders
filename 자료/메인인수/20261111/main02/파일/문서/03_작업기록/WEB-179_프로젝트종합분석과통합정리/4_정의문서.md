# WEB-179 관리·검증 기준

- 기준 프로젝트: main의 실제 개발 구조. 브랜치 이름만으로 전체 작업 완료를 판단하지 않는다.
- 통합 완료: 선택한 파일의 출처·독립성·검증·참조 수정이 끝난 상태. 원래 브랜치의 나머지 작업 완료를 의미하지 않는다.
- 진행 중·통합 대기: 원본 유지, 선행 작업과 검증 조건 기록. ‘작업 완료’ UI 표시·최신 커밋만으로 병합하지 않는다.
- 아트 보관: 자료/아트원본은 입력/출처/검증, 게임/public/assets는 배포 결과다.
- 수치 구분: public/assets51,182,826B→48,924,519B는 정적 파일 크기 합계. FPS·로딩 시간·총 저장소 크기의 감소가 아니다.
- 검사 구분: npm test의 모델27파일/53회/1242항목과 별도 브라우저11개/359항목을 구분한다.4개 육안 갤러리 및 실제 모바일 기기 검사는 이번에 실행하지 않았다.
- 세계관: 설정v1.12·지도v24. 기존 캐릭터 소속은 보류를 유지한다.
- 사업: 목표 사용자·수익 모델·인력·기간은 근거 있는 사실과 제안/전제를 표시한다. 확정 출시분모가 없어 전체 진행률을 만들지 않는다.
