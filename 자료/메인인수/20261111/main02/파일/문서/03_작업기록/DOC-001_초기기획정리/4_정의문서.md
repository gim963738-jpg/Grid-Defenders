# DOC-001 — 정의 변경

- 현재 정의의 진입점: [정의 목록](../../05_프로젝트정의/정의목록.md).
- 장비칸: 임시 5열×6행, 최종 UI 크기와 다름.
- 임시 영웅: 탱커·근접·원거리·힐러 4종 후보. 기본 수치는 시험용.
- 아이템: PDF 20종을 I01~I20로 식별. 조합식 미정.
- 모양 좌표: 아이템 내부 칸 좌표, 화면 위치 아님.
- 임시 이미지: 적용 허용, DOC-001에서는 생성·적용하지 않음.
- 오염: 낮은 구매가 대신 옵션 불이익, 정화는 정상 복구 방향.
- 모드별 스킬: 같은 스킬의 일반전·보스전 효과 분리.
- 별도 제단·수동 회복 구슬: 보류, 현재 제외.

문서 작성과 내용의 유저 최종 확정은 구분한다.
