# WEB-006 — 정의

- RECIPES: 입력 아이템ID2개와 출력ID를 갖는 조합4종. 입력 순서 무관, 서로 다른 실제 아이템2개 필요.
- anvils: 모루 수량. 초기0, 개발 버튼+10, 조합1회당1 소모. 일반 전투 획득은 아직 없음.
- Gear.order: 마지막 장착·이동·회전 순서. 오래된 배치부터 판정.
- Gear.costBasis: 구매품 가격 또는 조합 재료의 누적 구매가. 판매 환급은 절반 버림.
- gearStates: 영웅별 활성 상태. 경계 밖 또는 앞서 놓인 블록과 겹치면 비활성. 비활성 블록도 실제 점유 칸은 유지.
↳ 쉽게 말하면: 빨간 장비도 칸에 남아 있으므로 다른 장비와 겹칠 수 있습니다. 목록의 ‘가방으로’로 회수할 수 있습니다.
- 비활성 장비: 공격·공속·체력·방어·재생·골드 효과 모두 제외. 겹침/경계 문제가 해소되면 자동 활성.
- 영웅 장비칸만 겹침·경계 밖 허용. 공용 가방은 기존 겹침·경계 제한 유지.
- 병사 정보: 미배치는 기본 수치, 배치 후는 강화 적용 수치. 기존 강화·판매 조작 유지.
- 개발 리셋: 전투·유닛·장비·골드·모루·상점·기록·선택·배속 초기화. 파일이나 Git 이력 삭제 아님.
- UI F: 오른쪽 개발 도구·조합 패널. 좁은 화면에서는 게임 아래. 최종 게임 화면이 아닌 임시 도구.
