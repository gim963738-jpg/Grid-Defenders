# 현재 보스 화면
가로 보스 화면은800×360. 전장만x4/y8/608×342로 표시하고 오른쪽은 비워둔다. 아군4열8행의 각 칸과 실제20명까지의 배치가 일치한다. 배우와 효과는 기존1000×562.5 월드에서 계산하고 같은 비율로 표시한다.

일시정지·배속·설정 준비중·홈의 순서는 웨이브와 같다. 버튼40×32px/간격4px/오른쪽4px/위8px이며 동일 노드와 기존 API를 공유한다. 스킬/상태 패널을 숨겨도 기존 전투·자동 스킬·시간 제한·보상 계산은 변경하지 않는다. 화면에는 이번 요청 범위인 필드와 상단 공통 버튼만 표시한다. 개발자 도구는 종전대로 프레임 아래에 있다.

구현·관련 검증 완료. 이후 보스 UI 추가는 별도 사용자 요청 범위다.
