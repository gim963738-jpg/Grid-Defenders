# 대상과 완료 조건
대상: landscape-entry.ts/CSS, bossBattleView.ts, 새 bossSkillIcons.ts 및 관련 문서.
800×360 전체 필드 위에서 영웅3명과 지휘자·상단 버튼이 겹치지 않아야 한다. 기존 수동/자동 발동과 정지/쿨타임/사거리/사망 상태를 정확히 표시하고 웨이브 복귀와 기존 세로 화면을 유지해야 한다.
스킬 구현 규약을 확인했다. 원래 버튼/이벤트와 전투 모델을 사용하며 피해·타수·판정·효과 프레임은 변경하지 않는다. 활성 스킬 그림은 기존 검격/화염/암살자 아이콘 영역을 재사용하고 평타·지휘 문양은 SVG로 구현한다.
