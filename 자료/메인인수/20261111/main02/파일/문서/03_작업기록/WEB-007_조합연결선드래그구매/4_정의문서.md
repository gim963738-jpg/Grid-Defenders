# WEB-007 — 정의

## 접촉과 안내
- recipeForTypes: 아이템 종류2개의 기존 조합식 검사, 순서 무관.
- touching: 같은 소유자 격자에서 회전된 실제 블록의 변이 맞닿고 겹침·경계 문제가 없는 쌍.
- adjacentPairs: 접촉과 조합식을 만족하는 모든 후보. 모루가 없어도 노란 선 유지.
- combinationPlan: 현재 영웅→공용 가방, 생성 번호 순으로 후보를 선택하고 사용한 아이템은 제외. 후보 선 개수와 실행 횟수는 재료 공유 시 다를 수 있음.
↳ 쉽게 말하면: 철검 하나가 두 재료와 연결되어도 그 철검을 두 번 쓰지는 않습니다. 버튼에 실제 실행 횟수가 표시됩니다.
- 노란 실선: 같은 격자에서 붙은 유효 조합 쌍.
- 파란 점선: 짚은/선택한/드래그 중인 아이템과 조합식이 맞는 상대. 접촉·모루 여부와 별개인 안내. 상대 블록에 파란 테두리.
- combination-links: 입력을 가로채지 않는 화면 고정 SVG. 보이는 격자·스크롤 영역의 칸 중심을 연결, 스크롤/화면 크기 변경 시 다시 계산.

## 조합과 구매
- combineMany: 전체 후보·재료 중복·접촉·모루를 먼저 검사한 뒤 일괄 실행. 부족하면 부분 소비 없이 실패.
- 모루 비용=실행 쌍 개수. 재료2개씩 소비. 결과는 가방 자동 배치, 누적 구매가 합산·판매 절반 버림 유지.
- 결과 미리보기·조합식 목록은 현재 UI에서 제거. 실제 조합 후 가방의 블록과 상세 정보·로그에서 결과 확인. 도감은 미구현.
- buy(position): 기존 버튼 구매 유지. 상점 상품을 공용 가방에 드롭해도 구매하며 골드 차감은 성공 시 한 번만 수행. 막힌 칸·경계는 가방 빈 칸 자동 배치.
- 겹침 장비 비활성 규칙은 유지. 서로 겹친 두 재료는 접촉 쌍에 포함하지 않음.
- 오른쪽 90도 회전·가방으로 해제 버튼 제거. 더블클릭 회전·상세 회전·가방 드래그 해제·비활성 회수 목록 유지.
