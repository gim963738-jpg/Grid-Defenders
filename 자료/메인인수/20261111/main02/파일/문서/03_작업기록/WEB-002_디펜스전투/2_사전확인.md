# WEB-002 — 사전 확인 및 범위 확장

## 목표
진단 화면을 실제 조작 가능한 디펜스 시험 화면으로 교체.
↳ 쉽게 말하면: 병사와 영웅을 놓고 적을 잡으며 장비를 구매·장착하는 흐름을 확인한다.

## 승인 근거
첫 디펜스 보고서 후 유저가 `가능한 만큼 최대한 구현 진행`으로 제외 목록의 범위 확장을 요청했다. 진행 시작 시 병사·영웅 소환, 강화·판매, 장비 배치·회전·해제, 가방·상점 연결과 미정 조합·보스 보류를 안내했다.

## 파일
- 게임/src/main.ts: 입력·HTML 패널·Pixi 연결.
- 게임/src/defense.ts: 시험 전투 및 소환·장비·경제 상태.
- 게임/src/defenseConfig.ts: 임시 유닛·아이템·가격·블록·경로.
- 게임/src/defenseView.ts: Pixi 전장·유닛·체력·공격선.
- 게임/src/style.css, 게임/index.html: 세로형 UI.
- 게임/README.md: 실행·조작·한계.
- task.md, 큰기획, 전투·아이템 세부기획, 정의목록.
- 이번 5개 작업 기록, UI 라벨 설명·실제 라벨 이미지.

## 완료 기준
- 몬스터 순환, 병사 선택 배치·차감·자동 공격·처치 보상.
- 영웅 무료 소환·3명 제한·판매 금지.
- 병사 강화·판매, 상점 구매·리롤, 장비 이동·회전·해제·판매.
- 잘못된 장착에서 중복·아이템 소실·잘못된 차감 방지.
- 모바일 폭·빌드·브라우저 동작 확인, 미구현 명시.

## 보류
실제 웨이브·게임오버·보스·영웅 스킬·조합식·오염·로비·영구 저장·최종 디자인. 별도 신규 의존성 없음.
