# WEB-002 — 작업 일지

- 날짜: 2026-11-02.
- 구현: 외곽 순환, 4×4 배치, 병사3종·영웅4종 후보, 자동 공격·사거리·몬스터 체력·처치 수·보상.
- 경제: 병사 선택 소환·강화·판매, 영웅 무료·3명·동일 영웅 중복 임시 금지, 영웅 판매 금지.
- 장비: 수치형9종, 영웅별5×6, 회전·드래그/탭 이동·해제·판매, 배치 완료 시 효과 반영, 실패 상태 유지.
- 상점: 상품5칸·구매·리롤·공용 무제한 가방.
- UI: 도형 전장과 캐릭터, 소환·장비·상점 탭, 배속1/2/3, A/B/C 라벨 스크린샷.
- 구조: 모델(defense.ts), 설정(defenseConfig.ts), Pixi 표현(defenseView.ts), DOM 입력(main.ts) 분리.

## 검증
- TypeScript 검사·Vite 빌드 통과.
- Orca 내장 브라우저에서 모델 검증23개 통과: 소환 차감·점유·강화·판매, 영웅 제한·판매 금지, 구매·장착 수치, 경계/겹침 실패 원자성, 회전·해제·판매·골드 부족·순환·생성 상한·자동 처치 보상.
- 100초 모의 전투에서 원거리 영웅1명으로28마리 처치, 골드 증가 확인. 무배치 시험은 최대30마리 유지.
- 실제 UI 흐름: 캔버스 배치·강화·영웅 선택·구매·장착·회전·해제 성공.
- 탱커 철검 장착 시 공격40→55, 해제 후40 확인.
- 합성 touch PointerEvent 드래그 장착 성공·잔여 드래그 표시0 확인. 실제 모바일 하드웨어 검증은 아님.
- 320px·390px·1280px 폭에서 가로 넘침 없음. Orca 콘솔 오류0.
- 최종 검사에서 발견한 Pixi Graphics 자식 추가의 폐기 예정 API 경고는 Container로 변경하여 제거.
- 화면 이미지를 열어 전장·정보·패널 표시 확인. 테스트 라벨은 캡처 후 실행 화면에서 제거.
