# WEB-002 — 정의

- Defense: 골드·유닛·몬스터·장비·상점의 시험 상태 및 변경 규칙.
- Unit: id, kind, slot, level, spent, cooldown. 영웅과 병사를 kind로 구분.
- Enemy: 누적 이동 거리·위치·현재/최대 체력·이동 속도. 경로를 돌면 위치만 순환하고 이동 거리는 증가.
- Gear: 고유id·아이템 정의·소유 영웅id 또는 null(공용 가방)·배치 좌표·회전 횟수.
- equip: 경계·겹침 검사 후 한 번에 소유자·위치·방향 반영.
  ↳ 쉽게 말하면: 놓을 수 있는 자리인지 먼저 확인하므로 실패해도 장비가 사라지거나 효과가 잘못 바뀌지 않는다.
- 선택 회전: 드래그/배치 전 임시 방향. 실제 배치 성공 전 기존 효과 유지.
- 기준값: defenseConfig.ts와 전투·아이템 문서의 WEB-002 항목 참조. 모두 최종 밸런스가 아닌 시험값.
- 전장 라벨: [A/B/C 설명](../../04_UI/디펜스화면/라벨설명.md).
- UI 세로 스크롤: 하단 조작은 패널 높이에 따라 내려서 확인. 전투는 계속 진행.
- 자동 스킬·모루·보스 등 미구현 후보를 실제 동작과 구분.
