# WEB-113 정의문서
임시 정의: 병과별17개 노드와16개 선. 화면720×560 내부 캔버스, 기기 폭의 스크롤 창. 이 숫자는 최종 기획이 아닌 빈 기반 배치이다.
SpecialtyNode: id/name/x/y/parents. SpecialtyTree: classId/nodes. createSpecialtyTrees는 병과마다 새 객체와 ID를 생성. parent 연결은 시각적인 선만 표시하며 해금이나 선행 조건 판정 없음.
경로 #specialty/{infantry,archer,mage,support,assassin,tank}. 상단 뒤로는 #specialty, 홈은 로비. 선택 노드는 메모리 Map에 병과별 유지, 새로고침 시 초기화. 노드 모두 효과·성장 단계 미정, 강화 비활성. 통계 계산·재화 소비·localStorage·전투 코드를 호출하지 않는다.
