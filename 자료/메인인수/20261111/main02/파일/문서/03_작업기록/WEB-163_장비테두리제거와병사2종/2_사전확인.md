# 대상과 완료 조건
대상: landscape-entry.ts/CSS, 새 soldierArt.ts, main.ts, defenseView.ts, bossBattleView.ts, 병사 PNG2개 및 문서.
장비 외곽선과 정보 버튼이 사라지고 기존260×312px 패널·32px 칸·장비 조작을 유지해야 한다. 보병과 궁병이 같은 원본 이미지로 카드/드래그/전장에 표시되어야 하며 복수 병사·제거/초기화 시 표시가 정상이어야 한다.
imagegen 스킬의 기본 내장 도구로 투명 PNG를 생성하고 원본을 프로젝트에 복사한다. 기존 이미지는 덮어쓰지 않는다. 스킬 구현 규약의 투명 여백·균일 배율·발 기준점·판정 분리를 확인했다.
이번 아트는 각 병사1장의 정지 자세다. 새 공격/걷기 프레임·전투 수치·로비 편성 연동을 추가하지 않는다.
