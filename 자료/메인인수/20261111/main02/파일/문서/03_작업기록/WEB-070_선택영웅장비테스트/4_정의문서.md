# 정의문서
버튼: dev-test-gear, 선택 영웅 장비 테스트 / 질풍의 검 ×5 · 가속 룬 ×2.
프리셋(0부터 시작 x,y,90도 회전 횟수): 질풍의 검 I08 (0,0,0),(2,1,0),(1,2,0),(0,3,0),(2,3,3); 가속 룬 I03 (1,0,0),(3,0,1). 총 19칸, 빈칸 (0,2).
활성 효과 합계: 공격력 +100, 공격속도 +95% 가산. 기본 공속 ×1.95.
대상은 장비 화면의 선택 영웅 ID. 기존 같은 종류는 최대 필요 개수까지 재사용, 다른 기존 장비는 공용 가방 보관. 재클릭 시 동일 7개 재배치. 다른 영웅과 기존 가방 아이템은 변경하지 않음.
골드/모루 소비 없음. 새 생성품 원가 0. 가방의 기존 아이템은 자동 소비하지 않음.
