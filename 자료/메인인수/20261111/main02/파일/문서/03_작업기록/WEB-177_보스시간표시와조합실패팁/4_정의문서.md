# UI 정의
## 가로 보스 시간
- 기존 #boss-time-limit를 재사용하고 role=timer를 부여한다. #boss-screen의 .boss-wave-heading은 상단 8px/가운데, 168×32px, 글자 16px/줄높이 20px로 표시한다.
- 기존 제목과 중복 보스 조작 버튼은 숨긴다. 타이머 표시는 포인터 입력을 가로채지 않으며 우측 공통 조작 버튼의 위치·크기를 유지한다.
- 일반 모드의 기존 제한은 60초다. 남은 10초 이하는 urgent 경고색, 무한 테스트는 시간 제한 없음이다. 제한시간 판정과 전투 모델은 변경하지 않았다.

## 가로 상점 조합
- #live-combine은 항상 활성화한다. 실제 클릭 처리의 전투 상태 확인과 기존 일괄 combineMany 검증은 유지한다. 모루가 부족할 때 일부만 조합하지 않는다.
- #live-combine-tip은 버튼 위 8px, 폭 196px/글자 14px/줄높이 20px/안쪽 여백 8×10px로 표시한다. 화면 좌우 경계를 보정하고 화살표는 버튼 중심을 가리킨다.
- 모루 부족 문구는 모루가 모자랍니다. 이며 재료 없음·공간 부족은 기존 실패 이유를 사용한다. role=status, aria-live=polite, aria-atomic=true, 버튼 aria-describedby로 연결하고 pointer-events:none을 적용한다.
- 표시 시간은 2800ms이며 재클릭 시 갱신한다. 메뉴 종료·메뉴/장면 전환·다른 버튼·드래그 시작·조합 성공·HMR 해제 시 팁과 연결을 지운다. 실패 시 재료·모루·골드는 그대로 유지한다.

## 상태
시간 표시와 조합 실패 팁은 구현 완료다. 역할별 자동 배치 + 별도 보스 진형 저장은 제안/미확정/미구현이며, 힐러 역할은 영웅 디자인·콘셉트·스킬 설정 이후로 보류한다. 사용자 최종 화면 확인은 별도다.
