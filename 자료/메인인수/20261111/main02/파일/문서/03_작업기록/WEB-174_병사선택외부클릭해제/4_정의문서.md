# 병사 선택 해제 규칙
`soldierSelectionPress`는 이번 입력 직전의 전장 병사 ID·소환 대기 종류·드래그 여부를 임시로 보관한다. 포인터 입력은 pointerdown, 키보드/프로그램 click(detail0)은 클릭 캡처 단계에서 기록한다. 클릭 버블 단계는 기존 선택/버튼 동작 뒤에 실행한다.

같은 병사 ID가 계속 선택돼 있으면 `selectedUnit=null`, 같은 병과가 계속 대기 중이면 `pending=null`로 바꾸고 관련 병사 상세를 닫는다. 새 병사/영웅으로 전환한 경우는 그대로 두고 첫 선택을 같은 클릭에서 취소하지 않는다. 드래그/기본 동작이 취소된 이벤트·비전투 상태·장면 전환 중에는 적용하지 않는다. 포인터 취소/클릭 완료 시 임시 기록을 비운다.

`selectedHero`와 영웅 소환 대기는 건드리지 않는다. 가로 화면은 `soldier-selection-cleared` 이벤트로 병사 카드 선택을 동기화하고 병사 카드의 aria-pressed/is-selected는 실제 소환 대기로 계산한다. 영웅과 상점 카드는 기존 선택 값을 사용한다.
