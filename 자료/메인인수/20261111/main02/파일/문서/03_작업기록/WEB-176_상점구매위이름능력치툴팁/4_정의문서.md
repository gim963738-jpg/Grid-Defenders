# 상품 툴팁
표시 대상은 selectedCard가 offer-N인 유효한 상품이다. 호버만으로 표시하지 않는다. 상점이 열려 있고 전투 조작이 가능하며 구매 버튼이 표시될 때 열린다. 드래그 중, 선택 해제, 구매 성공, 새로고침, 메뉴 종료, 다른 전투 장면에서는 숨긴다. 취소된 드래그 후 상품 선택이 유지되면 다시 표시한다.

폭176px/안쪽8×10px, 제목14px·줄높이18px, 능력치12px·줄높이16px/제목과4px 간격. 전장 직계 자식으로 트레이 스크롤 잘림을 피한다. 구매 버튼 최종 위치 위8px 간격, 상품줄 좌우 범위 안으로 제한하고 화살표는 구매 버튼 중앙을 향한다. 선택 상승6px/140ms와 기존 구매 버튼 크기는 유지한다.

이름과 수치만 출력한다. 공격력·물리 방어·마법 방어·체력·공속·초당 회복·골드 획득을 사용하며 공속/골드는 백분율로 표시한다. 원본 description의 시험용 크기 문구/조합/이미지는 출력하지 않는다. 내용은 textContent로 설정한다. pointer-events:none으로 구매나 전장 입력을 가로채지 않으며 선택 상품과 구매 버튼에 aria-describedby를 연결한다.
