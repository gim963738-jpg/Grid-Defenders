# 정의문서
검 영웅 연속 검격: 쿨타임4초, 범위반경48, 시전 당시 공격력100%×3. 원거리 화염 스킬의 설정값을 공유. 검 영웅은 물리, 원거리는 마법이라는 기존 속성 감산 유지. 평타와 별도 발동.
검기 잔상 0~0.25초, 연속 검로0.25~0.7초, 내려치기0.7~0.9초, 충격파0.9~1.39초. 타격은0.91/0.98/1.05초의 세 최대 충격 프레임. 다른 시트 프레임은 추가 피해 없음.
시전 지점의 몸 중앙을 고정 피해 중심으로 사용하고, 표시만 몬스터 발밑에 정렬. 웨이브 전환/리셋/보스 재시작 시 효과 정리. 전투 종료 후 잔상은 소멸하되 추가 피해/전투 시간 없음.
보스: 배치된 영웅 전원 카드 생성. 평타 딜레이는 각 공격속도/장비 기준. ranged 화염 기둥, melee 연속 검격은 개별 4초 타이머. 탱커/힐러는 평타만 표시하고 두 번째 스킬칸은 빈 상태. 사망 영웅은 흐림 처리. 자동 스킬은 지휘자 및 배정 영웅 전원에 적용.
