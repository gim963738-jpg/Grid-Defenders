# WEB-001 — 정의

- PixiJS Application: 렌더러와 화면 갱신을 초기화하는 진입 객체.
  ↳ 쉽게 말하면: 게임 그림을 그릴 작업 화면을 준비하는 객체.
- TypeScript: strict 검사 사용, JavaScript 작성 오류를 빌드 전에 확인.
- Vite: 개발 서버와 배포용 묶음 생성.
- 임시 캔버스: 390×694 논리 픽셀. 최종 게임 화면 규격 아님.
- 렌더링 해상도: 기기 배율 최대 2, WebGL 우선. 실제 기기 최적화 전 임시 설정.
- 진단 화면: 사각형+실행 확인 문구. 게임 UI 배치에 대한 결정이 아님.
- npm.cmd run dev: 로컬 127.0.0.1 개발 서버. 휴대폰 외부 접속 설정 아님.
- npm.cmd run build: 검사 후 dist 생성, 상대경로 자산 사용.
- node_modules·dist: 다시 생성 가능한 로컬 산출물, Git 제외.
