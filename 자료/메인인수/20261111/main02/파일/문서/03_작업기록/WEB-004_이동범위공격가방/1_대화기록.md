# WEB-004 — 대화 기록

유저 수정 요청:
1. 영웅 공격 범위 표시를 진하게.
2. 영웅 이동, 병사가 있는 자리는 교체.
3. 병사 이동.
4. 전장 영웅 클릭 시 하단 장비창 자동 연결.
5. 보병은 공격 이펙트 안 모든 적, 마법병은 지정 대상 주변 범위 타격.
6. 상점의 공용 가방을 영웅 인벤토리 같은 격자로 변경하고 아이템을 그 안에 배치.

AI가 드래그 이동·자리교체, 기존 사거리의90도 부채꼴/반경48px 폭발, 무제한 행 확장 가방, 파일·완료 조건을 보고했다.
유저가 영웅↔영웅·병사↔병사 교체도 허용하고, 공용·영웅 가방 블록 더블클릭 회전을 추가 요청했다.
앞서 보고한 범위 및 추가 사항의 구현 지시로 받아 진행했다.
