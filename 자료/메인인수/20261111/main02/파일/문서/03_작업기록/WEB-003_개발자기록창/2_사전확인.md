# WEB-003 — 사전 확인

## 승인 범위
- 이미지 왼쪽 여백에 개발 기록창, 구역별 피해/처치·보상/골드 사용·판매.
- 넓은 화면은 왼쪽 고정, 좁은 화면은 게임 아래. 기존 게임 중심 위치 유지.
- 이름·고유번호·배치 위치, 피해·체력 전후, 골드 이유·증감·잔액.
- 최신 위·구역별100건·독립 스크롤·새로고침 초기화.

## 파일
- defense.ts: 타입 및 제한된 기록 버퍼, 실제 거래·피해 발생 지점의 기록.
- main.ts: 기록 UI 갱신, 선택 유닛 번호·위치 표시.
- index.html·style.css: 별도 개발자창·반응형 위치.
- task·README·정의목록·UI 라벨 문서·실제 화면 캡처·작업 기록5개.

## 완료 조건
공격/실제 피해·체력·처치 보상·골드 거래가 게임 상태와 일치. 실패한 행동에서 가짜 거래 없음. 게임 UI 겹침·가로 넘침·무제한 기록 없음.

## 제외
게임 밸런스 변경, 추가 전투·스킬, 영구 로그·다운로드·검색·추가 제어 기능, 최종 디자인.
