# WEB-003 — 정의

- DevLog: id·전투시간·구역·텍스트 및 검증용 공격자/대상/피해/체력/골드 수치.
- LogCategory: damage(피해), reward(처치 보상), economy(사용·판매).
- DEV_LOG_LIMIT: 구역별100건, 총 최대300건.
- logRevision: 기록 변경 횟수. 게임 상태 갱신용 revision과 별개.
- sourceId/targetId: 유닛/몬스터 고유번호. 판매·처치 후에도 기록은 당시 내용을 유지.
- attack: 공격 수치. damage: 실제 체력 감소량.
  ↳ 쉽게 말하면: 체력이5 남은 적을75로 공격하면 공격75·실제 피해5라고 표시한다.
- goldBefore/goldAfter/goldDelta: 거래 직전·직후 잔액과 실제 증감. 무료 소환은0.
- 시간: 배속이 반영된 전투 경과 시간, 분:초. 실제 시계·벽시계와 다름.
- D 영역: 임시 개발자 기록창. 게임 원래 UI가 아니라 테스트 확인용.
- 임시성: 새로고침 후 기록 보존 안 함. 파일 내보내기·서버 전송 없음.
