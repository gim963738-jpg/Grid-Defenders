# WEB-089 작업일지
2026-11-04 구현·검증 완료. 탱커/힐러 이미지 적용, 신규 마법 딜러/암살자 생성 및 임시 스탯. 영웅6종 소환 카드·정보·장비·드래그·웨이브·보스 편성에 이미지 연결. 소환 정원3 유지.
암살자 평타6/8/10 완료 타격, 웨이브 참격250%/4초, 보스35%×3+경로250%/5초·한칸 전진/복귀. 물리/마법 방어30% 감소5초·깨진 방패 아이콘·DPS 연결. 평타 도중 스킬 사용 시 미완료 타격 취소, 완료 피해 유지. 보스 자동 기본ON·새게임ON·수동OFF 재시험 유지.
사용자가 작업 도중 제공한 고해상도1536×1024 시트로 교체하고 해시 동일 확인. 원본의 참격 셀은12번 표시가 빠져 실제15개이므로 논리12프레임은11번을 유지하고13~16은 각각 원본 번호에 대응. 타격10프레임 완료 시점 유지. 배경/번호선 혼입을 제거하고 캐릭터/발밑 이펙트 위치 고정.
검증: npm.cmd run build 및 타입검사 통과. 브라우저25개 검사 모듈의434개 검사 전부 통과(기존381+신규53). 실제 소환6종/암살자·마법·탱커3명 배치와 보스 편성 연동, 자동ON·방어감소5초/양방어 수치 표시 확인. 390px 화면과 실제 Pixi 렌더 추출에서 점프/대상 발밑 타격을 시각 확인. 320px에서 가로 넘침 없음, 스킬별 툴팁 내용·경계·X 비활성·이미지만 나오는 드래그 확인.
사용자 최종 시각 확인과 최종 밸런스 확정은 별도. 추가 영웅의 미배정 스킬·힐러 치유 등은 이번에 구현하지 않음.
