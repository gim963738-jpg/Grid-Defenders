# 정의문서
gear-sale-layer는 shop-market의 상품/상인 영역 위에 표시. 일반 선택이 아닌 드래그 이동 임계값을 넘긴 보유 아이템에만 표시.
기본 상태는 어두운 판매 안내, sale-drop-active 때 붉은 배경/테두리·놓아서 판매·+환급G. pointer-events:none으로 기존 드롭 판정 유지. hover만으로 판매하지 않고 pointerup 시 실행.
판매가는 기존 Math.floor(costBasis/2). 무료 개발자 장비는0G. 가격 계산/재화/장비 능력치 갱신 규칙은 기존 모델 유지. 미구매 상점 상품에는 판매 레이어를 만들지 않음.
