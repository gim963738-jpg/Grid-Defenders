# WEB-005 — 사전 확인 및 범위

## 목표
배치 전·후 영웅의 상세 정보는 클릭 팝업에 모으고 상시 카드·장비 UI 중복을 줄인다.

## 변경
- index.html: 장비창 hero-tabs/hero-stats 제거, 선택 영웅 제목, 비모달 팝업 영역.
- main.ts: 영웅 카드 축소, 기본/장비 적용 정보 구분, 위치 보정·닫기, 장비창 자동 연결 유지.
- style.css: 약62px 카드와 이미지 참고2열 팝업 스타일. 폐기된 중복 패널 스타일 제거.
- README·task·정의·UI 라벨·작업 기록5개·확인 이미지.

## 완료 조건
- 배치 전 카드는 기본 능력치, 배치 후는 선택한 영웅의 장비 적용 능력치.
- 장비창 중복 버튼·수치 줄 없음, 현재 영웅은 제목으로 식별.
- 작은 화면에서 팝업이 넘치지 않음.
- 영웅3명 제한·소환·장비·병사 강화/판매 동작 유지.

## 제외
미구현 치명타·회피·흡혈 수치 추가, 영웅 일러스트 제작, 전투 밸런스·스킬·저장 시스템 변경.
