# WEB-005 — 정의

- heroInfo: 현재 정보창 대상 kind와 배치 unitId. unitId가 null이면 기본 능력치 미리보기.
- refreshHeroInfo: 미배치 UNITS 기본값 또는 배치 game.stats 결과로 내용 구성.
- positionHeroInfo: 카드 DOM/전장 좌표를 기준으로 위치를 잡고 화면 경계 안으로 보정.
- closeHeroInfo: 정보창만 닫으며 전투·이미 선택한 소환 대기 상태는 멈추지 않음.
- E 영역: 영웅 클릭형 비모달 팝업.
  ↳ 쉽게 말하면: 능력치를 확인하는 동안에도 게임은 계속 진행되고 다른 곳을 누르면 닫힌다.
- hero-card: 약62px 소형 영웅 소환 버튼. 정원 가득/배치됨이어도 정보는 열람 가능.
- gear-title: 현재 선택한 영웅 이름·고유번호·장비 제목. 별도 영웅 선택 버튼 대체.
- 최대 체력은 현재 일반전에서 저장된 체력 소모량이 아니라 영웅의 최대 능력치. 미구현 수치와 구분.
