# 화면 정의
- 주소: /lobby-preview.html
- 캠프 폭: 최대 480px. 모바일에서는 화면 폭 사용.
- 표시값: 지휘관 Lv.1, 경험치 24%, 골드 480, 모루 0, 잊혀진 숲 제1구역, 최고 웨이브 10. 모두 시안용 고정값.
- 메뉴: 상점/영웅/전투/병영/기록. 전투 탭 선택 상태 고정.
- 대화상자: 기본 dialog의 Escape 닫기, 배경 클릭 닫기, 닫은 뒤 원래 버튼 포커스 복귀.
- 불꽃: 장식용 CSS 애니메이션. 움직임 줄이기 설정 지원.
- 게임 모듈 import 및 게임 상태 저장 없음.
