복사한 원본·메타데이터·검수 파일은 **41개, 46,127,005B**다. 원본 복사 41건의 SHA-256이 같고, 외부 원본의 해시·수정 시각이 바뀌지 않았다. 검수 보고서는 그 문서가 작성된 당시의 검수 결과로 보관했으며, 그 안의 과거 `전장 미검수` 등 상태를 새 검수 완료로 덮어쓰지 않았다.

`게임/scripts/pack-blond-art.ps1`과 `pack-slime-art.ps1`은 실행 위치와 관계없이 저장소 내부 원본을 기본 입력으로 찾는다. 기존 명시적 `SourceRoot` 사용도 유지하며 `OutputRoot`로 임시 폴더 재생성이 가능하다. `sources.json`에는 기존 출처·해시를 유지하면서 `inputSource`, `archiveManifest`만 추가했다. Windows PowerShell의 한글 경로 해석을 위해 스크립트 UTF-8 BOM을 유지했다.

재현 검증에서는 실제 배포 PNG를 덮어쓰지 않고 별도 임시 출력에서 슬라임 PNG 4개와 금발 전사 PNG 3개를 만들었다. **PNG 7개가 기존 파일과 바이트 단위로 동일**했고 좌표·프레임 정보 JSON 2개는 구조적으로 같았다. 아트 보관 PNG 35개도 모두 디코드 검사를 통과했다. 실행 정책 때문에 직접 호출이 거부된 뒤 검증 프로세스에만 `-ExecutionPolicy Bypass`를 지정했으며 시스템의 지속 실행 정책은 바꾸지 않았다.

## 7. 최종 처리 경계

**이번에 완료한 것:** 8개 영역의 위치·브랜치·파일 분포 조사, 검증된 원본 41개 복사, 세계관 7개 선별 통합, 상인·기획 원본의 내부 이관, 패커 기본 경로 수정, 출처·복구 추적 기록, 기존 런타임 재현 검증, 앱 작업 목록의 이름·설명·계층 정리다.

**보존한 것:** 외부 작업 영역의 미커밋 변경, 생성 중이거나 채택이 끝나지 않은 아트·도구·영상, 과거 백업·handoffs, 역사 문서다. 사용 여부가 불명확한 파일은 삭제하거나 임의로 최신본에 통합하지 않았다.

**추가 판단이 필요한 것:** 아이템 규칙 확정, 공방 재료 연결·권리 검토, 신규 아트 채택, 동작 생성 경로와 전장 검수, 장기 원본·백업 보존 정책이다. 브랜치 전체 완료율은 분모가 확정되지 않아 제시하지 않았다. 현재 사용 가능 기능과 신규 통합 후 전체 실행 결과는 종합 보고서의 기능 진행 현황·검증 결과와 함께 판단한다.
