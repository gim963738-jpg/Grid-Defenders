각 계획의 전체 작화 참조는 8장 중 해당 대상에 맞는 실제 원본이어야 한다. 8장 모두를 한 호출에 넣지 않으며 총 참조 한도는 5장이다. 분석 원본 16장과 자세·그립·재질 자료는 역할을 적어 보조로 사용한다. 참조 번호·순서·실제 프롬프트의 역할도 사람이 대조한다.

도구는 입력의 일관성을 검사한다. 출력 화풍 합격, 사용자 시안 승인, 내장 이미지 도구 강제 차단을 수행하지 않는다. 역사적 style_recovery_20261108/recovery-plan.json은 수정하지 않고 보존하며 현재 입력 예시로 쓰지 않는다. 새 검증 결과는 output/gc9-style-standard-20261108/verification.json에 기록한다.
