- 전체 백업: output/backups/Grid-Defenders-날짜-시간.zip. 소스·문서·자산·첨부·현재 dist 빌드를 포함한다.

복원: ZIP을 새 폴더에 풀고 게임 폴더에서 npm.cmd ci, npm.cmd run dev 실행.
