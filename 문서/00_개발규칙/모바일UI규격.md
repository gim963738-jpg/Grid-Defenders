# 공통 모바일 UI 규격
사용자 요청: 로비부터 상점·영웅·전투·병영·기록까지 모든 메뉴에 같은 APK/안드로이드 앱 크기 기준을 사용한다.

Android에는 APK용 고정 필수 해상도가 없다. 본 프로젝트는 360×800 논리 화면을 설계 기준으로 선택하며 실제 기기 폭/높이에 반응한다. 1080px 등 물리 해상도에 UI 크기를 고정하지 않는다.

## 프로젝트 공통값
- 구현: 게임/src/mobile-ui.css. 모든 메뉴에서 재사용한다.
- viewport: device-width, initial-scale=1, viewport-fit=cover. 사용자 확대 제한 없음.
- 폭: 기기 폭 100%, 넓은 화면에서는 최대 480 CSS px의 세로 게임 틀. 최소 검증 폭 320px.
- 높이: 최소 100dvh, 콘텐츠가 길면 세로 스크롤. 화면별 임의 확대/축소 없음.
- 여백: 기본 좌우 12px, 요소 간격 8px. 기기 안전 영역은 env(safe-area-inset-*) 추가.
- 터치: 최소 48×48 논리 영역. 그림 자체는 보통 24~32px.
- 글자: 주요 본문/버튼 14px, 보조 12px, 제목 20~22px. 이 글자 크기는 프로젝트 선택값이며 Android 의무 수치가 아니다.
- 영웅 목록: 4×4 유지. 상세 스킬/장비는 전체 폭 4칸으로 배치하여 터치 크기를 확보한다.

## APK 통합 경계
현재 적용 범위는 독립 로비/영웅 UI 및 준비 중 메뉴의 공통 틀이다. 기존 실제 게임 코드와 연결하지 않았다. 상점·전투·병영·기록의 독립 페이지를 만들거나 실제 게임을 통합할 때 동일 스타일을 사용한다.
WebView에서는 viewport와 폰트 확대를 검증하고, 네이티브 시스템 바/컷아웃 inset을 전달하거나 네이티브에서 한 번만 소비한다. 실제 APK 빌드 및 실기기 인증을 수행한 것으로 간주하지 않는다.

## 공통 하단 메뉴 고정 (WEB-132, 2026-11-05)
독립 로비의 상점·영웅·전투·병영·기록은 화면별 메뉴를 중복 생성하지 않고 body 하위의 공통 app-bottom-nav 하나를 사용한다. 화면 하단 안전영역+28px(현재 바닥 가이드 공간)에 고정, 높이72px, 최대폭456px/좌우12px. 본문은 하단116px+안전영역을 확보한다. 스크롤·화면 이동·활성 표시 변경 시 위치와 아이콘 크기는 유지한다. 영웅 상세·훈련·특기 하위 화면도 포함한다. 상점/기록은 현재 안내 패널이며 실제 메뉴 구현 후에도 이 기준을 유지한다.

하단 메뉴 아이콘은 WEB-133부터 navigation-icons.ts의 공통 금색 선화5종을 사용한다.32×32 표시/32×32 viewBox/선1.6/둥근선끝을 공유하고, 선택 시 밝은금색과 약한그림자만 적용한다. 화면전환이나 선택에 따른 크기변경은 없다.

WEB-134: 독립 로비 html은 scrollbar-gutter:stable로 스크롤바 공간을 미리 확보한다. 긴 영웅 화면에서 스크롤바 생성 시 중앙정렬이 이동하지 않도록 한다. 공통 하단 메뉴 버튼은 :active에서도 transform:none으로 위치를 유지한다.

WEB-143: 영웅 상세는 능력치/스킬/장비3탭을 공통메뉴 위16px 간격으로 고정한다. 상세탭 높이50px, bottom116px+safe, 공통메뉴와 같은폭. 상세본문은 bottom196px+safe 여백 확보. 영웅목록이나 다른화면에서는 상세탭 숨김.

WEB-146: 영웅능력치각항목64px높이로통일. 공통메뉴와상세탭간격16px.

## 로비→실제 전투 연결 (WEB-148)
전투 시작·종료·보상 후 캠프 복귀 연결을 적용했다. 캠프에서 진입한 실제게임의 #app 최대폭도480px로 맞춘다. 전장 로비복귀 버튼/확인창 버튼은48px 이상이다. 실제전투의 기존 조작UI는 유지하며 이번 연결에 영웅편성 연동·전체전투UI 리디자인을 포함하지 않는다. 저장은현재브라우저 기준이다.

## WEB-151 가로 전투
사용자 승인 가로 시안을 실제 전투에 연결. 전투 가로 기준800×360, 공통 CSS 사용. 사용자 지정 버튼40×32/카드72×72/간격2 및20칸은 가로 전투에만 적용. 원본 세로 경로 유지. 현재 브라우저 실행 기준이며 APK 회전/실기기 최적화 검증은 별도.

## WEB-152 가로 전투 장비 및 카드
영웅 장비5×4/20칸, 공용가방5열3행 이상. 우측 패널 높이304px로4행과 가로 스크롤바를 가리지 않는다. 카드72×72/간격2 유지. 영웅 이름칸18px/선택상승6px/140ms, 병과 엠블럼20×20. 기존 세로 장비4×5는 유지한다.

## WEB-153 공용 가방 확장·영웅 장비 선택
가로 전투 공용 가방은7열×3행(21칸)에서 시작해 세로 확장한다. 영웅 장비5열×4행과 공용 가방의 칸을26×26px로 통일한다. 오른쪽 패널 높이312px, 영웅 장비 목록148px, 각 영웅 패널 최소136px로 초기 모든 행과 스크롤바를 표시한다. 배치된 영웅 클릭 시 상점 열기·해당 장비칸 강조·목록 자동 스크롤을 수행한다. WEB-152의 가방 열 수/패널 높이를 대체하며 기존 세로 전투의5×3 공용 가방은 유지한다. 현재 브라우저 가로 화면에서 검증했으며 실제 APK 검증은 별도다.

WEB-154: 영웅 인벤토리 목록의 첫 패널 왼쪽/마지막 패널 오른쪽 여백을 auto로 설정해 남는 공간을 양쪽에 동일 배분한다. 목록이 넘치면 여백 없이 기존 가로 스크롤을 사용한다. 칸/패널 크기는 유지한다.

## WEB-155 가로 상점 구매와 고정 가방
사용자 추가 확인으로 공용 가방은7×3(21칸) 고정/스크롤 없음, 추가 장비칸은 상점 상품 슬롯6개를 뜻한다. 영웅 장비5×4/칸26px 유지. 우측 패널 폭208px·높이284px·상단44px·오른쪽4px, 영웅 장비 목록 폭146px, 조합 버튼40×32px를 그 오른쪽에 배치한다. 공용 가방 격자194×82px로 패널 내부 좌우 여백은7px다.
상점 상품6개와 새로고침은72×72px/간격2px/전체516px, 왼쪽68px에서 우측 패널과4px 간격으로 배치한다. 선택 상승6px/140ms, 상단 구매 버튼72×24px/카드와2px 겹침. 선택 카드와 버튼을 수용하는 목록 높이108px. 아이템 회전180ms이며 동작 줄이기 설정에서는 전환을 생략한다. 회전·해제·판매 버튼을 없애고 기존 두 번 클릭/R·가방 드래그·판매 드래그를 사용한다. 기존 세로 화면은5상품/가방 세로 확장을 유지한다. 현재 브라우저 검증이며 실제 APK 검증은 별도다.

WEB-156: 기존 resource-wallet 컴포넌트를 가로 전투 왼쪽12px/상단144px에108×72px로 배치한다. 골드·모루를34px 높이 두 행/간격4px로 쌓아800×360의 세로 중앙에 맞추며 길목 시작128px보다8px 안쪽에서 끝난다. 가방 제목·재화 중복·조합 안내·영웅명·미소환 안내를 제거하고 선택/능력치 버튼의 접근성 이름을 유지한다. 삭제된 문구 행만큼 장비 패널 높이를246px로 줄인다. 상점 행동 결과는 왼쪽12px/상단224px의 재화 아래에 표시한다. 격자와 상품 크기는 유지한다.

WEB-157: 사용자 요청으로 상품 수를5칸으로 변경한다. 상품5개+새로고침의 총폭442px/왼쪽142px, 카드72×72px/간격2px/우측 인벤토리와4px 간격. 판매 드래그 영역도 같은 범위를 사용한다. WEB-155의6상품/516px 규칙을 대체한다.

## WEB-158 재화 경계와 영웅 정보
재화 UI는 왼쪽4px/폭84px/상단144px/높이72px로 조정한다. 오른쪽 끝88px이 전장 전체 배경 경계94px보다6px 앞에 위치한다. 기존 글자 크기와 재화 연결은 유지하며 상점 결과 메시지도 같은 폭을 사용한다. WEB-156의 왼쪽12px/폭108px 규칙을 대체한다.
일반 영웅 선택은 영웅 탭과 우측 정보창(오른쪽4px/상단44px/208×312px)을 연다. 실제 능력치10항목을2열로 표시하고 아래에서 착용 장비를 세로 스크롤로 확인한다. 상점 중 영웅 선택은 상점을 유지하고 기존208×246px 영웅 장비/공용 가방을 표시한다. 정보창과 가방은 상호 배타적이다. 선택 영웅의 카드/인벤토리는 화면 안으로 자동 스크롤하며 기존800×360 전장과 격자 크기는 유지한다. WEB-153의 영웅 선택 시 무조건 상점 진입 규칙을 대체한다.

## WEB-159 영웅 능력치 한 줄·장비 배치
영웅 정보창은 우측4px/상단44px/272×312px로 넓힌다. 항목10개를2열로 유지하며 각124×18px 안에서 이름과 값을 한 줄에 좌우 정렬한다. 글자 크기는 유지한다. 착용 장비는 목록 대신 실제5×4/칸26px/격자138×110px를 아래에 중앙 배치한다. 실제 장비와 좌표·모양·회전·비활성 상태가 같으며 확인용 격자에는 편집 버튼을 만들지 않는다. 전장 배경 오른쪽과 정보창 사이8px를 유지한다.
상점 상품5개+새로고침의 폭442px는 유지하고 x142→102로40px 왼쪽 이동한다. 판매 드래그 영역도 함께 이동한다. 재화와14px, 상점 인벤토리와44px 간격으로 겹치지 않는다. WEB-158의208px 정보창/장비 목록 및 WEB-157의 상품줄x142 규칙을 대체한다.

## WEB-160 보스전 모바일 필드
가로 보스전 프레임은 웨이브와 같은800×360px. 필드는x4/y8/608×342px로 기존1000×562.5 월드의16:9 비율을 유지한다. 아군4×8 격자·캐릭터·SVG 레이어가 같은 좌표 사각형을 사용하며 판정 좌표는 변경하지 않는다. 우측은 다음 UI 작업을 위한 빈 공간으로 유지한다.
상단 버튼은 `#app` 아래의 단일 live-controls 노드를 두 전투에서 공유한다. 기존 순서/40×32px/간격4px/오른쪽4px/위8px 유지. 전체172×32px, 필드와12px 간격이다. 보스전 기존 제목·타이머·상태 문구·지휘/영웅 스킬 패널과 중복 로비 헤더는 숨긴다. 이번 범위는 필드와 공통 조작뿐이며 실제 APK 검증은 별도다.
