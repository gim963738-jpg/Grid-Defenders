## 이미지 참조 식별자
- REF-01: 전장+소환 패널.
- REF-02: 보스 대치 진형.
- REF-03-A/B/C: 로비 / 영웅 장비 / 공용 가방·상점.
- REF-04: 전장+장비·공용 가방.
- REF-05: 전장+상점·공용 가방.
- REF-06: 픽셀 전장+소환 카드.

이 식별자는 채팅 이미지 기준이며 이미지 파일을 복사한 것은 아니다. 최종 UI 라벨·레이아웃 문서는 해당 작업 승인 시 생성한다.

## 용어
- 선쿨: 장착 후 첫 발동 전에 기다리는 시간.
- 모루: 아이템 조합 기회를 제공하는 재화. 영구 지원 건물과 구분.
- 영웅 타워: 현재는 배치 영웅을 뜻함. 별도 제단을 의미하지 않음.
- 임시: 변경 가능하며 구현·밸런스 검증 또는 유저 최종 확정과 다름.
- 보류: 구현 권한이 없는 미정 항목.

문서 간 상충을 발견하면 임의 결정하지 말고 유저에게 확인한다.
