# Grid Defenders — 현재 구현 현황

OPS-003 (2026-11-09): 6개 팀장과 독립 테스터를 배치하고 신규 게임개발/테스터 채팅의 규정 읽기를 확인했다. 기존 채팅 직접 알림은 CLI 제한으로 대기하며 시작 지침·공유규정은 연결했다. [현재 조직과 준비 상태](../../작업관리/조직안내.md).

## 세계관 도메인 계층 (OPS-002)

작업 목록을 세계관→몬스터/캐릭터→세부 담당으로 재배치했다. 기존 작업·규정·원본 경로는 보존하며 [도메인 색인](../../작업관리/도메인/README.md)에서 실제 원본과 담당을 찾는다.4개 부족한 관리/작업 공간을 추가했고 기존 역할 ID는 유지했다.20개 절차·도메인 검사와 실제 Orca 관계·원본 보존 검증을 통과했다. 게임 기능·수치·스킬 변경이나 새 제작 지시는 수행하지 않았다. [검증](../../작업관리/기록/OPS-002/검증.json).


최신 작업 분류: [세계관 중심 도메인 트리](../../작업관리/도메인/README.md). OPS-002에서 실제 부모/자식 관계와 원본 색인을 재편했으며 기존 제작·검수 기준과 자료 위치를 보존했다.


기준일: 2026-11-08 / WEB-185. 기준 프로젝트의 `게임/src`, `게임/tests`, 설정과 최신 작업 기록을 반영한다. WEB-180에서 7×4 진형 편집·자동배치·저장·보스전 연결을 구현했고, WEB-181에서 진형창을 전장 오른쪽 빈 공간으로 옮겼다. WEB-182에서7×6으로 확장하고 완료·자동배치를 하단 상점 카드 줄로 이동했으며 패널 제목을 제거했다. 사업 판단·전체 작업 영역·자원 통합 내역의 [프로젝트 종합 보고서](../06_프로젝트종합보고/2026-11-07/프로젝트종합보고서.md)와 PDF는 WEB-179 당시 상태를 보존하며, 이후 구현은 이 현황표와 해당 작업 기록을 따른다.

이 문서는 초기 기획과 현재 구현을 구분하기 위한 현황표다. **‘완료’는 명시한 시제품 기능의 구현 범위에 한정하며, 정식 출시·밸런스 확정·모바일 전체 기기 검증을 뜻하지 않는다.** 전체 진행률은 확정된 출시 범위와 분모가 없어 산정하지 않는다. 과거 문서의 ‘현재’, ‘최신’, ‘미구현’은 그 문서 작성 당시의 상태다.

## 새 작업 운영 체계 (OPS-001)

현재 대화 포함메인3개와 분야별8개 작업 공간을 연결했다. 메인02·03과UI 담당은 별도 브랜치·실제 채팅을 생성하고 공통 규정 읽기 완료 응답을 확인했다. 메인은 실제 시안·선택 조합을 만들며, 최초·수정 제작 지시 모두 사용자 이해 확인 후 전달한다. 분야별 기존 기준75개는 원래 위치를 보존하고 공통 규정 A와 연결했다. 작업 절차12개 검사와 UI 사본 빌드·코드/리소스 대조를 통과했다. 실제 제작 지시0건이며 앱4분할 GUI 배치는 변경하지 않았다. [시작과 폴더 트리](../../작업관리/README.md), [준비 상태](../../작업관리/기록/OPS-001/상태.json), [작업 기록](../03_작업기록/OPS-001_다중메인작업체계준비/3_작업일지.md).

### WEB-179 검증 기록

3. **첫 플레이와 완주 흐름(P1):** 강제 튜토리얼과 40웨이브 최종 승리 조건을 각기 설계·구현한다. 새 사용자가 기본 조작을 완료할 수 있고 일반 모드에서 패배/완주 모두 결과·보상·로비로 이어질 때 완료로 본다.
4. **영웅·성장 데이터 통합(P1):** 로비 시안과 전투 모델의 영웅 식별자·소유·성장·장비를 일치시킨다. 같은 영웅의 표시와 실제 능력치가 출전·귀환 후에도 일치할 때 완료로 본다. 힐러의 새 역할과 스킬은 콘셉트 확정까지 보류한다.
5. **출시·사업 범위 결정(P2):** 앱 포장, 수익 모델, 계정·서버 필요 범위, 최종 콘텐츠 분량을 결정한다. 기능 목록·비용 전제·검증 기준이 문서화되기 전에는 출시 일정이나 사업 전체 진행률을 확정하지 않는다.

진행 중인 다른 작업 영역의 원본은 유지한다. 여기의 ‘완료’나 작업명만으로 다른 브랜치 전체를 병합·삭제하지 않으며, 통합된 자료와 연결을 기다리는 자료의 세부 구분은 종합 보고서의 작업별 정리표를 따른다.
