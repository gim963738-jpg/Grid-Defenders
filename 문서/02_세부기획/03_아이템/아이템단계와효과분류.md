# 아이템 단계와 효과 분류

> 후속 골드 단가·단계별 가격 상한·옵션별 계산은 [아이템 옵션과 골드 가치](아이템옵션과골드가치.md)를 따른다. 최신 하급 장비 7종의 이름·칸수·주요 옵션은 아래 1단계 표를 따른다. 수호방패는 방어력 대신 가드율로 변경했다. 상위 장비의 기존 수치는 후보 기록이며 재조정 대상이다. 고유효과는 중첩 불가다.

기존 [임시 아이템](임시아이템.md)의 20종과 능력치를 기초로 단계별 획득 경로와 효과를 분류한다. 획득 경로는 아래 최신 기준을 적용하며, 능력치 수치는 골드 가치 측정 전의 후보값으로 유지한다.

## 현재 추가 아이템의 용도별 분류

현재 초급 목록은 장검을 중급 정밀 검으로 대체하고 매직 스태프도 중급으로 이동하여 15종이다. 아래 표는 초급의 주요 옵션과 조합식을 함께 표시한다. 중급 조합 결과는 별도의 2단계 표를 따른다. 실제 수치와 가격을 아직 정하지 않은 항목은 미정 상태를 유지한다.

| 분류 | 아이템 | 칸수 | 주요 옵션 | 조합식 (제작·재료 사용) |
|---|---|---|---|---|
| 공격형 | 단검 | 2칸 | 물리 공격력 | 재료 사용: 단검 + 숫돌 → 정밀 검<br>재료 사용: 단검 + 가속룬 → 질풍의 검 |
| 공격형 | 매직로드 | 2칸 | 마법 공격력 | 재료 사용: 매직로드 + 마력의룬 → 매직 스태프 |
| 공격형 | 가속룬 | 1칸 | 공격속도 | 재료 사용: 가속룬 ×2 → 신속의 룬<br>재료 사용: 단검 + 가속룬 → 질풍의 검 |
| 공격형 | 신속의 룬 | 2칸 | 공격속도 | 제작: 가속룬 ×2 → 신속의 룬<br>재료 사용: 질풍의 검 + 신속의 룬 → 폭풍의 심장 |
| 공격형 | 마력의룬 | 1칸 | 스킬증폭 | 재료 사용: 매직로드 + 마력의룬 → 매직 스태프<br>재료 사용: 매직 스태프 + 마력의룬 → 루나 스태프 |
| 방어형 | 수호원형방패 | 1칸 | 가드율 | 재료 사용: 수호원형방패 ×2 → 수호방패<br>재료 사용: 수호원형방패 + 활력의 수정 → 룬 방패 |
| 방어형 | 수호방패 | 2칸 | 가드율 | 제작: 수호원형방패 ×2 → 수호방패 |
| 방어형 | 가죽 갑옷 | 4칸 | 방어력 | 재료 사용: 가죽 갑옷 + 철괴 → 플레이트 |
| 방어형 | 활력의 수정 | 1칸 | 체력 | 재료 사용: 활력의 수정 ×2 → 활력의 원천<br>재료 사용: 수호원형방패 + 활력의 수정 → 룬 방패<br>재료 사용: 매직 스태프 + 활력의 수정 → 생명의숨결 (지팡이) |
| 방어형 | 활력의 원천 | 2칸 | 체력 | 제작: 활력의 수정 ×2 → 활력의 원천<br>재료 사용: 활력의 원천 + 체력 물약 → 재생의 부적<br>재료 사용: 활력의 원천 + 성배 → 대성배 |
| 방어형 | 체력 물약 | 1칸 | 체력 재생 | 재료 사용: 활력의 원천 + 체력 물약 → 재생의 부적 |
| 보조 | 깨진 낡은 은시계 | 2칸 | 쿨타임 감소 | 재료 사용: 깨진 낡은 은시계 + 정령의 힘 → 신비한 모래시계 |
| 보조 | 황금주머니 | 1칸 | 골드 획득 + · 고유 | — |
| 재료 | 철괴 | 1칸 | 좌우 각 1칸 가드율 + · 고유 | 재료 사용: 룬 방패 + 철괴 → 절대 방벽<br>재료 사용: 가죽 갑옷 + 철괴 → 플레이트 |
| 재료 | 숫돌 | 1칸 | 좌우 각 1칸 공격력 + | 재료 사용: 단검 + 숫돌 → 정밀 검 |


초급 합계는 공격형 5종·방어형 6종·재료 2종·보조 2종 = 15종이다. 공격속도와 스킬증폭은 공격형에, 쿨타임 감소는 보조에 둔다. 철괴·숫돌은 인접 부여형 재료로 관리한다. 표 오른쪽에서 제작법과 재료 사용을 구분한다. 장검은 중급 정밀 검으로 대체했으며 매직 스태프는 중급으로 이동했다.

## 직업별 초급·중급·상급 카테고리

현재 33종을 주력 용도로 분류한다. 이 카테고리는 장착 제한이나 피해 적용 계열의 새 규칙이 아니다. 마법 카테고리에는 마법 공격·스킬·보호·회복 장비를 함께 둔다. 공속·스킬증폭·쿨타임 감소 등은 다른 직업에서도 활용할 수 있으므로 공용 검토 목록을 따로 표시한다. 아직 효과 적용 범위가 미정인 옵션은 이 분류만으로 범위를 확정하지 않는다.

| 직업 카테고리 | 초급 | 중급 | 상급 |
|---|---|---|---|
| 물리 | 단검 · 가속룬 · 신속의 룬 | 정밀 검 · 질풍의 검 · 갈증이 담긴 구슬 | 파괴자의 대검 · 폭풍의 심장 |
| 마법 | 매직로드 · 마력의룬 · 깨진 낡은 은시계 | 매직 스태프 · 성배 · 정령의 힘 | 루나 스태프 · 생명의숨결 · 대성배 · 신비한 모래시계 |
| 탱 | 수호원형방패 · 수호방패 · 가죽 갑옷 · 활력의 수정 · 활력의 원천 · 체력 물약 | 룬 방패 · 재생의 부적 · 플레이트 | 절대 방벽 · 흑갑주 |

주력 분류는 물리 8종·마법 10종·탱 11종이다. 공용 4종까지 합쳐 원본 33종을 빠짐없이 포함한다.

| 공용·재료 | 단계 | 주용도 |
|---|---|---|
| 황금주머니 | 초급 | 경제·골드 획득 |
| 철괴 | 초급 | 인접 가드율 부여·방어 장비 조합 재료 |
| 숫돌 | 초급 | 인접 공격력 부여·정밀 검 조합 재료 |
| 용병의 징표 | 중급 | 주변 장비 강화·흑갑주 조합 재료 |

| 직업 | 다른 주력 분류에서 공용으로 검토할 장비 |
|---|---|
| 물리 | 마력의룬 · 깨진 낡은 은시계 · 정령의 힘 · 신비한 모래시계 |
| 마법 | 가속룬 · 신속의 룬 · 폭풍의 심장 |
| 탱 | 깨진 낡은 은시계 · 성배 · 정령의 힘 · 대성배 · 신비한 모래시계 |

공용 검토 장비는 추천 분류상 중복 표시일 뿐 아이템 종류 수에 다시 더하지 않는다. 체력·가드·방어 장비 또한 다른 직업의 생존 목적으로 사용할 수 있다. 실제 능력치 표시는 중급 `+`·상급 `++`를 유지한다.


## 단계별 획득 기준

최신 크기·가치 기준은 칸당 최대 1,300G, 1단계 1~2칸(최대 2,600G), 2단계 2~4칸(최대 5,200G), 3단계 4~7칸(최대 9,100G)이다. 4단계의 칸수와 최대 가치는 미정이다. 2칸·4칸은 구간이 겹치므로 크기만으로 단계를 결정하지 않는다. 기존 후보 20종의 칸수와 능력치는 이 기준에 맞춰 후속 재배정한다. 자세한 산정은 [아이템 옵션과 골드 가치](아이템옵션과골드가치.md)를 따른다.

| 단계 | 등급 | 상점 등장 | 조합 획득 | 효과 방향 |
|---|---|---|---|---|
| 1단계 | 하위 | 상점에서 바로 구매하는 기본 재료 | 상위 단계의 재료로 사용 | 기본 능력치 중심 |
| 2단계 | 중급 | 일정 확률로 등장 | 1단계 아이템 2개 조합 | 고유효과와 특수효과가 존재하는 단계. 개별 효과의 범위와 영향은 제한적 |
| 3단계 | 상급 | 아주 희박한 확률로 등장 | 일반적으로 조합으로 획득. 구체적인 재료 단계와 개수는 미정 | 고유효과와 특수효과가 존재하는 단계. 2단계보다 강화되지만 4단계와 큰 차이를 둠 |
| 4단계 | 최상급 | 등장하지 않음 | 조합으로만 획득. 구체적인 재료 단계와 개수는 미정 | 전투 규칙이나 영웅 운용을 크게 바꾸는 강력한 특수효과 |

상점 등장 확률의 구체적인 수치는 추후 설정한다. 2단계의 재료 2개가 반드시 서로 다른 종류여야 하는지는 미정이며, 기존 동일 아이템 2개 조합식은 일단 유지한다.

## 효과 분류 기준안

고유효과와 특수효과의 구체적인 경계는 다음 기준안으로 분류한다. 같은 이름의 효과 중첩 여부는 별도 결정한다.

| 구분 | 의미 | 기존 초안의 예 |
|---|---|---|
| 기본 능력치 | 장착 시 직접 더해지는 수치 | 공격력, 물리·마법 방어력, 체력, 공격속도, 가드율, 초당 회복 |
| 고유효과 | 특정 성능을 지속적으로 보정하거나 특정 조건에서 수치를 강화 | 방어력 무시, 피해 감소, 회복 효율 증가, 자동 스킬 쿨타임 감소 |
| 특수효과 | 배치, 추가 타격, 대상 수, 발동 요구 횟수 등 별도의 작동 규칙에 관여 | 인접 아이템 강화, 3회마다 추가 타격, 아군 피해 대신 흡수, 회복 대상 추가 |

2·3단계에 두 효과 유형이 모두 존재하도록 분류한다. 모든 개별 아이템에 고유효과와 특수효과를 각각 하나씩 붙이는지는 아직 확정하지 않는다.

4단계의 차이는 단순히 수치가 높은 데서 끝나지 않는다. 피해 분담, 핵심 기믹 가속, 회복 대상 확장처럼 영웅의 운용과 조합 방향에 큰 영향을 주는 것을 기준으로 삼는다. 기존 후보 효과가 이 차이를 충분히 만드는지는 이후 밸런스 설계에서 검증한다.

## 1단계 기본 구매 재료

|---|---|---|---|---|
| I01 (기존 대응) | 단검 | 2칸 | 물리 공격력 | 2,600G |
| 신규·ID 미정 | 수호원형방패 | 1칸 | 가드율 | 1,300G |
| I02 (기존 대응) | 수호방패 | 2칸 | 가드율 | 2,600G |
| I03 (기존 대응) | 가속룬 | 1칸 | 공격속도 | 1,300G |
| 신규·ID 미정 | 신속의 룬 | 2칸 | 공격속도 | 2,600G |

| 신규·ID 미정 | 활력의 원천 | 2칸 | 체력 | 2,600G |

최신 요청으로 위 7종의 이름·점유 칸수·주요 옵션을 정리한다. 실제 부여 수치와 판매가는 아직 확정하지 않는다. 칸수는 면적이며 구체적인 블록 모양도 별도 설정한다. 수호방패의 기존 고정 방어력 +100과 해당 가치 계산은 이 장비의 최신 옵션에서 폐기한다. 가드율은 기본 능력치이므로 가드율 옵션 자체에 고유효과 800G 또는 특수능력 1,500G를 별도 가산하지 않는다.

황금주머니(I05)는 골드 획득 +20%의 고유 아이템으로 지정한다. 최신 요청으로 1칸 기본 가치 1,300G에 고유효과 가치 800G를 더하여 아이템 전체 가치 2,100G를 배정한다. 실제 상점 판매가와 구체적인 중복 제한 범위는 후속 설정하며, 중복 불가 효과로 관리한다. 현재 수익 계산은 파티 보상에 효과가 한 번만 적용되는 경우다. 1라운드부터 일반·네임드·보스 보상 전체에 적용하면 19웨이브까지 추가 수입 11,600G, 총수입 69,600G다. 기존 전투 장비 7종과 별도로 관리한다. 신규 3종에 기존 I06~I20의 ID를 재사용하지 않으며, 구현 시 정식 ID를 배정한다. 게임 데이터·이미지·블록 좌표·상점·조합식에는 아직 반영하지 않았다.

### 초급 조합식 — 활력의 원천

활력의 수정 ×2 → 활력의 원천. 최신 사용자 확인으로 확정한 초급 조합식이다. 활력의 수정은 개당 1칸, 결과 활력의 원천은 2칸·체력 옵션이다. 실제 수치·조합 비용은 아직 미정이며, 재생의 부적의 재료인 활력의 원천으로 이어진다. 조합 결과인 활력의 원천은 표에서 붉은 이름으로 표시한다. 게임 코드에는 아직 반영하지 않았다.

### 추가 초급 조합식 — 신속의 룬·수호방패

- 가속룬 ×2 → 신속의 룬 (2칸·공격속도).
- 수호원형방패 ×2 → 수호방패 (2칸·가드율).

수호방패와 룬 방패는 별개다. 룬 방패의 재료는 수호원형방패 + 활력의 수정이며, 수호방패를 대신 넣지 않는다. 초급 조합 결과 3종(활력의 원천·신속의 룬·수호방패)은 모두 붉은 이름으로 표시한다. 실제 부여 수치·조합 비용은 미정이다.

### 추가 장비 후보 — 가죽 갑옷

| ID | 아이템 | 점유 칸수 | 주요 옵션 | 기본 능력치 가치 상한 | 단계 |
|---|---|---|---|---|---|
| 신규·ID 미정 | 가죽 갑옷 | 4칸 | 방어력 | 5,200G | 미정 |

최신 요청으로 4칸 방어력 장비를 추가한다. 실제 방어력 수치·물리/마법 적용 범위·블록 모양·가격은 미정이다. 초급 장비를 정리하는 문맥에서 나온 추가 요청이지만, 기존 1단계 1~2칸 구간과는 다르므로 초급 예외로 분류할지 또는 2·3단계에 배정할지는 아직 확정하지 않는다. 칸당 1,300G로 계산한 5,200G는 기본 능력치 최대 가치이며 판매가가 아니다. 게임 코드에는 미반영이다.

| ID | 아이템 | 구분 | 점유 칸수 | 부여 범위 | 부여 능력치 |
|---|---|---|---|---|---|
| 신규·ID 미정 | 철괴 | 고유 재료 아이템 | 1칸 | 같은 행의 바로 왼쪽 1칸·오른쪽 1칸 | 고유효과: 각 부여 위치에 가드율 +N% (중복 불가) |

최신 요청을 반영한 재료 아이템이다. 부여 범위는 철괴 위치를 기준으로 좌우 각각 한 칸이며, 수치는 N으로 유지한다. 기존 가드율의 직접 증가 방식으로 환산할 경우 +N%p로 계산한다. 철괴 자체의 기본 옵션, 주변 칸에 아이템이 있어야 하는지, 어떤 대상에게 능력치를 부여하는지, 최종 영웅 능력치 합산, 동일 장비가 양쪽을 차지할 때의 처리, 중첩·회전 규칙, 조합식·단계·가격·정식 ID는 아직 설정하지 않는다. 최신 요청으로 좌우 가드율 부여 기능을 고유효과로 지정하고 중복 불가로 처리한다. 고유효과 평가 가치는 800G이며, 철괴의 기본 가치와 전체 가격은 미정이다. 구체적인 중복 판정 범위는 후속 설정한다. 게임 코드에는 미반영이다.

### 장검의 중급 정밀 검 전환

### 추가 아이템 — 체력 물약·숫돌

최신 요청으로 체력 물약은 체력 재생, 숫돌은 철괴처럼 같은 행의 좌우 바로 인접한 1칸씩에 공격력 +N%를 부여하는 효과로 지정한다. 사용자의 `채력 물약` 표기는 체력 물약으로 정리했다. 체력 물약은 초급 1칸·체력 재생으로 지정했다. 초당 재생량·발동 방식·지속시간·소모 여부·가격은 미정이다. 숫돌은 1칸으로 지정했다. 증가량 N·물리/마법 적용 범위·부여 대상과 조건·중첩·고유 여부·회전·가격은 미정이다. 철괴와 같은 부여 방향을 사용하되, 철괴의 1칸·고유·중복 불가 설정까지 자동으로 복사하지 않는다. 정식 ID·단계·조합식은 별도 설정하며 게임 코드에는 미반영이다.

## 2단계 중급 조합 장비

최신 사용자 요청으로 현재 아이템 표의 능력치 숫자는 제거하고 방향·강도만 표시한다. 중급은 `+`, 상급은 `++`를 임시 강도 기호로 사용하며 실제 수치나 정확한 배율을 뜻하지 않는다. 칸수·조합식·인접 범위·추가 타격의 발동 조건은 유지한다. 초급 황금주머니 등도 목록에서는 숫자 대신 옵션 방향으로 표기한다. 이전 경제 계산의 +20%·+60%는 별도 계산 시나리오 기록으로 보관하며 실제 아이템 수치를 재확정한 것으로 취급하지 않는다.

최신 요청의 `원형방패`는 초급 수호원형방패, `물약`은 초급 체력 물약으로 연결한다. 정밀 검의 단검 + 단검, 룬 방패의 수호방패 + 활력의 수정, 재생의 부적의 활력의 수정 2개라는 이전 조합식은 위 공식으로 대체한다. 정밀 검의 기존 공격력 +40과 룬 방패의 방어력 +35·체력 +200은 최신 옵션의 확정 수치로 사용하지 않는다. 재생의 부적은 조합식만 변경하고 체력·재생 방향을 유지한다. 게임 코드의 조합식·능력치·아이템 목록은 아직 변경하지 않았다.

갈증이 담긴 구슬은 최신 요청으로 추가한 중급 상점 판매용 1칸 흡혈 아이템이며, 파괴자의 대검의 조합 재료다. 중급 2~4칸 구간의 예외로 사용자 지정 1칸을 우선한다. 흡혈 수치·적용 공격/스킬 범위·스탯 상한·가격·조합 획득 여부·고유/특수효과 여부는 미정이다. 1칸의 기본 가치 기준은 1,300G지만 실제 가격을 이 값으로 확정하지 않는다. 중급 목록은 아래 최신 이동·추가 내역을 포함해 집계한다.

매직 스태프의 중급 이동과 신규 성배·플레이트·정령의 힘을 포함해 중급은 10종이다. 성배는 2칸·보호 및 회복 증폭 옵션이며 대성배의 재료다. 성배 자체의 조합식·증폭 수치·적용 범위·가격·고유/특수효과 여부는 미정이다. 매직 스태프는 기존 마법 공격력 방향을 유지하며 재료 옵션을 자동으로 전부 추가하지 않는다. 플레이트는 최신 사용자 지정 중급 4칸·방어력 장비이며 가죽 갑옷 + 철괴로 조합한다. 실제 방어력 수치·물리/마법 적용 범위·가격·블록 모양·고유/특수효과 여부는 미정이다. 칸수 기준 기본 능력치 최대 가치는 5,200G다.

### 흑갑주의 주변 아이템 효과

- 지정 포인트는 위 2개·왼쪽 2개·오른쪽 2개·아래 2개로 총 8개다.
- 포인트에 아이템이 있을 때 아이템 개수에 따라 개당 방어력 +N%를 부여한다.
- 서로 다른 아이템이 각 포인트에 1개씩 있는 경우, 8개 기준 추가 증가율은 8N%다.
- 기본 방어력 수치, N, 증가의 기준 방어력, 물리/마법 적용 범위, 고유/특수효과 구분은 미정이다.
- 흑갑주 자체 크기는 6칸으로 지정했다. 블록 모양과 8개 포인트의 정확한 좌표는 아직 지정하지 않았다. 2×2 본체의 둘레인지 특정 기준점에서 두 칸씩인지 임의로 확정하지 않는다.
- 한 아이템이 여러 포인트를 덮을 때 한 번으로 셀지 포인트별로 셀지, 중복 장착 및 경계 밖 포인트 처리는 후속 설정한다.

기획만 반영한 상태이며 게임 코드에는 미반영이다.

기존 초안에는 2단계 고유효과로 분류할 별도 효과가 없다. 따라서 고유효과를 추가 설계해야 하며, 기본 능력치를 임의로 고유효과라고 바꾸어 부르지 않는다. 용병의 징표의 인접 범위와 증폭 대상 능력치는 미정이다.

기존 I10의 상점 전용·조합 불가 구분은 최신 단계 기준에 따라 폐기하고, 조합으로도 만들 수 있는 대상으로 변경한다.

최신 요청으로 파괴자의 대검은 물리 공격력·흡혈 방향으로 변경한다. 기존 공격력 +100·방어력 10% 무시 후보를 최신 능력치로 유지하지 않는다. 절대 방벽과 폭풍의 심장은 이번에 조합식만 지정했고 기존 크기·효과는 임시 후보로 남긴다. 재료의 칸수 합계만으로 결과 아이템의 크기를 자동 변경하지 않는다. 사용자의 `질풍검`은 질풍의 검, `룬방패`는 룬 방패로 연결한다.

이 단계에는 고유효과형과 특수효과형이 모두 존재한다. 추가 타격의 피해량·대상·다른 효과 발동 여부는 미정이다. 4단계의 핵심 기믹 변경과 차이가 나도록 효과 범위를 설정한다.

파괴자의 대검·절대 방벽·폭풍의 심장·대성배의 조합식을 지정했다. 대성배는 이번에 조합식만 변경했으며 기존 체력·회복 효율 후보 수치와 신규 성배의 보호 증폭 적용 관계는 후속 검토한다. 신비한 모래시계의 재료는 깨진 낡은 은시계 + 정령의 힘으로 지정했다. 기존 I15의 상점 전용·조합 불가 구분은 폐기하고 조합 획득을 기본 경로로 변경한다.

### 중급 정령의 힘과 신비한 모래시계

정령의 힘은 중급 2칸 장비다. 자기 기준 오른쪽 바로 인접한 1칸의 장비에 스킬증폭과 쿨타임 감소를 부여한다. `우측 한 칸`은 대상 위치이며 자체 점유 크기는 2칸이다. 블록 모양, 실제 증폭/감소 수치, 대상 장비가 가질 스킬의 범위, 중첩·회전, 가격·조합식·고유/특수효과 여부는 미정이다.

사용자의 `은시계`는 초급 깨진 낡은 은시계로 연결한다. 깨진 낡은 은시계 + 정령의 힘 → 신비한 모래시계로 조합식을 지정한다. 결과의 기존 3칸과 자동 스킬 쿨타임 20% 감소는 임시 후보이며, 정령의 힘의 스킬증폭이 결과에도 붙는지는 자동으로 확정하지 않는다. 최신 단계 집계는 초급 15종·중급 10종·상급 8종으로 33종이다. 게임 코드에는 미반영이다.

## 후속 설정 순서

1. 기본 능력치와 고유·특수효과 목록을 확정한다. 특히 2단계 고유효과의 빈자리를 설계한다.
2. 능력치 단위당 골드 가치와 고유·특수효과의 골드 가치를 측정한다.
3. 한 칸에 배정할 스탯 예산과 단계별 효율 차이를 정한다.
4. 조합 재료·가격·상점 확률을 설정한다.
5. 점유 칸 모양과 외형을 정하고 이미지를 제작한다.

## 기존 초안과의 관계

2026-11-05 사용자 요청을 반영한 기획 분류다. 단계별 획득 경로 및 상점 전용·조합 불가 구분은 이 문서가 기존 초안보다 우선한다. 기존 수치·시험 조합 4개를 기초로 유지하며, 게임 코드와 상점 확률은 아직 변경하지 않는다. 골드 가치·점유 칸 예산·이미지 디자인은 이번 분류 이후 진행한다.
