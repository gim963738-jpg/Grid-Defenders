# 아이템 옵션과 골드 가치

현재 아이템 목록의 옵션 표시는 최신 요청으로 수치 없이 중급 `+`·상급 `++`로 통일한다. 기호는 임시 강도 표현이며 수치·배율은 미정이다. 기본값·스탯 상한·칸당 가치·고유/특수효과 비용·이전 골드 수입 시나리오는 계산 기준과 기록으로 유지한다. 숫자 능력치에 의존하던 중·상급 기존 개별 산정액은 현재 가격으로 사용하지 않는다.

영웅 3명 × 장비 20칸 = 총 60칸을 기준으로 한다. 최신 합의에 따라 칸당 최대 가치는 1,300G로 설정한다. 영웅당 일반 완성 예산 20,000G와 효과를 제외한 기본 능력치 최대 가치 26,000G를 구분한다. 파티 일반 예산은 60,000G, 효과 제외 기본 능력치 최대 가치는 78,000G다. 효과를 별도 가산한 추산은 후속 절을 따른다. 실제 골드 획득량과 리롤 등 장비 외 지출은 후속 조정한다. [단계와 효과 분류](아이템단계와효과분류.md)의 기존 20종은 구성의 기초다.

## 영웅별 장비 예산과 칸당 기준

| 구분 | 장비 칸수 | 일반 완성 예산 | 칸당 평균 예산 |
|---|---|---|---|
| 영웅 1명 | 20칸 | 20,000G | 1,000G |
| 파티 3명 | 60칸 | 60,000G | 1,000G |

최신 칸당 최대 가치는 1,300G다. 개별 장비의 최대 가치는 `점유 칸수 ×1,300G`로 계산한다. 20칸을 모두 최대 가치로 채우면 효과 제외 기본 능력치 부분은 영웅당 26,000G, 파티 60칸이면 78,000G다. 이전 칸당 가치 2,000÷3G는 이 값으로 대체한다. 단계별 실제 부여 비율·효과 예산·판매가는 후속 조정한다. 칸당 최대 능력치 표는 유지한다.

## 블록 한 칸당 최대 능력치

최신 사용자 요청에 따라 `기본값을 제외한 추가 가능량 ÷ 영웅 장비 20칸`을 블록 한 칸당 최대 부여량으로 사용한다. 한 가지 스탯에 20칸을 모두 투자했을 때 해당 극한 상한에 도달하는 기준이다. 점유 칸수가 N인 아이템의 해당 스탯 최대량은 아래 칸당 최대량의 N배다. 여러 스탯을 함께 부여할 때의 예산 배분과 단계별 실제 부여 비율은 후속 설정하며, 아래 모든 최대량을 한 칸에 동시에 부여하는 것으로 취급하지 않는다.

| 스탯 | 기본값 | 극한 상한 | 기본 제외 추가 가능량 | 한 칸당 최대 부여량 |
|---|---|---|---|---|
| 공격력 | 100% | 500% | +400%p | +20%p |
| 물리 방어 | 피해 감소율 25% | 99% | +74%p | +3.7%p (기존 환산식상 고정 방어력 +250) |
| 마법 방어 | 피해 감소율 25% | 99% | +74%p | +3.7%p (고정 수치 변환은 계열별 환산식 기준) |
| 체력 | 100% | 1,000% | +900%p | +45%p |
| 공격속도 | 100% | 500% | +400%p | +20%p |
| 초당 회복 | 없음 | 상한 없음 | 제한 없음 | 상한에서 역산 불가. 별도 설정 |
| 치명타 확률 | 15% | 100% | +85%p | +4.25%p |
| 치명타 피해량 | 150% | 500% | +350%p | +17.5%p |
| 이동속도 | 100% | 500% | +400%p | +20%p |
| 회피율 | 5% | 60% | +55%p | +2.75%p |
| 가드율 | 0% | 60% | +60%p | +3%p |
| 효과 적중 | 100 | 200% | 수치 +100 | 수치 +5 |
| 저항 증가 | 증가 수치 0 (기본 저항 25) | 증가율 +99% | 증가 수치 +99 | 증가 수치 +4.95 |

%p는 기본값에 더해지는 비율 차이다. 예를 들어 공격력 한 칸 +20%p를 20칸에 배정하면 기본 100% +400%p = 500%다. 치명타 피해도 기본 150%에 +350%p를 더해 총 500%가 된다.

저항은 표시 수치 +4.95를 부여하는 기준으로, 실제 저항 수치 증가분은 기본 25 ×0.0495 = 1.2375다. 20칸 합계 증가 수치 +99이면 계산 후 저항은 25 ×1.99 = 49.75다. 효과 적중과 저항의 아이템 옵션에는 % 기호를 붙이지 않는다.

수호방패는 최신 하급 장비 기획에서 방어력 대신 가드율로 변경했다. 기존 방어력 +100 배정은 최신 수호방패에 적용하지 않는다. 칸당 최대 가치 1,300G와 위 최대 부여량을 기준으로 옵션 단가를 후속 재산정한다. 아래 기존 옵션 단가는 이전 비교용 임시값이다.

직업별 정리 카테고리는 물리·마법·탱 각각의 초급/중급/상급으로 추가했다. 주력 분류는 물리8·마법10·탱11, 공용 재료·경제·배치 보조4로 총33종이다. 다른 직업에서도 활용할 수 있는 공속·스킬·쿨감 장비는 공용 검토로 중복 표시하며 장착 제한을 뜻하지 않는다. 상세는 아이템단계와효과분류.md의 직업별 카테고리 표를 따른다.

## 현재 아이템의 용도 분류

현재 초급 15종은 공격형 5종(단검·매직로드·가속룬·신속의 룬·마력의룬), 방어형 6종(수호원형방패·수호방패·가죽 갑옷·활력의 수정·활력의 원천·체력 물약), 재료 2종(철괴·숫돌), 보조장비 2종(깨진 낡은 은시계·황금주머니)이다. 체력 물약은 체력 재생, 숫돌은 좌우 인접 각 1칸에 공격력 +N% 부여로 지정했다. 체력 물약과 숫돌은 모두 1칸으로 확정했다. 실제 수치·사용 방식·소모 여부·가격은 미정이며, 숫돌의 고유 여부도 미정이다. 용도와 단계·등급·고유효과는 별개이며, 상세 칸수와 옵션은 [아이템 단계와 효과 분류](아이템단계와효과분류.md)의 용도별 표를 따른다.

초급 조합식은 활력의 수정 ×2 → 활력의 원천으로 확정했다. 결과는 2칸·체력 옵션이며 실제 능력치와 조합 비용은 미정이다. 활력의 원천은 다시 체력 물약과 조합하여 재생의 부적이 된다.

중급 상점 판매 아이템 갈증이 담긴 구슬(1칸·흡혈)을 추가한다. 흡혈 수치·상한·적용 범위·단가·고유 여부·판매가는 미정이다. 파괴자의 대검은 정밀 검 + 갈증이 담긴 구슬 조합의 물리 공격력·흡혈 장비로 변경한다. 이전 방어력 무시 효과와 해당 가격 산정은 최신 대검에 적용하지 않는다.

최신 추가 조합식은 가속룬 ×2 → 신속의 룬, 수호원형방패 ×2 → 수호방패, 룬 방패 + 철괴 → 절대 방벽, 질풍의 검 + 신속의 룬 → 폭풍의 심장이다. 결과의 기존 크기는 유지하고 실제 수치·조합 비용·가격은 별도 설정한다. 매직 스태프의 중급 이동과 신규 성배 추가로 중급은 10종, 초급은 15종이다.

최신 마법 계열 조합은 매직로드 + 마력의룬 → 중급 매직 스태프, 매직 스태프 + 마력의룬 → 루나 스태프(마법 공격력 + 스킬증폭), 매직 스태프 + 활력의 수정 → 생명의숨결(지팡이·마법 공격력 + 보호 및 회복 증폭)이다. 루나 스태프와 생명의숨결은 상급 5칸이며 실제 수치는 미정이다. 중급 성배는 2칸·보호 및 회복 증폭이며, 활력의 원천 + 성배 → 대성배 조합의 재료다. 성배의 증폭 수치·상한·단가·가격·조합식·고유 여부는 미정이고 2칸의 기본 능력치 가치 상한은 2,600G다.

추가 중급 플레이트는 가죽 갑옷 + 철괴 조합의 4칸·방어력 장비다. 칸수 기준 기본 능력치 가치 상한은 5,200G이며 실제 방어력·가격은 미정이다. 흑갑주는 플레이트 + 용병의 징표 조합으로 기본 방어력과 주변 아이템당 방어력 +N%를 갖는다. 위·아래·좌·우 각 2개, 총 8개 포인트를 지정하며 서로 다른 아이템 8개가 각 포인트를 차지하면 추가 증가율은 8N%다. 흑갑주는 상급 6칸이며 기본 수치·N·증가 기준값·고유 여부·가격과 포인트 좌표·중복 카운트 규칙은 미정이다. 현재 중급은 10종, 상급은 8종이다.

루나 스태프·생명의숨결·흑갑주는 최신 요청으로 모두 상급으로 확정한다. 루나 스태프·생명의숨결은 각각 5칸, 흑갑주는 6칸으로 지정했다. 실제 수치·가격은 미정이다. 정령의 힘은 중급 2칸이며 우측 인접 1칸의 장비에 스킬증폭·쿨타임 감소를 부여한다. 실제 부여 수치·가격·고유/특수효과 여부는 미정이다. 신비한 모래시계는 깨진 낡은 은시계 + 정령의 힘으로 조합한다. 결과 크기·능력치 수치는 기존 임시값을 유지한다. 현재 초급 15·중급 10·상급 8 = 33종이다.

## 최신 하급 장비 구성

최신 목록은 [아이템 단계와 효과 분류](아이템단계와효과분류.md)의 1단계 표를 따른다. 단검 2칸(물리 공격력)·수호원형방패 1칸(가드율)·수호방패 2칸(가드율)·가속룬 1칸·신속의 룬 2칸·활력의 수정 1칸·활력의 원천 2칸의 7종이다. 실제 부여 수치와 가격은 미정이다. 황금주머니는 별도의 골드 획득 +20% 고유 아이템으로 지정한다.

두 방패의 가드율은 기본 능력치 예산으로 계산한다. 칸당 가드율 최대 +3%p 기준으로 원형방패 1칸은 최대 +3%p, 수호방패 2칸은 최대 +6%p다. 이는 최대 용량의 비교이며 실제 하급 장비 수치를 확정한 것은 아니다.

추가 요청 장비 가죽 갑옷은 4칸·방어력 옵션으로 기록한다. 기본 능력치 가치 상한은 4 ×1,300G = 5,200G다. 실제 방어력 수치·물리/마법 적용 범위·블록 모양·판매가·단계는 미정이다. 기존 초급 크기 구간은 1~2칸이므로 초급 예외로 둘지 별도 단계에 배정할지는 후속 설정한다.

고유 재료 아이템으로 철괴 1칸을 추가한다. 철괴의 같은 행 좌우 인접 1칸씩에 가드율 +N%를 부여하는 구상이며, 직접 증가 방식에서는 +N%p로 계산한다. 좌우 가드율 부여는 고유효과이며 중복 불가로 지정한다. 고유효과 평가 가치는 800G이고, 철괴의 기본 가치·전체 가격은 아직 미정이다. N·부여 대상·발동 조건·구체적인 중복 판정 범위·회전·조합식은 후속 설정한다. 상세 목록은 [아이템 단계와 효과 분류](아이템단계와효과분류.md)의 철괴 항목을 따른다.

매직로드는 초급 2칸, 매직 스태프는 중급 3칸이며 모두 마법 공격력을 부여한다. 매직 스태프의 조합식은 매직로드 + 마력의룬이다. 칸당 1,300G 기준 기본 능력치 가치 상한은 각각 2,600G·3,900G다. 실제 부여 수치·가격·블록 모양·단계·고유/특수효과 여부는 미정이다.

마력의룬은 1칸·스킬증폭 옵션으로 추가한다. 칸당 기준의 기본 능력치 가치 상한은 1,300G다. 스킬증폭의 실제 수치·적용 범위·계산식·스탯 상한·단가·판매가·고유/특수효과 여부는 아직 지정하지 않았다.

단검은 2칸·물리 공격력의 초급 장비다. 기존 초급 장검은 중급 정밀 검(I06)으로 대체하고 3칸·물리 공격력·단검 + 숫돌 조합식으로 설정한다. 기본 능력치 가치 상한은 3,900G이며 실제 수치·가격·고유/특수효과 여부는 미정이다. 룬 방패는 수호원형방패 + 활력의 수정으로 가드율·체력을 부여하며, 재생의 부적은 활력의 원천 + 체력 물약으로 조합한다.

깨진 낡은 은시계는 2칸·쿨타임 감소 옵션으로 추가한다. 칸당 1,300G 기준 가치 상한은 2,600G이며, 실제 감소 수치·적용 범위·계산식·중첩·쿨타임 감소 상한·단가·판매가·단계·고유/특수효과 여부는 미정이다. 기존 신비한 모래시계와 별도의 신규 장비다.

## 극한 아이템 빌드의 스탯 상한 기준

2026-11-05 사용자 요청으로 아래 전투 스탯과 상한 목표를 추가한다. 실현하기 어려운 조합까지 추구했을 때의 오버스펙 기준이며, 일반적인 완성 편성의 목표와 구분한다. 모든 스탯을 동시에 상한까지 올리는 것을 목표로 삼지 않는다. 상한 수치만으로 각 옵션의 골드 단가를 확정하지 않는다.

### 가드 피해 감소

가드 발동 시 피해를 25% 감소시키며 다른 피해 감소와 곱연산한다. 가드율은 발동 확률이고, 발동 시 감소량 25%와 구분한다.

- 가드 발동 피해 = 가드 적용 전 피해 ×0.75.
- 예: 원래 피해 100, 방어력에 의한 감소율 40%이면 가드 전 피해 60, 가드 발동 후 피해 45다. 방어력 감소율에 25%p를 더하지 않는다.

### 효과 적중 수치와 실제 판정 확률

효과 적중 스탯은 % 기호 없이 수치로 표시하고, 상한만 200%로 표기한다. 기본 효과 적중은 100이며 장비 효과가 +50이면 합계는 150이다. 실제 효과 적중 판정의 결과는 확률이므로 %로 표시한다. 예전 계산에서의 적중 배율 150%는 이제 효과 적중 수치 150으로 표기한다. 계산상의 대응은 같으며 기본 100을 두 번 더하지 않는다.

저항도 % 기호 없이 수치로 표시하고, 증가량 상한만 +99%로 표기한다. 기본 저항은 50 시험 이후 사용자가 제시한 최신 기본값 25를 적용한다. 아이템의 `저항 +45`는 내부적으로 기본 저항 대비 +45% 증가를 뜻하므로, 계산 후 저항 수치는 25 ×1.45 = 36.25다. `저항 +99`이면 25 ×1.99 = 49.75다. 기본 수치에 옵션 수치를 직접 더하는 방식으로 바꾸지 않는다. 표시 단위만 변경하며 최종 효과 적중 확률은 계속 %로 표시한다.

- 효과 적중 수치 A = 기본 100 + 장비 등으로 추가한 수치. 최대 200(상한 표시 200%).
- 계산 후 저항 수치 = 25 × (1 + min(R, 99) ÷ 100). R은 아이템 등에 표시하는 저항 증가 수치다.
- 효과 적중 확률 원값(%) = min(A, 200) − 계산 후 저항 수치.
- 실제 효과 적중 확률(%) = max(0, min(100, 효과 적중 확률 원값)).
- 추가 장비 효과가 없으면 A=100이며, 추가 수치 0을 총 적중 수치 0으로 취급하지 않는다.

| 효과 적중 수치 A | 저항 증가 수치 R | 계산 후 저항 수치 | 적중 확률 원값 | 실제 적중 확률 |
|---|---|---|---|---|
| 기본 100 | 추가 없음 0 | 25 | 75% | 75% |
| 100 | +50 | 37.5 | 62.5% | 62.5% |
| 기본 100 (추가 적중 없음) | +99 | 49.75 | 50.25% | 50.25% |
| 150 | +99 | 49.75 | 100.25% | 100% |
| 200 | +99 | 49.75 | 150.25% | 100% |
| 150 | +45 | 36.25 | 113.75% | 100% |
| 123 | +75 | 43.75 | 79.25% | 79.25% |

회피와 효과 적중의 적용 범위,스킬 자체 발동 확률의 처리 여부는 후속 설정한다.

공격력·공격속도는 기본값 포함 최종 비율로 표기하며 여러 증가 옵션의 합산/곱산 방식은 별도 확정한다. 치명타 확률의 아이템 증가량은 직접 증가(%p)로 표기하며, 기본 확률 포함 총 상한은 100%다. 치명타 피해량 상한은 기본값 포함 총 500%다. 신규 스탯의 골드 단가와 기존 옵션 단가 재조정은 후속 작업이다.

## 고정 방어력과 골드 가치

추가 방어력 0에서 기본 피해 감소율 25%, 추가 방어력 5,000에서 최대 99%가 되는 선형 환산을 작업 기준으로 사용한다. 기본 25%는 아이템의 골드 가치에 포함하지 않는다. 수호방패는 최신 요청으로 가드율 장비가 되었으므로 아래 방어력 +100 예시는 이 장비의 현재 옵션이 아니라 이전 방어력 단가 산정 기록이다.

- 피해 감소율(%) = 25 + min(추가 방어력 합계, 5,000) × 74 ÷ 5,000. 추가 방어력이 0 이상인 구간의 기준이다.
- 방어력 1 = 피해 감소율 +0.0148%p = 1.48G. 기존 피해 감소율 +1%p당 100G를 적용한 명목 옵션 단가다.
- 이전 산정 예시 방어력 +100: 피해 감소율 +1.48%p, 이전 임시 단가 기준 148G. 기본 25%에서 적용하면 26.48%다.
- 이전 산정 예시 방어력 +1,000: 피해 감소율 +14.8%p, 최종 39.8%, 이전 임시 단가 기준 1,480G다.

기본 피해 감소율에 더하는 %p와 받는 피해의 상대 감소율은 구분한다. 이 단가는 실제 생존 효율을 측정한 결과가 아니라 기존 골드 기준을 고정 방어력 단위로 환산한 값이며, 최대 상한 이후에는 피해 감소율이 더 증가하지 않는다. 상위 방어력 장비의 수치·가치 재배정은 후속 작업이다.

## 고유효과·특수능력 별도 가산 추산

이번 추산에서는 칸당 1,300G를 기본 능력치 최대 가치로 보고, 고유효과 1줄 800G와 특수능력 1줄 1,500G를 별도로 더한다. 앞서 계산한 영웅당 26,000G·파티 78,000G는 이 해석에서 효과를 제외한 기본 능력치 부분의 최대 가치가 된다. 효과 포함 최종 가치에도 같은 상한을 적용하려면 기본 능력치 예산에서 효과 비용을 차감해야 하므로 별도 구분한다.

- 아이템 추산 가치 = 점유 칸수 ×1,300G + 고유효과 줄수 ×800G + 특수능력 줄수 ×1,500G.
- 고유효과는 중복 불가다. 아래 풀템 추산은 각 장비의 고유효과가 서로 다르고 모두 유효하게 적용되는 경우다.
- 특수능력도 전부 유효하게 적용된다고 가정한다. 실제 중첩·발동 제한과 단계별 효과 부여 여부는 후속 설정한다.

| 단계 | 크기 | 기본 능력치 최대 가치 | 고유효과 1줄 추가 | 특수능력 1줄 추가 | 두 효과 각 1줄 추가 |
|---|---|---|---|---|---|

| 2단계 | 2~4칸 | 2,600~5,200G | 3,400~6,000G | 4,100~6,700G | 4,900~7,500G |
| 3단계 | 4~7칸 | 5,200~9,100G | 6,000~9,900G | 6,700~10,600G | 7,500~11,400G |

| 3단계 4개씩 (5칸씩) + 각 효과 2줄 | 35,200G | 105,600G | 27,600G 부족 |
| 3단계 5개씩 (4칸씩) + 각 효과 2줄 | 37,500G | 112,500G | 34,500G 부족 |

따라서 현재 모델에서는 돈이 남지 않는다. +20%에서 +60%로 이어지는 경제 빌드의 총수입은 파티 기본 능력치 부분의 최대 가치 78,000G와 같고, 효과까지 갖춘 3명 풀템에는 부족하다. 일반 예산 60,000G와 비교하면 18,000G가 더 있지만 이 차액을 모든 극고점 구성의 완성 여유로 보지는 않는다.

실제 판매가·조합 비용·중간 장비 판매 환급·리롤·병사 지출·경제 아이템 가격·점유 칸수·교체 시점은 아직 반영하지 않았다. 경제 아이템이 최종 장비에 포함되는지에 따라 이 비용을 별도로 더하거나 기본 장비와 중복 계산하지 않도록 설계해야 한다. 상한 수치의 동시 달성 가능성, 고유효과 중복 제한, 희귀 아이템 획득 확률과 실제 블록 모양도 별도 검증 대상이다. 현상금은 추가 보너스로 분리한 상태이며 그 금액을 자동 보충 수입으로 넣지 않는다.

## 추가로 필요한 설정

- 황금주머니는 [20웨이브 골드 보상 배정안](../01_전투/전투기본규칙.md)을 기준으로 산정한다. 현상금은 별도 보너스로 제외하고, 일반 360마리 ×100G + 네임드 2마리 ×3,000G + 10웨이브 보스 16,000G = 19웨이브까지 기본 수입 58,000G다. 시작 골드·골드 증가분·20웨이브 클리어 보상은 제외한다. 황금주머니의 보상 적용 범위와 획득 시점을 정해야 하며, 이전 +10%=150G 단가는 확정값으로 사용하지 않는다.
- 황금주머니는 1칸·골드 +20% 고유 아이템이며 기본 가치 1,300G에 고유효과 800G를 가산하여 전체 가치 2,100G로 배정한다. 시작부터 전체 기본 보상에 한 번 적용 시 추가 수입은 11,600G, 총 69,600G다. 실제 구매가 P를 빼면 순수 추가 수익은 11,600−P다. 구매가도 2,100G로 설정하는 경우 순수 추가 수익은 9,500G지만, 실제 상점 판매가는 아직 별도 설정 대상이다.
- 공격력은 숫자 1 = +1% 가정으로 산정했다. 대응이 달라지면 공격력 항목을 재산정한다.
- 수호방패가 가드율 장비로 바뀌었으므로 상위 방패의 능력치와 조합 방향을 재검토한다. 상위 방어력 장비는 이전 임시 단가로 비교한 상태이며 재조정 대상이다. 하급 7종의 실제 부여 수치·가격·블록 모양과 신규 ID를 설정한다.
- 가격 상한이 옵션 가치, 구매 가격, 조합 총비용 중 어디에 적용되는지 정한다. 모루·추가 골드 비용도 함께 설정한다.
- 고유효과 중첩 불가는 같은 효과를 가진 아이템 간 제한인지, 영웅당 고유효과 전체 한 줄 제한인지 정한다. 특수효과의 중첩 여부도 필요하다.
- 일반 장비 예산은 영웅당 20,000G, 파티 60,000G로 두고 효과 제외 기본 능력치 최대 가치는 영웅당 26,000G, 파티 78,000G로 구분한다. 효과 가산 후 가치와 최종 예산은 추가 조정한다. 옵션 단가·단계별 칸당 효율·실제 골드 획득량·장비 외 지출·완성 시점을 후속 설정한다.

## 적용 범위

2026-11-05 사용자 지정 단가와 상한을 반영했다. 이번 작업은 옵션 분류와 가치 계산이며, 기존 게임 데이터·상점 가격·조합식·전투 계산은 변경하지 않는다. 미정인 값이 있는 아이템은 최종 가격을 확정하지 않는다.
