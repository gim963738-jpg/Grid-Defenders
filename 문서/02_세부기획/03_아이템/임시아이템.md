# 임시 아이템

상태: PDF 20종을 임시 데이터 후보로 정리. 아래 시험용 칸·색상·모양은 AI 임시 설정, 확정 디자인 아님.

## 장비칸·표현
- 임시 영웅 장비칸: 가로 5 × 세로 6 = 30칸.
- 이유: 모바일 세로 화면의 폭을 과도하게 넓히지 않고 3~5칸 아이템의 회전·조합 결과를 시험할 공간 확보.
- 공용 가방: 무제한 대기 보관. 장비 그리드와 구분.
- 우선 아이템 그림 없이 색상 블록+짧은 이름으로 식별. 임시 이미지 적용도 허용되었으나 이번에는 생성하지 않음.
- 화면 내 실제 크기·위치·앵커는 미정. 이 문서의 그리드는 최종 UI 배치 승인이 아님.
- 등급 기본색: 하위 회색 #94A3B8 / 중급 초록 #22C55E / 상급 파랑 #3B82F6 / 최상급 보라 #A855F7.
- 색만으로 구별하지 않고 이름·ID를 함께 표시할 예정. 구체적 UI는 구현 전 확인.

## 효과 적용
공용 가방에서 장비칸에 배치를 완료하면 적용한다. 다른 곳에 내려놓아 장착 해제가 완료되면 해제한다. 드래그 중에는 직전 확정 배치 상태 유지.
쿨타임 아이템은 장착 후 선쿨 적용. 구체적 아이템별 시간과 재장착 시 남은 시간 처리는 미정.

## 모양 표기
`(x,y)`는 아이템 자체의 왼쪽 위를 (0,0)으로 잡은 칸 좌표다. 화면 좌표가 아니다.
↳ 쉽게 말하면: `(0,0),(1,0)`은 가로로 붙은 두 칸이다. 모양을 90도씩 돌릴 수 있다.
PDF의 불명확한 V·십자·다이아몬드는 시험용 칸 집합으로만 제안한다. 새로운 성능 효과는 추가하지 않는다.

## 미정과 제외
- PDF의 하위 조합 예시까지 포함하여 모든 조합 재료는 미정으로 둔다(후속 유저 지시 우선).
- 상점 전용·직군 전용 구분은 PDF 후보이며 세부 검토 대상.
- 아이템별 고유·일반·특수 분류, 중첩·증폭 계산, 가격·쿨타임·귀속 시점은 미정.
- 능력치·칸수는 개발 시험 후 변경 가능. 조합 재료를 임의로 만들지 않음.
- 영웅 장비칸 최종 크기를 확정하거나 실제 배치 화면을 만든 문서는 아님.

## WEB-002 연결 범위
- I01~I09의 수치형 장비만 구현. I10~I20은 데이터 후보 문서로만 유지.
- 장비칸 5×6, 배치·회전·이동·해제·영웅 간 가방 경유 양도, 직접 구매품 판매 구현.
- 배치 실패·드래그 취소는 기존 장비 상태 유지. 배치 완료 시 능력치 반영.
- 기본 수치는 합산, 공격속도% 합산 후 기본 공격속도에 곱하는 시험 계산. 고유·특수 효과 분류는 아직 미확정.
- 황금 주머니: 장착한 모든 영웅의 획득 증가율을 합산하여 처치 골드에 적용 후 버림(임시).
- 체력·방어·재생은 표시 수치에 반영. 일반전 아군 무피해라 방어·회복의 전투 판정은 없음.
- 상점 5칸, 초기 하위5종, 리롤20G로 I01~I09에서 중복 허용 추첨. 웨이브별 상품 풀은 미구현.
- 시험 가격: I01/02/04=60, I03=70, I05=100, I06/08=150, I07/09=160G.
- 판매는 직접 구매가의 절반 버림. 조합품·할인·오염의 원가 규칙에는 적용하지 않음.
- 쿨타임 아이템은 미구현. 선쿨 적용을 완료했다고 기록하지 않음.

## WEB-004 변경
- 공용 가방도5열 격자로 변경, 최소6행과 빈 여유행 표시. 보관 수량 제한 없이 행 확장.
- 구매 시 현재 방향 그대로 첫 빈 공간에 자동 배치. 해제 시에도 다른 블록과 겹치지 않는 빈 곳에 배치.
- 공용·영웅 가방 모두 더블클릭/두 번 탭으로 현재 자리에서90도 회전. 회전 버튼도 실제 즉시 회전으로 통일.
- 실패 시 방향·소유자·좌표·능력치 유지. 장비칸5×6은 고정, 공용 가방은 아래로 확장 가능.
- 공용 가방 내 이동과 두 가방 사이 이동을 지원. 드래그는 집은 블록 칸 위치를 보존.
- 상점에서 가방 선택 시 자동 메뉴 전환을 제거하고 ‘영웅에게 장착’으로 명시 전환.
- 두 탭에 보이는 공용 가방은 같은 상태를 공유하며 아이템을 복제하지 않음.
