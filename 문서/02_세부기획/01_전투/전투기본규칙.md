# 전투 기본 규칙

## 확정·현재 방향
- 세로형 모바일 웹 우선.
- 일반전: 외곽 순환 몬스터, 고정 배치 아군의 일방 공격.
- 병사: 코스트를 내고 선택 소환. 영웅: 현재 무료 선택 소환 예정.
- 보스전 중 영웅 소환 불가. 병사의 보스전 소환 가능 여부는 미정.
- 영웅 배치 완료 후 판매·교체 불가. 장비 교체·판매·조합은 가능.
- 일반전 기본 공격은 선두 우선(원기획). 순환 경로의 선두 판정·동률 처리는 추후 정의.
- 보스전: 전체 아군이 보스 진영과 이동하며 쌍방 자동 전투.
- 각 스킬은 일반전/보스전 효과를 분리한다.
  ↳ 쉽게 말하면: 같은 스킬 이름을 써도 전투 방식에 맞게 실제 효과가 달라진다.
- 예시 포효: 디펜스는 둔화·기절, 보스는 도발. 정확한 수치는 임시 영웅 문서 참고.
- 조작 중에도 전투 지속. 자동 감속 여부는 미정.

## 보류
- 보스 진형 선택 방식, 보스 전환·복귀 시 유닛 체력·사망 처리.
- 영웅 위치 이동·비용, 영웅 선택 후보 목록과 로비 사전 선택 여부.
- 공격 거리·우선순위·이동 충돌·근접 접근 방식.
- 수동 특수 스킬의 종류·발동 조건·버튼 위치.
- 일반전 전장 칸 수와 최종 UI 영역.
- 병사 종류·가격·판매율·강화 단계.
- 몬스터 생성 간격·최대 누적 수·본진 체력 규칙.
- 전투 중 유닛 경험치 레벨업은 채택하지 않은 보류 안건.

## 제외
별도 지원 타워·제단, 수동 회복 구슬은 현재 범위에서 구현하지 않는다.

## WEB-002 구현 상태 — 시험 규칙, 최종 확정 아님
- 전장 4×4 배치 칸. 보병·궁병·마법병 3종, 영웅 4종 후보 중 최대 3명.
- 같은 영웅은 중복 배치하지 않는 임시 제한. 캐릭터 최종 선택 규칙으로 확정하지 않음.
- 480G 시작. 병사 50/75/90G, 5레벨까지 강화(회당 기본 소환가×0.6×현재 레벨, 버림).
- 강화당 기본 공격력 25% 가산. 병사 판매는 소환·강화 지출 합계 50% 버림 환급.
- 몬스터 2.4초마다 생성, 이동 43 논리px/초, 체력 160+30초마다40. 처치 기본 12G.
- 누적 최대30에서 추가 생성 중지, 처치하면 생성 재개. 이번에는 웨이브·패배 처리를 구현하지 않음.
- 선두 임시 판정: 누적 이동 거리 최대, 동률이면 먼저 생성된 몬스터. 공격 사거리 내 대상만 선택.
- 영웅도 기본 공격만 연결. 클래스 스킬·상태이상·피해 유형·보스 상호 전투는 미구현.
- 전투 중단 없는 1·2·3배. 비활성 탭 복귀 시 한 프레임 최대0.1초로 제한, 실시간 오프라인 보상 없음.
- 원거리 환산을 포함한 시험 사거리는 defenseConfig.ts 참조. 논리 칸 단위의 최종 사거리와 구분.

위 값은 첫 전투를 시험하기 위한 설정이다. 보류 목록의 최종 설계를 대체하지 않는다.
