# 전투 기본 규칙

## 확정·현재 방향
- 세로형 모바일 웹 우선.
- 일반전: 외곽 순환 몬스터, 고정 배치 아군의 일방 공격.
- 병사: 코스트를 내고 선택 소환. 영웅: 현재 무료 선택 소환 예정.
- 보스전 중 영웅 소환 불가. 병사의 보스전 소환 가능 여부는 미정.
- 영웅 배치 완료 후 판매·교체 불가. 장비 교체·판매·조합은 가능.
- 일반전 기본 공격은 선두 우선(원기획). 순환 경로의 선두 판정·동률 처리는 추후 정의.
- 보스전: 전체 아군이 보스 진영과 이동하며 쌍방 자동 전투.
- 각 스킬은 일반전/보스전 효과를 분리한다.
  ↳ 쉽게 말하면: 같은 스킬 이름을 써도 전투 방식에 맞게 실제 효과가 달라진다.
- 예시 포효: 디펜스는 둔화·기절, 보스는 도발. 정확한 수치는 임시 영웅 문서 참고.
- 조작 중에도 전투 지속. 자동 감속 여부는 미정.

## 보류
- 보스 진형 선택 방식, 보스 전환·복귀 시 유닛 체력·사망 처리.
- 영웅 위치 이동·비용, 영웅 선택 후보 목록과 로비 사전 선택 여부.
- 공격 거리·우선순위·이동 충돌·근접 접근 방식.
- 수동 특수 스킬의 종류·발동 조건·버튼 위치.
- 일반전 전장 칸 수와 최종 UI 영역.
- 병사 종류·가격·판매율·강화 단계.
- 몬스터 생성 간격·최대 누적 수·본진 체력 규칙.
- 전투 중 유닛 경험치 레벨업은 채택하지 않은 보류 안건.

## 제외
별도 지원 타워·제단, 수동 회복 구슬은 현재 범위에서 구현하지 않는다.
