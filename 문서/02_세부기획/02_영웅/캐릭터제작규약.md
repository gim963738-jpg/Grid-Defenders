# 캐릭터 제작 순서와 분류

캐릭터는 출신 대륙과 클래스를 기준으로 정리한다. 일러스트 시안 승인 뒤 4방향을 제작하고, 이어 SD 시안을 승인받은 뒤 3방향을 제작한다. 생성 원본의 이미지 크기와 바이트를 보존한다.

## 출신과 클래스 선택

[캐릭터 제작 모음](../../../output/characters/char001/gallery.html)의 왼쪽에서 출신 대륙을 고르고 오른쪽에서 클래스를 선택한다. 상단 전체 클래스는 대륙 조건을 해제해 해당 클래스 캐릭터를 함께 보여준다. 등록 자료가 없는 분류도 새 캐릭터의 제작 분류로 선택할 수 있다.

첨부자료와 모든 이전 작업물은 출신·소속 미지정으로 보관한다. 기존 아르케리온 수석 빛 마법사 시안도 포함하며 현재 세계관에 배치하지 않는다. 신규 제작 캐릭터부터 사용자 설정과 선택한 출신·클래스를 기록한다. 출신 대륙과 현재 소속 국가·세력은 별도 항목이다.

## 캐릭터 설명과 태그

| 항목 | 기록 내용 |
|---|---|
| 이름 | 개인 이름. 미정이면 기존 특징을 나타내는 표시 이름 사용 |
| 특징 | 머리·복장·장비·외형을 구분하는 짧은 설명 |
| 출신 | 중앙·서·남·동·북대륙 또는 출신 미지정 |
| 소속 | 제국·왕국·도시·마탑·가문·부족·민족 등 확인된 국가와 세력 |
| 클래스 | 전사·검사·기사·궁수·마법사 등의 탐색 분류 |
| 직업 | 수석 빛 마법사처럼 실제 설정에서 정한 직업 |
| 무기 종류 | 장검·단검·활·지팡이 등 확인된 장비 |
| 배운 공격 계열 | 특정 검술·주술·도법·빛 마법 등 실제로 정한 계열 |

확인되지 않은 소속·직업·무기·공격 계열은 미지정으로 기록한다. 카탈로그의 외형에 따른 클래스 분류와 확정된 직업명은 구분한다. 무기를 들었다는 이유만으로 특정 검술 학파를 만들어 넣지 않는다.

[캐릭터 목록](../../../자료/캐릭터설정/캐릭터목록.json)과 [제작 순서 데이터](../../../자료/캐릭터설정/제작순서.json)를 원본 설정으로 사용한다.

## 중앙대륙 마법사 소속

중앙대륙 마법사의 기본 소속은 아르케리온의 독립 세력인 마탑이다. 왕국 소속 네 마법가문은 별도로 분류한다. 이 가문들은 마탑을 떠나 왕국에 몸을 맡긴 마법사들이 세웠으며, 마탑 출신 계보와 현재 소속은 구분한다.

에르디안·칼레도르는 친왕파 봉신가문, 벨사르는 귀족파, 오르딘은 중립이다. 가문별 전문 마법은 에르디안 화염마법, 칼레도르 공간마법, 벨사르 물속성 마법이며 오르딘은 특정 계열에 국한되지 않는 종합형이다. 가문의 전문 분야를 근거로 개별 인물이 배운 모든 마법이나 구체적인 스킬을 자동 확정하지 않는다.

이 소속 규칙은 앞으로 중앙대륙에 배치하는 신규 캐릭터에 적용한다. 기존 수석 빛 마법사 시안을 포함한 이전 작업물에는 중앙대륙·아르케리온·마탑 소속을 부여하지 않는다. 예전 제작 제목과 입력은 과거 시안의 기록이며 현재 세계관 배치를 뜻하지 않는다. 세력·가문 정의는 [세계관 설정집](../00_세계관/세계관설정집.md)과 [구조화 설정](../../../자료/세계관/세계관설정.json)을 따른다.

## 제작 순서

1. 출신·소속·클래스·직업·특징·무기·공격 계열을 기록한다.
2. 일러스트 시안 **1장**을 제작한다. 기본 시안은 오른쪽 앞 사선이며 요청 구도가 있으면 그 구도를 따른다.
3. 사용자의 명시적인 통과를 기다린다. 수정 요청이면 시안을 수정하고 다시 확인한다.
4. 승인된 디자인으로 일러스트 **4장**을 제작한다.
5. 완성한 일러스트를 바탕으로 SD 시안 **1장**을 제작한다.
6. SD 시안도 별도로 사용자의 명시적인 통과를 기다린다.
7. 승인된 SD 디자인으로 SD **3장**을 제작한다.

승인용 시안은 최종 방향 세트와 구분해 보관한다. 단순한 원본 보기·저장·최근 버전 표시는 시안 통과를 뜻하지 않는다. 이후 사용자가 순서를 직접 바꾸면 최신 요청을 적용한다.

| 형식 | 승인 후 제작할 방향 | 최종 방향 수 |
|---|---|---|
| 일러스트 | 정면 0도 · 오른쪽 정측면 90도 · 오른쪽 앞 사선 약 45도 · 후면 180도 | 4장 |
| SD | 정면 0도 · 오른쪽 정측면 90도 · 후면 180도 | 3장 |

정측면과 사선을 구분한다. 머리 크기·키·장비 위치·기준 높이를 같은 인물의 각 방향에서 맞춘다. 비대칭 무기와 장비는 인체 좌우를 유지하고 반대 방향을 단순 좌우 반전으로 만들지 않는다.

GC9 일러스트는 기존 그림체 기준을 적용한다. 드워프족의 평균 키 140cm와 땅딸막한 체형 등 종족 설정을 유지한다. SD의 픽셀 여부와 세부 표현은 사용자 요청을 따른다.

GC9 전신은 [여백 기준](../../../자료/캐릭터설정/GC9_프레이밍기준.json)에 따라 초기 기본값으로 상단 20%·좌우 각각 15%·하단 6%의 빈 여백을 확보한다. 기존 성인형 비율을 유지하면서 인물과 장비 전체의 화면 점유율을 줄인다. 한 캐릭터의 방향 세트는 같은 배율과 발 기준선으로 맞추고 원본 해상도·바이트를 보존한다.

2026-11-08 결정에 따라 SD는 **기존 SD 픽셀 스타일**을 기본 적용하고 [SD 공통 제작 기준](SD_공통제작기준.md)·[프롬프트](SD_생성프롬프트.md)·[구조화 기준](../../../자료/캐릭터설정/SD_공통제작기준.json)을 먼저 읽는다. 은발·날개 지팡이의 실제 원본을 체형과 프레이밍 기준으로 첨부한다. 기준 1254×1254에서 머리끝 y=253·발선 y=1178·인물 높이 926px이며 무기와 장비는 별도로 측정한다. 직업별로 본체 크기를 바꾸지 않는다. 새 SD 시험 스타일은 폐기되어 활성 참조로 사용하지 않는다.

## 원본 저장과 목록 등록

각 생성 결과의 실제 폭·높이·파일 경로·SHA-256과 프롬프트를 기록한다. 저장할 때 원본을 확대·축소하거나 JPEG로 다시 인코딩하지 않는다. 카드 표시 크기는 원본 파일 크기와 구분한다.

이미지는 캐릭터별로 묶어 보고, 상세 보기에서 같은 인물의 방향·형식 이미지를 전환한다. 이미지별 보기에서는 개별 방향과 이전 버전도 볼 수 있다.

신규 폴더는 스캔 대상·분류 로직·캐릭터 목록에 함께 등록한다. 일러스트와 SD의 버전 계열, 승인용 시안과 최종 방향 세트를 구분한다. 기존 8방향·걷기 시트·이전 테스트 자료는 보관 분류와 원래 경로를 유지한다.

## 한손 무기 공통 그립

검·도·몽둥이 등 한손 손잡이 근접무기는 사용자 확정 [한손 무기 그립 기준](한손무기그립기준.md)을 기본 적용한다. 실제 원본 자세·손가락 연결 참조를 첨부하고 팔·손목·다섯 손가락의 연결과 무기 축을 유지한다. 새로운 그립 승인 절차를 추가하지 않는다.
