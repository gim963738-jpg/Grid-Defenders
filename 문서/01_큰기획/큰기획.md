# Grid Defenders — 큰기획

상태: 원자료와 유저 답변을 정리한 초안. 최종 문서 확인 대기.

## 1. 방향과 참고
- 실시간 테트리스 인벤토리 관리 2D 타워 디펜스.
- 모바일 웹 우선, 세로 화면. 이후 Google Play 앱 출시 목표.
- 개발 구성: PixiJS + TypeScript + Vite. WEB-001에서 실행 기반 구성·검증 완료. 앱 포장 방식 미선정.
- 일반전: 운빨존많겜·랜덤다이스의 상단 순환 전장과 하단 조작 형태 참고. 무작위 소환·합성을 채택한 뜻이 아님.
- 보스전: Legion TD 2처럼 아군과 적군이 이동하며 싸우는 전개 참고.
- 장비창: 템빨용사: 픽셀 아이템 머지 RPG·실버앤블러드 참고.
- 채팅 이미지 6장은 약 50% 미완성 구상. 그림의 버튼·수치는 자동 확정하지 않음.
- 최종 디자인은 유저가 외부 유료 AI 등으로 준비 예정. 임시 이미지 적용 허용.

## 2. 전체 흐름
로비 성장·관리 → 게임 진입 → 병사·영웅 선택 소환 → 일반 웨이브 자동 전투 → 골드로 병사·장비 확보 → 장비 배치·조합 → 10웨이브마다 보스전 → 40웨이브 최종 보스.

일반전 중에도 전투를 멈추지 않고 장비·상점을 조작한다. 배속 지원. 정확한 배속 값은 미정.
최종 승리 보상·복귀, 중도 이탈·재접속 처리는 미정.

## 3. 전장과 유닛
- 몬스터는 외곽 길을 순환. 일반전에서 아군만 몬스터를 공격.
- 병사: 선택 소환, 골드 비용. 판매·단계별 강화 가능(원기획).
- 영웅: 현재 무료 선택 소환 예정. 일반전 중 소환, 보스전 소환 불가.
- 배치한 영웅은 판매·다른 영웅으로 교체 불가. WEB-004 유저 지시에 따라 영웅·병사 위치 이동과 모든 유닛 간 자리교체 허용.
- 기본 영웅 3명, 영구 성장으로 4번째 슬롯 해금(원기획).
- 전장 16~20칸은 원기획 범위이며 정확한 배치 칸 수 미정.
- 영웅·병사만 대상으로 진행. 별도 지원 제단은 보류.
- 상세: [전투 규칙](../02_세부기획/01_전투/전투기본규칙.md), [임시 영웅](../02_세부기획/02_영웅/임시영웅.md).

## 4. 장비와 인벤토리
- 영웅별 장비칸·무제한 공용 가방. 아이템 이동·회전.
- 원기획 4×5는 고정 아님. 현재 임시 크기와 블록은 [임시 아이템](../02_세부기획/03_아이템/임시아이템.md)에 정의.
- 장착 완료 시 효과 적용, 다른 곳에 놓아 장착 해제 완료 시 효과 해제. 드래그 도중만으로 상태 변경하지 않음.
- 쿨타임 아이템은 선쿨 적용. 재장착 악용 방지 세부 계산은 미정.
- 고유: 동일 효과 최대값 하나 / 일반: 중첩 / 특수: 조건부 효과(원기획). 개별 분류는 추후.
- 공용 조합템 양도 가능, 클래스·영웅 전용템 귀속(원기획). 구체적인 귀속 시점 미정.
- 판매 환급: 재료 원가 합계 절반의 소수점 버림(원기획). 비조합템·할인·오염 원가 기준은 추후 정의.

## 5. 경제·상점·조합
- 전투 골드, 웨이브 보상. 시작액·보상·가격은 미정.
- 상점 상시 사용, 유료 리롤·구매. 웨이브별 상품 등급 변화(원기획).
- 수동 소환 몬스터를 통한 모루 획득 구상. 모루는 아이템 조합 기회를 주는 재화.
- 모루와 골드 동시 지급은 밸런싱 때 결정. 조합식·모루 저장 및 소비 단위 미정.
- 오염은 일반 할인과 구분되는 위험·보상 제도. [오염과 정화](../02_세부기획/03_아이템/오염과정화.md) 참고.

## 6. 보스전과 종료
- 총 40웨이브, 10·20·30·40에서 전용 전투로 전환.
- 병사·영웅이 이동하며 몬스터와 쌍방 자동 전투.
- 진형은 랜덤·로비 선택·전투 중 선택 중 보류.
- 특수 스킬 하나 정도를 원하는 시점에 쓰는 방식 고려. 수동/자동 최종 방식 미정.
- 보스 후보: 10 기본 전력 검사 / 20 물리 대응 / 30 타격 횟수 대응 / 40 탱커 생존 대응. 원기획의 임시안이며 수치·판정 미확정.
- 패배 후보: 누적 몬스터 한계 초과, 본진 체력 0, 보스전 아군 전멸(원기획).
- 순환 구조에서 본진 체력 감소 방식, 보스 후 사망·체력·위치 복귀는 미정.
- 영웅 교체 불가가 우선. 특정 보스에서 신규 영웅 교체를 강제하는 것으로 해석하지 않음.

## 7. 로비·영구 성장
- 닉네임·랭크·레벨·재화 헤더, 시작 버튼, 병사 관리·상점·영웅 메뉴(원기획).
- 입장 토큰·에너지, 병사 수치 성장, 영웅 스킬 성장, 아바타·내실 효과(원기획).
- 실제 UI·성장 비용·결제·서버·계정 시스템은 미정. 아직 구현 승인 없음.

## 8. 순차 개발안 — 제안, 미승인
1. 큰기획 확인 및 플랫폼·엔진 선택.
2. 최소 전장·선택 소환·자동 공격·웨이브·패배 처리.
3. 영웅 장비칸·색상 아이템·효과 반영.
4. 상점·골드·모루 조합.
5. 이동형 보스전·모드별 스킬.
6. 오염·정화 등 확장 기능.
7. 로비·영구 성장·앱 출시 준비.

각 단계의 작은 기능을 개별 문서·작업으로 나눠 승인받는다. 이 순서는 구현 명령이 아니다.

## 현재 구현 — WEB-002
유저의 “가능한 만큼 최대한 구현 진행”에 따라 디펜스 시험 범위를 확장했다.
- 순환 적·선택 소환·일반 공격·골드 수급·병사 강화와 판매.
- 영웅 기본 공격, 무료 소환·3명 제한·판매 교체 금지.
- 수치형 장비9종, 5×6 장비칸·회전·이동·해제·공용 가방·상점 구매·리롤·판매.
- 라벨 구역 이미지 기록.
- 영웅 스킬·40웨이브·패배·보스·모루 조합·오염·정화·로비는 미구현. 완성 게임 아님.

이번 구현은 제안 단계들을 한 번에 최종 확정한 것이 아니라 가능한 시험 동작을 연결한 것이다.

## WEB-004 수정
유저 요청으로 유닛 이동·자리교체, 영웅 선택 시 장비창 자동 연결, 보병 부채꼴·마법병 원형 다수 타격, 격자형 공용 가방·두 가방 더블클릭 회전을 추가했다. 구체적인 시험 수치와 검증은 WEB-004 작업 기록 및 세부기획 참조.

## WEB-012 최신 구현 현황
- 일반50처치마다 현상금 수동 소환 기회, 활성1마리·처치 기본100G/모루1. 정상 모루 획득→조합 연결 완료(시험값).
- 병사 치명타10%·1.5배, 타격 실제 피해 숫자, 병사 이동 목표 잔상 추가.
- 이전 WEB-002 현황의 ‘모루 조합 미구현’은 후속 WEB-006~012로 대체. 영웅 스킬·40웨이브·승패·보스·오염/정화·로비는 미구현 유지.

## WEB-014 최신 시험 범위
- 30초 무한 웨이브, 일반10마리·시간 끝나면 일반 정리, 네임드/현상금 유지. 현재 테스트 중에는 실패 패배 없음.
- 일반형·물리/마법 방어형 및5웨이브마다 준보스급 네임드. 공격/방어 계열 분리, 같은 타입 피해0.75 임시 계산.
- 현상금은3웨이브마다 수동 소환 기회·대기3·활성1. 이전50처치 조건 대체.
- 정식40웨이브·진짜 보스전·승패·영웅 스킬·로비는 후속 기획 유지. 이번 무한 시험 모드와 구분.
