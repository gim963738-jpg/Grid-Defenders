# 4_정의문서.md

waveBossRoster: 실제 웨이브 유닛과 game.stats 결과를 복사. 슬롯의 행을 전열순서로, 열을 중앙 세로행으로 변환. 4×8 배치판·좌측 아군 유지. 보스 진입 때 편성/레벨/장비능력치 변화가 있으면 새 편성으로 초기화, 변화 없으면 기존 시험 이어가기. 개발자 다시 시험은 최신 웨이브 편성으로 강제 초기화. 웨이브 미배치 시 임의 아군 생성하지 않음. 원딜 미배치 시 영웅기술 비활성.
원딜 사거리=웨이브 현재사거리×1.5(기본345), 다른유닛=웨이브현재사거리. 체력은 전투시작시 현재 최대체력. 정식 방어공식은 기존 임시 일치방어0.75배 유지.
얼음수정 속도320, 목표추적, 도착시반경48범위피해·0.45초폭발·8파편. 동일 geometry로 Pixi/SVG 표시. 평타와3연타 모두 발사 순간 피해 없음. 전열 우선은 주표적 선택에 적용하고 폭발범위에 후열이 있으면 함께 피해. 보스 시험 피해/사망은 웨이브편성을 변경하지 않음.
