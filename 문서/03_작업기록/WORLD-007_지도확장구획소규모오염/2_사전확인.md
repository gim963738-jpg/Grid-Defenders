# 입력과 기준

원본은 오염지역 지명이 있는 지도 v22다. 기존 도시·국가·요새·엘프의 숲·드워프 지하왕국·큰 오염지역·차원 균열의 정체성과 인접 관계를 유지하면서 도시 사이의 땅과 내륙을 넓혔다.

대륙 구획은 실선, 내부 방향 구역은 점선으로 지정했다. 지리 구획을 새로운 국가나 정치적 종속 관계로 바꾸지 않는다. 작은 충돌지에는 지명과 번호 표식을 넣지 않는다.

내장 이미지 생성 도구와 imagegen 스킬을 사용했다. 희망 생성 크기는 3072×2048이었으나 실제 도구 반환 원본은 1536×1024였다. 실제 반환 크기와 바이트를 보관한다.
