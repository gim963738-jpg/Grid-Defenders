# 제작과 확인

내장 image_gen 한 번으로 넓은 내륙과 줄어든 도시 비중을 가진 가로형 지도를 생성했다. 기존 지명 16개와 새 구역명 20개, 총 36개 표기를 시각 확인했다. 작은 운석 충돌지 3곳은 서대륙 내륙·중앙 개활지·남부 사막 변두리에 이름 없이 배치됐다.

실제 원본은 1536×1024 불투명 RGB PNG다. 프로젝트 사본은 생성 원본과 바이트가 동일하며 확대 보간하지 않았다. v17~v22 해시도 유지됐다.

설정집 v1.5에 각 대륙의 지역 구획 표를 추가했다. 확장 지도에 맞춰 기존 표식 10개의 좌표를 갱신하고, HTML 지도 비율과 폭·높이도 실제 PNG 크기를 사용하도록 바꿨다.

구조 검증에서 이름 39개와 연결 경로 14개를 확인했다. 별도 숨김 브라우저에서 실제 지도 비율 3:2, 이미지와 표식 영역의 일치, 다섯 지역 표 각각 4행, 소규모 오염지 3곳의 무명 상태를 확인했다.

PC·390px·320px에서 가로 넘침 없이 표시됐고 버튼 높이는 최소 44px다. PC와 모바일 실제 렌더링 PNG를 열어 지도·표식·범례 배치를 확인했다. 전체 설정집의 새 구획·작은 오염지 설명과 기존 소수민족 국력 설정도 확인했다.
