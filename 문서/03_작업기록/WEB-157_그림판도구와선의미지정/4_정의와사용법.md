# 그림판 도구·선의 의미 지정 — WEB-157

2026-11-06. 사용자 최신 요청: 직선/곡선, 뒤로가기/초기화를 추가하고 선을 곧바로 이펙트로 쓰는 대신 ‘방향’, ‘구현됐을 때 모습’ 등 의미를 다양하게 부여한다. WEB-156의 색상별 고정 용도 UI를 대체한다. 기존 저장은 변환하거나 삭제하지 않고 이전 역할을 호환한다.

## 사용법

1. 공방 새로고침 → **그리기** → 필요하면 **새 그림 작업**. 주소: `http://127.0.0.1:5182/effect-workshop.html#drawing`.
2. **자유선**은 드래그, **직선**은 시작~끝을 드래그한다. **곡선**은 먼저 양 끝을 드래그하고, 다음으로 굽힐 곳을 한 번 누르거나 끌어서 확정한다. 중간에는 곡선 확정 버튼을 쓰거나 뒤로가기로 미완성 곡선을 취소할 수 있다.
3. 노랑/빨강/파랑/직접 선택 색은 편집용이다. 새 선의 의미는 기본 **미지정**으로, 그림만으로 이동/효과를 만들지 않는다. 그리기 전에 새 선의 의미를 미리 선택할 수도 있다.
4. 목록에서 선을 고르고 **이 선의 의미**를 정한다.
   - **방향·이동 경로**: 캐릭터 또는 연결할 모양/이펙트의 경로. 선 자체는 빛으로 출력하지 않는다.
   - **완성됐을 때의 모습**: 선을 순서대로 그리는 동작 대신 모양 전체를 표시한다. 윤곽 또는 닫아서 채운 외곽으로 사용한다.
   - **선을 따라 발생하는 연출**: 진행 방향대로 빛나는 선/빛 이동/끝점 폭발 등의 연출을 재생한다.
   - **참고·위치 표시**: 설명용 그림으로 보관하며 생성/이동/재생 길이에 반영하지 않는다.
   - **직접 의미 정의**: ‘빛3 분열 위치’, ‘완성 시 검날 외곽’ 등 이름을 자유롭게 적고 미리보기 적용 방법을 별도로 정한다. 기본은 참고 보관이다.
5. 각 선에 이름/의미와 상세 설명을 적는다. 모양/경로 연출의 **연결할 방향선**을 고르면 모양의 중심이 그 방향선을 따라 움직이고 같은 단계로 맞춰진다. 연결을 해제하면 그린 위치에 표시한다. 방향선 삭제/의미 변경 시 종속 연결을 해제하며 undo로 함께 복원한다.
6. **선택·점 수정**에서 끝점/굽힘점을 끈다. 곡선은3개 기준점으로 유지되어 자연스러운 곡선을 수정할 수 있다. 방향 반전도 곡선의 굽힘을 유지한다.
7. **뒤로가기**는 직전 저장된 변경을 취소하고 **다시하기**는 복원한다. 미완성 곡선은 먼저 취소한다. **초기화**는 현재 그림/설명을 지우고 자유선·미지정 상태로 돌아간다. 다른 보관함 작업은 유지하고 초기화한 그림/설명은 뒤로가기로 복구한다.
8. 전체 설명과 선별 설명을 보관하고 **설명 반영** 또는 **AI에 세부 요청**을 쓴다. 미지정·참고 선에는 설명만으로 임의의 효과를 만들지 않는다. 직접 정의한 이름을 자동으로 이해해 새 동작을 실행하지 않으며 선택한 적용 방법만 미리보기에 사용한다.
9. **설정한 선으로 미리보기**를 누른다. 아무 선에도 적용 가능한 의미가 없으면 먼저 의미를 정하도록 안내한다. **방향과 완성 모습 예제**는 방향 직선/완성 곡선/지면 참고선을 따로 지정한 예제다.

## 호환·데이터 계약

`gd.effect@1`/`drawing.version:1`을 유지하고 선택 필드를 확장했다. 기존 선에 purpose가 없으면 role move는 방향(캐릭터), slash/effect는 기존 경로 연출로 읽는다. 새로운 UI의 선에는 purpose를 명시한다. 새 도구의 역할은 색에서 추정하지 않는다.

- `purpose`: `unassigned|direction|appearance|path|reference|custom`.
- `meaning`:160자 이내 사용자 정의 의미. `behavior`:custom의 적용 방법 `reference|direction|appearance|path`.
- `guideColor`:편집용 HEX, 기존 `color`는 실제 효과색.
- `directionTarget`: `actor|effect`. 캐릭터 이동은 같은 단계에 하나만 허용한다. 이펙트 방향선은 같은 단계에 여러 개 가능하다.
- `directionId`:모양/경로가 연결할 방향선 ID. 존재하고 실제 direction이어야 한다. followActor와 중복 적용하지 않는다.
- `tool`: `pen|line|curve`. 직선 anchors는 시작/끝2점, 곡선 anchors는 시작/굽힘/끝3점이다. 곡선 points는 이차 베지어의33샘플이다. 기준점과 샘플의 불일치는 검증 오류로 표시하여 편집 모습과 렌더 결과가 달라지지 않게 한다.

미지정/참고 선은 시간표에서 제외한다. 실제 모양·방향의 시간은 단계/지연/길이로 정하고, 기존 최대64프레임·60초·24선·256점 한계를 유지한다. 편집 중 곡선의 미확정 데이터는 실행 취소/작업 전환/취소 때 저장하지 않는다. 별도 프로젝트로 이동하면 미확정 선이 새 프로젝트에 섞이지 않게 취소한다.

## 표시·전투 경계

신규 그림도 투명 콘텐츠 캔버스 → 기존 `SkillFrameSpec/createSkillFrame/SkillFrameArt` 경로,24px 여백/고정 pivot/균일 배율을 사용한다. 완성 모습과 방향선은 서로 다른 데이터이고, 방향선 좌표를 따라 모양 중심을 이동시킨 결과를 PNG로 출력한다. 참고선/편집 손잡이는 PNG에 들어가지 않는다.

영웅/스킬은 미배정이며 피해/사거리/대상/타격 수/쿨타임을 생성하거나 변경하지 않는다. 캐릭터 이동 정보는 기존 배치 JSON의 actorMotion, 편집 정보는 drawing으로 보관한다. 실제 게임 스킬 적용은 별도다. 사용자 후속 질문의 3D VFX는 투명 배경의 렌더 프레임 시트를2D 전장에 재생하는 방식으로 가능하다고 안내했으며, 이번 작업에 실시간3D/외부 시트 가져오기는 추가하지 않았다.
