# 범위와 완료 조건
수정 대상: landscape-entry.ts/landscape-game.css, 배치 계획을 공용으로 쓰는 landscape-inventory.ts, 가로 모드 GRID, 개발 장비 배치, 기존 main의 선택/정보 표시 브리지 및 회귀 검사.
완료 조건: 미리보기와 실제 드롭의 위치/비용 일치, 가방 겹침/빈 배경 취소 시 아이템·재화 유지, 회전 및 조합 결과가 장비판 안에 배치, 올바른 파랑/노랑 연결, 카드와 초기화/보스전 왕복 정상.
로비 페이지·전투 진입/복귀 라우팅·로비 영웅 데이터 연결은 수정하지 않는다. 스킬/평타의 피해 수치·시트 추출·모션 좌표는 변경하지 않는다.
