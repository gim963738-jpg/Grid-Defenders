# 정의

| 항목 | 값 |
| --- | --- |
| 캐릭터 확대 | 100~400%, +/−는 25%씩 |
| 이동 | 마우스/터치 드래그, 확대된 캔버스 경계 안으로 제한 |
| 휠/핀치 | 포인터 또는 두 손가락 중점을 기준으로 확대 |
| 발 확대 | 200%, 하체 중심 |
| 전체 보기 | 100%, 중앙, 현재 프레임 유지 |
| 시트 확대 | 100/150/200/300/400%, 패널 안에서 스크롤 |
| 기본 재생 | 기존 30프레임, 30fps, 무한 재생 켜짐 |
| 원본 상태 | 스프라이트·APNG 변경 없음 |
| 개선 설계 | 제안, 아직 게임에 미구현 |

상세 설계: [동작개선설계.md](../../../output/characters/gc9_longsword_dagger/run_right_30f_v01/동작개선설계.md).

핵심 방향은 달리기의 지지/공중/회수 자세를 먼저 고정하고, 머리·머리카락·얼굴·천·무기를 부착점이 있는 부위로 나누는 것이다. 바람과 표정은 게임 시간·실제 피해 확정 이벤트를 읽는 표현 상태로 구현한다. Pixi 웨이브 화면과 DOM/SVG 보스 화면에서 같은 상태를 사용한다. 수치·타이밍은 첫 시안을 위한 제안값이다.
