# 개인 이펙트 공방 — WEB-155

2026-11-06. 사용자 요청: 참고 사이트와 같은 방식으로 혼자 사용할 이펙트 공방부터 제작. 기존 프로젝트에서 로컬 실행하며 별도 배포/로그인 없이 사용한다. 참고 사이트의 소스·디자인·프리셋 자산을 복사하지 않았고, 기존 Pixi/Canvas와 프로젝트 자산으로 자체 구현했다.

## 사용

1. `게임/이펙트공방열기.cmd` 더블클릭 또는 `게임` 폴더에서 `npm.cmd run workshop` 실행. Node.js 필요, 처음에는 npm 의존성을 설치한다. 기본 주소 `http://127.0.0.1:5182/effect-workshop.html`. 이미 서버가 있으면 주소를 바로 연다.
2. 기본 효과(황금 참격/화염 폭발/불꽃/얼음/마법진/회복) 선택 또는 새 이펙트에서 작업을 만든다. 변경은 현재 브라우저에 자동 보관된다. 작업 복제/삭제/검색/실행 취소/다시 실행을 제공한다.
3. 레이어는 참격·섬광·충격파·파티클·마법진·화염. 표시/순서/추가/삭제, 각 색상 인덱스, 합성 방식, 중심/반경/회전/개수/시간 등을 편집한다. 선택한 종류에 사용하는 속성만 노출한다.
4. 이미지32~256px/2~64프레임/1~60FPS, 부드러운 표현 또는2/4px 도트. 배속0.25×/1×/5×, 정지, 한 프레임씩 이동, 스크럽, 반복을 지원한다. 미리보기 반복은 작성 편의용으로 기본ON이며 출력의 `settings.loop`와 독립이다. 숨긴 탭/열린 대화창에서는 재생 시간을 넘기지 않으며 렌더링이 느려도 경과 시간을 임의로 버리지 않는다.
5. 밝은 배경의 전체 프레임 및 실제 게임의 전장 렌더러로 검수한다. 전장 상단/중앙/시전자 발밑을 선택하거나 화면을 눌러 기준점을 이동한다.
6. 작업 JSON은 재편집/백업용, PNG 시트와 배치 정보 JSON은 게임 연결용이다. 현재 프레임/밝은 배경 검수 이미지도 별도 출력한다.

## AI 작업 연결

`AI 작업 요청`에서 원하는 변경을 적고 현재 작업 전체와 스키마가 포함된 프롬프트를 복사하거나 TXT로 받는다. 대화에 전달해 받은 완전한 JSON을 가져온다. 사이트 안의 자동 생성 API/외부 AI 호출은 없다. `gd.effect@1`은 자체 형식으로 PXF 그래프를 변환 없이 가져오지 않는다. 파일과 붙여넣기는512KB 이하, 최대12레이어, 저장함100작업까지다.

## 프레임·원본·배치 계약

- 대상 영웅·평타·스킬 및 웨이브/보스 적용 여부: 현재 미배정. 공방 연출 자산이며 기존 피해 배율·타수·사거리·대상·쿨타임·캔슬 규칙을 생성/변경하지 않는다. 실제 스킬 연결 시 스킬 구현 규약의 피해/대상/시간 계약을 별도로 작성한다.
- 원본: 절차적 도형과 고정 시드의 파티클로 생성한 콘텐츠 캔버스. `background:'transparent'`. 원본 JSON은 자동 저장/내보내기로 보존한다. 공개 사이트의 원본 PNG/그래프는 사용하지 않는다.
- 모든 프레임은 `SkillFrameSpec → createSkillFrame → SkillFrameArt`를 사용한다. 콘텐츠 `size × size` 바깥 사방24px 여백/동일한 발광 패딩 처리를 사용하며 투명 이미지에 암부 제거를 다시 수행하지 않는다.
- `placement.pivotX/Y`는 콘텐츠 기준0~1. 원본 기준점은 `(size*pivotX,size*pivotY)`, 패딩 이후 기준점은 `(24+size*pivotX,24+size*pivotY)`. 한 동작의 기준점을 고정하고 전장 배율은 `displaySize / contentHeight`로 균일 적용한다. 패딩 때문에 효과가 작아지지 않는다.
- 그림이 콘텐츠의 바깥2px에 닿는 프레임은 표시하고 PNG 시트/현재 프레임/게임 배치 JSON 출력을 막는다. JSON 백업과 밝은 검수 이미지는 가능하다. 패딩으로 잘림을 숨기거나 경계를 강제 삭제하지 않는다. 효과가 아예 없는 출력도 막는다. 원본 크기/레이어 중심/반경을 조정한다.
- 실제 전장 미리보기는 `Defense` 독립 모델과 `createDefenseView`를 사용한다. 틱·전투 공격·피해·경제·보상·플레이어 저장은 적용하지 않는다. `createDefenseView.effectLayer`를 노출해 효과를 본체보다 위, 이름/체력 등 라벨보다 아래에 놓는다. 기존 호출에는 영향이 없다.
- 타격 표시는1부터 시작하는 `placement.impactFrame`. 배치 정보의 `impactTimeMs=impactFrame/fps*1000`은 해당 프레임이 끝난 시점이다. 현재는 시각 표식이며 피해 발생기가 아니다.

## 출력 JSON

- 작업: `format:'gd.effect@1'`, `name`, `settings{size,frames,fps,pixelSize,loop}`, `palette`(HEX3개), `placement{pivotX,pivotY,displaySize,impactFrame}`, `layers`.
- 레이어: 고유한 영문/숫자/밑줄/하이픈 `id`, `name`, `type`, `enabled`, `blend:'normal'|'add'`, `color:0|1|2`, `x/y`, `start/end`, `radius`, `thickness`, `rotation`, `spread`, `amount`, `speed`, `opacity`, `seed`. 스키마/범위는 `src/effect-workshop/model.ts`가 단일 정의다. 가져오기는 스키마 검증 후 허용한 필드만 재구성하고 코드/URL을 실행하지 않는다.
- 시트: `format:'gd.effect-sheet@1'`, 투명 배경, 콘텐츠 크기, 패딩, 셀 크기/행/열, 프레임별 셀/콘텐츠 사각형/패딩 후 pivot/anchor/durationMs, 전체 durationMs와 타격 완료 표식을 포함한다.
- 셀은 이미24px 패딩이 적용되어 있다. 게임 연결 시 전체 셀과 제공 anchor를 사용한다. `contentRect`는 패딩 전 콘텐츠의 추출 위치를 설명하는 정보이며, 내보낸 전체 셀에 배경 제거/패딩을 중복 적용하지 않는다.

## 저장·구현 위치

현재 origin의 `grid-defenders.effect-workshop.v1`만 쓴다. 게임 저장 키는 쓰지 않는다. 읽기 실패 시 원본 데이터를 덮어쓰지 않는 임시 모드, 쓰기 실패 시 JSON 백업 안내. 브라우저 저장은 계정/서버 동기화가 아니며 다른 포트/브라우저/시크릿 모드에서 공유되지 않는다.

화면: `게임/effect-workshop.html`. 모델/렌더러/독립 전장/화면/스타일: `게임/src/effect-workshop/`. 빌드 입력은 기존 Vite 다중 페이지에 추가했다. 모바일은 `mobile-ui.css`의 여백/본문14px·보조12px/48px 조작 기준을 사용하며480px까지의 작업용 세로 화면, 데스크톱은3패널 작업실이다.

## 범위

현재는 정해진2D 도형을 합성하는 첫 버전의 제작 도구다. 자유 드로잉/캐릭터 동작 생성/이미지 시트 편집/자유 연결 노드 그래프/원본 PXF 호환/외부 AI 자동 호출/서버 저장/기존 영웅 스킬에 자동 적용은 포함하지 않는다. 기능 구현 및 작성자 검증과 사용자의 최종 외관 확인은 별개다.
