# 분류 수정과 검증

기존 13개 제작 묶음은 `source_group` 출처로 보관하고, 화면용 카테고리 6개를 따로 정의했다. 제작본에 GC9 적용 여부를 기록해 테스트 마무리/과정으로 분류했다. 유지 대상 외의 참조는 첨부자료로 모았다. 동일 파일 사본의 연결 문서도 합쳐 보존했다.

카테고리별 고유 이미지 수는 은발 지팡이 12개, 테스트 마무리 시안 32개, 테스트 과정 작업물 70개, 첨부자료 31개, GC9 참조 16개, SP13 참조 13개다. 모든 고유 이미지는 카테고리 하나에 속한다.

검증 결과:

- 고유 이미지 174개·실제 경로 179개·기존 갤러리 항목 83개 보존. 모든 원본 SHA-256 일치.
- 생성 기록·프롬프트 등 연결 문서 139개와 HTML/JSON 일치 확인.
- GC9 마무리 32개, 비GC9 과정 70개, 첨부자료 31개와 보존 대상 3묶음의 소속 확인.
- Orca 기존 갤러리에서 6개 카테고리, 검색·구도·버전 필터, 더 보기·원본 보기·배경 전환 확인.
- 은발 지팡이의 최근본 8장·초안 3장·참조 1장 유지 확인.
- 모바일 너비 390에서 가로 넘침과 원본 보기·접힌 필터 확인.
- 브라우저 확대 배율에 따른 소수점 레이아웃 차이는 원본 배율 검사에서 0.5픽셀 이내 허용. 이미지 자연 크기 1254와 CSS 지정 너비 1254px는 유지.
- `git diff --check` 통과.

이미지 생성·이미지 리샘플링·외부 API 호출은 수행하지 않았다.
