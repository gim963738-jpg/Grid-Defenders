# 저장과 보존

프로젝트에 PNG·설정·정확한 프롬프트·생성/참조 기록·검수 결과를 보관했다. 내장 도구의 기본 생성 경로에 있던 원본도 유지했다.

카탈로그 빌더에 중앙제국 수석 빛 마법사의 출처·캐릭터·구도·문서 링크를 추가하고 JSON/HTML을 함께 갱신했다. 신규 왼쪽 카테고리는 추가하지 않았다. 금발 전사 10장과 SD 8방향 순서도 유지한다.

사용자 첨부의 소속 표기와 지도 표기는 원문으로 기록했고 지도 이미지와 세계관 명칭을 수정하지 않았다. 기존 이미지·프롬프트·인계 자료, 게임 코드·task.md·API 연결/키 설정은 변경하지 않았다. 커밋·푸시는 수행하지 않았다.
