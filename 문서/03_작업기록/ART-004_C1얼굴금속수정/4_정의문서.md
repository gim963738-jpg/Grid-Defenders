# 사용자 선호와 수정 버전 정의

| 항목 | 정의 |
|---|---|
| c1-1 | 기존 c01_front에 해당하는 정면 |
| c1-2 | 기존 c01_threequarter에 해당하는 사선 |
| C4 | 사용자 평가상 전체·얼굴 표현 최우선 기준. 금속도 긍정 평가 |
| C3 | 사용자 평가상 금속 표현 최우선 기준 |
| C1 V2 | 구성과 비율을 유지하고 얼굴선·피부 광택·금속 면과 장식 가독성을 수정한 새 PNG 2장 |
| 100% 원본 비교 | PNG 1픽셀을 CSS 1픽셀로 표시. JPEG 축소본 확대와 구분 |
| 200% 보기 | 원본 픽셀 확대 관찰. 해상도 증가가 아님 |

C2~C6와 이전 C1은 수정하지 않는다. C1 V2의 최종 화풍 선호는 사용자 확인 전이다.
