# C1 V2 제작과 검수

내장 `image_gen`으로 C1 정면·사선을 각각 1회 생성했다. 정면은 이전 C1·C4 얼굴·C3 금속을, 사선은 새 C1 정면·이전 C1 사선 구도·C4 얼굴·C3 금속을 참조했다.

두 파일의 실제 크기는 1024×1536이다. 정면은 2048×3072 요청과 반환 크기가 달라 실제 값을 기록했으며 고해상도 출력이나 업스케일 완료로 주장하지 않는다.

[원본 비교](../../../output/character-redesign-6x2/revisions/c01-v2/comparison.html)에서 이전·새 파일을 실제 100% 크기로 표시한다. 브라우저의 원본·표시 너비가 모두 1024임을 확인했고, 얼굴·흉갑·방패·손의 화면 캡처를 열어 비교했다. 정면·사선 전환과 200% 관찰용 확대도 확인했다.

[정확한 생성 기록](../../../output/character-redesign-6x2/revisions/c01-v2/생성기록.json)과 [검수 결과](../../../output/character-redesign-6x2/revisions/c01-v2/검수결과.md)에 프롬프트·참조 순서·실제 크기·해시·수정 범위를 기록했다. 기존 전체 비교 화면에는 C1 수정본 링크를 추가했다.

사용자 평가를 AGENTS.md·그림체 기준·프롬프트 문서에 반영했다. 수정본에 대한 최종 사용자 판단은 별도다.
