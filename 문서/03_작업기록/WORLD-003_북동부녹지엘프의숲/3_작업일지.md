# 제작과 확인

내장 image_gen에 전체 지도와 표시 확대본을 함께 전달해 한 번 생성했다. 새 녹지 육지가 기존 양쪽 해안에 닿고, 호수 서쪽에서 연결 녹지까지 이어지는 숲과 “엘프의 숲” 표기가 보이는 결과를 선택했다.

원본 반환 크기는 1254×1254, 불투명 RGB PNG다. 생성 원본과 프로젝트 복사본의 바이트가 동일하며 확대·축소하지 않았다. v17·v18·v19의 해시도 이전 기록과 일치한다.

설정집 v1.1에 자연 거점 항목을 추가하고 최신 지도 경로를 v20으로 바꿨다. 엘프의 숲 위치와 지형 설명만 기록했으며 국가·정치 소속은 미지정으로 보관했다. 지도 열람본에 지리·거점 메뉴와 8번 표식을 추가했다.

구조 검증에서 기존 다섯 대륙·두 수도·네 가문·두 부족·두 신을 유지하고 이름 17개, 연결 경로 14개를 확인했다. 브라우저 검사에서 지도 v20, 메뉴 7개, 표식·범례 8개와 엘프의 숲 선택을 확인했다. 390·320px 화면에서도 가로 넘침이 없고 버튼 높이는 최소 44px이다.

오른쪽에 열려 있던 전체 설정집도 새 지도와 숲 설명으로 갱신했다.
