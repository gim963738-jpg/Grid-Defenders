# 4_정의문서.md

DPS=해당 전투 누적 실제 피해/전투 경과시간(평균). 웨이브는각웨이브 시작시, 보스는시험 초기화시 집계 초기화. 보스 일시정지·재진입은 같은 집계 유지. 기록100건제한과 독립된 누적집계. 아군만 표시하고 피해를 준 유닛부터 행 생성, 판매·사망 후 기여분 유지.
웨이브는hit에서 실제 체력감소량 기록. 보스는동시 피해합에서실제 체력감소량을구하고 각공격피해비율로 배분하여 초과피해·중복집계 방지. 얼음투사체는발사시가아닌 도착시피해 집계, 범위피해는피해자별실제합. 치명타·스킬보너스 포함, 적공격 제외. 초기시간0은DPS0으로표시.
