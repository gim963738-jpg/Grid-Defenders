# OPS-003 대화·승인 근거

2026-11-09 사용자: “그럼 지금구성 세팅먼저 진행해줄래”. 앞서 합의한 운영 방식의 실제 구성 세팅 승인이다.

- 사용자가 게임 방향·최종 합격·애니메이션 재생 속도를 결정한다.
- 메인은 요청·수정 내용을 이해하고 사용자 확인 후 팀장에게 제작 지시한다.
- 실제 게임과 기존 작업을 조사해 필요한 팀장을 구성한다. 예시 조직의 9개 팀에 고정하지 않는다.
- 고정 담당은 팀장급까지, 별도 테스터 AI를 둔다. 하위 에이전트는 필요 시 활용하며 기존 작업·이력·규정을 보존한다.
- 외주 요청·수령은 팀장 책임. 완성 스프라이트를 불필요하게 분해·재조립·재생성하지 않는다. 게임 적용은 원본을 유지하고 지정 위치·사용자 결정 속도로 한다.
- 분류·배치는 메인 담당 실무. 진행 중 부서 신설이 필요하면 필요성과 책임 범위를 설명한 뒤 진행한다.
- 게임 서버·결제·라이브 운영은 제외. 외부 제작 계정 연결·유료 생성은 후속 준비다.

OPS-001·002 결과와 사용자의 기존 제작물·미커밋 상태를 보존한다. 이번 요청은 조직·규정·담당 창 세팅이며 새 게임 콘텐츠 제작 승인은 아니다.
