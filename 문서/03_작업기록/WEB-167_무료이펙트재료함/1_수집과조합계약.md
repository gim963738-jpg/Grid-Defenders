# WEB-167 · 무료 이펙트 재료함

2026-11-07. 사용자 요청: 상업적 부분유료화 게임에 사용할 무료 이펙트를 규약에 맞게 수집하고 분해·조합하기 좋게 구성한다.

## 수집 범위와 이용 조건

직전 대화의 Kenney Particle/Smoke, unTied Games 무료 Gigapack, CodeManu 무료 VFX, OpenGameArt 특수 효과 모음, CraftPix 무료 이펙트 팩을 조사한다. 유료 확장분은 구매하지 않는다. 실제 확보한 팩/파일/애니메이션/정적 재료/색상 변형을 구분해 집계하고 다운로드 실패·로그인 필요·불명확한 이용 조건은 명시한다.

원본 ZIP과 라이선스 원문·출처 URL·다운로드 시각·SHA256을 보존한다. 수정본에도 출처 정보를 연결한다. 원본 소재 재배포 및 제작 도구 번들 제한이 있는 팩은 공개 배포용 public/dist에 포함하지 않는다. 개인 공방의 로컬 재료함과 실제 게임에 넣을 완성 연출을 구분한다.

## 원본·분해

원본 파일은 보존하고 별도 정규화 출력에 개별 프레임·셀 좌표·원본 크기·프레임 시간·출처를 기록한다. 시트의 셀 크기와 프레임 수는 포함된 메타데이터와 실제 파일 구조로 판단한다. 이미 합쳐진 이미지의 불꽃·빛·연기를 원래 제작 레이어처럼 복원했다고 표현하지 않는다. 프레임/구간 단위 분해와 여러 재료의 합성을 지원한다.

이미 투명한 원본의 RGB/알파를 유지한다. 검은 배경으로 확인되는 원본은 별도 처리와 기록 없이 투명 자료로 취급하지 않는다. 프레임별 개별 크롭으로 기준점을 흔들지 않는다. 패딩과 원본 콘텐츠 표시 배율을 분리한다.

## 조합과 전투 계약

개인 공방에서 재료 미리보기, 프레임 구간, 시간, 위치, 균일 크기, 회전, 불투명도, 합성을 조절하고 결과를 PNG/배치 정보/출처와 함께 출력한다. 피해·사거리·대상 수·쿨타임·명중 시점은 변경하지 않는다. 기존 공방 저장함은 보존한다.

밝은 배경과 투명 여백을 확인하고 실제 게임 연결 여부와 검수 범위를 정확히 기록한다. 미리보기 재생/정지·배속, 모바일 공통 터치 영역, 관련 기능 검사 및 빌드를 검증한다.
