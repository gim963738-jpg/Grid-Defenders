# WEB-167 · 무료 이펙트 재료함 구현과 사용법

2026-11-07. 스킬 구현 규약을 적용했다. 상업적 부분유료화 게임에 쓸 무료 소재 수집과 개인 공방의 분해·조합이 범위이며, 실제 전투 피해·사거리·대상 수·쿨타임·명중 프레임은 추가하거나 변경하지 않았다.

## 확보한 자료

- 34개 무료 팩, 원본 배포 파일 63개(약 622MiB). 전체 개인 보관함은 원본·정규화·검수 이미지를 합쳐 약 1.93GiB.
- 기본 재료 497개: 애니메이션 314개, 정적 파티클/텍스처 183개.
- 크기·FPS 변형 포함 632개: 애니메이션 449개, 정적 파티클/텍스처 183개. 총 14,561프레임.
- unTied 무료 Gigapack 105종 × 2크기, CodeManu 22종 × 30/60FPS, Kenney Particle/Smoke, OpenGameArt CC0 모음, CraftPix 무료 효과 6팩.
- CraftPix는 사용자가 브라우저에서 로그인한 뒤 공식 다운로드 버튼으로 받았다. 인증 쿠키·비밀번호·OAuth 토큰을 추출하거나 보관하지 않았다. Kenney Smoke도 공식 브라우저 다운로드를 사용했다.
- OpenGameArt의 Lasers and beams는 칸 크기가 제각각이고 일부 그림이 원본 가장자리에서 끊겨 있어 임의 격자 분해하지 않았다. 원본은 다운로드 가능하다. 효과가 아닌 풀 배경 2팩도 원본만 보관했다.

보관 위치: `.local/effect-materials/`. `acquisition.json`은 출처·라이선스·배포 파일 SHA256, `catalog.json`은 재료·원본 셀·순서·시간·기준점·여백, `licenses/`는 확인한 이용 조건, `archives/`와 `originals/`는 원본, `normalized/`는 가공 아틀라스와 밝은 전체 프레임 이미지다. 원본 ZIP을 유지하므로 이름이 같은 중복 추출 파일도 원래 배포본에서 확인할 수 있다. AI/EPS/Blend/SMP/Spine/XCF/PSD 등의 제공된 작업 파일도 ZIP에 보존했다.

## 여는 방법

기존 `게임/이펙트공방열기.cmd`를 실행한다. 공방의 **무료 이펙트 재료함**, 갤러리의 **무료 재료함** 링크를 누르거나 `http://127.0.0.1:5182/effect-materials.html`을 연다.

1. 움직이는 바둑판에서 재료를 누르면 조합에 추가된다. 이름·종류·제작자로 검색하고 크기/FPS 변형을 함께 볼 수 있다. 페이지당 24개가 재생되며 화면 밖 항목은 그리기를 쉰다.
2. 시작·끝 프레임으로 필요한 구간만 고른다. 출발 시각, 속도, 마지막 프레임 유지, 나타남·사라짐을 조절한다. 위 레이어부터 그리므로 뒤에 추가한 레이어가 앞에 보인다.
3. 위치, 균일 크기, 시작 각도와 재생 중 회전량, 마지막 크기 배율, 색상 회전, 불투명도, 합성, 반전, 원본 기준점을 바꾼다. 레이어는 최대 12개다.
4. **프레임·출처 보기**에서 밝은 회색/초록 배경의 모든 프레임을 보고 원하는 낱장을 PNG+출처 ZIP으로 받는다. **사용법·출처**에서 원본 배포 파일과 제작자 페이지를 연다.
5. **전장에 보기**에서 상단 길/중앙, 0.25×·1×·5×, 재생/정지, 특정 시각 슬라이더로 실제 전장 렌더를 확인한다. 이 미리보기는 독립 전투 모델이며 게임 저장이나 피해를 발생시키지 않는다.
6. **게임용 PNG 시트 + 출처 ZIP**을 누른다. 모든 출력 프레임의 경계 접촉을 검사하며, 닿는 경우 크기/위치를 조절하도록 해당 프레임 번호를 알려준다. 안전 여백을 포함한 PNG, 프레임 좌표·원본 크기·기준점·시간 JSON, 편집 조합 JSON, CREDITS.txt가 함께 나온다.

빠르게 시작할 때는 **화염 폭발 / 번개 참격 / 마법 발동**을 누른 뒤 재료와 색을 바꾼다. 기존 조합을 바꾼 작업도 되돌리기로 복원할 수 있다. 모바일에서는 카드를 선택하면 조합 화면으로 이동하며 **재료 목록으로** 버튼으로 돌아간다.

## 형식과 보존

조합은 `gd.material-composition@1`, 출력 좌표는 `gd.sprite-animation@1`이다. 원본 재료는 로컬 ID로 참조하며 외부 이미지 URL이나 코드가 포함된 입력을 실행하지 않는다. 기존 절차적 `gd.effect@1`과 다른 형식이므로 공방의 기존 JSON 입력에 붙이지 않는다. 조합의 JSON 열기를 사용한다.

기존 작품 저장 키 `grid-defenders.effect-workshop.v1`은 변경하지 않는다. 별도 `grid-defenders.material-composition.v1`에 자동 저장한다. 작업 중 사용자의 본 공방에서 작품 15개와 청염 화염방사 활성 ID를 읽기로 확인했으며, 검사는 별도 5191 포트에서 진행했다.

분해는 원본 낱장/시트의 프레임과 구간 단위다. 합쳐진 PNG에서 불꽃·연기 등의 원래 제작 레이어를 자동 복원하는 기능은 아니다. 원본 FPS가 없는 자료는 **원본 FPS 미기재 · 편집 기본 15 FPS**로 표시하며 사용자 조정이 가능하다. 모든 재료의 기본 기준점은 원본 캔버스 중심이고 수정할 수 있다. 프레임별 자동 중앙 정렬이나 크롭으로 모션을 흔들지 않는다.

## 이용 조건 처리

26팩은 개별 제작자 페이지에서 CC0를 확인했다. unTied는 제공된 license.txt의 상업 게임 이용·크레딧 의무·소재/제작 도구 재배포 제한을 적용한다. CodeManu 페이지의 public domain 설명과 CC BY 4.0 표시가 달라 보수적으로 CC BY 4.0 크레딧·라이선스 링크·변경 표시를 출력한다. CraftPix 6팩은 무료 라이선스의 상업 게임/수정 허용과 원본/수정 소재 재배포·소재 추출 도구 배포 제한을 따른다.

- [unTied 무료팩](https://untiedgames.itch.io/super-pixel-effects-gigapack)
- [CodeManu 무료팩](https://codemanu.itch.io/vfx-free-pack)
- [CraftPix 이용 조건](https://craftpix.net/file-licenses/)
- [Kenney Particle 제작자 배포](https://opengameart.org/content/particle-pack-80-sprites), [Smoke](https://kenney.nl/assets/smoke-particles)
- [OpenGameArt 수집 대상 모음](https://opengameart.org/content/special-effects-cc0)

다운로드 원본을 공개 앱의 public 폴더에 넣지 않았다. Vite 개발 모드의 로컬 전용 `/__materials/` 경로만 허용된 파일을 읽는다. 빌드에는 개인 재료가 복사되지 않는다. 다른 사람에게 원본 소재 모음/내보내기 도구를 배포하지 않고, 자신이 만든 게임용 결과에 해당 출처를 적용하는 흐름이다. 원본과 검수용 이미지/ZIP은 Git 제외 경로다.

## 검증 결과와 한계

- 타입 검사와 프로덕션 빌드 통과.
- 모델·실제 UI·출력 34개 검사 통과: 순방향/역방향의 가변 프레임 시간, 지연/유지/페이드, ID 보존, 미확인 재료 입력 거절, 구간 편집, 복제, 초기화/되돌리기/다시하기, 출처, 갤러리 재생/정지, 메모리 캐시 교체 중 합성 누락 방지, 추천 조합 3개 전체 프레임 출력.
- 14,561프레임 전수 자동 검사: 14,335프레임은 원본 RGBA와 정확히 일치, 검정 매트 226프레임은 검정 위 재합성의 채널 오차 2 이하. 모든 원본 좌표 범위·출력 투명 여백·고유 ID 확인.
- 원본 셀 경계에 닿는 소재 359개는 표시했다. 투명 여백을 더해도 원래 잘린 그림이 복원된다고 간주하지 않는다.
- 밝은 배경의 전체 프레임 검수 이미지를 632개 생성했다. 직접 눈으로 확인한 것은 대표 팩과 조합이며, 전체 632개 재료의 모든 프레임을 수동 승인한 것은 아니다.
- 샘플 출력 39프레임 ZIP의 CRC, 모든 PNG 외곽, 프레임 매핑, 필수 크레딧 검사 통과. 3개 추천 조합 모두 출력 검사 통과.
- 전장 상단/중앙의 실제 표시 확인. 0.25×·1×·5× 및 정지 검사 통과. 320/390px, DPR3에서 가로 넘침 없음, 조작 버튼/요약/메뉴 48px 이상 확인. 390px 전장의 실제 렌더 버퍼 1170×1290 확인.
- DPR3 상태의 Orca 스크린샷에 브라우저 캡처 왜곡이 있어 시각 산출물은 DPR1로 별도 촬영했고, DPR3는 레이아웃/버퍼/기능 측정으로 확인했다.
- 로컬 파일 경로/Origin/Host/쓰기 제한 검사와 PNG·PSD·ZIP 원본 다운로드 확인. 공개 빌드에 원본/카탈로그 미포함 확인.

증거: `output/effect-materials/functional-checks.json`, `mobile-320.json`, `mobile-390.json`, `export-and-private-route.json`, `.local/effect-materials/frame-audit.json`. 직접 게임 스킬에 장착하거나 공개 배포한 작업은 아니다.

## 재수집·재생성

1. `python 게임/tools/collect-effect-materials.py` — 공개 무료 배포 자료 수집. 네트워크/서버 실패는 acquisition.json에 기록한다.
2. CraftPix와 Kenney Smoke는 공식 브라우저로 로그인/다운로드 후 `python 게임/tools/import-material-downloads.py`. 로그인 정보를 읽는 스크립트가 아니다.
3. `python 게임/tools/build-material-catalog.py` — 확인된 구조를 기준으로 로컬 아틀라스/작은 미리보기/밝은 전체 프레임 이미지/목록 생성.
4. `python 게임/tools/validate-material-catalog.py` — 모든 프레임 원본·좌표·투명 여백 검증.

수집 도구는 Python requests, Pillow, NumPy를 사용한다. ZIP 경로 이탈과 과도한 압축 해제 크기를 검사하며 배포 파일 내 코드를 실행하지 않는다.
