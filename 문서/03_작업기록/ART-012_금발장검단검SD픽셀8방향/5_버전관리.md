# 저장과 분류

새 SD 픽셀 8장·프롬프트·참조/생성 기록·ZIP·비교 페이지·검수 자료를 별도 버전 폴더에 저장했다. 기존 GC9 일러스트와 은발 지팡이 묶음은 유지했다. 이전 이미지 경로 183개 모두 SHA-256이 바뀌지 않았다.

카탈로그 빌더에서 중첩 픽셀 폴더를 상위 GC9 폴더보다 먼저 분류하고, 일러스트와 픽셀의 버전 계열을 분리했다. 새 화면 카테고리는 추가하지 않았다. 픽셀 표시는 파일의 화풍 정보로 정하고, 제작 도구 서버에는 기존 공개 컬렉션 경로 안의 ZIP 다운로드 MIME을 추가했다.

게임 코드·task.md·API 키나 모델 연결 설정은 수정하지 않았다. 내장 생성 도구의 기본 저장 원본도 유지했다. 커밋·푸시는 수행하지 않았다.
