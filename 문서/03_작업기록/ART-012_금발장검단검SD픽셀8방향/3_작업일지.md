# 생성과 검수 · 2026-11-07

내장 image_gen으로 방향별 투명 PNG 8장을 개별 생성했다. 정면 → 오른쪽 정측면·후면 → 남은 사선과 왼쪽 정측면 순서로 참조를 이어 사용했다. 모든 호출과 참조 순서·해시·정확한 프롬프트·기본 생성 경로를 기록했다.

실제 크기는 8장 모두 1254×1254다. 생성 파일과 프로젝트 사본의 SHA-256이 같으며 확대·리샘플링·좌우 반전·색상 배경 제거는 하지 않았다. 모든 파일에서 투명 픽셀과 불투명에 가까운 피사체 픽셀을 확인했고, 가시 외곽은 캔버스에 닿지 않는다.

밝은/어두운 배경의 전체 8방향과 정면 원본 100% 렌더를 시각 확인했다. 무기 두 자루·장검 가드의 고리·청색 사선 장식·두 종류 장화·양발 입상·앞뒤 얼굴과 후드 구분을 확인했다. Orca의 DOM·모바일·원본 배율 검증은 통과했으나 이 탭의 캡처는 빈 화면으로 저장되어, 별도 숨김 headless Edge 렌더를 통해 실제 외곽과 얼굴·금속 표현을 확인했다.

ZIP은 PNG 8개만 포함하며 각 항목의 바이트가 원본 PNG와 일치한다. 제작 모음은 191개 이미지 경로·186개 고유 이미지·6개 카테고리다. 이전 183개 경로의 해시가 유지됐다. 새 픽셀 8장은 테스트 과정 작업물, 기존 GC9 메인은 테스트 마무리 시안에 각각 남겼다. 파일·분류·링크·검색·모바일 브라우저 검증과 제작 도구 서버 테스트 7개를 통과했다.

방향별 작은 생성 편차가 남아 있으며 사용자 최종 승인으로 표시하지 않았다. 이번 결과는 정지 이미지 8장이며, 게임의 공통 발 기준점·픽셀 격자 정규화와 애니메이션 통합은 별도 작업이다.
