# 현재 규칙
`landscape-hero-selected`를 받을 때 현재 메뉴가shop이면shop을 유지하고 나머지는hero로 진입한다. 영웅 카드 선택도 정보창을 갱신하며 미배치 영웅은 임시 전투 유닛 정보로 기존 stats 계산을 미리 본다. 로비 편성/성장 데이터를 새로 연결하지 않는다.

정보창은 체력·공격력(피해 종류에 맞는 이름)·공격 속도·물리 방어·마법 방어·사거리·치명타 확률/피해·체력 재생·골드 획득을 표시한다. 장비는 선택 영웅 소유만 표시하고 비활성 이유를 함께 보여준다. 일반 정보창과 상점 가방은 동시에 열리지 않는다. 빈 곳/Escape/전투 장면 전환 시 닫는다.

재화는 x4~88/y144~216, 전장 전체 배경은x94부터다. 두 영역 사이6px 간격을 확보한다. 영웅 정보창은 우측4px/상단44px/208×312px이며 기존 상점 가방208×246px은 유지한다. 구현·관련 검증 완료.
