# 변경과 검증

2026-11-07 프로필 21종과 클래스 분류 10개를 등록했다. 출신 대륙과 클래스의 교차 선택, 상단 전체 클래스, 캐릭터별 묶음·개별 이미지 보기, 같은 캐릭터의 방향 이미지 전환을 구현했다.

이름·특징·태그 검색과 이전 자료 필터, 구형 묶음 주소와 금발 전사의 SD 8방향 우선 순서를 유지했다. 상단 클래스 선택은 대륙과 남은 검색 조건을 해제한다.

일러스트 시안 승인 후 4방향, 이어 SD 시안 승인 후 3방향 제작을 규약·구조화 데이터·AGENTS·GC9 프롬프트에 연결했다. 원본 보기나 최근 버전 표시는 승인으로 처리하지 않는다.

파일 검증에서 이미지 193개 보관 경로의 해시·원본 크기와 이전 목록 83개 항목을 확인했다. 브라우저에서는 중앙대륙+마법사 1명, 전 대륙 궁수 4명, 빈 분류의 제작 문맥, 캐릭터 21종·최신 이미지 85장, 전체 이미지 188장과 페이지 추가를 확인했다.

금발 전사 10장과 앞 8장의 방향 순서, 은발 지팡이 8장과 관련 이미지 전환, 원본 1254px 실제 표시, 중복 보관 경로, 대륙·클래스 북마크 복원을 확인했다. 390·320px에서 가로 넘침이 없고 버튼 높이는 최소 44px이다.

PC·모바일 실제 렌더링을 확인했고 최종 PC 화면의 이미지 21장이 모두 로드되는 것도 확인했다. 로컬 서버의 문서·프로필 읽기 경로를 확장한 뒤 기존 검사 7개가 통과했다. 이미지 생성 API는 호출하지 않았다.
