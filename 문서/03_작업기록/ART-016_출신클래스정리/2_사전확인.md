# 입력 자료와 범위

기존 갤러리·빌더·정리 기준과 사용자가 표시한 상단 클래스 위치·카드 영역을 확인했다. 세계관의 다섯 대륙, 수석 빛 마법사 설정, 기존 이미지·문서·일부 원본을 확인해 프로필을 정리했다.

기존 자료는 이미지 경로 193개, 고유 이미지 188장, 중복 경로 5개다. 최신 이미지 85장·이전 버전 39장·참조 64장과 기존 7개 보관 묶음을 유지한다.

개인 이름·소속 국가·배운 학파는 확인된 설정만 기록했다. 카탈로그 클래스는 정리용 분류이며 실제 직업명과 별도로 보관한다. 출신은 중앙대륙 분류 1명, 미지정 20명으로 등록했다.
