## 영상에서 반영한 특징

1080×1080/30FPS/86프레임의 약 2.867초 클립이다. 영상의 캐릭터는 오른쪽에서 왼쪽으로 분사한다. 노즐 주변은 주황색, 중심은 흰색에 가까운 강한 빛, 전방의 넓은 외곽은 파란색과 청록색이다. 분사 중 작은 불꽃과 큰 외곽이 계속 바뀌고, 차단 후 푸른 잔불이 먼저 나간 위치에서 소멸한다.

캐릭터 준비/회수 동작을 제외한 **2.4초·64프레임**으로 구성했다. 영상에 겹친 적·캐릭터·피해 숫자·UI와 경계에서 잘린 부분이 있으므로 원본 픽셀을 분리한 출력이 아닌 **절차적으로 새로 그린 재현**이다. 원본 영상은 보존했고, 분석용 프레임은 `output/flamethrower/`에만 저장했다. 원본 영상과 캡처를 배포용 소스 묶음에 넣지 않았다.

## 결과와 편집

- 이름 **청염 화염방사**, 프리셋 ID `flamethrower`. 기존 기본 효과18종에 추가해 총19종이다.
- 사용자 저장함의 기존13개 작업을 ID·시각·레시피 원문 그대로 보존하고 새 작업1개를 저장했다. 새 ID는 `87c133c8-cafe-4f3d-973f-2a0c50709351`, 저장함14개와 자동 저장 상태를 확인했다.
- `flamethrower.ts`의 전용 `jet` 레이어가 연속 분사와 시간 차단을 담당한다. 분사된 부분의 이동 시간을 기준으로 노즐부터 꺼지고 앞쪽 잔불이 남는다. 지속 구간에서는 단발 폭발처럼 계속 약해지지 않는다.
- 흰 중심의 불규칙한 모양, 푸른/청록 외곽 조각, 가는 주황색 분사줄기, 작은 불씨와 부드러운 잔광을 합성한다. 시작의 짧은 푸른 불꽃은 별도 레이어다.
- 공방에서 분사 길이·두께·퍼짐·움직임 속도·개수·랜덤 시드·불투명도와 팔레트를 수정한다. 노드의 원본 레이어/변환/색상/페이드/합성도 기존대로 사용할 수 있다. `jet` 형식 검증과 AI 요청의 지원 종류 목록을 연결했다. FPS 표시만 소수 두 자리로 읽기 쉽게 정리했고 실제 타이밍 값은 유지했다.
- 기본 방향은 왼쪽, pivot은 발이 아닌 노즐(.84,.52)이다. 원본256×256, 사방24px 패딩, 셀304×304, 8×8 시트, 콘텐츠 표시220px. `impactFrame=6`은 완료 시각 표시이며 피해에 연결하지 않는다.

`게임/public/effect-recipes/flamethrower/`에 편집 JSON, 투명 PNG 시트, 배치 JSON, 사용법 및 4파일 ZIP을 제공한다. 현재 공방의 `jet` 지원이 필요하며 PNG는 일반 투명 이미지다. README에 좌우 반전 시 기준점 변경도 설명했다. 실제 게임의 영웅/무기/스킬/피해에 자동 장착하지 않았다.
