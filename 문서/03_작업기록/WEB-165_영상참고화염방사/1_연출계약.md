# WEB-165 · 영상 참고 화염방사 계약

사용자가 제공한 `C:\Users\user\Downloads\Video Project.mp4`의 화염방사를 공방에서 편집 가능한 독립 VFX로 재현한다. 원본 영상은 변경하지 않는다.

- 참고: 1080×1080, 30FPS, 86프레임, 약 2.867초. 주황색 노즐 불꽃, 넓어지는 흰 중심, 푸른 전방 외곽과 잔불, 분사 중 맥동. 원본 방향인 오른쪽에서 왼쪽으로 제작한다.
- 원본을 직접 분리한 그림이 아니라 코드로 만든 재현이다. 영상에는 캐릭터·적·숫자·UI가 겹치고 전방 불꽃 일부가 화면 경계에 잘린다. 재현 소스에는 화염만 포함하며 가려진 모양은 새로 구성한다.
- 식별: 재사용용 ‘청염 화염방사’. 특정 영웅/무기/공격의 자동 장착 없음.
- 피해·대상·부가효과: 추가하지 않는다. impactFrame은 프레임 완료 시각 표시이며 피해 미연결.
- 시간: 점화 → 지속 분사 → 노즐 차단 → 전방 잔불 소멸, 약 2.4초/64프레임. 원본의 준비·회수 캐릭터 모션은 포함하지 않는다.
- 좌표: 노즐 기준 콘텐츠(.84,.52), 고정 축. 원본256×256 투명 콘텐츠, 사방24px 패딩, 304×304 셀. 표시 크기는 콘텐츠 기준220px, 균일 배율.
- 표시/범위: 길이·두께·퍼짐·소용돌이 속도를 편집할 수 있게 한다. 가장 큰 프레임에도 원본 경계에서 여유를 두며 표시 범위와 전투 판정을 분리한다.
- 출력: 공방 프리셋/새 저장 작업, 편집 JSON, 투명 PNG 시트와 배치 JSON. 밝은 회색/초록 전체 프레임 및 실제 전장 상단/중앙을 확인한다.
