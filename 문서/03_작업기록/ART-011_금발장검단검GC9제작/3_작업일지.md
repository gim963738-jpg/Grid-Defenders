# 생성과 검수

복장·머리·무기·C4 얼굴·C3 금속의 이미지 5장을 참조해 내장 image_gen으로 메인 시안 1장을 생성했다. M05 원본은 사전 분석에 사용했다. 최초 6장 입력은 참조 개수 한도로 사전 거절되어 실제 이미지가 생성되지 않았고, 5장으로 수정한 호출이 성공했다.

다운로드 22의 청색 목도리·은빛 판금·갈색 벨트와 바지·비대칭 다리 장비, 23의 금발, 스케치의 장검과 단검을 반영했다. 장검 오른손·단검 왼손, 장검의 청색 사선 장식과 고리형 손 보호대, 날개 형태 가드를 확인했다.

실제 파일은 1024×1536 RGBA다. 요청한 1536×2304와 구분해 기록했으며, 확대·리샘플링하지 않았다. 투명 픽셀 1,071,663개, 알파 240 이상 피사체 439,915개이며, 가시 외곽은 캔버스에 닿지 않는다.

밝은/어두운 배경에서 전체 인물·손·두 무기·발과 외곽을 시각 확인했다. 실제 원본 1024픽셀 너비와 화면 맞춤 보기를 확인했다. 생성 결과에는 모델이 해석한 세부 문양과 형상 차이가 있으며, 사용자 최종 승인으로 표시하지 않았다.

제작 모음에는 제작본 1장과 입력 참조 3장을 추가했다. 실제 이미지 경로 183개, 고유 이미지 178개, 카테고리 6개다. 제작본은 테스트 마무리 시안, 입력은 첨부자료에 분류했다. 기존 항목·원본 해시·문서 링크와 브라우저의 검색·필터·모바일 표시 검증을 통과했다.
