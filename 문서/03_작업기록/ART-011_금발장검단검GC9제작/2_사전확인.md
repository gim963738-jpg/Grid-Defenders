# 참조 역할과 구성

다운로드 22의 청색 목도리·후드·은빛 흉갑과 팔 갑옷·가죽 벨트·갈색 바지·비대칭 다리 장비를 복장으로 사용한다. 다운로드 23에서는 짧게 층진 금발과 흐르는 앞머리만 사용하며, 흰금 코트와 어깨 위 대검은 가져오지 않는다.

사용자 스케치 상단은 장검, 하단은 단검으로 읽었다. 장검에는 청색 사선 장식·부채처럼 뻗는 가드·폐쇄형 손 보호대, 단검에는 짧고 각진 날과 가드를 적용한다. 장검 오른손·단검 왼손으로 두 무장만 배치한다.

GC9 그림체 기준과 생성 프롬프트를 확인하고, 실제 C4 정면·C3 정면·GC9 M05 로난 원본을 시각 확인했다. M05는 성인 남성형 비율의 사전 분석으로 참고했다. 실제 호출은 도구의 5장 한도에 맞춰 사용자 구성 참조 3장과 C4 얼굴·C3 금속 기준 2장을 사용한다. 참조 인물의 정체성은 옮기지 않는다. 내장 image_gen을 사용한다.
