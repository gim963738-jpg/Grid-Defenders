# 제작과 확인

내장 image_gen에 v18 전체 지도와 사용자 위치 확대본을 함께 전달해 한 번 생성했다. 왕국 앞 해안에서 강 하구까지 이어지는 녹지를 눈으로 확인하고 선택했다.

결과는 1254×1254 불투명 RGB PNG다. 생성 원본과 프로젝트 보관본의 바이트가 같으며 크기를 변경하지 않았다. v18과 v17 원본 해시도 유지됐다.

설정 데이터의 최신 지도 경로를 v19로 갱신하고 열람본과 설정집을 다시 빌드했다. 지도 읽기에 남부 해안 녹지 연결 설명을 추가했다. 국가·가문·신앙·부족 설정은 동일하다.

구조·경로·원본 보존 검사와 브라우저의 최신 이미지 경로, 지도 번호·지역 선택·북마크·390/320px 화면 검사가 통과했다. 오른쪽에 열려 있던 전체 설정집도 최신 지도로 갱신했다.
