# WEB-185 사전 확인

작성 시점 정정: 이 파일은 실제로 구현·검증 후에 작성한 요구사항·완료 기준의 사후 정리다. 작업 전에 작성·저장한 사전확인 문서가 아니다. 당시 채팅으로 방향은 안내했지만, 대상 파일·제외 범위·완료 조건·검증 방법을 모두 사전에 보고하지 못했다.

사용자 요청 범위: 실제 가로 웨이브 길목과 몬스터 경로를 직사각형으로 변경. 대상은 landscapeField.ts·가로 지형 검사·기존 저장 복귀 좌표와 관련 문서다.

완료 기준: 네 변이 수평/수직이고 네 모서리에서 직각 이동, 배치20칸 유지, 흙길 질감·잔디 연결 유지. 기존 저장을 불러와도 몬스터가 새 길 위에 바로 표시되어야 한다. 세로 전장·보스 필드·능력치·R 기준은 유지한다.

검증 방법: 타입·빌드·모델 검사,800×360 실제 브라우저의 코너 픽셀·배치·이동·보스 왕복 확인. 원본 이미지 변경·로비 통합·전체 밸런스 변경은 범위에 포함하지 않는다.
