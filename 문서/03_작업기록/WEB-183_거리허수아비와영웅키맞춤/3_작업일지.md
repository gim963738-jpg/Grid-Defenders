2026-11-08 완료. 진형 하단 묶음을 x90/y284에서x160/y260으로 이동해 배치판 아래8px에 붙였다. 완료72×72px·자동배치88×72px·간격4px, 안내를 포함한 전체 폭356px로 우측 패널과8px 간격을 유지한다.

devRangeDummy.ts/css를 추가해 개발자 도구에 거리 허수아비 ON/OFF를 연결했다. 흰 발밑 점을 기준으로0.5R부터3R까지6개 원·거리 라벨을 표시한다. 파랑/노랑 교대, 실제 드래그와 방향키 이동, 전장별 위치 유지, 선택 해제·정지 중 상시 표시를 지원한다. 웨이브와 보스의 서로 다른 좌표 배율을 사용한다.

크기 조정 대상을 반대로 이해해 금발 전사를 줄였던 변경은 사용자 정정 후 복원했다. 최종적으로 금발 전사는 기존 몸 높이57/72를 유지하고 첨부된 원거리 딜러를 같은 높이로 확대했다. rangedArt.ts에서 원본의 머리/발 기준과 투명 여백을 분리해 비율·발 위치를 유지한다. 웨이브57, 보스72는 각 전투의 논리 좌표 기준 몸 높이다.
