# 현재 규칙
`RULES.shopSlots`: 가로6/세로5. 초기·리셋·새로고침 모두 이 수를 따른다. 추가 상품도 기존 아이템 정의를 사용한다.

가로 공용 가방은7×3 고정. 구매 위치 탐색이 실패하면 결제하지 않는다. 장착 해제/이동/회전/개발자 장비 교체는 기존 아이템을 보존하며 실패한다. 조합 결과도 공간을 사전 검증한다. 세로 전투는 기존 세로 확장 방식이다.

상점 카드는 선택 시6px 상승하고 별도 구매 버튼을 표시한다. 구매 버튼은 카드와2px 겹치며 중첩 button 요소를 사용하지 않는다. 회전 애니메이션은 표시만 보간하고 모델의 판정/점유 칸을 늘리지 않는다.

회전·해제·판매 버튼은 제거했으며 키보드/두 번 탭/드래그 기능은 유지한다. 조합 버튼은 영웅 장비 오른쪽에 고정하고 공용 가방과 선택 영웅의 기존 조합 규칙을 사용한다. 가방 스크롤·확장 예정 행은 제거한다. 구현·관련 검증 완료, 사용자 최종 화면 확인 대기.
