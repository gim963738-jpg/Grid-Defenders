# WEB-181 사전 확인

목적은 진형창을 사용자 이미지의 우측 빈 공간에 배치하는 것이다. 대상은 formation-panel.ts/css와 landscape-entry.ts의 패널 연결, 관련 현재 문서다.

완료 기준: 전장·상단 버튼에 겹치지 않음, 28칸과 자동배치·완료 버튼 모두 표시, 암막 없음, 넓은 창에서도 전장과 위치 일치, 기존 편집·종료·저장 동작 유지. 검증은 빌드와 실제 브라우저 위치·조작 검사로 한다.

이번 위치 요청에 맞춰 격자만30×42px로 구성하며 주요 버튼의48px 높이와 공통 글자 크기를 유지한다. 모델·스킬·로비 연결·다른 전투 배치는 변경하지 않는다.
