# 반영과 확인

2026-11-07 설정집을 v1.3으로 갱신했다. “엘프와 드워프 소수민족” 절에 공통 국력 기준, 비교 표, 민족별 설명을 추가했다.

드워프와 사하리드의 빈번한 교류를 주요 관계 표에 추가하고, 남부 지역의 드워프 설명에도 연결했다. 지도 8·9번에서는 거점 설명과 민족 설명을 함께 표시한다.

구조·경로 검증과 숨김 브라우저의 실제 표시 확인을 수행했다. 민족 비교 표 2행, 주요 관계 5행, 엘프·드워프의 국력과 교류·성향 문구를 확인했다. 전체 설정집은 390·320px에서 가로 넘침이 없다.

설정집의 새 절을 실제 PNG로 캡처해 비교 표와 본문의 가독성을 확인했다.
