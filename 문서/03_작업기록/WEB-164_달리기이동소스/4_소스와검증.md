# WEB-164 · 달리기와 이동 소스 10종

2026-11-07. 사용자 요청: 달릴 때 생기는 먼지와 이동 이펙트를 다양한 형태의 소스로 제작.

## 결과와 사용

`게임/public/effect-recipes/movement/`에 가벼운 발먼지, 묵직한 발구름, 모래 질주, 출발 먼지, 급정지 스키드, 눈가루 발걸음, 물웅덩이 질주, 바람 대시, 불꽃 추진, 번개 질주를 만들었다. 먼지의 크기와 발생 순서, 퍼짐, 긴 꼬리, 지면 긁힘, 낙하 물방울, 곡선 띠, 불씨, 지그재그 점멸로 동작과 실루엣을 구분했다.

공방 기본 효과에 10종을 추가했다(기존 8종 포함 총 18종). 갤러리에서 **이동 소스**를 검색하거나 `effect-gallery.html?q=이동%20소스`로 열면 새 10종만 비교한다. 카드의 **이 효과로 시작**을 누르면 별도 새 작업이 생긴다. 갤러리의 **이동 소스 10종 받기**는 약 2MB ZIP을 내려받는다.

ZIP은 각 효과의 편집 JSON·투명 PNG 시트·배치 JSON 30개와 README/manifest 총 32개 파일이다. 상세 사용법과 좌우 반전 기준점은 소스 디렉터리 README에 적었다. 새 소스를 사용자 저장함에 강제로 복제하지 않았다. 기존 공방 창을 유지하고 같은 사용자 주소의 새 갤러리 탭에 10종을 열었다.

## 연출 계약

- 식별: 영웅 공통 재사용용 VFX 소스. 특정 영웅/스킬/공격 동작과 연결하지 않는다.
- 피해·대상·부가효과: 없음. 사거리·대상 수·타수·쿨타임을 추가하지 않는다. impactFrame 5는 공통 포맷의 완료 시각 표시이며 피해와 무관하다.
- 시간: 40FPS, 28~48프레임, 0.7~1.2초. 총 348개 논리 프레임. 첫/마지막은 투명하다. 반복용 발먼지·모래·눈·물보라는 loop=true, 단발 출발/스키드/속성 대시는 false다.
- 좌표: 기본 오른쪽 이동, 꼬리는 왼쪽. 콘텐츠 발 기준점(.68,.68)을 매 프레임 고정한다. 좌우 반전 시 기준점 X도 .32로 반전한다.
- 원본: 코드로 생성한 192×192 투명 콘텐츠, 사방 24px 패딩, 240×240 셀, 8열 시트. 각 프레임 위치와 마지막 행 유효 개수는 배치 JSON에 기록한다.
- 표시: 콘텐츠 기준 132~166px 균일 배율. 발먼지는 발이 닿은 좌표에 남기는 단발 배치를, 바람/불꽃/번개는 이동하는 발 기준점 추적 배치를 권장한다. 실제 게임 연결은 이 작업에 포함하지 않았다.

## 구현

- `movementPresets.ts`: 독립적인 10개 레시피와 식별자/이름/설명. 색상만 바꾼 복제 대신 레이어 구성과 시간/기하를 달리했다.
- `movementRender.ts`: 일반 합성의 겹치는 먼지 구름(`dust`), 끝이 가늘어지는 곡선 띠(`wind`), 월드 위쪽 발사/낙하 물방울(`splash`). 랜덤 시드와 프레임으로 재현하며 사용자 레시피를 변경하지 않는다.
- 기본 레이어 열거/검증, 공방의 두께·퍼짐·속도·개수·시드 조절, 노드 원본, 편집 JSON, PNG 및 AI 요청의 지원 종류에 연결했다. 기존 레이어 그리기 코드는 유지했다.
- 갤러리 검색어 URL을 지원하고 이동 검색 결과에 소스 다운로드 링크를 표시했다. 작은 화면에서도 검색/다운로드 컨트롤은 48px 이상이며 가로로 넘치지 않는다.

## 검증

- 브라우저 자동 검사 311개 통과: 신규 소스 81, 공방 공통 188, 갤러리 모델 27, 갤러리 UI 15.
- 10종 모두 편집 JSON 왕복, 전체 프레임 렌더, 원본 경계/패딩 투명도, 첫/마지막 투명, 기준점/균일 표시, 시트 프레임 좌표, 결정적 재현, 원본 불변을 검사했다. 노드 합성은 중간 Canvas의 일반 합성 알파 반올림을 고려해 최대 3/255 오차 내 픽셀 일치를 확인했다.
- 밝은 회색/초록의 전체 프레임 contact 이미지 10장을 시각 확인했다. 소스 경계에 닿는 프레임 0개. PNG 배경은 투명하며 검수용 밝은 배경은 소스 시트에 포함하지 않는다.
- 공방의 실제 전장 렌더러에서 발 기준점을 나타내는 정지 시전자를 함께 놓고 10종 각각 상단/중앙 총 20장면을 확인했다. 신규 피해/보상/플레이어 저장을 실행하지 않는 독립 시험 장면이다.
- 별도 localhost 저장함에서 물보라 프리셋으로 새 편집 작업을 열고 추가 레이어 속성, 실제 전장, 0.25×/1×/5× 재생과 정지를 확인했다. 최초 타이머 샘플은 브라우저 숨김/프레임 정지와 섞여 무효였고, 보이는 탭에서 requestAnimationFrame에 맞춘 최종 검사 세 속도 모두 통과했다. QA 저장함 20개는 원문으로 복구했다.
- 320px/DPR3에서 가로 넘침 없음, 전장 CSS 폭 274px/실제 Canvas 폭 780px. 갤러리 2열/최소 터치 48px, ZIP HTTP 응답과 ZIP 서명, manifest 10종 확인. 390px/scale1 갤러리 화면 시각 확인. DPR3 Orca 화면 캡처에는 반복 타일 현상이 있어 그 PNG는 시각 판정에 사용하지 않고 DOM/Canvas 치수 검사와 scale1 캡처를 사용했다. 실기기 테스트는 별도다.
- 사용자 주소의 저장 작업 13개와 저장 원문 전체가 작업 시작 백업과 동일하다. 사용자 갤러리에서 5열/10개 전부 실제 프레임 변화 확인.
- TypeScript/Vite 프로덕션 빌드 통과. ZIP이 빌드 산출물에 포함됨을 확인했다. 외부 API/클라우드 게시 없음.

검증 산출물: `output/movement-effects/`. `source-audit.json`, `regression-results.json`, `playback-audit.json`, `gallery-mobile-download.json`, `storage-audit.json`, `gallery-animation.json`, 밝은 contact 이미지 및 전장 이미지에 증거를 남겼다. 사용자 최종 외관 확인은 후속 피드백으로 받는다.
