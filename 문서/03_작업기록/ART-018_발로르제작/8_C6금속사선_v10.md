# 발로르 v10 금속 보정·C6 사선 비교

사용자는 v09 금속 질감·빛반사가 C6와 다르다고 지적하고, 금속 보정 후 C6 금발·흰 판금 오른쪽 앞 사선 v1과 같은 방향 한 장을 추가 요청했다. 이번 요청에 따라 정면 금속을 수정하고 사선 비교 시안 1장을 추가했다. 일반 순서의 사전 시안 승인과 별개로 이 추가 비교 방향은 사용자가 직접 지시한 범위다. 다른 방향과 SD는 제작하지 않았다.

이번 금속의 우선 참조는 C6 정면·사선 실제 PNG다. 기존 공통 C3 우선 규칙을 전역 교체하지 않는다. GC9 영어 고정 블록은 각 호출에 원문 그대로 사용했다. C6 복장·금장·모피·금발을 복제하지 않고 v09 발로르 디자인을 유지하는 편집이다. 한손 그립 원본 두 장은 최초 두 호출에 첨부했다.

C6 원본의 실제 방향은 코·가슴이 화면 왼쪽을 향하며 화면 오른쪽의 인체 왼쪽 귀·어깨가 가까운 구도다. 발로르도 왼손 방패가 가까운 쪽, 오른손 검이 먼 쪽이다. 파일명/카테고리의 오른쪽 앞 사선은 사용자와 C6의 기존 이름을 유지한다.

반사 띠를 줄이고 넓은 은색 기본 면·회보라 음영으로 보정했다. 견갑·방패 테두리의 세밀한 반사면은 C6보다 조밀하게 남아 있어 사용자 확인 대기다.

정면·사선은 각각1024×1536 RGBA 생성 원본이며 크기·바이트를 그대로 유지했다. 양쪽 모두 안전 영역 밖 알파32 픽셀0. 정면 머리끝373·발선1386(본체1014px), 사선377·1436(1060px). 사선 본체가 약4.5% 커 최종 정렬 세트로 표기하지 않고 비교 화면의 표시 높이만 맞춘다.
