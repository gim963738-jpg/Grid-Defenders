# 작업 결과

내장 image_gen으로 판금·망토 디자인과 얼굴·그립을 수정하고 투구를 벗은 정면·오른쪽 정측면·후면을 제작했다. 최종 세트는 `illustration_3views_v04`다. 후면 손은 손잡이를 감싸도록 접촉을 보완했고 검날은 몸 앞쪽에서 망토에 가려지는 구조로 정리했다.

전체 생성 호출 14건 중 프로젝트에 보관한 이미지 11장이며, 이전 자세로 제작 중 최신 참조로 대체된 3건은 생성 원본 경로와 프롬프트만 기록했다. 최종 세트와 시안·이전 방향·그립 중간본을 구분한다.

최종 3장은 각각 반환된 1024×1536 PNG 원본을 그대로 복사하고 ZIP으로 묶는다. 생성 원본과 보관본의 SHA-256, 최종 ZIP 내부 바이트, 카탈로그 링크·분류·이전 원본 보존을 확인한다. 구체적인 확인 결과는 제작 폴더의 검증 JSON과 카탈로그 검증 기록에 남긴다.

검증을 완료했다. 최종 PNG 3장과 ZIP 내부 3항목의 바이트가 일치하며, 보관한 생성 이미지 11장도 도구 반환 원본과 일치한다. 이전 목록의 193개 경로·188개 고유 이미지가 보존됐다. 제작 모음은 209개 경로·202개 고유 이미지이며 현재 88장·이전 버전 47장·참조 67장이다. 실제 알파 값을 보존하며 배경의 부분 투명 픽셀도 원본대로 유지한다.

제작 모음의 발로르 현재 3방향·출신·클래스·친왕파 태그, 이전 분류·구형 주소·원본 보기와 모바일 390px·320px 탐색 검사를 통과했다. 내장 브라우저의 새로고침이 모바일 뷰포트를 복원하는 경우에는 요청 폭을 다시 적용하고 실제 폭이 일치할 때 검사하도록 검증 도구를 보완했다. 두 모바일 폭에서 최소 버튼 높이 44px와 가로 넘침 없음을 확인했다.

## v05 후속 보정

세 방향의 방패를 약 2/3 전신 높이로 확대하고 측면 검의 단단한 형태와 축을 보정했다. 후면 오른손은 손바닥 가죽면·엄지두덩·손가락 안쪽을 보이는 그립으로 수정했다. 배경은 실제 알파를 정리하고 흰 바탕의 전체 프레임 및 원본 배율 손 부위를 브라우저에서 확인했다. 검은 코너 도트가 사라진 확인 이미지는 `output/reviews/balor-v05/light-native-qa.png`에 보관한다.

이번 생성은 4회이며 최종 3장과 측면 중간본 1장을 모두 원본 바이트로 보존한다. 전체 기록은 18회 호출·프로젝트 보관 이미지 15장이다. 기존 v04 3장과 ZIP은 보존하고 v05만 현재 버전으로 표시한다. 호출의 실제 산출물과 프롬프트를 연결하도록 목록 빌드를 보완했고, 이전 v04 투구 미착용 상태도 유지한다.

v05의 1024×1536 RGBA 원본 3장, ZIP 내부 바이트 일치와 이전 209개 경로·202개 고유 이미지 보존 검사를 통과했다. 빈 코너 128×64 영역 12곳은 알파 최댓값 0~1로, 사용자 화면에서 보이던 어두운 도트가 남지 않았음을 밝은 배경에서도 확인했다. 목록은 215개 경로·208개 고유 이미지이며 현재 88장·이전 버전 51장·참조 69장이다. PC·390px·320px 목록 검사도 통과했고 오른쪽 제작 모음은 서대륙 → 기사 → 최신 3장 보기로 열어뒀다.

## 새 SD 디자인 시안 v01

사용자 견본 3장의 비율·색 덩어리·카메라를 적용해 투구 미착용 발로르를 SD 픽셀풍으로 구성했다. 내장 image_gen 2회로 초기 시안과 대형 방패 보정을 생성했다. 실제 반환 크기는 각각 1254×1254이며 원본 바이트·알파를 그대로 보존했다. 참조 5개 제한에 맞춰 중복된 전체 자세 참고를 제외하고 발로르 일러스트·SD 견본 3장·손가락 연결 가이드를 첨부했다.

최종 SD 시안 1장만 현재 버전으로 등록하고 초기 방패 크기 이미지는 이력으로 보관한다. SD 화풍은 GC9 일러스트와 별도 표시하며 같은 발로르 프로필·서대륙 기사 분류를 유지한다. 시안은 사용자 확인 대기이며 후속 3방향은 아직 생성하지 않았다.

밝은 배경의 전신·무기·손과 실제 알파를 확인했다. 참조 3장과 생성 결과의 보관 바이트가 원본과 일치한다. 기존 215개 경로·208개 고유 이미지는 보존됐고 제작 모음의 파일·링크·SD 확인 대기 상태와 PC·390px·320px 탐색 검사를 통과했다. 오른쪽 제작 모음에 SD 시안을 열어뒀다. 게임용 저해상도 팔레트·고정 픽셀 격자·애니메이션 검증 결과로 표기하지 않는다.

## 기존 SD·새 SD 정면 비교

내장 image_gen 2회로 기존 SD 스타일 정면과 새 SD 스타일 정면을 개별 제작했다. 동일한 발로르 구성·색·장비·검 그립·정면 입상을 유지하고 각 스타일의 실제 참조를 분리했다. 두 PNG는 모두 1254×1254 생성 원본이며 ZIP 내부 바이트도 일치한다. 기존 220개 경로·213개 고유 이미지는 보존됐다.

비교 화면은 왼쪽 기존 SD·오른쪽 새 SD이며 원본 저장과 배경 전환을 제공한다. 밝은 바탕에서 전신을 확인했고 PC·390px·320px에서 두 SD 패널·배경 전환·44px 터치 크기와 가로 넘침 없음을 검사했다. 제작 모음은 두 비교본을 스타일 선택 대기로 등록하며 기존 SD 시안과 일러스트를 보존한다. 비교 요청을 특정 SD 스타일의 최종 통과로 처리하지 않는다.

## 기존 SD 채택과 공통 크기 확정 · 2026-11-08

사용자 선택에 따라 기존 SD 정면을 디자인 선택본으로 확정하고 새 SD 생성물 3장은 폐기 이력으로 분류했다. 입력 견본 3장도 활성 화풍 참조에서 제외한다. 기존 디자인 승인을 저장하며 스타일을 재확인하지 않는다. 이후 본체 프레이밍은 은발 기준을 적용하는 상태로 분리해 기록했다.

같은 1254×1254 원본에서 해부학적 머리·발 ROI를 알파 32 기준으로 실측했다. 은발·날개 지팡이는 머리끝 y=253·발선 y=1178·본체 926px, 금발 전사는 1215px, 발로르는 1230px다. 새 SD 공통 제작 기준·프롬프트·구조화 기준과 제작 순서·AGENTS.md에 실제 은발 원본을 필수 참조로 연결했다. 직업별 본체 확대를 막고 장비 외곽·인물 높이·발 기준선을 분리한다.

기준 확인 화면은 세 원본을 화면에서만 동일한 머리선·발선으로 정렬한다. 기존 PNG는 재저장하지 않았다. 기존 222개 경로·215개 고유 이미지의 SHA-256이 유지됐고 목록의 현재 89장·이전/폐기 54장·참조 72장을 확인했다. 기존 SD 선택본만 현재 목록에 남고 새 SD 3장은 폐기 표시와 향후 참조 제외 상태다.

파일·링크·구조화 기준과 실제 원본 해시 검사를 통과했다. 제작 모음과 기준 뷰어의 PC·390px·320px 검사도 통과했으며 실제 표시된 세 인물의 머리선·발선 정규화 좌표가 일치한다. 기준/원래 크기 전환·명암 배경·44px 터치 크기·가로 넘침을 확인하고 오른쪽에 기준 뷰어를 열었다. 이번 작업에서는 신규 캐릭터 PNG나 후속 방향을 생성하지 않았다.

## GC9 전신 여백 추가 · 2026-11-08

GC9 위·좌·우 여백 요청을 별도 프레이밍 기준으로 작성했다. 초기 기본값은 상단 20%·좌우 각각 15%·하단 6%이며 인물·장비·망토 전체를 x=15~85%, y=20~94% 안에 균일 배율로 배치한다. 기존 성인형 등신·체형과 한 캐릭터의 방향별 배율·발선을 유지한다. 원본 생성 단계에서 여백을 확보하고 기존 PNG를 재저장하지 않는다.

그림체 기준·한국어/영어 고정 프롬프트·입력 양식·제작 순서·AGENTS.md를 함께 갱신했다. SD의 별도 키 기준은 변경하지 않았다. 여백/안전 영역 수식과 입력 양식·제작 순서 연결을 검증했고 목록 빌드와 기존 원본 해시·링크 검사를 통과했다. 이 작업은 향후 제작 규칙 반영이며 새 GC9 이미지를 생성한 기록으로 표기하지 않는다.


## GC9 정면 얼굴·장비 포함 여백 보정 · 2026-11-08

사용자는 장비가 좌우·머리 위로 돌출해 잘리는 것을 막기 위한 여백이며 장비를 따로 배치하는 뜻이 아니라고 명확히 했다. 인물과 손에 든 검·방패·착용한 망토의 연결·자세·상대 크기를 유지해 전체만 균일하게 줄이는 규칙으로 기록했다.

실제 M02·M05와 C4를 다시 관찰했다. 제작 당시 M02·C4 참조가 사용됐지만 v05의 코·입·턱 표현이 GC9보다 사실적으로 남은 점을 확인했다. 부드러운 28세 남성·갈색 머리·회청색 눈과 청은 갑주·고정 그립을 유지하며 얼굴선·피부 명암을 간결하게 보정했다.

내장 image_gen 2회 중 첫 출력은 여백이 부족해 중간본으로 보관했다. 빈 배치 안내도를 보조 참조로 사용한 정면 v06은 1254×1254 RGBA 생성 원본이다. 알파 32 이상 전체 외곽 기준 위 21.2%·좌우 약 25.1%·아래 8.9%이며 안전 영역 밖의 유효 픽셀은 0이다. 기존 223개 이미지 경로의 SHA-256을 모두 보존했고 생성 원본과 최종 파일의 해시가 일치한다.

현재 목록은 GC9 정면 v06 1장과 선택된 기존 SD 정면이며 v05 3방향은 이전 이력으로 보존한다. v06 측면·후면은 생성하지 않았다. 파일·링크 검증과 제작 모음 PC·390px·320px 검사를 통과했다. 새 수정본의 사용자 통과는 미정이며 SD 선택·공통 키 규칙은 유지한다.


## 정측면·후면 방패 각도만 수정 · 2026-11-08

사용자는 방패 뒤의 빨강 표시가 손잡이·팔걸이, 파랑이 전완, 노랑이 손이며 오른쪽을 보는 구도와 후면에서 **방패 각도만** 수정하라고 명시했다. 팔·손·자세를 바꾸는 뜻으로 해석하지 않는다. 초기 정면 yaw 초안은 실행하지 않았다.

내장 image_gen으로 기존 v05 두 방향의 방패 각도를 수정했다. 최초 출력에 검은 배경 잔여물이 생겨 각 방향을 추가 편집해 실제 투명 알파로 정리했다. 총 4회 생성이며 중간본·프롬프트·생성 기록을 보관했다. 최종 정측면·후면은 각 1024×1536 반환 원본이며 SHA-256이 도구 원본과 일치한다. 정면 v06과 SD 선택은 유지했다.

기존 226개 이미지 경로의 바이트를 모두 보존했고 목록은 232개 경로·225개 고유 이미지로 갱신했다. 최신 목록은 GC9 정면 v06·정측면/후면 v07·기존 SD 선택본이며 이전 v05와 각도 수정 중간본은 이력으로 남긴다. 후속 수정본에 대한 사용자 통과는 미정이다.
