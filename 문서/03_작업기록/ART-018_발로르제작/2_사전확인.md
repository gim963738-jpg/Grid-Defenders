# 제작 기준

GC9 v1.1 그림체 기준·생성 프롬프트와 캐릭터 제작 규약을 적용한다. 판금·천은 GC9 M05·A04, 금속 면은 C3를 참조했다. 투구 탈착 얼굴에는 남성 얼굴 참조와 C4 표현을 적용하고 선택된 정면을 같은 인물의 측면·후면 기준으로 사용한다. 실제 호출별 참조는 생성 기록에 보존한다.

기존 21종의 배치 보류는 유지한다. 발로르는 신규 인물이므로 서대륙·발트레인 왕국 친왕파·기사로 등록한다. 성기사 스타일만으로 성휘 대교회 소속이나 빛 마법을 추가하지 않는다.

최신 세부 요청의 3방향과 투구 탈착 선택을 우선한다. 공통 기본 제작 순서와 이번 캐릭터의 예외를 구분하며 SD를 추가 제작하지 않는다.
