## 검증

| 검사 | 결과 | 범위 및 한계 |
|---|---|---|
| npm test | 통과: 57회 검사 묶음, 1,500개 단언, 실패 0 | 세로/가로 모델. 기존 브라우저 전용 15묶음은 이 명령에서 실행하지 않음 |

| 실제 화면 검사 | 32/32 통과 | 별도 127.0.0.1:5197 저장소, 800×360 iframe, 실제 메뉴·저장·보스전 UI |
| 화면 참조 | [검증 이미지](검증/formation-800x360.png) | 편집판 28칸과 완료 버튼 표시, APK 실기기 검증 아님 |

화면 검사 원문은 [결과 JSON](검증/formation-browser-result.json), 재실행 코드는 [검사 스크립트](검증/formation-browser-check.js)에 보존했다. 3보병·2궁병·1마법병·3영웅의 별도 시험 전투를 사용했다. 기존 사용자 전투 저장소를 사용하지 않았다.

초기 화면 검사에서 전역 footer 여백과 스크롤바 때문에 창 하단이 잘려, 패널 내부 여백을 명시하고 편집 중 배경 스크롤을 잠갔다. 종료 직후 버튼 재활성화와 포커스 복귀, 이전 close 이벤트가 새로 열린 창에 영향을 주지 않는 처리도 검증했다. HMR로 표시된 기존 이어하기 모달은 해당 버튼을 통해 해제한 뒤 검사했다.

추가 검토: 전열 선호 칸 초과, 영웅 중열 확보, 구 저장 호환, 저장 복원, 유닛 판매·초기화, 기존 세로 보스 좌표 유지. 실제 Android/WebView·터치 장치 인증, 대규모 전투 밸런스 및 간격 슬라이더는 별도 후속 작업이다.
