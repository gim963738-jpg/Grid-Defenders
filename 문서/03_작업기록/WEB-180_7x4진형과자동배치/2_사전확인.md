# WEB-180 사전 확인

- 목적: 기존 진형 버튼을 실제 배치 편집기로 연결한다.
- 기준: AGENTS.md, 개발규칙, 모바일UI규격, WEB-178 진형 버튼, 기존 중단·복귀 저장 모델.
- 대상: 진형 모델·패널, Defense 소환/판매/초기화, 가로 메뉴, 보스 초기 배치, 전투 저장, 관련 검사와 현재 문서.
- 범위: 실제 소환된 유닛의 28칸 배정, 역할별 자동배치, 수동 이동·교환, 저장, 다음 보스전 적용, 편집 중 전투 정지·복귀.
- 완료 기준: 유닛 누락/중복 칸 없이 배정, 영웅은 중열, 자동배치가 진행 화살표 오른쪽, 800×360에서 완료 버튼까지 표시, 실제 보스 시작 좌표 일치, 기존 세로 전투·저장 호환.
- 검증: TypeScript 및 프로덕션 빌드, 양 레이아웃 모델 검사, 별도 저장소 원점의 브라우저 검사와 스크린샷.

요청에 포함된 기능 구현으로 진행했다. 간격 슬라이더·진형 프리셋·새 스킬·로비 영웅 연결·APK 제작은 이번 범위가 아니다. 다른 작업의 이미지 파일과 과거 사업 보고서 스냅샷은 수정하지 않는다.
