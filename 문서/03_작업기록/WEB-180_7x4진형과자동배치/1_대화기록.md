# WEB-180 대화 기록

2026-11-07. 요청: 진형을 가로 7칸·세로 4칸으로 만들고 진행 방향을 12시로 표시한다. 진행 방향 아이콘 오른쪽에 자동배치를 배치하며 전열·중열·후열로 자동 분배하고 영웅은 중열로 처리한다.

사용자 확정: 7×4, 위쪽 진행, 자동배치 위치, 영웅 중열. 구현 시 해석: 위에서 전열 1행·중열 2행·후열 1행. 보병 전열, 궁병·마법병 후열 우선, 선호 구역이 차면 남은 칸을 사용한다. 유닛 선택 후 이동·교환할 수 있다.

실제 가로 전투의 진형 버튼에 연결했다. 진형과 웨이브 배치 칸은 분리하고 다음 보스전에서 적용한다. 기존 보스전은 오른쪽 진행이므로 편집판을 시계 방향 90도 회전해 사용한다. 배치 규칙은 구현·검증을 마쳤으며 사용자 최종 외관 확인은 아직 받지 않았다.
