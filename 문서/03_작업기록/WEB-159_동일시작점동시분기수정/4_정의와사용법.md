# 같은 지점에서 동시 출발하는 선 — WEB-159

2026-11-07. 사용자 보고: 같은 점에서 동시에 출발하려고 두 선을 그리면 두 번째 선을 만들 수 없다.

## 원인과 수정

실제 사용자 화면을 읽기 전용으로 확인했다. 직선 도구·새 선 의미=방향·이번 단계에 함께가 선택돼 있었으며, 첫 선은 role=effect/purpose=direction/step1/대상 미지정이었다. 저장 오류는 ‘같은 단계의 캐릭터 이동 방향은 하나로 정해 주세요’였다. 공통 시작점 충돌이 아니라 새 방향선이 캐릭터 이동으로 취급되어 두 번째 방향을 거부한 문제다.

- 새 방향선은 명시적으로 `directionTarget=effect`로 만든다. 저장된 현대식 방향선(role=effect 또는 slash, purpose/behavior=direction)의 대상 생략도 effect로 읽는다. 사용자 첫 선의 좌표·시간·색·의미를 바꾸지 않고 이 기본값을 적용한다.
- 이전 role=move의 대상 생략은 actor로 유지하고 명시적인 actor도 보존한다. 한 캐릭터의 모순된 동시 이동은 계속 거부하며 오류에는 이펙트 방향선 선택 방법을 안내한다. 여러 독립 이펙트 방향은 같은 단계에 허용한다.
- **같은 시작점에서 분기** 버튼은 선택한 선의 시작 좌표·실행 단계·시작 지연에 새 선을 맞춰 동시 출발한다. 원래 지연이0이면 새 선도0이며, 지연이 있다면 그 값도 복사한다. 선택한 선이 이전 단계여도 가장 큰 단계가 아닌 그 선의 단계에 만든다.
- **이번 단계에 함께**를 사용하면 선택한 선의 단계를 사용한다. 그리기 시작점이 해당 단계의 기존 시작점12 CSSpx 안에 있으면 정확히 같은 좌표로 붙인다. Alt를 누르면 이 자동 붙이기를 건너뛴다.
- 직선·자유선·곡선 모두 분기할 수 있다. 곡선의 첫 기준점도 공통 시작 좌표로 보존한다. 미완성 분기 취소/뒤로가기/포인터 취소/작업 전환은 저장된 그림을 보존한다.
- 겹친 시작점에서 점을 수정할 때 선택한 선의 점을 먼저 찾는다. 동일 좌표에 선이 여러 개면 공통 시작점에 분기 개수를 표시한다.
- 화면의 방향 대상·안내·사용법·AI 요청 규칙을 같은 기본값으로 맞췄다.

## 사용법

1. 공방 새로고침 → **그리기** → 목록에서 첫 방향선을 선택한다.
2. 선의 속성 위 **같은 시작점에서 분기**를 누른다.
3. 캔버스에서 새 선의 끝을 향해 드래그한다. 시작 좌표는 첫 선의 시작점으로 고정된다. 곡선이면 다음 동작으로 굽힘점을 정한다.
4. 두 선의 단계가 같고 지연0이면 동시에 출발한다. 새 방향선은 기본 **연결할 모양·이펙트의 이동**이다. 빛/검기 모양을 따로 그린 경우 각 모양에 해당 방향선을 연결한다. 방향선 자체는 출력 이미지가 아니다.
5. 추가로 갈라지는 선도 첫 선 또는 원하는 분기선을 선택해 같은 버튼으로 만든다. 취소하려면 **분기 취소** 또는 **뒤로가기**를 누른다. 완료된 분기는 일반 undo/redo로 복구한다.

## 출력·전투 계약

이번 변경은 그리기 입력·방향 대상 기본값·단계 선택을 수정한다. 기존 VFX 투명 렌더러,24px 여백, pivot/균일 배율, 프레임 완료 표시를 사용한다. 영웅/스킬/평타는 미배정, 피해/타수/사거리/대상/쿨타임 변경 없음. 명시적인 캐릭터 이동과 이펙트 분기를 구분하고 캐릭터를 두 위치로 복제하지 않는다.

노드 연결도는 기존 방식대로 각 모양에 방향선을 연결한다. 이미 노드를 사용하는 작업에 새 선을 추가했다면 원본 추가와 최종 출력 연결도 구성해야 한다.
