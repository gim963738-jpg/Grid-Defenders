# 채팅 미리보기 재생 수정 · 2026-11-07

사용자가 채팅에서 영상이 재생되지 않는다고 알려왔다. 이전 검증은 일반 Orca 브라우저에서만 수행해 채팅 시각화의 정책과 차이가 있었다.

설치된 Orca 앱의 채팅 시각화 정책에서 `media-src 'none'`을 확인했다. 따라서 HTML의 `<video>`에 MP4 데이터를 넣어도 채팅 내부에서는 재생할 수 없다. 영상 원본 디코딩 결과와 채팅 미리보기 재생을 구분한다.

이를 우회하는 보안 설정 변경 없이, 허용된 이미지와 캔버스로 실제 출력 PNG 240장을 시간순 재생하는 미리보기로 교체했다. 4초·60fps 시간과 프레임 순서를 유지하고 채팅 크기 제한에 맞춰 미리보기 화질만 축소한다. 재생·일시정지·처음부터·프레임 이동·배경 선택을 제공한다. 기존 투명 MOV·WebM·1024px PNG에는 변경이 없다.

`chat_player.py`와 `chat_player.template.html`은 재현 코드, `chat-preview-v02.json`은 미리보기 크기·프레임 정보다. 새 채팅 파일 이름은 `sword-strike-frames-v02.html`이다. `csp-preview-check.html`은 `media-src 'none'`과 이미지/스크립트 허용 정책을 적용한 검증 화면이다. 실제 검사 결과는 `verification-chat-v02.json`에 별도로 보관한다.

일반 플레이어에서 열 수 있는 H.264 MP4는 `preview-checkerboard.mp4`로 제공하며 표시용 격자가 포함되어 있다. 투명 영상 원본은 MOV·WebM이다.
