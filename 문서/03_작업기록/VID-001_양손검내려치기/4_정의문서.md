# 동작과 표시 계약

| 항목 | 값 |
|---|---|
| 대상 | 금발 장검 전사, 화면 오른쪽 정측면 |
| 출력 | 1024 × 1024, 4.000초, 60fps, 총 240프레임 |
| 배경 | 실제 알파 투명, 바닥·그림자·라벨 없음 |
| 번호 | PNG 파일 0000~0239, 논리 프레임 1~240 |
| 시간 | 프레임 i의 표본 시각 i/60초, 마지막 프레임 표시 종료 4초 |
| 0~0.88초 | 빈손을 장검 손잡이에 모아 양손 잡기 |
| 0.88~1.70초 | 머리 위로 검 들어 올리기 |
| 1.70~2.18초 | 짧게 힘 모으기 |
| 2.18~2.68초 | 오른쪽 아래로 연속 가속 내려치기 |
| 2.68~4.00초 | 반동과 양손 낮은 자세 정리 |
| 기준점 | 발은 고정, 몸통과 팔만 변형·회전 |
| 검 | 원본 디자인 참조 강체 1개, 두 손이 같은 검 손잡이에 연결 |
| 원본 추출 | 균등 셀 가정 없이 측정한 아틀라스별 영역 사용 |
| 피해 판정 | 없음; 영상의 접촉 자세는 시각 시점이며 게임 피해와 독립 |

원본 영역과 리깅 좌표·매 프레임 자세·알파 바운딩 박스는 `animation.json`에 저장한다. 실제 표시 영역과 안전 여백은 `verification-frames.json`을 따른다. 투명 여백 때문에 게임 영웅 크기를 자동 변경하지 않으며, 이번 작업은 게임 통합용 프레임/앵커 계약을 새로 적용하는 단계가 아니다.

`preview.html`의 밝은 회색·초록·어두운 회색·전장 배경은 확인용이다. `preview-checkerboard.mp4`에는 격자가 들어 있고 투명 원본은 MOV·WebM이다.
