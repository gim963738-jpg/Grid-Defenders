# VID-001 · 양손 검 들어 올려 내려치기

2026-11-07 사용자 요청: 캐릭터디자인2 브랜치의 오른쪽 방향 이미지를 가져와 두 손을 검에 모으고, 들어 올린 뒤 내려치는 배경 없는 4초·60프레임 영상 제작.

대상은 해당 작업 폴더의 금발 장검·단검 전사 SD 픽셀 8방향 중 오른쪽 정측면 90도다. 정측면과 오른쪽 앞 사선 원본을 현재 영상제작 작업 폴더에 복사하며 출처 원본은 변경하지 않는다.

`60프레임`은 채팅에 안내한 대로 60fps로 해석한다. 4초 × 60fps = 240프레임이며, 과거 작업의 총 60장 추출과 다르다. 사용자 최종 시각 확인은 아직 받지 않았다.

현재 연결된 도구에 영상 생성 모델이 없어 이 사실을 안내하고, 내장 image_gen으로 원본을 참조한 동작용 파츠를 만든 후 2D 관절 애니메이션으로 영상을 제작한다. 영상 생성 모델 사용 결과로 표현하지 않는다.
