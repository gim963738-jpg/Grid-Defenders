작업 브랜치: `gim963738-jpg/영상제작`.

원본 출처: `gim963738-jpg/캐릭터디자인2` 작업 폴더의 미추적 제작물. 출처 파일을 복사했으며 SHA-256 동일 여부를 검증한다. 소스 브랜치 변경·체크아웃·병합은 하지 않는다.

이번 산출물은 `output/animation/sword-overhead-right-v01/`, `tools/sword-animation/`, 이 기록 폴더에 로컬 저장한다. `manifest.json`은 전달 파일 크기와 SHA-256을, 전체 ZIP은 영상·240개 PNG·파츠·프롬프트·검증·미리보기·재현 코드를 포함한다.

커밋·푸시는 요청받지 않았으므로 수행하지 않는다. 로컬 저장을 GitHub 저장으로 표현하지 않는다.

재현 순서: `python -m pip install -r tools/sword-animation/requirements.txt`, `python tools/sword-animation/render.py`, `python tools/sword-animation/verify.py`, `python tools/sword-animation/package.py`. 브라우저 검증 JSON은 실제 재생 검사 결과를 별도로 저장한다. ZIP의 재현 코드는 프로젝트 루트의 원래 코드 위치에 복원해 실행한다.
