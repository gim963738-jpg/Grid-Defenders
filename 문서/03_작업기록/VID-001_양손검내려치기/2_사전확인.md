# 목표와 대상

사용자의 이번 요청은 관련 원본 조회·복사, 동작용 파츠 제작, 애니메이션 렌더링, 투명 영상 인코딩과 로컬 저장을 포함한다. 별도 승인 절차를 추가하지 않는다.

출력 위치는 `output/animation/sword-overhead-right-v01/`, 재현 코드는 `tools/sword-animation/`이다. 게임 코드·전투 판정·캐릭터디자인2 원본 파일은 변경하지 않는다.

완료 조건은 오른쪽 방향 유지, 양손 모으기 → 검 들어 올리기 → 내려치기 → 마무리, 4.000초·60fps·240장, MOV와 WebM의 실제 알파, 모든 프레임의 투명 외곽과 충분한 여백이다. 검증은 PNG 전체 프레임, 밝은 배경과 전장 이미지 합성, 인코딩한 두 영상의 직접 디코딩으로 수행한다.

양손 사용을 위해 단검은 파츠 제작 시 허리에 수납한다. 이것은 이번 동작의 구성 변경이며 기존 두 무기 대기 원본을 대체하지 않는다. 별도 공격력·피해 범위·타격 횟수는 정하지 않는다.
