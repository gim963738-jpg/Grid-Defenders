# 가로 보스전 스킬 HUD
영웅 스킬 영역: left8/bottom8/높이64px. 영웅마다188×64px 묶음(초상화64px + 간격8px +56px 아이콘2개/간격4px), 묶음 간격8px. 최대3명580px, 영역 최대폭712px. 미배정 칸은 빈칸/대시로 표시하고 새 스킬을 만들지 않는다.
지휘자: right8/bottom8/64×64px, 기존 boss-commander-skill 버튼을 이동한다. 기존 병사 공격력+100/지속10초/쿨타임15초, 영웅 강화 제외 규칙은 그대로다. 버프 상태 테두리와 남은 쿨타임·상세 툴팁을 제공한다.
상단 자동: 기존 boss-auto-skills 버튼을 재생/일시정지 왼쪽에 이동,40×32px/간격4px. AUTO/ON·OFF와 aria-pressed를 실제 autoSkills와 동기화한다. 보스5버튼 총216px, 웨이브4버튼172px. 원래 자동 지휘/영웅 고유 스킬과 기본 자동 공격 규칙은 유지한다.
평타 칸은 자동 공격 딜레이 확인용이며 고유 스킬만 기존 버튼으로 수동 발동한다. 접근/재사용 대기/정지/전투 불가/종료를 표시한다. 일시정지와 사망 중 수동 발동은 차단한다. 기존 캐릭터·피해/효과·사거리 판정은 변경하지 않는다.
기존 세로 화면은 원래 패널/자동 버튼 위치와 전체 설명을 사용한다. WEB-160에서 숨겼던 스킬을 위 가로 HUD 형태로 노출한다.
