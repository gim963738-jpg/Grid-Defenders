# 반영과 검증

기존 프로필 21종을 출신 unassigned·소속 빈 배열·배치 상태 deferred로 통일했다. 빌더에 배치 보류 프로필의 출신·소속 유지 검사를 추가했다. 수석 빛 마법사의 현재 소속 메타데이터를 미지정으로 바꾸고 세계관의 활성 캐릭터 연결을 해제했다.

세계관 v1.11과 캐릭터 제작 모음 JSON·HTML, 설정집 Markdown·전체 HTML·현재 경로 데이터를 빌드했다. 첨부자료와 기존 작업물은 미배치, 신규 제작부터 배치한다는 기준을 지침과 제작 규약에 기록했다.

세계관 구조 검증과 캐릭터 원본 검증을 통과했다. 이미지 188종·보관 경로 193개, 원본 크기·SHA-256과 기존 7개 보관 분류를 유지했다. 클래스·특징·장비와 일러스트·SD 제작 순서도 유지한다.

브라우저에서 중앙대륙 마법사 0종, 출신 미지정 마법사 2종과 수석 빛 마법사의 소속 미지정 태그를 확인했다. 출신·클래스 북마크, 기존 보관 묶음, 원본 보기와 390px·320px 검증을 통과했다. 첫 모바일 터치 높이 확인이 한 차례 실패했으나 직접 재확인과 동일한 전체 검수 재실행은 통과했으며 제품 UI는 수정하지 않았다.
