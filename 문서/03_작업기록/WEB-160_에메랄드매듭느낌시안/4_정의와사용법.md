# 에메랄드 매듭 — WEB-160

2026-11-07. 사용자 요청: “초록빛이 갈라지고, 레이저로 연결됐다가 서로 꼬이며 모여서 회전·폭발하는 느낌”. 선 번호와 긴 JSON을 사용자가 직접 조립하는 방식 대신, 움직이는 시안을 공방에 추가하고 자연어 피드백으로 수정한다.

## 완성 시안

**에메랄드 매듭**,192px 콘텐츠·64프레임·20FPS·3.2초·투명 배경. 표시 크기는168px, 기준점은 중앙이다.

| 구간 | 연출 |
| --- | --- |
|0~0.23초|중앙에서 초록빛이 응집하고 두 빛이 같은 점에 겹침|
|0.23~0.65초|왼쪽 아래와 오른쪽 위로 두 갈래 분열|
|0.65~1.08초|각 부모의 실제 위치에서 다시 분열해 네 빛으로 확장|
|1.10~1.62초|두 쌍의 레이저를 차례로 연결하고 중심 연결 추가|
|1.62~2.42초|광원 위치가 교차하면서 레이저가 휘고 꼬임, 두 매듭으로 수렴|
|2.54~2.96초|두 매듭이 빠르게 회전하며 중심으로 조여듦|
|2.90~3.20초|중심 섬광·회전 광선·충격파·파편 폭발 후 투명하게 종료|

광원과 레이저의 실제 좌표가 연결된다. 이전 WEB-159/JSON 시안의 고정 직선 제한을 해소했다. 매 프레임 양 끝 광원의 위치에서 레이저 경로를 다시 계산하므로 이동 중에도 끝점이 붙어 있고, 굴곡은 끝점에서0으로 감쇠하여 선만 떠다니지 않는다.

## 사용법

- 현재 사용자 공방에 **에메랄드 매듭**을 별도 새 작업으로 추가하고 재생했다. 기존8개 작업을 남기고9개가 됐으며 이전 활성 작업도 보존했다. 원본 작업 JSON을 검증 폴더에 백업했다.
- **내 작업 → 에메랄드 매듭**, 또는 **기본 효과 → 에메랄드 매듭**으로 연다. 기본 효과를 누르면 새 복사본으로 편집한다.
- **미리보기**에서 전체 움직임, **전체 프레임**에서 밝은 배경 검수, **실제 전장**에서 게임 위 표시를 확인한다.
- **빛·레이저 연출** 패널에서 빛 크기·레이저 두께·발광 강도를 조절한다. 팔레트로 색을 바꾸고 FPS로 전체 속도를 조절한다. 실행 취소/다시 실행·자동 저장을 지원한다.
- 노드 화면에서는 **빛·레이저 연출** 이미지 소스로 사용할 수 있다. 색상/발광/마스크 등 기존 노드와 연결 가능하며 최종 출력에서 끊으면 출력에 나타나지 않는다.
- **내보내기 → 투명 PNG 시트 / 시트 배치 정보 JSON / 수정 가능한 작업 JSON**을 사용한다. 별도 샘플은 `게임/public/effect-recipes/emerald-weave.effect.json`이다.
- 이후 수정은 “분열을 더 빠르게”, “레이저를 굵게”, “마지막 폭발을 크게” 같은 자연어 피드백으로 진행한다. 이 작업에서 임의의 자연어를 자동 해석하는 외부 AI API를 연결한 것은 아니다.

## 구현·데이터 계약

`gd.effect@1`에 선택 필드 `sequence`를 추가했다. 예전 그림/레이어/노드 JSON은 그대로 열린다.

- `lights`: 위치·회전·크기의 시간 키프레임, 표시 구간, 부드러운 등장/소멸, 잔상.
- `beams`: 두 광원의 ID, 표시/연결 시간, 굵기, 굴곡·꼬임 시점과 위상. 광원 생존 구간 안에서만 존재하며 자기 자신을 연결하지 않는다.
- `bursts`: 중심 좌표, 구간, 반경, 회전·광선·파편과 재현 가능한 시드.
- 시간은 전체 재생 길이의0~1 비율이다. FPS가 달라져도 후반 동작을 자르지 않고 전체 연출을 같은 비율로 재생한다. 새 데이터는 외부 코드/URL을 실행하거나 가져오지 않는다.
- 광원 최대12개·광원당 키64개·레이저24개·폭발8개로 제한하고 ID·시간 순서·끝점 참조·색 인덱스·숫자 범위를 검증한다. 노드에서는 하나의 연출 소스를 여러 출력으로 분기한다.
- 원본은 투명 캔버스이며 기존 `SkillFrameSpec → createSkillFrame → SkillFrameArt`를 사용한다. 콘텐츠192px에24px 여백을 더해240px 셀을 만든다.8열 시트는1920×1920px이다. 패딩과 별개로 콘텐츠 기준 pivot/균일 표시 배율을 유지한다.
- 배치 JSON은 sequence와 팔레트·정규화 시간 기준을 보관한다. 피해/사거리/타수/대상/쿨타임은 미배정이다.58번째 프레임 완료 시점2.9초는 폭발 표시이며 피해와 연결하지 않는다. 실제 게임 스킬에 자동 장착하지 않는다.

## 검증

- 총362검사 통과. 기존315 + 새 프리셋 공통9 + 신규 연출 모델/렌더28 + 연출UI10.
- 모든 프레임에서 레이저 양 끝과 실제 광원의 좌표 일치, 실제 굴곡 변화, 부모 위치에서 분열, 네 빛→두 매듭 수렴, 회전·폭발 타이밍, JSON 왕복·결정적 렌더·노드 변환 일치·최종 출력 우회 방지·입력 검증을 확인했다.
- 새 제어값·undo/redo·자동 저장·노드 속성·PNG 출력 가능 여부와 새 빈 그림에 이전 연출이 섞이지 않는 것을 UI에서 검사했다. 기존 그리기/분기/노드/공방UI도 다시 확인했다.
-64프레임을 밝은 초록/회색 배경에 나열했다. 기본값과 노출한3개 제어값의 최댓값에서 콘텐츠 경계 닿음0프레임, 패딩 외곽 알파0을 확인했다. 첫/마지막 프레임은 투명하다.
- 실제 전장 상단/중앙에서 꼬임 구간을 확인했다.320/390px 가로 넘침 없음,320px/DPR3에서 새 슬라이더296×48px 및 전장274×302 CSSpx/780×860 렌더를 확인했다. 캡처는DPR1에서 확인했으며 실기기 검증은 별도다.
-0.25×·1×·5×·정지의 기존 UI 검사를 재실행했다. 타입 검사·프로덕션 빌드·`git diff --check` 통과.
- QA는 별도 `localhost:5182` 창에서 수행했다. 사용자 `127.0.0.1:5182`에는 요청한 완성 시안 한 개만 실제 UI로 추가했다. 기존 작업을 덮어쓰지 않았다.
