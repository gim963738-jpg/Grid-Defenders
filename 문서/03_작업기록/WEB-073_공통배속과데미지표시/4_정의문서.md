# 정의문서
지원 배속:0.25×,0.5×,1×,2×,3×,5×. 초기1×에서 클릭 시2→3→5→0.25→0.5→1 반복. 선택은 웨이브/보스 간 유지. 게임 리셋 시1×로 복귀.
main ticker의 실제 시간 제한0.1초 안에서 speed배 시뮬레이션을 최대0.05초씩 분할. 웨이브 tick은 실제 단위, 보스 tick은 시뮬레이션 단위로 호출해 배속 중복 또는 시간 제한 손실 방지. DPS와 전투시간은 기존 게임 시간 기준. 화면 전환과 승리 후 복귀 대기 시간은 실제 시간 유지.
데미지 숫자는 기본ON. OFF 시 웨이브의 일반/치명타 피해 텍스트와 보스 피해 텍스트만 숨김. 체력/이름/쿨타임/이펙트/전투 피해/로그/DPS는 유지. 기존 텍스트 풀도 즉시 숨기며 켜면 현재 살아 있는 숫자를 다시 표시. 이 표시 설정은 장면 전환 및 게임 리셋 후에도 유지.
