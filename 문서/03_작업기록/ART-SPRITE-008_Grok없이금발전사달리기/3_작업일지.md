# 작업 일지

2026-11-07.

1. 내장 이미지 생성 스킬과 기존 확정 캐릭터의 오른쪽/정면 참조를 확인했다.
2. 내장 `image_gen`으로 오른쪽 달리기 6×5 시트를 실제 생성했다. Grok 및 외부 API 키는 사용하지 않았다.
3. 실제 반환 크기 1374×1145px를 30장으로 분리하고 재샘플링 없이 고정 256px 캔버스로 포장했다.
4. 원본 21번 검 끝 3픽셀의 셀 경계 누출을 발견해 21/22의 추출 경계만 8px 옮겼다. 두 캐릭터의 위치는 유지했다.
5. 30프레임 APNG, 번호 시트, 순서 JSON, 무한 재생·프레임 선택·배경·속도 조절 미리보기를 만들었다.
6. 최종 셀 가장자리·알파·원본 픽셀 귀속과 APNG 전체 디코딩을 확인했다. 브라우저 반복·정지·재개·속도·배경 전환과 390px 화면을 확인했다.

검사 기록은 결과 폴더의 `verification.json`, `source-grid-verification.json`, `ownership-verification.json`, `browser-verification.json`에 있다. 원본 격자에서 발견한 경계 값은 숨기지 않고 남겼으며 실제 출력의 귀속 수정 결과를 별도로 기록했다.

프레임별 얼굴·갑옷·무기 및 자세 변화는 이미지 생성의 검토 사항으로 남는다. 엄격한 픽셀 팔레트 정리와 실제 게임 통합 검사는 실행하지 않았다. 결과는 사용자 검토용 1차 시트다.
