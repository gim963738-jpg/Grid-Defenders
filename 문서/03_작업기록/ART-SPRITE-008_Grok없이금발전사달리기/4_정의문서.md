# 정의

| 항목 | 값 |
| --- | --- |
| 대상 | 금발 장검·단검 SD 전사 |
| 동작 | 오른쪽 달리기, 제자리 반복 |
| 생성 경로 | 내장 image_gen, 실제 이미지 시트 생성 |
| 영상 생성 | 수행하지 않음 |
| 셀 / 격자 | 256×256px / 6열×5행 |
| 시트 크기 | 1536×1280px |
| 순서 | 왼쪽→오른쪽, 위→아래, 01…30→01 |
| 시간 | 30fps, 합계 1,000ms, 각 프레임 33/34ms |
| 공통 시각 기준점 | (128,234), 판정과 분리한 명목상 기준점 |
| 재생 기본값 | 재생 중, 무한 반복 켜짐 |
| 추출 특례 | 21/22 경계 8px 오른쪽 이동, 원래 캐릭터 위치 유지 |
| 사용자 확인 | 대기 |
| 게임 통합 | 미실행 |

`preview-atlas.webp` 및 채팅 HTML은 용량을 줄인 표시용 사본이다. 실제 납품 PNG는 256px 원본 크기와 알파를 유지한다. 생성 프롬프트의 요청 크기와 실제 반환 크기는 `generation-record.json`에 각각 기록한다.
