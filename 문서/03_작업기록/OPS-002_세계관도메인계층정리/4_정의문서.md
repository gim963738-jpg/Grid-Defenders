# OPS-002 도메인 정의

| 도메인 | 역할 ID | 처리 |
|---|---|---|
| 세계관 | world | 새 관리·색인 공간, domain/world-index |
| 세계관/몬스터 | monsters | 기존 몬스터 공간 재사용 |
| 세계관/몬스터/몬스터 스프라이트 | monster_sprites | 새 작업 공간, domain/monster-sprites |
| 세계관/캐릭터 | characters | 기존 캐릭터·세계관 공간 재사용 |

| 세계관/캐릭터/캐릭터 스프라이트 | sprites | 기존 캐릭터 동작·시트 공간 재사용 |
| 세계관/캐릭터/캐릭터 능력치 | character_stats | 새 분류·작업 공간, domain/character-stats |

| 캐릭터 스프라이트/영상·모션 소스 | video | 기존 영상 공간 보존 |
| 캐릭터 스킬/이펙트·제작도구 | effects | 기존 공용 도구 공간 보존 |

도메인 내부10노드, UI·아이템 외부 역할2개, 총12개 전문/관리 역할과 기존 메인3개다. 새 관리 노드를 추가 메인 채팅으로 간주하지 않는다. 새 제작 AI는 시작하지 않았다.

분류 원본은 [도메인 트리](../../../작업관리/도메인/트리.json), 실제 전달 대상은 [브랜치목록](../../../작업관리/브랜치목록.json)이다. 각 노드의 index.json은 실제 원본 위치·상태·참조 해시를 기록한다. 파일의 물리적 위치를 도메인 분류와 구분하며 기존 경로를 끊지 않는다.

기획 문서·시제품 수치·실제 구현·사용자 합격의 구분을 유지한다. 몬스터의 신체·동작 검수와 캐릭터의 인간형/무기 동작 기준을 하나로 강제 통합하지 않는다.
