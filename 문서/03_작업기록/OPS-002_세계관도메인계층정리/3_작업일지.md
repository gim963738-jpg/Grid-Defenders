# OPS-002 작업 일지

2026-11-08. 규칙·작업 목록·운영 기준·직전 기록·실제 Orca/Git 상태를 확인하고 [사전확인](2_사전확인.md)을 먼저 저장했다.

- 기존11개 작업 공간의 실제 관계·HEAD·미커밋 상태와 수정 대상 지침·운영 원본을 저장소 밖에 백업했다.
- 세계관 관리·몬스터 스프라이트·캐릭터 능력치·캐릭터 스킬4개 공간을 공식 Orca CLI로 추가했다. 새 제작 AI는 시작하지 않았다.
- 실제 작업 목록을 세계관→몬스터/캐릭터→세부 담당으로 재배치했다. 기존 몬스터·캐릭터·일러스트·캐릭터 스프라이트 공간의 실제 경로·Git 브랜치·채팅 이력은 유지한다.
- 영상·모션 소스를 캐릭터 스프라이트 아래, 이펙트·제작 도구를 캐릭터 스킬 아래에 보존했다. 이펙트의 공용 도구 성격을 원본 색인에 표시했다. UI·아이템의 기존 위치와 메인3개는 유지했다.
- 공유 도메인 폴더와 각 노드의 index.json에 실제 작업 공간·원본 위치·자료 상태를 연결했다. 기존 세계관 자료가 캐릭터 작업 공간에 있는 경우 그 원본 위치를 보존해 참조한다. 새 체크아웃의 과거 사본을 최신 원본으로 사용하지 않도록 명시했다.
- 공통 규정 A1.1에 도메인 분류를 연결하고 분야별 제작·검수 규정은 보존했다. 기존 역할 ID를 유지해 과거 작업 기록과 전달 경로를 끊지 않았다.
- 기존12개 절차 검사와 새8개 도메인 검사, 총20개 테스트를 통과했다. 누락된 노드·잘못된 부모·순환·중복 담당·오래된 분류 경로를 거부하는 경우를 포함한다.
- 실제 Orca 조회로 부모 관계·표시 이름·원본 경로·기존 HEAD를 검증했다. 원래 게임 변경 파일과 UI 작업 사본·실행 리소스의 보존 대조도 통과했다.
