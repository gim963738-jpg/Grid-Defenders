# OPS-002 버전 관리

기존11개 작업 공간의 경로·Git 브랜치·HEAD와 채팅 이력을 보존했다. 분류용4개 Git 작업 공간을 추가했으며 실제 경로·브랜치는 [브랜치목록](../../../작업관리/브랜치목록.json)에 기록했다. Git 브랜치 이름 변경·병합·리셋·스태시·커밋·원격 푸시는 하지 않았다.

[정리 전 상태](../../../작업관리/기록/OPS-002/before.json)에 저장소 밖 백업 경로와 원본 지침 해시·기존 작업 상태가 있다. [CLI 영수증](../../../작업관리/기록/OPS-002/영수증)과 [정리 후 실제 관계](../../../작업관리/기록/OPS-002/after-orca.json)를 보존한다. 연결 지침은 기존 문서 뒤에 추가해 원래 내용의 바이트 접두부를 유지했다.

현재 운영은 A1.1.0이며 A1.0.0의 과거 기록·검증은 보존한다. 이번 변경은 부모 관계·분류 색인·연결 규정·검사와 문서에 한정되며 기존 게임 코드와 아트 원본은 유지한다.
