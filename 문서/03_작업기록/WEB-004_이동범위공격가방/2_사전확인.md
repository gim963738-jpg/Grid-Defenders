# WEB-004 — 사전 확인 및 승인

## 목표
요청6개와 블록 더블클릭 회전을 구현·검증·로컬 저장.

## 변경 대상
- defense.ts: moveUnit, 범위 판정·다수 피해, 가방 좌표·빈 공간·회전.
- defenseView.ts: 진한 범위, 공격 영역 이펙트, 입력 대상 유지.
- defenseConfig.ts: 부채꼴 반각/폭발 반경 시험값.
- main.ts: 유닛·아이템 드래그, 영웅 클릭 메뉴 연결, 격자 렌더·더블클릭/두 번 탭.
- index.html·style.css: 공용 격자·선택 장비 조작·안내.
- README·task·큰기획·전투/아이템 세부기획·정의·UI 라벨·이번 기록5개·화면 이미지.

## 완료 조건
- 모든 유닛 이동·교체 가능, 경계 밖 드롭은 취소.
- 이동 후 골드·강화·장비·ID·공격 대기시간 보존.
- 영웅 클릭 시 정확한 영웅 장비창 선택, 드래그는 단순 클릭과 구분.
- 보병·마법병 이펙트 내부 적만1회씩 피해, 처치 보상 중복 없음.
- 공용 가방 구매품 자동 배치·무제한 확장·이동·회전·장착/해제 시 소실·겹침 없음.
- 두 가방 더블클릭 회전1회, 경계·충돌 실패 시 기존 상태 유지.
- 빌드·브라우저·모바일 폭 확인.

## 범위 밖
영웅 자동 스킬·보스·웨이브·조합·영구 저장·신규 아이템·최종 디자인. 기존 사거리·가격·공속 수치 변경 없음.
