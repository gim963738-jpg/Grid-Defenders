# WEB-004 — 정의

- moveUnit: 유닛 ID를 유지하며 slot 이동, 점유 대상이 있으면 두 slot 교환. 타입 제한 없음.
- AttackArea: sector(중심·반경·방향·반각) 또는 circle(중심·반경), 표시 지속시간·색상 포함.
- inAttackArea: 적 중심이 해당 부채꼴/원 내부인지 판정. 동일 값으로 Pixi 이펙트 그림.
  ↳ 쉽게 말하면: 보이는 공격 영역과 실제 맞는 영역을 따로 계산하지 않는다.
- hit: 대상별 실제 피해·처치·골드·로그 처리. 사망 적 재처리 금지.
- Gear.owner: 영웅 ID는 장비칸, null은 공용 가방. x/y는 해당 가방 내부 칸 좌표.
- canPlace: 소유 공간·경계·점유 검사 후 변경. 실패하면 기존 소유자/방향/좌표 유지.
- findBagSpace: 위에서 아래·왼쪽에서 오른쪽 순서로 현재 모양이 들어가는 빈 자리 탐색.
- bagRows: 최소6행, 아이템 위치에 따라 여유행을 포함해 확장. 보관 수량 상한 아님.
- rotateGear: 현재 기준칸에서90도 회전. 경계·겹침 불가 시 안내하고 회전하지 않음.
- double-click: 같은 블록 ID의 빠른 두 클릭/두 탭 또는 브라우저 이중 클릭 입력. UI 갱신 때문에 DOM이 교체돼도 ID로 판정, 중복 회전 방지.
- 블록 오프셋: 집은 칸과 모양 기준칸의 차이. 드롭 위치에서 차이를 빼어 모양을 유지.
