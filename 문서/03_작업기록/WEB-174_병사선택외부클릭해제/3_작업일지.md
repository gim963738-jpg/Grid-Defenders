# 작업 일지 — 2026-11-07
- 포인터를 누르기 전 병사 선택/소환 대기를 기록하고, 클릭 동작이 처리된 뒤 같은 선택이 남으면 해제한다. 첫 선택이나 다른 유닛으로 전환한 선택은 유지한다.
- 배경·메뉴·조작 버튼·전장 밖 클릭과 같은 병사/카드 재클릭으로 선택을 해제한다. 전장의 강조·상세·승급 버튼과 카드의 소환 대기/강조가 함께 갱신된다.
- 드래그 완료 및 취소된 클릭은 일반 해제 처리에서 제외한다. 승급/배치 등 버튼의 실제 동작이 먼저 완료되고 선택 상태만 정리된다.
- 가로 병사 카드 강조는 실제 `api.pending`과 일치시켜 드래그 소환 후에도 카드만 선택 상태로 남지 않게 했다. 영웅/상점 카드의 기존 선택 규칙은 유지한다.

## 검증
실제 브라우저23항목 통과: 배경/프레임 밖 해제, 병사 카드 첫 선택/재클릭/다른 카드 전환/빈 목록/조작 버튼, 실제 마우스 전장 첫 선택/재클릭/다른 병사 전환/빈 공간, 드래그 이동 후 선택 유지 및 다음 클릭 해제, 승급1회 후 해제, 정상 단일 소환/비용/대기 해제, 배치 후 외부 클릭, 영웅 배치/정보창, 상점 첫 선택/재클릭. 입력 전 렌더 갱신을 기다린 상태에서 배치를 확인했다.

프로덕션 빌드와 diff 공백 검사 통과. 별도 영구 테스트나 전투/아트 전체 회귀 검사는 추가하지 않았다. 사용자 최종 화면 확인은 별도다.
