# WEB-184 사전 확인

작성 시점 정정: 이 파일은 실제로 구현·검증 후에 작성한 요구사항·완료 기준의 사후 정리다. 작업 전에 작성·저장한 사전확인 문서가 아니다. 당시 채팅으로 방향은 안내했지만, 대상 파일·제외 범위·완료 조건·검증 방법을 모두 사전에 보고하지 못했다.

대상: 가로 웨이브의 지형 표시·진행 경로·배치 격자 연결. 사용자 요청으로 구현과 검증이 승인된 범위다.

변경 파일: landscapeField.ts 신규, defenseConfig.ts, landscape-entry.ts, landscape-game.css, 관련 검사와 현재 문서. 기존 이미지 파일을 덮어쓰지 않는다.

완료 기준: 직선 길 기준 폭58px, 안쪽 기준선x160/450, 진행 중심x131/479, 기존20칸 유지. 잔디·흙길이 단단한 사각 절단면 없이 연결되고 실제 몬스터 이동·배치·보스 왕복이 정상이어야 한다.

검증: 타입·빌드, 세로/가로 모델 검사, 격리한800×360 브라우저의 DOM·SVG 픽셀·이동 확인. 실제 모바일 기기 성능과 전체 전투 밸런스는 이번 검증 범위에 포함하지 않는다.
