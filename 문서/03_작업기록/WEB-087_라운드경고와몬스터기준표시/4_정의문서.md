# 정의문서
- upcomingWaveWarning: 현재 wave/waveTime/bossPending에서 다음 라운드 종류와 남은 초 반환. 남은 시간10초 초과/0초 이하 또는 보스 게이트 중에는 null.
- wave-alert: 전장 중앙의 경고 오버레이. named=주황, boss=빨강. 라운드 시작까지 유지하며 기본10→1 카운트다운. 전장 클릭/드래그를 막지 않음.
- waveWarningKey: 라운드/종류가 바뀔 때만 설명과 접근성 라벨 갱신. 초 표시만 별도로 갱신.
- enemy-limit: 두 일반 웨이브 분량. 현재 RULES.waveMonsters=10이므로20. 카운트 표시 기준이며 패배 판정과 연결하지 않음.
확정 범위: 사용자 요청 경고 및 수량 표시. 신규 실패 조건·몬스터 수 제한·전투 수치 변경 없음. 최종 외관 확인 대기.
