# 공방 부품 노드와 사용성 — WEB-168

사용자 요청: 전체 이펙트를 한눈에 확인하고, 마법진의 불꽃·바닥 고리·문양처럼 의미 있는 부분을 분리해 보관하고 다른 작품에 재사용한다. 기존 기능의 사용성과 렌더링 낭비도 점검한다.

- 적용 범위: 개인 이펙트 공방, 전체 갤러리, PNG 재료함. 실제 전투 피해·사거리·타수·대상·쿨타임은 변경하지 않는다.
- 원본: 사용자 저장 작품과 수집 PNG는 보존한다. 부품은 선택 노드의 입력 연결과 독립 팔레트·그림 경로·시간표를 복제한다. 완성 PNG의 원래 레이어를 자동 복구한다고 표시하지 않는다.
- 시간: 부품의 내부 시간 비율은 유지하고 현재 작품의 전체 길이에 맞춘다. 현재 작품의 FPS·프레임 수·기준점·표시 크기를 자동 변경하지 않는다.
- 좌표: 원본 정규화 좌표와 픽셀 설정을 유지한다. 상위 캔버스에 균등 비율로 그린다. 노드 카드 배치는 시각 좌표와 분리한다.
- 저장: `gd.effect@1` 그래프에 `component` 소스 노드 추가. 부품 원본을 JSON 안에 포함해 외부 파일 참조 없이 백업한다. 부품 보관함은 작품 저장함과 별도 키를 사용한다. 손상된 보관함을 읽기 중 덮어쓰지 않는다.
- 분리 예제: 마법진 화염 분출, 192px·60F·30FPS. 바깥 고리·사각 문양·솟는 불꽃·불씨 네 소스. 빛·레이저 연출은 광원·레이저·폭발 그룹도 독립 추출한다. 레이저 이동에 필요한 광원 위치는 투명 상태로 보존한다.
- 한계: 부품 3중첩/전체 원본24개/내부 포함256노드, 작업 JSON512KB. 내 부품60개/2MB. 지원하지 않는 재귀·외부 이미지·코드 실행은 허용하지 않는다.
- 검증: 노드 추출 전후 픽셀·팔레트·연결·방향·JSON·저장·실행 취소, 밝은 회색/초록 전체60F, 실제 전장 상단/중앙과320·390px/DPR3, 재료함 정지 상태 렌더링과 속성창 유지, 타입 검사와 빌드.
