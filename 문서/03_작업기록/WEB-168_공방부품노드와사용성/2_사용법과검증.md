# 부품을 꺼내 쓰는 공방

## 원하는 결과부터 보기

공방 왼쪽 **전체 이펙트 한눈에 보기**를 누르면 기본 효과와 내 작품을 한 격자에서 재생한다. 검색·전체 화면·배경·재생 속도·카드 크기를 조절할 수 있다. 각 카드의 **구성 부품 보기**는 해당 작품의 노드 화면으로 이동한다. 기본 효과는 새 작업을 만들고, 저장 작품은 기존 작업을 연다.

## 불꽃만 다른 마법진에 넣기

1. 기본 효과 **마법진 화염 분출**을 열고 **노드**를 선택한다. 바깥 고리, 사각 문양, 솟구치는 불꽃, 떠오르는 불씨가 별도 소스다.
2. 불꽃 노드를 선택하면 오른쪽에서 **전체 결과 / 선택한 부분**을 함께 본다. **노드 재생** 또는 아래 타임라인으로 움직임을 확인한다.
3. **이 부분 보관**에서 이름과 카테고리를 정한다. 색상·발광 같은 처리 노드를 선택하면 그 앞쪽 소스와 연결도 함께 저장된다.
4. 다른 작품에서 **부품 보관함 → 내 부품 → 현재 작품에 넣기**를 누른다. 원래 색상과 모양을 가진 부품 노드가 최종 출력에 자동 합성된다.
5. 부품을 선택한 상태에서 색상·크기·발광 처리 노드를 추가한다. 연결을 자동으로 끼워 넣는다. 이 처리 노드를 삭제하면 원래 입력과 출력을 다시 연결한다.

부품 보관함의 **현재 작품의 구성 / 다른 저장 작품의 구성**에서도 필요한 부분을 찾아 바로 추가하거나 **보관**할 수 있다. 에메랄드 같은 연출은 전체 연출뿐 아니라 광원·레이저·폭발 그룹을 따로 제공한다. 레이저 끝점의 움직임은 보이지 않는 광원 경로로 유지한다.

## 보존되는 것과 범위

- 기존 작품을 바꾸지 않고 복제한다. 팔레트가 다른 작품에 넣어도 부품 자체의 색상을 유지한다.
- 내부 시간 비율은 보존하고 현재 작품의 전체 길이에 맞춰 재생한다. 캐릭터 이동 자체를 상위 작품의 이동 명령으로 추가하지 않는다.
- JSON에 부품 원본을 함께 넣으므로 보관함에서 지워도 이미 넣은 작품은 유지된다. 부품 삭제 취소·개별 JSON·보관함 백업·가져오기를 지원한다.
- 레이어로 남아 있는 절차적 효과/그림/연출을 분리한다. 완성 PNG 속 불과 문양을 원래 레이어로 자동 복구하지 않는다. 수집 PNG의 구간·낱장·색·합성은 무료 재료함에서 다룬다.
- 3중첩·원본24개·전체256노드·작업512KB, 부품 보관함60개·2MB 제한을 넘으면 변경 전에 오류를 표시한다. 기존 저장 데이터를 읽지 못하면 덮어쓰지 않는다.

## 함께 고친 불편

| 항목 | 변경 |
|---|---|
| 노드 이동·화면 확대 | 픽셀이 바뀌지 않는 편집은 전체 프레임을 다시 생성하지 않음 |
| 노드 미리보기 | 매 프레임 PNG 인코딩 대신 Canvas 사용. 연속 프레임 입력으로 갱신이 계속 밀리던 debounce 문제 수정 |
| 부품 추가 취소 | 배치 조정까지 한 번의 작업으로 묶어 실행 취소 한 번으로 복구 |
| 연결도 재구성 | 가져온 부품 소스를 유지 |
| 기본 효과 목록 | 고정된 프리셋과 미리보기 캐시 재사용 |
| 전체 프레임 | 해당 화면을 열 때만 DOM 생성 |
| PNG 재료 설정 | 값을 바꿔도 위치·회전 등 펼쳐 둔 설정창 유지 |
| PNG 재료 재생 | 보이는 카드만 관찰하고 프레임 변경 시 갱신. 매 프레임 UUID 생성과 레이아웃 측정 제거 |
| PNG 조합·전장 정지 | 같은 프레임의 재합성·텍스처 재생성 생략. 위치 변경은 한 번 다시 그림 |
| 숨긴 페이지·종료 | 숨김 상태의 시간 진행 중단, 종료 시 관찰자·애니메이션·전장 정리 |

## 검증 기록

사용자 포트5182 저장함을 UI 시험에 쓰지 않고 별도5191에서 검사했다.

- `effect-components.check.ts`: 모델/픽셀31개 + UI14개 통과. 원본 픽셀·팔레트 독립·그림 시간표/방향·입력 연결·JSON 왕복·손상 저장 보존·중첩 제한·카테고리·추가/실행 취소/다시 실행·처리 삭제 연결 유지·줌 시 타임라인 재사용·연속 프레임 갱신·삭제 복원.
- 기존 노드36개, 공방206개, 갤러리29개, 그리기27개, 분기12개 통과. 위 신규45개와 합계355개.
- 타입 검사와 프로덕션 빌드 통과. 새 소스의60프레임 모두 경계 미접촉. `all-frames.png`에서 밝은 회색/초록의 전체 프레임과 네 부품을 확인했다.
- 부품 보관함320px·390px/DPR3에서 문서/대화상자 가로 넘침 없음, 표시된 버튼·입력48px 이상.
- 실제 전장 상단/중앙에 부품이 포함된 작품 표시. DPR3 버퍼1170×1290, 390px에서 표시344×379, 320px에서274×302로 같은 종횡비. 원본 캔버스 캡처 `battle-art-top.png`, `battle-art-center.png` 보관.
- 전장0.25×·1×·5× 선택과 정지 프레임 조작 확인. 이번 자동 브라우저는 숨김 상태가 자주 유지되어 실시간 배속 경과를 장시간 측정하지 않았다. 대신 연속 프레임 입력 중 노드 갱신/정지를 별도 검사했다.
- PNG 재료함24카드 표시, 추천 조합 추가, 펼침 상태 `[false,true,false]` 유지, 크기 변경 저장, 정지 제어 확인. 기존 재료함 전체 검사는 숨긴 페이지의 자동 재생 검사에서 중단되어 이번355개에 포함하지 않았다. 원본 프레임/라이선스 수집 검사는 WEB-167 기록을 따른다.

산출물은 `output/effect-components/`. 게임 전투에 새 스킬을 장착하거나 외부에 사이트/원본 소재를 공개 배포하지 않았다. 사용자의 최종 외관 평가는 구현·자동 검사와 별개다.
