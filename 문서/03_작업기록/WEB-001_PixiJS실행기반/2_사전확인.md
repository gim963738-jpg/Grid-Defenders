# WEB-001 — 사전 확인

## 목표
PixiJS 초기화 화면이 브라우저에서 실행되고 배포용 빌드가 성공하는 상태.
↳ 쉽게 말하면: 게임 제작을 시작할 기본 작업장이 정상 동작하는지 확인한다.

## 생성·변경 범위
- 게임/package.json, package-lock.json: 설치 패키지·버전·실행 명령.
- 게임/index.html: 초기 진입 화면과 진단용 캔버스 크기 설정.
- 게임/tsconfig.json: TypeScript 검사 설정.
- 게임/src/main.ts: PixiJS 초기화와 렌더링 확인 도형·문구.
- 게임/README.md: 실행·빌드 안내.
- 게임/.gitignore: 설치 폴더와 빌드 산출물을 Git 저장에서 제외하는 필수 보조 설정.
- task.md, 큰기획.md, 정의목록.md: 현재 상태 갱신.
- 해당 작업 5개 기록 문서.

## 제외
전투·소환·장비·상점·이미지·게임 UI 배치·호스팅·앱 배포. 원본 HWP 수정 없음.

## 승인 근거
첫 작업 범위 보고 → 유저의 PixiJS 선택 → 이전 기획 GitHub 저장 → 유저 `다음진행`.

## 완료 조건
- npm 설치와 TypeScript 검사·Vite 빌드 성공.
- 브라우저에서 캔버스와 진단 도형·문구 표시.
- 좁은 화면에서 가로 넘침 없음.
- 실제 실행 결과·미확인 항목 기록.
