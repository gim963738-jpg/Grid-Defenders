# 제작과 검증

지정 원본 20장을 그대로 복사해 5열×4행 시트와 APNG·미리보기를 만들었다. 원본 SHA-256 일치, 연결 15(앞23)→16(새09), APNG 20장 디코딩·256px·1333ms·단발 재생과 연결부 재생 버튼을 검사했다. 밝은 배경의 번호 시트를 확인했다.

후속 요청으로 HTML 미리보기에 무한 재생 토글 버튼을 추가했다. 켜면 20→01 반복 및 자동 재생, 끄면 마지막 자세 정지다. 반복 경계·여러 회차 진행·일시 정지/재개·반복 끄기 후 종료를 브라우저로 확인했고 배포 ZIP의 HTML과 안내도 갱신했다. PNG 프레임과 다운로드용 단발 APNG는 유지했다.
