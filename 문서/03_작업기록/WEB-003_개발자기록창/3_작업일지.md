# WEB-003 — 작업 일지

- 날짜: 2026-11-02.
- 구현: 임시 개발자 기록창3구역, 넓은 화면 왼쪽/모바일 아래, 최신 위·독립 스크롤.
- defense.ts: 피해·처치·골드 거래를 발생 지점에서 직접 기록. 공격값과 실제 체력 감소량 분리, 잔여 체력0 하한. 거래 실패 시 기록 안 함.
- main.ts: 공격 로그는 게임 패널 갱신과 분리, 약0.15초 간격 화면 반영. 변화한 구역만 갱신, 읽던 기록 위치 유지.
- 구역별 메모리·DOM 최근100건. 로그 번호는 게임 객체 번호와 별도여서 대상 식별에 영향 없음.
- 선택 유닛 정보에 고유번호와 배치 행·열 추가.

## 검증
- TypeScript·Vite 빌드 성공.
- 모델16개 검증: 소환/강화/판매/구매/리롤 잔액, 실패 거래 무기록, 초과 공격에서 실제 피해5(공격75), 공격자·대상·시간, 중복 처치 방지, 무료 영웅0G, 골드 보너스 버림, 구역별100건 상한·최신순.
- 실제 UI: 궁병 소환 -75, 강화 -45, 철검 -60, 리롤 -20이480→280G와 일치.
- 실제 자동 공격: 공격38로 잔여체력8인 적에게 실제 피해8 표시, 처치12G·잔액 전후 확인.
- 데스크톱에서 왼쪽 패널과 게임 겹침 없음.320px 모바일에서 하단 배치·가로 넘침 없음.
- 스크롤 중 신규 피해 기록 추가 시 동일 행 유지(위치 오차1px 미만).
- 실제 화면 캡처를 열어3구역과 내용 표시 확인.
- 새로고침 시 초기화. 실제 기기·장시간 성능 및 영구 보존은 검증 범위 아님.
