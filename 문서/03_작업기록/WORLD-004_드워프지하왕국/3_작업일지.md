# 제작과 확인

내장 image_gen에 v20 전체 지도와 산맥 확대본을 전달해 한 번 생성했다. 사하리드 왕국 오른쪽 산맥에 새겨진 석문과 따뜻한 불빛의 지하 입구, “드워프의 지하왕국” 표기를 시각 확인했다.

출력은 1254×1254 불투명 RGB PNG다. 생성 원본과 프로젝트 보관본의 바이트가 동일하며 크기를 변경하지 않았다. v17~v20의 이전 지도 해시도 유지됐다.

설정집 v1.2에 드워프 지하왕국의 위치와 지하 입구 설명을 추가했다. 남부 지역 본문과 지리·거점 항목에 연결했으며 다른 국가에 대한 종속·동맹 관계는 지정하지 않았다.

구조 검증은 이름 18개·연결 경로 14개와 기존 국가·수도·가문·신앙·부족 설정을 확인했다. 브라우저에서 메뉴 7개·표식과 범례 9개, 두 자연·지리 거점 선택, 390/320px의 가로 넘침 방지와 최소 44px 버튼을 확인했다. 개별 거점을 누르면 해당 거점 설명을 표시한다.

전체 설정집을 v21 지도와 새 설명으로 갱신했다. 이전 오른쪽 설정집 탭은 사용자가 닫은 상태이므로 다시 열지 않고, 추가 확인은 별도 숨김 브라우저에서 수행했다.
