# WEB-012 — 사전 확인

- 대상: defenseConfig.ts(시험값), defense.ts(현상금·치명타·피해 이벤트), defenseView.ts(몬스터/숫자/이동 잔상), main.ts·index.html·style.css 및 관련 문서.
- 일반 처치 누적50마다 소환 기회1회. 대기 기회 누적, 활성 현상금1마리 제한, 처치 후 다음 기회 사용 가능. 현상금 처치는50조건 제외.
- 버튼은 오른쪽 위 길 안쪽, 기회가 있으면 표시. 클릭 즉시 경로 시작점 등장, 기존 순환 경로 이동. 일반30마리 한도와 별도로 현상금1마리 허용.
- 모루1개·기본100G, 기존 장비 골드 획득 보너스 적용. 보상 로그에 모루와 골드 기록.
- 병사3종 기본 치명타10%·1.5배, 공격1회당 판정. 범위 공격은 같은 판정을 공유. 영웅의 치명타는 이번에 추가하지 않음.
- 모든 유닛의 적 타격 실제 체력 감소량을 숫자로 표시, 치명타는 큰 노란 글씨. 병사 이동 목표 칸에 반투명 실루엣·테두리.
- 제외: 웨이브·보스전·스킬·현상금 추가 패턴·모루 추가 용도·승패.
- 완료 조건: 조건/중복 소환/보상/초기화·치명타/숫자 수명·이동 잔상/실제 이동·모바일·빌드 검증.
