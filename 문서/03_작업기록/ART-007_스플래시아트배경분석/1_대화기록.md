# 스플래시 아트 배경 분석 요청

작성일: 2026-11-06.

사용자는 스플래시 예시 13장을 제공하고, 캐릭터의 콘셉트를 살려 주는 배경의 특징을 분석·해석·분류·정리한 뒤 재사용할 생성 프롬프트 양식을 요청했다. 이어 기존 그림체 규칙의 준비 상태와 저장 이름을 물었다.

기존 그림체의 저장 이름은 **GC9 캐릭터 그림체 기준**, 식별자·버전은 **GC9 v1.1**이다. 이번 배경 구성 규칙은 **SP13 v1.0**으로 구분했다. 캐릭터 화풍에 관한 C4 얼굴·C3 금속 우선 기준은 계속 적용한다.

이번 요청은 분석과 프롬프트 준비다. 신규 스플래시 이미지 생성이나 모델 가중치 추가 학습을 수행하지 않았다.
