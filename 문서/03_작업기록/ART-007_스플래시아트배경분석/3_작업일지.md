# 분석과 검증

13장의 원본을 바이트 변경 없이 보관했다. 개별 기록에는 관찰 요소·구도·전경·중경·후경·광원과 색·제작상 해석·적용 규칙·그대로 옮기지 않을 요소를 저장했다. 주된 배경 역할에 따라 8유형을 정하고 보조 유형도 기록했다.

배경 구성 규칙, 통합 스플래시 기본 프롬프트, 유형별 모듈 8개, 배경 단독 제작 양식, 수정 문구와 기획 입력 JSON을 작성했다. HTML 보고서에는 주 유형 필터, 관찰 항목 전환, 개별 분석 펼침, 원본 100% 보기를 추가했다.

검증 결과:

- 원본 13개의 SHA-256·크기를 Downloads 및 목록과 대조해 일치 확인. 원본 합계 1,164,121바이트.
- 참조 13개·유형 8개·유형별 소속·고유 ID·9개 관찰 항목·JSON 구문·보고서 내장 데이터 일치 확인.
- 규칙·양식·보고서의 정적 로컬 링크 12개와 원본 경로 13개 확인.
- Headless Edge에서 이미지 13개 디코딩, 전체 및 8유형 필터, 관찰 항목 9개 전환, 원본 보기 작동 확인.
- 첫 원본의 자연 너비와 표시 너비 모두 735픽셀. 모바일에서도 원본 크기를 유지하고 내부 스크롤로 표시.
- 화면 너비 1400에서 3열, 390에서 1열. 모바일 페이지 가로 넘침 없음. 데스크톱 캡처 시각 확인.
- `git diff --check` 통과.

신규 이미지 출력은 없어 스플래시 결과의 화풍·인물 일치도를 검증하지 않았다.
