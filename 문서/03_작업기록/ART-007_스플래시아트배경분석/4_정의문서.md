# SP13 산출물 정의

| 항목 | 정의 |
|---|---|
| GC9 v1.1 | 누적 16장에 근거한 기존 캐릭터 그림체 규칙 |
| SP13 v1.0 | 이번 13장의 배경·구도·상징·광원을 재사용하는 구성 규칙 |
| S01~S13 | 사용자 제공 순서에 따른 참조 ID. 공식 인물 설정의 식별자가 아님 |
| T01~T08 | 무장·파편 / 실공간·무대 / 매체·지식 / 속성 흐름 / 거대 배후 형상 / 소품군·공연 / 기하·투영 / 확대 초상 |
| 주 유형 | 한 그림에서 콘셉트를 가장 크게 전달하는 배경 역할 |
| 보조 유형 | 주 유형을 보완하는 구성. 새 작업에서 전부 합치지 않음 |
| 프롬프트 양식 | 캐릭터 콘셉트부터 공간·행동·빛까지 채우는 제작용 문구. 통합 및 배경 단독 모드 포함 |
| 입력 JSON | 기획 기록용 입력 양식. 생성 API 요청 스키마가 아님 |
