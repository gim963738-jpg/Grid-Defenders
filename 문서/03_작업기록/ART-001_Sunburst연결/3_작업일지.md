# 작업 일지

2026-11-05. Node.js 내장 HTTP/fetch/FormData로 로컬 제작 도구를 구현했다. 실행은 Orca의 `Sunburst 이미지 제작` 터미널에서 수행하며 주소는 `http://127.0.0.1:8788/`이다. 기존 오른쪽 갤러리 탭에서 제작 화면을 열었다.

검증: 커넥터/서버 모의 테스트 20개 통과, JS 문법과 diff 공백 검사 통과. 실제 브라우저에서 3프리셋, 참고 이미지 66개, 키 미등록 상태를 확인했다. 지연 FileReader 모의 검증으로 업로드 중 제출 및 동시 업로드 제한을 확인했다. 결과 메타데이터는 임시 파일에서 원자 교체한다.

실제 유료 이미지 생성은 하지 않았다. 키 등록 전이므로 OpenAI 인증·모델 접근·크레딧 적용·실제 이미지 생성 성공은 검증하지 않았다. 사용자 원본 이미지와 게임 동작은 변경하지 않았다.

후속 확인: 사용자가 비밀키를 저장한 뒤, 크레딧 대기 중 작업하지 말라는 지시에 따라 로컬 키 인식만 확인했다. 이후 사용자가 삼각형 한 장으로 실제 호출을 명시적으로 요청하여 Sunburst 2.6/high, 1024×1024, 흰 배경의 검정 삼각형을 1회 요청했다. API는 HTTP 429 `credit_balance_exhausted`(크레딧 없음)를 반환했다. 이미지가 생성되지 않았으며 재시도하지 않았다. 작업 ID: `ba7bbfdf-bc55-4c9c-a58e-fb4041f53319`. 요청·오류 기록은 해당 결과 폴더의 metadata.json에 저장됐다. 이 실패로 실제 생성 성공이나 모델 접근 가능 여부까지 검증됐다고 판단하지 않는다.
