# 연결 정의

| 프리셋 ID | API 모델 | quality |
|---|---|---|
| sunburst-2.6-high | gpt-image-2.6-sunburst | high |
| sunburst-2.5-xhigh | gpt-image-2.5-sunburst | xhigh |
| sunburst-2.5-high | gpt-image-2.5-sunburst | high |

참고 없음: Images generations. 참고 있음: Images edits의 multipart `image[]`. 모델 대체나 자동 재시도는 하지 않는다. 한 번에 PNG 1장, 4개 참고 이미지, 파일당 12MB. 이미지 품질과 대화 모델의 추론 강도는 별개다.

키는 `tools/image-studio/.env.local` 또는 `OPENAI_API_KEY`에서 읽는다. 로컬 설정 파일 우선이며 서버가 새 요청마다 다시 읽는다. 브라우저에 키를 보내지 않는다. 결과 위치는 `output/imagegen/sunburst/<요청 ID>/`. 참고 사본·프롬프트·요청 ID·가능한 사용량을 함께 보존한다. Usage 미반환은 0원이 아니다.

제작 규약의 60프레임/여백/기준점/동작 검수는 이 연결 도구에서 자동 보증하지 않으며 실제 제작에서 별도 적용한다. Pro 혜택 연결과 잔액은 OpenAI 결제 설정에서 관리한다.
