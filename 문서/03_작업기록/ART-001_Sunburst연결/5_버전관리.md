# 버전 관리

프로젝트에 로컬 저장했다. 이번 요청으로 커밋·푸시하지 않았다. 기존 갤러리와 다수 캐릭터·지도 이미지에 선행 변경이 있어, 이번 작업과 관계없는 변경은 그대로 보존했다.

새 파일: `tools/image-studio/`의 서버·커넥터·화면·테스트·실행 스크립트·README·설정 예시 및 본 작업 기록. 수정 파일: 기존 캐릭터 갤러리의 제작 화면 링크. 루트 `.gitignore`에서 `.env.local`과 도구 런타임 폴더를 제외했다.

비밀키가 들어갈 `.env.local`은 `git check-ignore`로 추적 제외를 확인했으며 커밋 대상이 아니다. 사용자가 추후 저장할 때에도 기존 캐릭터/지도 변경과 API 도구 변경을 구분해 검토한다.
