# 수평 일섬 · 시작점부터 소멸하는 검상 — WEB-162

2026-11-07. 요청 순서: 가로 일직선으로 길게 베고 지나간 검상 → 진한 선이 먼저 생긴 뒤 시작점부터 천천히 연해지며 소멸 → 뻗어나가는 선과 점 제거 → 잔상을 유지하면서2배 빠르게 소멸. 최신 속도 요청은 아래 후속 기록에 반영했다.

## 변경과 사용

- **수평 일섬**은 긴 검상이 한 번에 선명해지고 왼쪽 시작점부터 오른쪽 끝으로 부드럽게 지워진다. 움직이는 광점, 순차로 뻗는 경로, 주변으로 갈라지는 보조 선은 제거했다. 정지한 검상 몸체와 가느다란 중심 검광 두 모양만 합성한다.
- 기본 효과의 수평 일섬과 `게임/public/effect-recipes/horizontal-slash.effect.json`을 갱신했다. 저장된 초기 시안은 설정 패널의 **검상 시작점 소멸 적용**으로 현재 작업에 반영할 수 있다. 실행 취소/다시 실행을 지원한다.
- 사용자 기존 작업 ID `e1a7153d-aaf0-4530-88c1-22d49986b9b8`에 실제 UI로 적용했다. 저장함11개→11개, 다른10개 작업과 이름·팔레트·표시 크기·pivot은 유지했다. 자동 저장과 미리보기 반복 재생을 확인했다.
- 재생 길이는1.3초·52프레임·40FPS다. FPS로 전체 속도를 바꾸고 그리기 화면에서 모양별 실제 색/두께를 편집한다. 기존 작업을 다시 만드는 대신 같은 작업에 피드백을 반영했다.

## 데이터와 전투 계약

`drawing.strokes[].fadeAlong` 선택 필드를 추가했다. `{from:[x,y],to:[x,y],start,end,softness}`이며 좌표는 콘텐츠의0~1 정규화 좌표다. start/end는 해당 선의 `duration+linger`에 대한0~1 비율, start<end, softness는0.02~0.5다. 서로 같은 방향 좌표는 거부한다. 선의 방향 반전은 소멸 방향도 반전한다.

선마다 임시 투명 캔버스에서 알파를 감쇠해 이미 그린 다른 선이나 기본 레이어를 지우지 않는다. 필드가 없는 기존 그림은 이전 렌더 경로를 유지한다. 저장·작업 JSON·AI 요청·PNG 시트/배치 정보·노드 출력에 같은 필드를 보존한다.

원본은 절차적 투명 콘텐츠256×256px, 패딩24px, 셀304×304px이다. 중앙 pivot과220px 균일 표시를 사용하며 실제 검상 길이는 콘텐츠 폭의0.82다. 시트는8열7행, 논리 프레임1~52만 사용한다. impactFrame4는 완료 시각100ms의 표시이며 피해와 연결하지 않는다. 영웅·피해·사거리·대상·타수·쿨타임 변경과 실제 게임 스킬 장착은 없다. 실제 전장 확인은 공방의 독립 전장 렌더러에서 수행했다.

## 저장 오류 복구

초기 시안의 보조 섬광 duration0.095초가 허용 최솟값0.1초보다 작았다. 사용자가 시안을 저장한 뒤 공방을 다시 열 때 전체 저장함 검증이 실패해 임시 모드가 된 것을 확인했다. 원본 저장함을 먼저 백업한 뒤 수평 일섬의 해당 값 하나만0.1초로 고치고11개 작업을 모두 검증하여 복구했다. 이후 이번 최종 모양으로 갱신했다.

같은 오류가 다시 저장되지 않도록 새 작업을 추가하기 전에 전체 레시피를 검증한다. 오류가 있으면 저장함을 변경하지 않고 메시지를 표시한다. 복구 전 원본은 `output/horizontal-slash/library-before-repair.json`, 최종 수정 전 작업과 저장함은 `before-fade.effect.json`, `library-before-fade.json`으로 보존했다.

## 후속 — 잔상 유지·소멸 속도2배

사용자의 “사라지는속도가 조금늦다”, 이어진 “2배는 빨라야해” 요청에 따라 최종 길이를1.3초에서0.65초로 줄였다. 기본 FPS만 높여 실제 그림 시간이 잘리는 방식 대신 두 모양의 delay0.015→0.0075초, duration0.9→0.45초, linger0.385→0.1925초를 함께 절반으로 줄였다. 소멸 축·부드러운 감쇠·형태·팔레트·두께는 유지한다.39프레임·60FPS이며 이전52프레임·40FPS 기록은 최초 수정 이력이다. 피해 미연결 완료 표시는4프레임/약66.7ms다.

기본 프리셋·샘플 JSON을 갱신하고 기존 수평 일섬 ID에 UI로 반영했다. 적용 직전 보관함13개→13개, 다른12개 작업과 시간 이외의 모든 레시피 데이터가 동일함을 확인했다. 자동 저장·1×반복 재생 상태로 열었다. 사용자가 작업 중 추가한 다른 작업을 보존했다.

관련111검사(소멸13·공방 공통98)와 타입 검사/프로덕션 빌드가 통과했다. 기존 검사의 샘플 프레임을 전체 길이에 대한 비율로 바꿔39프레임에서도 처음의 진한 선·중간 소멸·반전·노드 출력을 검사했다. 밝은 초록/회색39프레임, 첫/마지막 투명·표시35프레임·경계 닿음0, 실제 전장 상단5프레임/중앙20프레임을 확인했다.320/390px 가로 넘침 없음과DPR3,0.25×·1×·5× 재생/정지를 재확인했다. 산출물과 수정 전 저장함은 `output/horizontal-slash/faster-fade/`에 보존했다.
