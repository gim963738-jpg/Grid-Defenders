# 금발 전사 정의
## 임시 전투 값
| 항목 | 값 |
| --- | --- |
| 식별/표시 | blond / 금발 전사 |
| 체력 / 물리 공격 | 1400 / 85 |
| 공속 / 사거리 | 초당1.1회 / 130 |
| 물리 방어 / 마법 방어 | 35 / 20 |
| 치명타 확률 / 총 피해 | 기존 공통10% / 150% |
| 소환 / 한도 | 무료 / 기존 영웅3명 중1명 |

평타는 기존 일반 물리 단일 공격이다. 전투 모델에서 공격 주기에 따라 기존 방어·치명타·장비/훈련·피해 집계 규칙을 적용한다. 시각 애니메이션은 피해를 결정하지 않는다.

## 정지 8방향
원본1254×1254 PNG8장을 색/배경 변경 없이 균등 축소한다. 출력160×160 셀8개/1280×160 아틀라스, 몸 높이128, 고정 발 위치(80,144). 원본 발 중심은 하단20행 전경의 중심을 측정하고 원본 경계·기준점·배율·SHA-256을 기록한다. 정면/앞오른쪽/오른쪽/뒤오른쪽/뒤/뒤왼쪽/왼쪽/앞왼쪽 순서다. 초상화는 정면 머리 영역을 정사각으로 추출한다.

## 보스 오른쪽 걷기
원본6720×4320/10열6행/672×720 셀60개. 원본 공통 기준점(273,703)을 유지해 1/4 균등 축소한 게임용1680×1080/168×180 셀을 사용한다. 각 셀 기준점(68.25,175.75), 전체 공통 몸 높이171.5다. 원본 각 프레임 지속시간의 합4017ms를 적용한다. 60프레임은60fps를 의미하지 않는다.
↳ 쉽게 말하면: 같은60장을 원본 약4초 속도로 재생하고, 작은 모바일 화면에 맞춰 파일 크기만 줄인다.

`BossActor.walk`에는 direction/moving/elapsed를 둔다. 기존 이동 루프가 실제로 이동한 틱에서만 시간을 더한다. 방향2(오른쪽)+이동+생존+전투 중일 때 걷기를 사용한다. 정지/종료/초기화는 정지 이미지로 돌아간다. 배속과 일시정지는 공통 전투 시간에 따른다.

표시는 `SkillFrameSpec → createSkillFrame → SkillFrameArt → skillFramePlacement`를 사용한다. 이미 투명한 원본에는 배경 제거/번짐을 적용하지 않고24px 공통 여백을 추가한다. 출력 패딩은 몸 크기 계산에서 제외한다. 웨이브 몸 높이57, 보스 몸 높이72 월드 단위로 가로세로 같은 배율을 적용한다. 보스 발은 기존 캐릭터 영역 하단에 맞춰 actor.y+32다. SVG overflow를 열고 입력을 받지 않아 무기/의상을 배치칸으로 자르지 않는다.

## 스킬 아이콘
`public/assets/heroes/blond-warrior-v1/skill-preview.png`: 은색 검·청색 궤적·금색 테두리의 임의 시안. 내장 image_gen 생성 원본을 복사했다. 보스56px 미부여 칸과 기존 세로 소환 비활성 칸에서 표시한다. 클릭/자동 시전 대상에 포함하지 않는다.

## 출처와 재현
`게임/scripts/pack-blond-art.ps1 -SourceRoot <캐릭터디자인2/output>`가 게임용 아틀라스/프레임 정의/초상화/출처 기록을 만든다. `public/assets/heroes/blond-warrior-v1/sources.json`은8방향 원본 해시·추출 범위·배율, 걷기 원본 시트/메타데이터 해시·기준점·반복 경계 한계를 보관한다. 원본은 다른 작업트리에 보존하며 수정하지 않는다.
