# 작업 일지
2026-11-07. 클래스별진형배치.md에 병사와 영웅의 배치 가능 열을 표로 정리했다. 자동배치·교환도 같은 허용 표를 사용하도록 기획에 기록했다. 자동배치 우선순위·열 포화 처리와 기존 캐릭터별 클래스 연결은 별도 결정 항목으로 남긴다.

후속 수정: 발로르 패시브의 “전열 아군 영웅”을 사용자 원문인 “전열 클래스 아군 영웅”으로 고쳤다. 기사·전사의 가드율 10% 증가를 실제 배치 열과 무관한 클래스 판정으로 정리하고, 확인 대기 문구를 제거했다. 다른 스킬 문구·보스전용 색상 표시는 보존한다.
