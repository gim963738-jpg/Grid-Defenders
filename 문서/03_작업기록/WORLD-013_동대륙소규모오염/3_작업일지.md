# 제작과 검증

내장 image_gen의 부분 수정 작업으로 지도 v24를 생성했다. 호수 동쪽·진월국 북쪽 내륙에 기존 작은 충돌지와 비슷한 보랏빛 운석 오염지역 한 곳을 추가했다. 기존 세 곳을 포함해 소규모 오염지는 총 네 곳이다. 36개 지명과 기존 지형·거점을 시각 확인했다.

생성 원본은 1536×1024 불투명 RGB PNG다. 프로젝트 사본은 생성 원본과 SHA-256이 같고 확대·축소하거나 재인코딩하지 않았다. v17~v23 이전 지도 해시는 유지됐다.

설정집 v1.12에 동대륙 오염지역 설명과 무명 충돌지 좌표를 기록하고 지도 열람본·전체 설정집·현재 경로 데이터를 빌드했다. 세계관 구조·문서 링크·지도 원본 검증을 통과했다.

Orca 열람본에서 지도 v24의 실제 1536×1024 로드, 기존 표식 10개, 동대륙 한 곳·총 네 곳의 무명 소규모 오염지 데이터를 확인했다. 지역 선택·북마크·390px·320px의 가로 넘침과 터치 높이 검증도 통과했다.
