# OPS-004 정의문서

목적: 매 작업 하달 후 수신 에이전트가 자기 작업진행방법과 적용 기준을 본문으로 읽은 뒤 작업하도록 연결한다.

공유 운영 원본은 `C:/Users/user/Desktop/Grid Defenders/작업관리`다. 역할별 진입점은 각 공간의 작업연결.json의 workMethod와 requiredReadings다.

| 구분 | 처리 |
|---|---|
| 고정 필독 | 자기 AGENTS·작업진행방법·공통/분야 규정·파일 책임·조직/도메인·도구 사용법 |
| 작품별 필독 | 담당 메인/팀장이 최신 제작기준·피드백의 실제 경로를 초안에 추가 |
| 현재 상황 | 작업대장·브랜치/메인 목록·자기 작업연결을 read-pack liveContext로 읽음 |
| 착수 확인 | 현재 작업·차수·수신 역할 및 모든 필독 문서의 해시·적용 요약 |
| 기준 변경 | 최신 문서 재열람 후 새 확인서를 기록, 이전 증거 보존 |
| 하위 담당 | 자기 작업 방법을 포함한 별도 위임/읽기 확인, 팀장 확인과 결과 연결 |
| 메인 자체 분석 | 자기 문서를 읽고 사전확인에 적용 기록, 작업대장 대상 작업과 구분 |

상태 흐름: draft → confirmed → prepared → delivery_receipt_recorded → in_progress → awaiting_user → accepted 또는 수정 차수. 사용자 합격과 기술 검증을 구분한다.

완료 기준은 17개 역할의 필독 연결, 발송문 자동 첨부, 누락/구버전/다른 작업 확인 차단 및 정상 재확인 검증이다. 실제 다음 제작 작업에서는 읽기 확인서와 결과의 기준 준수 여부를 함께 검수한다.

현재 도구의 상세 사용법: [작업대장 사용법](../../../작업관리/도구/사용법.md).
