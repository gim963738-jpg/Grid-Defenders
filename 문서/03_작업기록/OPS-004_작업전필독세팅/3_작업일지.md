# OPS-004 작업일지

2026-11-09. 사용자 요청에 따라 작업을 하달받은 에이전트가 자신의 작업 방법을 읽고 착수하는 절차를 설치했다.

## 실제 변경

- 메인 3개와 기존 팀장·테스터·전문 담당/자료 공간을 합친 17개 역할에 `기준/<역할>/작업진행방법.md`를 작성했다. 역할별 기존 규정과 작품별 원본 기준은 보존했다.
- 17개 작업 공간의 AGENTS.md에 매 작업 필독 지침을 추가했다. 기존 본문은 그대로 앞부분에 보존했다. 작업연결.json과 메인/브랜치 목록에 workMethod, requiredReadings, readingPolicyVersion을 연결했다.
- 작업대장 prepare가 승인된 전문 프롬프트를 보존하면서 필독 목록/명령을 별도 발송문에 자동 첨부하도록 했다.
- read-pack은 필독 본문과 현재 해시, 별도 현재 작업/역할 연결 자료를 출력한다. start는 작업·차수·역할·문서별 해시·적용 요약을 검사하고 확인서 사본을 보존한다.
- 미착수·확인 누락·기준 갱신 시 결과 반환을 차단한다. 실패 시 작업 이력·상태·브랜치 잠금을 유지한다. 새 확인 후 계속할 수 있고 수정 차수는 이전 확인을 재사용하지 않는다.
- 하위 위임 양식에 자체 작업 방법·필독 문서·하위 확인서 경로를 추가했다. 미등록 단기 하위 담당은 자기 확인서를 작성하고 팀장이 확인한다. 팀장 착수 기록으로 대신하지 않는다.
- 메인 자체 분석은 사전확인에 읽은 문서와 적용 내용을 기록한다. 추가 사용자 승인 절차를 만들지 않았다.

## 검증

- 새 필독 동작 검사 17개 및 기존 검사 25개, 합계 42개 통과. 임시 폴더만 사용했다.
- 17개 역할의 작업 방법/포인터/필독 파일/기존 AGENTS 보존 검사 통과. 백업 34개 해시 일치.
- 독립 검토자가 OPS-003 보호 대상 328개와 게임개발/테스터 기준 사본 각 178개를 비교해 변경 0을 확인했다. 해당 스냅샷 범위의 결과다.
- 독립 검토에서 지적한 기존 메인 절차의 start 누락과 자동 목록의 도메인 자료 누락을 보완했다. 자주 변하는 작업 상태는 별도 liveContext로 읽고 다른 작업의 상태 갱신 때문에 확인을 무효화하지 않는다.
- 실제 게임 콘텐츠 지시, 외부 생성, 신규 AI 채팅 생성, Git 커밋/푸시는 수행하지 않았다.

근거: 공유 작업관리/기록/OPS-004/설정검증.json 및 tests.txt. 현재 규정 A/팀장 운영 규정은 v2.1.0, 각 역할 작업진행방법은 v1.0.0이다.

## 적용 범위와 한계

설정 완료는 모든 기존 채팅의 현재 턴이 새 지침을 이미 읽었다는 뜻이 아니다. OPS-003에서 확인한 기존 채팅 직접 공지 제한을 유지하고, 다음 실제 작업 지시에는 필독 절차가 첨부된 발송문을 사용한다. 도구는 문서 확인 기록을 검증하며 모델 이해 자체나 도구 밖 편집을 기술적으로 보장하지 않는다. AGENTS·발송문·작업대장·결과 검수를 함께 사용한다.
