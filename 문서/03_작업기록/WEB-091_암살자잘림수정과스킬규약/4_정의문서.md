# WEB-091 정의문서
현재 시각 처리 규약은 [스킬 구현 규약](../../00_개발규칙/스킬구현규약.md). WEB-090의 암살자 추출 배경/경계 처리 설명은 이번 공통 처리로 대체한다. 전투 규칙은 그대로 유지.
SkillFrameSpec: 원본 사각영역, background(transparent/dark), 원본 좌표의 pivot, 선택 actor 보존 타원. SkillFrameArt: 원본 contentWidth/Height, padding, 출력 texture/url, 정규화 anchorX/Y.
createSkillFrame: 캐시 생성 시 한 번 배경 처리·여백·잔광 생성. skillFramePlacement: 원본 높이를 기준으로 균일 확대하고 pivot 고정. 투명 여백 때문에 영웅이 작아지거나 이펙트가 늘어나지 않는다.
공통5번 원형 x510~646. 기존 x544~667의 잘못된 추출 제거. 공통1번 끝은x158로 조정해 옆 초승달 꼬리 혼입 제거. 논리 참격12번은11번 이미지를 공유한다.
웨이브 순수 효과는 전체 전장의 유닛 아래 레이어에 표시. 칸 마스크 없음. 보스 순수 타격도 z-index1, 유닛2. 캐릭터 모션은 투명 여백을 포함하는 SVG를 overflow visible로 표시.
전투 수치 변경 없음: 평타35%×3/6·8·10완료, 참격250%/4초/10완료, 보스35%×3+250%/5초/6·10·14·20완료. 원거리/검 영웅 효과의 전면 재작업은 이번 범위에 포함하지 않는다.
