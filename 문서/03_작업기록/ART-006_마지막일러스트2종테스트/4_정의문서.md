# 마지막 테스트 산출물 정의

| 항목 | 정의 |
|---|---|
| t14 | 다운로드 14의 검보라 쌍단검 남성형 |
| t15 | 다운로드 15의 분홍 머리·검은 리본 여성형 |
| 01 front | 정면 0도 |
| 02 side | 화면 오른쪽을 향한 정확한 정측면 90도 |
| 03 back | 후면 180도. 앞 가슴 문양·얼굴을 뒤에 복제하지 않음 |
| 04 threequarter | 화면 오른쪽을 향한 약 45도 사선 |
| 선택본 | 1024×1536 투명 PNG 8장. 전달 ZIP에 포함 |
| 수정 전 후보 | 여성 후면 머리 길이 수정 이전 PNG 1개. variants에 보존, 전달 ZIP에서 제외 |
| 렌더링 기준 | C4 얼굴선, C3 금속 면을 재질과 성별에 맞춰 적용. 원본 디자인은 별도 유지 |

원본의 SD·픽셀 비율, 잘린 구도와 개별 얼굴을 그대로 보존하지 않는다. 네 방향은 같은 인물의 생성 일러스트이며 정확한 3D 모델 회전이나 픽셀 기준선 정규화 산출물과는 구분한다.
