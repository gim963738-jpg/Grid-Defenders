# 요청과 결정
사용자는 피드백 1~7번에 답했다. 전투 필수 정보가 웨이브를 뜻하는지 질문했고, 툴팁의 화면 가림 허용 범위와 전장 선택 표시 방식을 물었다. 모바일 크기 조절은 배치 완료 후 진행하며, 조작 안내는 구체적인 안을 제시한다. 성장 동선은 패배 결과에서 연결한다. 7번 중단·복귀는 우선 구현하도록 요청했다.

이번 구현은 7번이다. 앱/페이지 이탈 시 정지, 복귀 재개 안내, 같은 브라우저에서 전투 저장·이어하기를 구현했다. 1~6번은 설명/제안과 결정 기록이며 화면 배치·툴팁·선택 아트·성장 결과창을 이번에 변경한 것은 아니다.

제안: 툴팁은 선택 카드 근처 빈 공간에서 짧게 열고 선택 대상/배치 목적지/구매 버튼을 피하며 드래그 시 닫는다. 선택 영웅은 전장 발밑 링과 머리 위 V 표시로 구분한다. 첫 행동 안내는 성공 시 사라지고 실패 원인은 행동 근처에 짧게 표시한다. 성장 안내는 패배 원인·보상·훈련·재도전 순서로 정리한다. 사용자 최종 디자인 확인은 별도다.
