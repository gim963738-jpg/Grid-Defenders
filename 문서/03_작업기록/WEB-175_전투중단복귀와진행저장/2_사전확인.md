# 목표와 범위
이전 a47dc3d의 로컬/원격 main 일치를 확인했다. 저장·보상·장면 전환 및 모바일 규격을 읽고 기존 기능과 비교했다. 명시적인 7번 구현 요청 범위에서 진행하며 추가 승인을 요구하지 않는다.

대상: main.ts, landscape-entry.ts, training.ts, 신규 battleSave.ts / battleContinuation.ts / battle-continuation.css, 관련 검사 및 README/task/작업 기록/공통 UI 정의.

완료 조건: 숨김 중 전투 시간과 공격 진행 정지, 복귀 후 명시적 재개, 수동 정지 유지, 새로고침 시 웨이브와 보스 상태 복원, 새 전투/중도 포기/정상 종료 시 체크포인트 정리, 같은 전투 ID의 보상 중복 차단. 저장 실패는 진행 중인 화면을 손상시키지 않으며 보상 저장 실패는 정지 후 재시도를 제공한다.

검증: 순수 저장 모델의 가로/세로 왕복 및 연속 실행 동일성, 생명주기/복귀창 검사, 훈련/전투 진행 회귀, 실제 브라우저의 새로고침·보스·로비 왕복·보상 검증, 타입 검사와 빌드. 아트/공격 판정/밸런스/전장 크기 수정은 없다.
