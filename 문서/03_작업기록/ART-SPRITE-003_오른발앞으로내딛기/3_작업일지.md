# 제작과 확인

내장 image_gen에 참조 3장과 전방 내딛기 동작을 전달해 새 6×5 시트를 생성했다. 오른쪽 판금 장화가 왼발 앞을 지나 화면 오른쪽에 착지하는 전체 번호 시트를 밝은 배경에서 확인했다.

1374×1145px 생성 원본의 229px 셀을 확대·축소 없이 256px로 포장했다. 서로 다른 30장, 투명도와 셀 경계 여백을 확인했다. 브라우저에서 프레임 선택·배경 전환·마지막 자세 정지와 모바일 가로 넘침 없음·48px 조작 영역을 검사했다. APNG 30장 전체 디코딩, 256px 크기·2000ms·단발 재생도 확인했다.

사용자의 기존 연결 순서는 JSON에 기록하고 새 후보 번호와 구분했다. 최종 연결 선택은 아직 받지 않았다.
