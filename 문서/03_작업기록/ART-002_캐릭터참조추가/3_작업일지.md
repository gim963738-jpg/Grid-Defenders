# 2026년 11월 6일 참조 추가 결과

## 변경

7장 모두 전체 프레임을 직접 확인하고 A01~A07로 등록했다. 누적 16장, GC9 v1.1이다. 각 이미지의 얼굴·머리·체형·실루엣·채색·팔레트·가져올 표현·고정하지 않을 설정을 기록했다.

[참조목록](../../../자료/캐릭터그림체/GC9/참조목록.json)에 원본 경로·해상도·바이트 크기·SHA-256·추가 묶음 구분을 저장했다. 기존 목적별 조합 8개를 유지하고 7개를 더해 총 15개다.

[그림체 기준](../../02_세부기획/02_영웅/캐릭터그림체/GC9_그림체기준.md)과 [생성 프롬프트](../../02_세부기획/02_영웅/캐릭터그림체/GC9_생성프롬프트.md)에 전신 판금 연결, 절제된 금속 반사, 흰 겹옷의 옅은 그림자, 검붉은 장비 분리, 밝은 웃음과 대형 장식의 층 분리를 반영했다. 입력 양식에 참조 버전과 명암 표현 선택 항목을 추가했다.

[비교 보고서](../../../자료/캐릭터그림체/GC9/분석리포트.html)는 전체 16장·초기 9장·추가 7장 필터로 갱신했다. 첫 화면은 추가분 7장이다. 채팅용 자체 포함 보고서는 새 파일로 저장했으며 404,608바이트다. 이전 채팅 보고서를 덮어쓰지 않았다.

## 검증

- 기존 참조 9개와 조합 8개의 데이터가 작업 전과 동일하다.
- 원본 16장의 SHA-256·바이트 크기·해상도와 보관본이 모두 일치하며 중복 해시는 없다.
- 16개 관찰 레코드, 조합 15개의 ID, 2개 묶음의 수량·구성, 입력 JSON v1.1을 검증했다.
- 문서 링크, 보고서의 원본·문서 경로와 개별 관찰 데이터가 연결된다.
- Headless Edge에서 프로젝트 보고서와 채팅용 보고서 모두 이미지 16/16 로드를 확인했다.
- 필터 수량 16/9/7, 관찰 항목 전환, 확대 대화상자가 작동한다.
- 1120px 화면은 3열, 390px 화면은 1열이며 모바일 가로 넘침이 없다. 두 화면의 캡처를 열어 확인했다.

신규 캐릭터 생성·실제 출력의 화풍 일치도 검수·모델 가중치 추가 학습은 미실행이다. 사용자에게 보여지는 Orca 인라인 최종 렌더는 별도다.
