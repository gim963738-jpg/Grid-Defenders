# 참조 추가 로컬 저장 상태

원본 추가 7장과 누적 참조목록·보고서·기준·프롬프트·입력 양식·AGENTS.md 안내를 로컬에 저장했다. 이전 ART-001 기록과 초기 원본 9장을 보존했다.

커밋·푸시는 수행하지 않았다. 게임 코드와 task.md는 변경하지 않았다. 브라우저 검증 프로필·스크립트·화면 캡처·이전 목록 비교본·채팅용 HTML은 이 채팅의 scratch 폴더에만 저장한다.

버전 관리 확인은 이번 자료 경로를 대상으로 한다.

```powershell
git status --short
git diff --check
git diff -- AGENTS.md
```
