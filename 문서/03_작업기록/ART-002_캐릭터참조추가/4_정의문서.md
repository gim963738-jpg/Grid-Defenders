# 확장된 GC9 참조 정의

| 항목 | 정의 |
|---|---|
| GC9 v1.1 | 초기 묶음의 고정 식별자 유지. 실제 원본 수량은 16장 |
| B01 | 이전 사용자 제공 원본 9장. 기존 M01~M05·F01~F04 유지 |
| B02 | 추가 사용자 제공 원본 7장. 제공 순서에 따라 A01~A07 |
| A01·A06 | 이름이 없는 파일을 적발·금장 갑옷, 분홍 장발·흑익으로 식별. 공식 이름 추정 없음 |
| 추가분의 성별 | 사용자 미지정으로 유지. 외형과 제작 역할로 참조 선택 |
| 목적별 조합 | 기존 8개 + 추가 7개 = 15개. 실제 생성에서 검증된 최적 조합을 뜻하지 않음 |
| 명암 표현 선택 | 기본 셀, 절제된 판금 반사, 옅은 흰 겹옷 명암, 검붉은 장비 구분 등. 인물 설정에 맞게 선택 |

이번 추가는 저장된 참조·관찰·제작 지시의 확장이다. 입력된 원본의 캐릭터 정체성·의상·효과를 다른 캐릭터의 필수 설정으로 삼지 않는다.
