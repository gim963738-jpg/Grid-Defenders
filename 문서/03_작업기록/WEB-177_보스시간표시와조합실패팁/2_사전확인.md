# 범위와 검증
이전 b212834의 로컬/원격 main 일치를 확인했다. 개발규칙·task·공통 모바일 UI 규격·직전 작업 기록과 실제 코드의 타이머/조합 동작을 확인했다.

변경 대상은 게임/src/landscape-entry.ts, 게임/src/landscape-game.css 및 작업 기록이다. 가로 보스의 기존 제한시간 요소를 상단 중앙에 표시하고, 가로 상점의 조합 버튼을 항상 활성화하여 클릭 시 실패 이유를 버튼 위 팁으로 보여준다.

완료 조건은 일반 보스 60초·마지막 10초 강조·무한 테스트의 시간 제한 없음 표시, 모루 부족/재료 없음 안내, 실패 시 재료·모루·골드 보존, 충분할 때 기존 일괄 조합 성공이다. 화면 경계와 기존 조작 버튼이 겹치지 않는지도 확인한다.

보스 진형 변경·힐러 구현·로비 영웅 연결·세로 전투 UI 변경·새 조합식·수치 변경은 포함하지 않는다. 사용자의 이번 구현 요청 범위에서 진행하며 최종 화면 확인은 별도다.
