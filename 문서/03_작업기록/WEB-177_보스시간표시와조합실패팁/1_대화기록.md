# 요청과 결정
사용자는 보스전 제한시간 표시를 추가하고, 조합 버튼은 항상 활성화한 상태에서 모루가 부족하면 메시지 팁을 띄우도록 요청했다. 조합은 기존 일괄 조합 방식을 유지하며 한 쌍 선택 방식으로 변경하지 않는다.

보스 진형은 좋은 방안을 제시하는 단계다. 역할별 자동 배치를 기본값으로 제공하고 사용자가 보스 진형을 수정·저장하는 방안을 제안했으며, 아직 확정하거나 구현하지 않았다. 웨이브 5×4와 기존 보스 4칸 기준 변환의 정리는 후속 결정 사항이다.

힐러 역할은 영웅 디자인·콘셉트·스킬 설정 이후 진행하기로 사용자가 결정했다. 이번에는 회복 행동이나 스킬을 추가하지 않는다. 사용자 최종 화면 확인은 별도다.
