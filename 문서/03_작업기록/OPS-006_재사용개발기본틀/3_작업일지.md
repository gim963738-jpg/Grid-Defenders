# OPS-006 작업일지

2026-11-09. 바탕화면 `프로그램 개발 기본 세팅`에 시작 문서, 프로젝트 설치 지시, 공통 규정, 역할별 프롬프트, 작업/피드백 양식, 완료 확인표, 복사용 요청문을 작성했다.

기본구조생성.py는 신규 대상의 작업관리 골격과 AGENTS/CLAUDE 연결을 만든다. 메인3개/테스터 역할을 파일로 준비하고 실제 팀장은 프로젝트 분석 후 결정하게 했다. 실제 에이전트를 생성하거나 미연결을 준비 완료로 표시하지 않는다. 기존 운영 폴더가 있으면 변경 없이 중단하며, 기존 AGENTS/CLAUDE 본문은 백업과 원문 접두 바이트를 보존한다.

검증.py를 임시 폴더에서 실행했다. 생성·한글/공백 경로·원문/제품 파일 보존·백업 해시·역할 상태·재실행 무변경·기존 운영 폴더 충돌 중단·누락 검출·문서 링크 검사 10항목 통과. 대상 사용자의 실제 다른 프로젝트는 변경하지 않았다.

Claude/VS Code의 실제 세션/위임/화면 기능은 이 작업에서 실행 검증하지 않았다. 설치 지시문은 실제 지원 확인 후 연결하고 미지원은 정확한 후속 프롬프트를 제공하도록 했다.
