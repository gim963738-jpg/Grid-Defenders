# 사전확인 근거와 범위

실제 생성 전 메인01 작업 방법·팀장 규정·전문지시/하위위임 양식·필독 절차를 읽고, 바탕화면 신규 팩을 생성하겠다고 사용자에게 알렸다. 바탕화면에서 관련 기본 세팅 파일을 검색했다.

이 문서는 종료 시 사전 검토 내용을 정리한 연결 기록이며 변경 전에 저장한 문서라고 주장하지 않는다. 실제 사전 검토/범위 안내는 현재 대화의 도구 실행 전 commentary에 있다.

범위는 독립 재사용 문서·설치 보조 스크립트·임시 폴더 검증이다. 기존 제품 코드·다른 프로젝트·메인02/03의 운영 상태는 수정하지 않는다. 실제 Claude/VS Code 환경 설치나 화면 조작을 수행하지 않는다.
