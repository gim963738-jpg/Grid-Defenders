# DOC-001 — 대화 기록

유저는 초기 기획 문서 생성·로컬 저장 제안에 `진행`으로 승인했다. 임시 이미지 적용 권한도 추가했다.

합의 요약: 세로 모바일 웹 우선, 추후 앱 출시. 일반전 순환·일방 공격, 보스전 이동·쌍방 공격. 병사 유료 선택 소환, 영웅 현재 무료 선택 소환 예정·보스 소환 불가·판매 교체 불가. 장비 배치 완료 시 효과 반영, 쿨타임 아이템 선쿨. 모드별 스킬 옵션. 오염은 저가 구매에 따르는 불이익을 정화하는 제도. 제단·회복 구슬은 보류.

원자료: 통합 HWP, 수정안 PDF, 채팅 이미지와 후속 답변. 이전 대화의 모든 문장을 복제한 기록은 아니며 이번 작업에 필요한 결정만 정리했다.
