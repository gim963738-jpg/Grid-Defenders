# 슬라임 표시 정의
| 대상 | 이미지 |
| --- | --- |
| 일반 `normal` | 노란 슬라임 |
| 물리 방어 `physical` | 파란 슬라임 |
| 마법 방어 `magic` | 빨간 슬라임 |
| 네임드/현상금 | 기존 특수 외형 유지 |

## 추출·기준점·크기
정지 아틀라스는 128×128 셀 8개이며 순서는 앞/앞오른쪽/오른쪽/뒤오른쪽/뒤/뒤왼쪽/왼쪽/앞왼쪽이다. 원본 alpha≥16 몸체 경계를 측정하고 주변 8px 여유를 포함해, 가로세로 같은 배율로 몸체 폭 104px에 맞춘다. 출력 바닥 기준점은 (64,112)이다.

물결 시트는 원본 1536×1280 PNG를 바이트 그대로 유지한다. 256×256 셀, 6열×5행, 고정 기준점 (128,228), 전체 프레임 몸체 폭 211px이다. 셀의 투명 여백을 프레임마다 자르지 않는다. 원본 상단 0~157행은 고정되고 하단 158~255행만 변한다.

게임 안 몸체 표시 폭은 두 종류 모두 28 월드 단위다. 정지 이미지는 28/104, 물결은 28/211의 동일 가로세로 배율을 사용한다. 고정 바닥 위치는 (몬스터 x, 몬스터 y+기존 반경)이다. 일반 체력바는 y−21에 두어 이미지와 겹치지 않게 한다.
↳ 쉽게 말하면: 그림이 차지하는 실제 폭과 발 위치를 맞추고, 투명 여백 때문에 크기가 달라지지 않게 한다.

## 재생·판정
`slimeDirection(distance)`는 기존 경로의 다음 지점까지 방향을 8방향으로 분류한다. 노랑/오른쪽/양의 이동 속도 조건에서 `floor(game.elapsed×30)%30` 프레임을 표시한다. 일시정지하면 게임 시간이 멈춰 프레임도 멈추고 배속도 같은 시간을 따른다. 그 외에는 해당 방향 정지 이미지다.

원본 PNG의 셀 범위는 시각 표시용이다. 몬스터 경로·이동 속도·기존 반경 8·피해 판정은 그대로 유지한다. Sprite는 입력을 받거나 격자에 의해 잘리지 않는다. 프레임 Texture는 미리 생성해 반복 사용한다.

## 재현
`게임/scripts/pack-slime-art.ps1 -SourceRoot <round-slime 원본 폴더>`로 게임용 정지 아틀라스와 원본 애니메이션 복사본을 생성한다. `public/assets/monsters/slimes-v1/sources.json`에 각 원본 해시·범위·배율을 보관한다. 다른 작업트리를 수정하거나 새 이미지를 생성하지 않는다.
