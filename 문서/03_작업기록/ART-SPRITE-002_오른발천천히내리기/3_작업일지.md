# 제작과 확인

내장 image_gen으로 참조 4장을 전달해 새 투명 PNG를 생성했다. 원본은 1374×1145px, 6×5개의 229px 셀이다. 셀을 확대·축소하지 않고 투명 여백만 더해 최종 256px 프레임과 1536×1280px 시트로 포장했다.

번호 표시 시트, 개별 PNG, JSON, 한 번 재생하는 APNG와 HTML을 저장했다. 30장 모두 서로 다른 파일이며 알파·불투명 내용과 셀 가장자리 여백을 확인했다. 밝은 배경의 전체 번호 시트도 확인했다.

브라우저에서 이미지 로드·프레임 선택·배경 전환·마지막 프레임 정지·390px 가로 넘침 없음과 48px 조작 영역을 검사했다. APNG는 30장 전체 디코딩, 256px 크기·2000ms·한 번 재생을 통과했다. 후속 연결 후보 선택은 사용자가 진행한다.
