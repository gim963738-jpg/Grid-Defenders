# 4_정의문서.md

임시 지휘자1 공격 지휘: 보병·궁병·마법병 공격력+100, 10초 지속·15초 재사용, 중첩 불가. 영웅 제외, 기본 능력치는 변경하지 않고 피해 산정 시 보너스 적용.
영웅카드: 원거리딜러 이미지와 기술2개 세로 배치. 기술1은 자동 평타, 대기시간은1/공격속도(현재1초). 기술2는 버튼 클릭 시 평타 피해3회, 0.12초 간격, 쿨타임4초. 평타 자동 공격은 계속 유지. 생존·전투중·사거리 조건 만족 시 사용 가능. 사거리 밖에서는 쿨타임 소모 없음. 매 타격 전열 우선 표적 재선택.
전투 정지 시 스킬 타이머도 정지, 재시험·게임 리셋 시 초기화. 시험 재화·일반전 능력치에 영향 없음. 효과 시간은 임시이며 사용자 확인 대기.
