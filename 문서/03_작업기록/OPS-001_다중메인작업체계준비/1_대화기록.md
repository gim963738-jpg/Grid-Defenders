# OPS-001 대화 기록

사용자는 메인3개와 분야별 작업 브랜치로 작업 방식을 바꾸고 실제 사전 준비·폴더·브랜치·채팅 생성을 요청했다.

확정한 역할: 메인은 분석·기획·실제 시안 제작·부분 조합·전문 지시·검수·통합 관리를 한다. 제작·수정 지시는 메인이 이해를 설명하고 사용자 확인 후에만 전달한다. 담당 브랜치는 기존 기준을 읽어 결과물과 검증·규정 정교화를 함께 수행한다. 사용자 피드백을 원문·결과 차수·규정 버전으로 연결한다.

메인01은 현재 대화이며 새 메인02·03을 만든다. 기존 UI 제작은 별도 브랜치에서 이어받는다.4분할 GUI 배치는 채팅 생성과 구분한다. 예시 슬라임 제작·디자인10종은 실제 지시가 아니다.

실제 준비 요청 원문: “사전준비와 브랜치 정리 메인채팅브랜치도 만들고 하는 새로운 작업방법의 폴더트리? 준비를 해야하잖아”.
