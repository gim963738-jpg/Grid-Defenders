# OPS-001 버전 관리

기존main과7개 전문 작업 공간의 원본·미커밋 변경을 보존했다. 신규 메인02·03·UI 브랜치는1a54b47에서 시작하며 UI에는 당시 현재 작업 사본을 추가했다. main의 기존 코드를 제거하거나 기존 작업 전체를 자동 병합하지 않았다.

복구 정보와 원본 해시는 [백업 목록](../../../작업관리/기록/OPS-001/baseline.json), [지침 연결 전후](../../../작업관리/기록/OPS-001/connector-manifest.json), [UI 사본](../../../작업관리/기록/OPS-001/ui-copy-manifest.json), [실행 리소스](../../../작업관리/기록/OPS-001/ui-public-manifest.json)에 기록한다. 저장소 밖 백업 경로는baseline.json에 있다.

[기존 UI 시안 참고](../../../작업관리/기록/OPS-001/ui-design-references.json)와 [Orca 정리 전 상태](../../../작업관리/기록/OPS-001/orca-before.json)도 보존한다. UI의 시작 사본과 새 작업의 변경을 구분해 후속 통합한다.

변경은 로컬 저장과 로컬 브랜치·Orca 역할 초기화다. 커밋·원격 푸시는 수행하지 않았다. 현재 프로젝트에 이미 존재하던main의 원격 미반영1커밋과 이번 미커밋 준비 변경을 구분한다. 각 채팅의 초기화 안내는 실제 제작·수정 지시와 구분한다.
