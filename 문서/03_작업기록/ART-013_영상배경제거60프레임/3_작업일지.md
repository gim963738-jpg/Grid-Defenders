# 추출·배경 제거·패킹 · 2026-11-07

원본 영상 97장을 프레임 보간 없이 디코딩했다. 첫 프레임 0초부터 마지막 프레임 4초까지 시간상 균등한 목표점 60개를 잡고 가장 가까운 서로 다른 원본 프레임을 선택했다. 선택한 번호와 실제 시각은 source-and-extraction.json에 기록했다.

하늘·잔디 분리 뒤 큰 캐릭터 연결 영역을 선택했다. 어두운 하늘색 외곽 잔여를 제거하도록 범위를 보완하고, 칼의 밝은 청색 내부 장식이 분리되어 없어지지 않도록 둘러싸인 전경 영역을 복원했다. 단순 색 키로 금속의 밝은 면을 지우지 않았다.

60장 전체 가시 영역을 합해 공통 추출 원점 x=367, y=-1을 정했다. 프레임마다 따로 중앙 정렬하지 않고 같은 672×720 캔버스로 추출했다. 시트는 10열×6행, 6720×4320 실제 알파 PNG다. 같은 피벗은 한 칸 안의 (273,703)이다. 소스 픽셀을 확대·축소하지 않았다.

60개 개별 PNG의 모든 픽셀과 시트 칸이 동일하고, 남긴 전경 픽셀의 RGB가 디코딩 원본과 같음을 검증했다. 모든 프레임에 실제 투명 영역과 피사체가 있으며 외곽이 잘리지 않는다. 밝은/어두운 배경의 60장 전체, 원본 100%, 재생 진행, 마지막 프레임 접근과 모바일 390px에서의 레이아웃을 검증했다.

완성 ZIP은 69개 항목으로 개별 프레임 PNG 60장, 시트 1장, JSON·미리보기·기록·manifest를 포함한다. ZIP 내부 모든 바이트를 원본 파일 SHA-256과 대조했다. 원본 MP4의 해시가 바뀌지 않았다.

제작 모음에는 대표 시트 한 장만 추가해 개별 60장이 카드를 늘리지 않도록 했다. 총 192개 이미지 경로·187개 고유 이미지·6개 카테고리다. 기존 191개 경로의 해시를 유지했고, 대표 시트는 테스트 과정 작업물에 분류했다. 파일·링크·분류·갤러리 브라우저와 제작 도구 서버 테스트 7개를 통과했다.
