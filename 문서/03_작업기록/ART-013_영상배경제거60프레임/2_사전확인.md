# 원본 영상과 처리 방법

원본은 1280×720 H.264 영상이며, 영상 스트림 길이는 약 4.016667초다. 실제 디코딩 프레임은 97장이다. 스트림의 r_frame_rate 60/1만 보고 원본 프레임 수나 실제 평균 프레임 속도를 추정하지 않고, 프레임별 표시 시각을 읽었다. 오디오 길이 4.096009초와 영상 길이를 구분했다.

배경은 청색 하늘과 초록 잔디다. 금발·청색 천·은빛 판금·칼의 청색 장식이 구분되는 팔레트이므로 로컬 색 분리와 연결 영역으로 전경을 추출했다. 캐릭터의 청색 장식처럼 본체와 분리되는 내부 전경 영역을 보존한다. 이 영상에 맞춘 규칙이며 범용 배경 제거 모델로 표시하지 않는다.

환경에 FFmpeg가 없어 FFmpeg 공식 다운로드 페이지가 연결하는 Gyan Windows 빌드를 로컬 도구 캐시에 내려받고 제공 SHA-256과 대조했다. Python 이미지 패키지·외부 배경 제거 서비스·새 AI 이미지 생성은 사용하지 않았다. 원본과 중간 프레임은 별도 경로로 보존했다.
