# 원본 보존과 등록

원본 MP4와 기존 캐릭터 PNG는 변경하지 않았다. 원본 영상은 Downloads에, 추출 중간 프레임은 Orca 작업 캐시에, 최종 산출물은 별도 output/animation 버전 폴더에 보관했다.

재현용 도구는 tools/video-sprites에 보관한다. 캐릭터 제작 모음 스캐너는 대표 시트 PNG 하나만 읽고, videoWalk60 출처로 테스트 과정 작업물에 등록한다. 개별 60장은 재생 페이지·ZIP·JSON으로 연결한다. 화면 카테고리 6개와 은발 지팡이 묶음을 유지한다. 새 폴더는 제작 도구 서버의 공개 컬렉션 경로에 추가했다.

기존 이미지 191개 경로의 SHA-256이 바뀌지 않았고, 인계 항목 83개와 중복 경로 연결도 유지했다. 게임 코드·task.md·API 연결/키 설정은 변경하지 않았다. 커밋·푸시는 수행하지 않았다.
