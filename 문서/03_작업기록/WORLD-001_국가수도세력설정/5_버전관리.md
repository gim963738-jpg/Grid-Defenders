정확한 지도 생성 프롬프트, 내장 도구 결과 경로, 원본·출력 해시, 실제 이미지 크기는 output/world/maps/continent_world_lore_v18.generation-records.json에 기록했다. 같은 폴더의 prompt.txt와 review.json에서 프롬프트와 시각 검수를 확인할 수 있다.

구조·경로·원본 보존 검증은 tools/world-atlas/verify.mjs, 브라우저 동작 확인은 tools/world-atlas/verify-browser.mjs와 output/world/atlas/browser-verification.json으로 남겼다.

이번 작업은 로컬 산출물로 보관했다. 커밋과 푸시는 실행하지 않았다. 기존 게임 구현·전투 수치·작업 목록과 이미지 API 설정은 변경하지 않았다.
