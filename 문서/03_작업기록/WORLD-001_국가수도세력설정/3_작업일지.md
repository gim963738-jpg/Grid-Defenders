# 작업과 확인

2026-11-07에 국가·수도·교회·신·네 가문·두 부족의 이름과 관계를 구조화 설정에 기록했다. 이 설정에서 Markdown 설정집, 전체 HTML 설정집, 지도 옆 지역별 열람본을 함께 생성하도록 빌더를 추가했다.

내장 이미지 생성 도구로 v17 원본을 참조해 v18 지도를 한 번 생성했다. 실제 반환된 1254×1254 불투명 PNG를 크기 변경 없이 보관했다. 두 수도의 크기 차이, 대교회가 큰 수도 안에 있는 배치, 다섯 대륙과 국가·요새의 표기 13개를 눈으로 확인했다.

설정 검증에서 다섯 대륙, 두 수도, 네 가문의 봉신 2·귀족파 2 구분, 두 부족, 두 신, 전체 이름 16개와 연결 경로 14개를 확인했다. v17의 SHA-256은 기존 기록과 동일하다.

Orca 브라우저에서 6개 지역·관계 메뉴, 7개 지도 번호와 범례, 지도 번호 숨기기·복원, 작은 수도 북마크의 새로고침 복원을 확인했다. 중앙의 세 표는 수도 2행·세력 2행·가문 4행이다. 390·320px 화면에서 가로 넘침이 없고 버튼 높이는 최소 44px이다.

별도 Edge 렌더링을 실제 PNG로 캡처해 PC 지도·모바일 지도·모바일 북부 설정·전체 설정집의 중앙대륙 본문을 시각 검수했다. 전체 HTML 설정집도 모바일 두 크기에서 가로 넘침 없이 다섯 대륙과 표 7개를 표시했다.

기존 로컬 이미지 서버의 세계관 파일 읽기 경로와 관련 검증을 추가했다. 서버 검사 7개가 통과했다. 캐릭터 제작 모음도 브라우저 검사에 통과했으며, 7개 카테고리와 금발 전사의 SD 8방향 우선 순서를 유지했다.
