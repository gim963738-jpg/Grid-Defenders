# 기준 자료 확인

기존 세계 지도 v17과 장발·안경·흰 로브의 인간 남성 수석 빛 마법사 제작 자료를 확인했다. 기존 큰 중앙 도시의 위치와 지형, 북부의 작은 요새, 북서부 충돌 흔적·오염지대, 남동부 차원 균열을 유지하는 방식으로 새 지명을 배치했다.

기존 큰 도시는 발레시온으로 지정하고 북동쪽에 훨씬 작은 마법도시 아르케리온을 추가했다. 성휘 대교회는 발레시온 안의 구역으로 배치한다.

원본 지도와 캐릭터 이미지·실제 생성 프롬프트는 제작 당시 기록으로 남긴다. 이전 아르켈리온·하르케리온 표기는 아르케리온의 이전 표기로 기록하며, 현재 설정의 표준명은 사용자 최신 지정인 아르케리온이다.

사용한 지침은 프로젝트 개발 규칙과 이미지 생성·문서 작성 스킬이다. 문서 작성 스킬의 품질 기준을 프로젝트의 기존 로컬 문서 체계에 적용했다.
