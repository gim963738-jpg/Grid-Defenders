# WEB-011 — 정의

## 경계 보정
- outside: 회전된 블록의 실제 칸이 격자 경계를 넘는지 판정. 공용 가방은 기존처럼 아래로 무제한 확장, 좌우/위 경계만 제한.
- nearestFree: 같은 격자에서 비충돌 앵커 후보의 거리 제곱 최소. 동률은 위 행→왼쪽 열 순서. 현재 방향 유지, 자기 칸은 빈 곳으로 취급.
↳ 쉽게 말하면: 블록이 밖으로 걸치면 가장 가까운 들어갈 자리를 찾아 옮기며, 빈 곳을 만들려고 다른 장비를 밀지는 않습니다.
- correctedPosition: 경계 안이면 요청 위치, 경계 밖이면 nearestFree. 영웅 칸 내부의 의도적인 겹침 비활성 규칙은 유지.
- 이동·회전·구매 잔상·조합 결과에 공통 반영. 조합은 재료 제거 예정 칸과 다른 완성품까지 고려해 소비 전에 검사. 영웅 빈칸이 없으면 원상태 유지/안내.

## 상점·자동 장착
- shopDiscounts: 상품별 할인 여부. 초기/리롤/리셋마다 독립20% 추첨. 화면 갱신·선택·드래그로 재추첨하지 않음.
- shopPrice: 정상가격×(할인 시0.5) 버림. 원본 ItemDef 가격은 유지.
- Gear.costBasis: 실제 구매가. 반값 구매품은 할인 구매가의 절반 환급, 조합품은 실제 재료 원가 합산 후 절반 환급.
- shop-market: 전투 상점 제목·상품을 감싼 드래그 판매 영역. 보유 장비 드롭 시 sellGear 사용, 미구매 상품을 상점으로 가져가도 판매하지 않음.
- autoEquip: 공용 가방 아이템을 지정 영웅의 현재 방향 빈자리로 자동 장착. 골드 비용 없음, 활성 배치만 허용.
- hero-drop-target: 드래그 중 영웅 테두리. 빈칸 없으면 붉게 표시.
- center-notice: 화면 중앙 비모달 안내, 약2.8초. 실패 아이템은 공용 가방에 유지.

## 병사 승급
- 기존 개별 병사 upgrade 비용·능력치·5레벨 상한 유지. 새 등급/병종 진화 추가가 아님.
- field-upgrade: 전장에서 선택한 병사 바로 아래 고정 좌표 버튼. 스크롤/화면 크기/이동에 위치 동기화.
- card-upgrade: 소환 패널의 해당 병사 종류 카드 아래 선택 개체 번호와 비용. 두 버튼은 같은 개체만 승급.
- 영웅·미배치 병사는 승급 버튼 없음, 골드 부족·상한은 비활성.
