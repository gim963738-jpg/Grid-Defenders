# 정의문서
- hero-skill-slots: 중앙 영웅에 연결된3칸 UI. assigned는 실제 스킬 설명 버튼, empty는 disabled X 상자.
- summonHeroSkill: 검/원거리 영웅의 배정된 액티브 스킬 정보. 전투용 BLADE_SKILL/FIRE_SKILL 상수를 참조. 다른 영웅은 미배정.
- summonSkillIcon: 제공 시트의 아이콘 사각형을 SVG로 표시. 새 이미지·스킬 제작 없음.
- hero-skill-tooltip: 버튼 근처에 표시되는 클릭 설명 창. 현재 중앙 영웅 변경·탭 변경·화면 전환·바깥 클릭·Escape에 닫힘.
확정 범위: 사용자 요청한 표시/설명 기능. 평타 제외. 미구현 칸 클릭 시 상태 변경·툴팁·전투 효과 없음. 사용자 외관 확인 대기.
