# 전체 이펙트 분류·재료함 통합

사용자 요청: “이펙트 전부 분류해서 재료함에 집어넣어”. 현재 수집한 무료 효과, 공방 예제, 브라우저 저장 작품 및 꺼내 쓸 수 있는 구성 부품을 한 재료함에 제공한다. 새 외부 팩 수집은 이번 범위에 포함하지 않는다.

- 재료마다 연출 분류, 출처, 완성 효과/구성 부품/낱개 이미지 구분을 표시하고 검색·필터한다. 크기·FPS 변형도 기본 표시한다.
- PNG와 절차적 효과를 같은 조합에서 재생·내보낸다. 절차적 재료는 추가 시 검증한 레시피를 조합 JSON에 보관하여 원래 작품의 수정·삭제에 영향받지 않게 한다.
- 원본 다운로드와 라이선스·크레딧을 보존한다. 무료 원본은 `.local/effect-materials`의 개인 자료로 유지한다. PNG에 합쳐진 내부 레이어를 자동 복구했다고 표현하지 않는다.
- 미정리 빔 시트는 실제 배치 확인 후 안전하게 분리 가능한 부분만 원본 픽셀·알파 그대로 추출한다. `art_source=existing`, generate2dsprite의 기존 프레임 처리 경로를 적용한다. 배경·지형은 효과와 혼동하지 않게 참고 소재로 분류한다.
- 기존 공방 저장 작품·부품·조합을 보존한다. 원본 기준점·추출 영역·투명 여백·표시 크기를 분리하며 피해·사거리·대상 수 등 전투 규칙은 변경하지 않는다.
- 분류 누락, 결정적인 재료 ID, 레시피 포함 백업 복원, 혼합 렌더·출처 ZIP, 밝은 배경과 전장 및 모바일 화면을 검증한다.
