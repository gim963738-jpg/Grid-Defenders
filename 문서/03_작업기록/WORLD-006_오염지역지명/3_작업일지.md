# 제작과 확인

내장 image_gen에 전체 지도와 위치 확대본을 전달해 한 번 생성했다. 북서부 충돌 지형 아래쪽의 “오염지역” 표기와 기존 15개 지명을 시각 확인했다.

선택한 결과는 1254×1254 불투명 RGB PNG다. 생성 원본과 프로젝트 복사본의 바이트가 동일하며 크기를 변경하지 않았다. v17~v21 원본 해시도 보존됐다.

지도 v22와 설정집 v1.4로 갱신하고 오염지역 위치 설명과 10번 표식을 연결했다. 구조 검사에서 이름 19개·연결 경로 14개를 확인했다.

별도 숨김 브라우저에서 지도 v22·표식과 범례 10개·10번 표기의 두 자리 숫자·선택 설명·북마크 복원을 확인했다. 전체 설정집의 새 지도·지명 설명과 기존 소수민족 국력 문구도 확인했다.
