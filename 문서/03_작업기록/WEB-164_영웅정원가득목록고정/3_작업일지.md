# 구현과 검증
2026-11-06: 정원 도달 여부를 기존 RULES.heroLimit로 판단한다. 정원이 차면 실제 소환 종류만 중복 없이1세트로 생성하고 미소환 카드는 생성하지 않는다. 기존 반복 카드 선택은 같은 영웅의 대표 카드로 이어진다.
정원 상태 전환 시 휠 자동 정렬 예약과 진행 중 드래그를 취소하고 스크롤0으로 고정한다. 복제 카드 접근성 처리·휠·스크롤·자동 정렬에도 같은 정원 조건을 적용했다. 빈자리 발생 시 기존27장/3세트 순환을 복구한다.
부분 확대 배율(DPR0.9)에서 카드 정렬 좌표가 주기 경계를 조금 넘으면 양쪽으로 재배치될 수 있어 경계에 반 칸 여유를 두었다. 카드 크기/정렬 간격은 유지한다.
브라우저27항목 통과:0/2/3명, 마지막 영웅 드래그 소환, 중복/비활성 DOM 제거, 휠/좌우 드래그 정지, 정보 선택/재진입, 다른 탭, 빈자리 복구, 대기 중 자동 정렬/진행 중 제스처 취소, 확대 배율 안정성. 화면 확인·타입검사·프로덕션 빌드·git diff --check 통과.
시험 편성은 별도5178 서버/페이지에서 사용했다. 실제 APK/실기기 검증 및 사용자 최종 확인은 별도다.
