# 영웅 선택 목록 상태
정원 미달: 기존9개 논리 초상화·3세트/27장·최대5장 표시·양방향 순환과 자동 정렬 유지.
정원 도달: RULES.heroLimit(현재3명) 이상이면 실제 소환된 종류별 대표 카드1장씩만 생성한다. 미소환/반복 카드는 생성하지 않는다. 목록은scrollLeft0·가로 overflow 숨김·순환/스냅 없음. 남은 카드는 정보 확인용 선택을 유지한다.
정원 상태 변경 시 휠 타이머·진행 중 드래그를 취소한다. 빈자리가 생기면 기존 소환 목록과 순환으로 복구한다. 소환 한도·비용·전투 모델을 바꾸지 않는다.
부분 배율에서 생기는 소수점 스크롤 좌표를 허용하도록 중앙 주기의 경계 재배치 검사에37px(반 카드 간격) 여유를 둔다. 재배치 목표 주기와74px 정렬 간격은 기존대로다.
