# OPS-005 정의

새 Codex 실행 기본값: GPT-6.1 Sol / 중간. 기술 식별자: model=`gpt-6.1-sol`, model_reasoning_effort=`medium`.

기본값 저장과 기존 세션 전환은 다르다. 이 작업은 Codex 설정 파일과 프로젝트 실행 규정을 저장한 상태이며, 열려 있는 Orca 대화의 GUI 선택을 일괄 전환한 상태가 아니다. 모델/추론 강도 외 설정, 이미지·영상 모델, 게임 내용은 변경하지 않는다.

공식 근거: [설정 파일](https://learn.chatgpt.com/docs/config-file/config-reference), [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol).
