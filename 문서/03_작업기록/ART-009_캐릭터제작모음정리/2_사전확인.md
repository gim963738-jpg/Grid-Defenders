# 인계와 이미지 범위 확인

인계 문서의 기존 갤러리에는 이미지 83개가 등록되어 있었고 경로가 모두 유효했다. `output/characters/`의 이미지 100개 중 등록되지 않았던 17개는 제작 과정의 원본·구도·재질 참조였다. 이 100개는 인계 스냅샷의 같은 경로와 SHA-256이 모두 일치한다.

현재 브랜치의 6종 정면·사선, C1 수정, 붉은 모험가 4방향, 마지막 일러스트 2종, 은발 지팡이 8방향을 추가했다. GC9 원본 16장과 SP13 원본 13장도 참조 용도로 분류했다. 지도·로비·API 연결 시험과 인계 스냅샷 사본은 캐릭터 목록에서 제외했다.

기존 갤러리는 같은 폴더의 `gallery.legacy-20261106.html`에 보관했고, 원래 주소를 통합 갤러리에 계속 사용한다. 환경 설정 내용이나 API 키는 읽거나 출력하지 않았다. Orca CLI 스킬의 브라우저 지침을 적용했다.
