# 분류와 검증

실제 이미지 179개 경로의 크기·알파·SHA-256을 수집했다. 같은 바이트의 사본 5개 경로를 연결해 고유 이미지 174개로 정리했다. 생성한 제작본은 113장, 원본·구도·화풍·배경 참조는 61장이다.

13개 제작 묶음과 캐릭터·구도·버전 기준을 적용했다. 같은 목적과 구도의 최근 제작본 74장, 이전 버전·초안 39장, 참조 61장으로 구분했다. 최근 버전은 사용자 승인과 구분하고, C4 얼굴·전체와 C3 금속의 사용자 기준을 표시했다.

갤러리에 검색·제작 묶음·캐릭터·방향·정렬·더 보기·밝은/어두운 배경·원본 100%·화면 맞춤·다운로드·모든 보관 경로·프롬프트 연결을 제공했다. 좁은 화면에서는 상세 필터를 접고 제작 묶음을 선택할 수 있다.

기존 제작 도구의 로컬 `/gallery`에서도 다른 제작 폴더의 이미지와 문서를 읽을 수 있도록 한정된 정적 경로를 연결했다. 실제 외부 이미지 API는 호출하지 않았다.

검증:

- 원본 179개 경로의 SHA-256 불변과 인계 스냅샷 이미지 100개 일치 확인.
- 인계 갤러리 83개 항목 전부 보존, 174개 고유 해시, 179개 보관 경로, 연결 문서 139개 확인.
- HTML 내장 목록과 JSON 일치, C1 수정본·6종·포니테일 4방향·마지막 테스트·8방향 선택 분류 확인.
- Orca 기존 갤러리 탭에서 4개 상태 탭·13개 묶음·검색과 구도 조합·빈 결과·24장 추가 표시·중복 경로·배경 전환 확인.
- 기본 이미지 24장 디코딩, 원본 보기의 실제 1254픽셀 배율과 화면 맞춤 확인.
- 너비 390에서 가로 넘침 없음, 접힌 필터 열기·묶음 선택·원본 보기 확인. 데스크톱과 모바일 화면 직접 확인.
- 로컬 제작 도구 서버 테스트 7개 통과. 신규 경로·JFIF·문서 표시와 설정 파일 비노출 검증은 모의 API로 수행.
- `git diff --check` 통과.
