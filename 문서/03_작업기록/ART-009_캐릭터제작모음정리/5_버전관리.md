# 로컬 저장과 유지

`tools/character-catalog/`에 이미지 읽기·분류 빌드·갤러리 템플릿·파일 감사·Orca 브라우저 검증을 저장했다. `output/characters/catalog/`에 기존 83개 항목·이미지 메타데이터·통합 목록·정리 기준·브라우저 검증 결과를 보관했다.

기존 갤러리 HTML을 갱신하고 같은 폴더에 이전 HTML을 보존했다. `tools/image-studio/server.mjs`의 정적 읽기 경로와 해당 서버 테스트에 갤러리 호환을 추가했다. AGENTS.md에 목록 위치와 갱신 방법을 연결했다.

기존 이미지와 프롬프트, 인계 스냅샷·bundle·삭제 결과는 유지했다. 게임 코드·task.md는 변경하지 않았고 커밋·푸시는 수행하지 않았다. 실제 이미지 생성·외부 API 호출은 없다.
