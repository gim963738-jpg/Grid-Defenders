# 정의문서
웨이브 카드: WAVE/남은시간/진행바, 하단 전장 몬스터 N마리. N은 hp>0인 일반·네임드·현상금 전체. 일반 생성 한도30은 기존 유지하되 전체 카운트에 /30을 붙이지 않음.
pause/boss-pause는 전역 정지 상태 공유. 정지 때 재생 아이콘 및 aria-pressed=true, 재개 때 정지 아이콘 및false. 배속은 바로 왼쪽, 기존6개 값 유지.
정지 시 stepCombat 콜백을 수행하지 않으므로 모델 시간/피해/효과/스킬 진행 없음. 보스 수동 스킬은 비활성화하고 카드에 일시정지 표시. 중지한 시간을 재개 시 따라잡지 않음. 전장 렌더/장면 이동/장비와 개발자 조작은 가능.
삭제된 상단 골드·처치·웨이브 상세 DOM 조회 제거, 재화는 기존 소환/가방 UI에서 계속 표시.
