# 구조
LANDSCAPE_BATTLE은 battle-landscape.html 경로에서만 활성. 전투 좌표800×360, SLOTS5×4(칸58×42), 길목중심x128~482/y68~264의 둥근 경로. Canvas는 같은 CSS800×360/고DPI로 렌더하며 스프라이트와 이펙트를 비균등 확대하지 않는다. 기존 단일 Defense 모델을 모든 가방/상점/전투가 공유한다.
영웅 가방은 가로 스크롤로 위쪽, 공용가방은 오른쪽 아래. 기존 4×5 장비와5×3 공용가방, 공용가방 확장·회전·조합·연결 활성/비활성 규칙 사용. 아이템 선택 후 목적칸 클릭 또는 드래그, 상점은 클릭 구매/목적칸 드래그 직접 구매.
하단 카드는72×72,간격2,왼쪽116 비움, 한 번에5개. 영웅9개 표시카드는 기존6병과를 재사용하며 중복/정원 검사는 모델에 위임. 횡드래그와 위로드래그소환을 방향으로 구분.
