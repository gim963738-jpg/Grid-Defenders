# 출력 정의

| 항목 | 값 |
|---|---|
| 입력 | Gemini 생성 MP4에서 추출한 원본 PNG 240장 |
| 캐릭터 | 오른쪽으로 달리는 금발 전사, 청색 망토, 장검과 단검 |
| 크기 | 1280×720 고정 |
| 시간 | 24fps, 240장, 영상 스트림 10초 |
| PNG | `frames/frame_0001.png`부터 `frame_0240.png` |
| 좌표 | 원본 위치 유지, 매 프레임 재중심 정렬 안 함 |
| 알파 | 실제 RGBA, 불필요한 배경은 0 |
| RGB | alpha가 0보다 큰 모든 픽셀은 원본 RGB 유지 |
| 무기·이펙트 | 캐릭터·장검·단검·망토의 외곽을 보존하며 배경 잔여물을 분리 |
| 영상 | VP9 실제 알파 WebM |
| 미리보기 | 격자가 포함된 H.264 MP4와 밝은 배경 확인표 |
| 게임 피해·앵커 | 이번 작업에서 정의하거나 변경하지 않음 |

모델의 원본 예측은 `masks/raw_####.png`에 보존해 정리 결과를 재현할 수 있다. 각 프레임 알파 영역과 원본 시각·SHA-256은 `frames.json`에 기록한다.
