# 배경 제거 작업

NVIDIA RTX 2060 환경에서 ONNX Runtime DirectML과 ToonOut 분리 모델을 로컬 실행한다. ToonOut은 애니메이션 그림체용 BiRefNet 모델이며, 사용한 ONNX 변환본과 원 모델은 MIT 라이선스다.

- 원 모델: https://github.com/MatteoKartoon/BiRefNet
- ONNX 변환본: https://huggingface.co/sprited/birefnet-toonout-onnx
- 고정 리비전: `2ded6fe6063fe146b7b30d8b4cfc5636df322525`
- 모델 캐시: `C:/Users/user/.cache/video-matting/toonout/birefnet-toonout-fp16.onnx`

모델 입력만 규정대로 1024×1024와 ImageNet 정규화로 준비한다. 예측 알파를 원본 1280×720 좌표로 돌린 뒤 원본 RGB와 결합한다. 납품 PNG의 캐릭터 RGB·해상도·좌표는 바꾸지 않는다.

일부 프레임에서 캐릭터 손·망토에 배경 수정과 식물이 닿아 자동 분리 결과에 섞였다. `refine_mattes.py`에서 작은 연결부·고립 잔여물·테두리의 숲 초록색을 정리하고, 밝은 청색/보라색 수정과 분홍 꽃잎의 색·크기·형태를 이용해 해당 잔여물만 추가 제거한다. 검의 짧은 청록색 인레이, 청색 망토와 금속 부위는 별도 조건으로 보호한다. 전체 명도 필터나 직선 잘림으로 처리하지 않는다.

후반 일부 프레임에서 장화에 닿은 긴 청록색 속도선도 배경으로 분리했다. 이 영상의 길고 가는 청록색 선을 검의 짧은 장식과 구분하는 조건을 적용한다. 영상 전경 전체를 그대로 마스킹하는 범용 방식이 아니라 이번 캐릭터 추출용 정리다.

188번은 원본 바위가 장화 일부를 가린다. 자동 마스크가 바위까지 잡아 프레임 하단이 불투명해진 것을 외곽 검사로 발견했다. 실제 보이는 바위/장화의 곡선 경계를 `matte-corrections.json`에 측정해 별도 제외 마스크로 적용한다. 원본 바위가 가린 장화 픽셀은 생성하거나 복원하지 않는다. 직선으로 발을 잘라 숨기지 않는다.

인접 189번도 같은 바위가 장화에 붙어 남아 안전 여백 검사에서 발견했다. 이 프레임도 원본의 곡선 접촉 경계를 측정해 분리하고, 가린 부분은 복원하지 않는다.

원본 프레임과 결과의 살아 있는 픽셀 RGB가 같은지 전 프레임 검사한다. 투명 외곽·안전 여백·240장 수량·PNG 읽기·WebM 디코딩 알파·ZIP 무결성을 확인한다. 밝은 초록/회색 확인표를 저장한다. 실제 게임 엔진 통합 검증은 수행하지 않는다.

실제 검사 결과와 완료 여부는 출력의 `verification.json`을 따른다. 사용자 최종 시각 승인은 별도다.
