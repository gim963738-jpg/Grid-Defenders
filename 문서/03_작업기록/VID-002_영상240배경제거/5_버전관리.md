# 저장 및 재현

현재 브랜치 `gim963738-jpg/영상제작`에 로컬 저장한다. 커밋·푸시는 요청받지 않았으므로 하지 않는다.

원본 영상과 기존 240장 추출 폴더는 보존한다. 모델 캐시는 결과 ZIP에 포함하지 않는다. 모델 출처와 SHA-256을 메타데이터에 보관한다.

실행 순서:

1. `python tools/video-frames/remove_background.py` — 로컬 모델 예측과 기본 분리.
2. `python tools/video-frames/refine_mattes.py` — 잔여물 정리.
3. `python tools/video-frames/remove_background.py --package-only` — 결과 메타데이터, 영상과 기본 ZIP.
4. `python tools/video-frames/verify_transparent.py` — 최종 프레임 및 실제 WebM 알파 검사.

완성 ZIP은 `frames/`의 투명 PNG 240장과 메타데이터·확인표·투명 영상·격자 미리보기를 포함한다. 디스크 결과와 ZIP은 최종 검사 후 다시 맞춘다. 정확한 실행 환경은 재현 스크립트와 설치 버전을 참고한다.
