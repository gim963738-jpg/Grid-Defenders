# 작업 범위

사용자의 배경 제거 요청에 따라 로컬 분리 모델 준비, 프레임 처리, 잔여 배경 정리, 검수와 로컬 저장을 수행한다. 외부 유료 생성 서비스를 사용하지 않는다.

원본 영상과 기존 추출 PNG는 보존한다. 결과는 `output/video-frames/gemini_generated_video_00ffc02e-transparent-v01/`에 별도로 저장한다. 투명 PNG 240장, 원본 24fps 투명 WebM, 격자를 넣은 확인용 MP4와 전체 프레임 ZIP을 구분한다.

캐릭터를 생성·다시 그리거나 자세를 변경하지 않는다. 위치 정규화, 게임 통합과 전투 판정 변경은 범위에 포함하지 않는다.
