# WEB-166 · 던파 PC 스킬 리소스 수집

2026-11-07. 사용자 요청: “던파 스킬 리소스 전부 가져와볼래?”

## 범위

설치된 PC 던전앤파이터 클라이언트에서 플레이어 직업의 스킬 이펙트 리소스를 찾고, 읽을 수 있는 파일을 별도 작업 출력으로 추출한다. 분류가 불명확한 공통 이펙트는 후보로 구분한다. 파일 목록·원본 경로·압축/이미지 버전·추출 성공/실패·이미지 크기와 오프셋을 기록한다. 일부만 추출했거나 이미지 조각만 확보했다면 ‘전체 스킬 완성’으로 표현하지 않는다.

## 원본·표시 계약

- 원본 설치 파일은 읽기만 한다. 추출 결과는 별도 출력 폴더에 저장한다.
- 원본의 알파, 프레임별 실제 크기·오프셋·링크를 보존한다. 전체 스킬 시간과 합성 순서를 이미지 인덱스에서 임의 추측하지 않는다.
- 암호화/알 수 없는 압축/미지원 버전은 읽기 실패로 기록하고 성공으로 위장하지 않는다.
- 추출 성공 후 밝은 회색/초록 배경에서 이미지와 알파를 확인한다. 이 단계는 리소스 수집이며 실제 전장에 연결하기 전의 검수임을 명시한다.
- 설치 위치·파일 형식·수량·전체 용량은 현장 조사로 확정한다. 사용자 저장 공방과 기존 이펙트를 덮어쓰지 않는다.

## 전투 계약

영웅·웨이브·보스에 장착하지 않으며 피해·사거리·대상 수·쿨타임·명중 시점을 추가하거나 변경하지 않는다. 원본 좌표와 표시 pivot 및 패딩 처리는 향후 선택한 스킬을 공방/전장에 통합할 때 별도로 검증한다.
