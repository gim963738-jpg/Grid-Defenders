# 4방향 캐릭터 산출물 정의

| 항목 | 정의 |
|---|---|
| 정면 | 0도, 얼굴·가슴·골반·무릎이 카메라를 향함 |
| 정측면 | 90도, 화면 오른쪽을 향하는 정확한 옆모습. 사선과 구분 |
| 후면 | 180도, 얼굴과 앞쪽 장비 면이 보이지 않는 뒤쪽 |
| 3/4 사선 | 약 45도, 앞면과 옆면이 함께 보이는 방향 |
| 남성형 리모델링 | 원본 구성은 유지하고 기존 약 8등신의 남성형 인체·얼굴 표현으로 재구성 |
| 비대칭 구성 | 오른팔 긴 은색 완갑·오른무릎 앞 보호판. 후면의 오른팔은 화면 오른쪽 |
| 투명 출력 | 실제 RGBA PNG. 바깥 영역 알파 0과 알파 240 이상 가시 영역을 확인 |
| 100% 검수 | 원본 PNG 1픽셀을 CSS 1픽셀로 표시. 축소 JPEG 확대와 구분 |

파일당 크기는 1024×1536이다. 네 방향은 같은 캐릭터의 생성 일러스트이며, 정확한 3D 회전·픽셀 기준선 정규화 산출물과는 구분한다.
