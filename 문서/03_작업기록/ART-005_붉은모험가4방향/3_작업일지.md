# 붉은 머리 모험가 4방향 제작과 확인

내장 `image_gen`으로 정면을 먼저 생성하고, 정면과 원본 삼면도를 참조해 정측면·후면을 제작했다. 마지막 사선은 새 정면·정측면·후면을 함께 참조했다. 각 출력별 1회씩 총 4회 생성했다.

[작업 폴더 비교 화면](../../../output/red-haired-adventurer-4views-v1/index.html), [PNG 4장 묶음](../../../output/red-haired-adventurer-4views-v1/adventurer_4views_png.zip), [생성 기록](../../../output/red-haired-adventurer-4views-v1/생성기록.json), [검수 결과](../../../output/red-haired-adventurer-4views-v1/검수결과.md)를 저장했다.

네 PNG 모두 실제 1024×1536이며 알파 투명을 확인했다. 완전 불투명 255만을 정상 조건으로 삼는 최초 검증은 도구 반환 알파 최대값 254 때문에 중단됐다. 알파 240 이상 가시 영역과 알파 0 바깥 영역을 확인하는 조건으로 바로잡아 실제 통계를 기록했으며, 이미지 픽셀 자체는 수정하지 않았다.

생성 원본·프로젝트 복사본 해시, 입력 복사본 해시, ZIP의 4장 구성·CRC·해시, 프롬프트 참조 경로를 확인했다. 브라우저에서 4개 원본 로드·방향·영역·배경 전환, 100% 원본 너비 1024, 모바일 가로 넘침 없음을 검증했다. 흰색·차콜 배경 캡처를 열어 전체 프레임과 투명 가장자리를 확인했다.

AGENTS.md에 네 방향 제작 규칙과 자료 경로를 연결했다. 생성물의 최종 화풍·구성 일관성에 대한 사용자 판단은 별도다.
