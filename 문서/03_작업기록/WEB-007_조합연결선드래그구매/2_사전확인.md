# WEB-007 — 사전 확인

- 대상: defense.ts(접촉·일괄 조합·구매 좌표), main.ts(입력·연결선·조합 UI), index.html·style.css, 관련 문서·화면 기록.
- 현재 영웅 장비칸과 공용 가방에서 유효 조합 쌍 표시. 같은 격자의 상하좌우 변 접촉만 노란 선, 대각·겹침·경계 밖 제외.
- 짚은 아이템과 조합식이 맞는 보이는 상대는 파란 점선. 상점 미구매 상품도 지원하되 이 단계에는 구매·소비하지 않음.
- 공용 가방 드롭 시 구매. 지정 칸이 막혔으면 빈 칸 자동 배치. 밖에 드롭·취소·골드 부족은 구매 없음.
- 오른쪽 조합 버튼: 현재 영웅+가방의 중복 없는 조합을 일괄 실행. 횟수·모루 필요/보유만 표시, 결과 미리보기 제거.
- 재료를 공유하는 후보는 현재 영웅→공용 가방, 아이템 생성 번호 순서로 선택. 같은 아이템은 한 번만 소비.
- 완성품은 공용 가방 자동 보관. 기존 네 조합식·판매 원가 규칙 유지.
- 제외: 도감·추가 조합식·모루 정상 수급·새 디자인·다른 영웅의 장비 일괄 조합.
- 완료 조건: 선·접촉·구매/취소·여러 조합의 모루 소비·결과 비공개·모바일 크기·빌드 검증.
