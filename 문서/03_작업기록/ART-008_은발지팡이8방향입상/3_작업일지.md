# 8방향 제작과 검수

내장 image_gen을 11회 호출했다. 정면·오른쪽 정측면·후면을 먼저 생성하고, 지팡이와 원통 장비의 인체 좌우가 원본과 달라 이 3장을 수정했다. 수정 정면과 후면을 함께 참조해 앞 사선 2개·뒤 사선 2개·왼쪽 정측면을 각각 생성했다.

선택 PNG 8장과 수정 전 초안 3장을 작업 폴더에 보존했다. 모든 호출의 정확한 프롬프트·입력 순서·내장 도구 저장 경로를 기록했다. 초기 측면·후면이 참조했던 정면 V1도 별도 스냅샷 경로와 해시로 구분했다.

검수 결과:

- 최종 8장 모두 실제 1254×1254 RGBA PNG. 저장 시 리샘플링하지 않음.
- 각 파일에 완전 투명 픽셀과 알파 240 이상 피사체가 존재. 가시 외곽은 가장자리에 닿지 않음.
- 전체 가시 외곽 하단은 y=1178~1189, 범위 11픽셀. 발·지팡이를 포함한 통계이며 수작업 발 기준점 정규화와 구분.
- 정면·측면·후면·앞뒤 사선 모두 입상. 왼손 지팡이·오른쪽 허리 장비와 반대 측면의 팔 가림 관계를 시각 확인.
- Headless Edge에서 최종 이미지 8장 및 원본 디코딩, 배경 3종 전환, 8개 원본 보기와 참고선 전환 확인.
- 화면 너비 1600의 4열, 390의 2열 표시 확인. 모바일 가로 넘침 없고 원본 보기는 1254픽셀 유지.
- 밝은 배경과 어두운 배경의 전체 8방향 캡처를 직접 확인.
- 선택본만 넣은 ZIP을 생성. JSON·로컬 링크·입력 스냅샷·SHA-256·ZIP 내용은 최종 파일 감사로 확인.

수작업 픽셀 격자 정규화·전투 애니메이션·실게임 통합은 수행하지 않았다.
