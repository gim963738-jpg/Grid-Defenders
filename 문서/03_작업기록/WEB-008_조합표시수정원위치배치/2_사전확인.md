# WEB-008 — 사전 확인

- 대상: main.ts 연결선 입력/색상, defense.ts 결과 배치, index.html 패널 순서/안내, style.css 회색선, 관련 문서·화면 기록.
- 파란 선은 누르는 동안만 표시. 손 놓기·취소·창 포커스 상실 시 제거. 선택만으로 다시 표시하지 않음.
- 기존 combinationPlan과 노란 선을 일치시키고, 재료 공유로 계획에서 제외된 후보는 회색으로 표시. 조합 순서와 모루 비용은 유지.
- 결과는 첫 번째(생성 번호가 앞선) 재료의 소유자·기준 칸·방향 유지.
- 완성품 공간 부족: 공용 가방은 재료/모루를 소비하기 전에 전체 배치 검증 후 실패 안내. 영웅 장비는 기존 겹침/경계 비활성 규칙 적용.
- 공용 가방 → 선택 아이템 상세 → 전투 상점 순서로 변경.
- 제외: 새 조합식·도감·재료 우선순위 선택 UI·모루 정상 수급.
- 완료 조건: 놓은 뒤 점선 없음, 공유 후보 노랑/회색 구분, 같은 가방·장비칸의 조합 기준 위치 유지, 상점 순서·구매 유지, 빌드 통과.
