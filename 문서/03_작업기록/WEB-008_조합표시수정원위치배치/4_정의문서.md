# WEB-008 — 정의

- 파란 점선: 실제 포인터를 누르고 있는 아이템 또는 드래그 중인 상품의 상대 안내. pointerup·pointercancel·window blur로 제거. 단순 선택/키보드 포커스는 표시 조건 아님.
- 노란 실선: combinationPlan의 이번 실행 대상. 모루 부족 시에도 재료 계획 선은 유지하고 실행 버튼에서 비용 확인.
- 회색 실선(combo-deferred): 조합식과 접촉은 맞지만 선순위 쌍이 재료를 사용하여 이번 계획에서 제외된 후보. 아이템 자체의 능력치를 끄는 뜻은 아님.
- 기존 우선순위: 현재 영웅 → 공용 가방, 각 후보 생성 번호 순서. 같은 재료 중복 소비 금지. 선순위가 사라지면 다음 후보 승격.
- 완성품 배치: 해당 쌍의 첫 재료 owner/x/y/turns 유지. 원위치 장착 완성품은 영웅 능력치에 즉시 반영.
↳ 쉽게 말하면: 영웅 장비에서 합쳤으면 그 장비칸에, 가방에서 합쳤으면 가방의 그 자리에 완성품이 생깁니다.
- 공용 가방 완성품은 경계·다른 블록·같이 만들어지는 완성품과 충돌하지 않아야 함. 전체 검증 실패 시 재료/모루 소비 없음, 빈 곳으로 자동 이동하지 않음.
- 영웅 장비칸 완성품의 겹침/경계 밖은 기존 빨간 비활성 규칙 유지, 임의로 가방에 해제하지 않음.
- C-3 순서: 공용 가방·선택 상세·전투 상점. 구매 버튼/상품 드래그 구매·가방 확장 유지.
