# 제작 대상과 최신 지시 적용

사용자가 요청한 이미지 생성과 추가 인물의 제작을 수행한다. 별도 승인 절차를 추가하지 않는다.

대상은 6종 × 정면·사선 각 1장, 총 12장이다. 원본 6장과 구도 참조 2장을 보관하고, 정확한 생성 프롬프트·참조 순서·검수 결과·비교 화면·PNG 묶음을 저장한다.

기존 일반 그림체 자료의 얼굴·체형 보존 문구보다 이번 사용자의 재구성 지시를 우선한다. 구성 참조와 인체·얼굴 참조를 분리하고, 새 정면이 완성되면 그 결과를 같은 인물의 사선 참조로 사용한다. 남성형 2종·여성형 4종으로 제작했다.

게임 코드·전투·스킬·UI·task.md·Downloads 원본은 변경하지 않는다. 모델 추가 학습, 게임 통합, 원격 저장은 이번 생성 작업에 포함하지 않는다.
