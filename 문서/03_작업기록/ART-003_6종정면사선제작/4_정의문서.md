# 이번 캐릭터 전환의 정의

| 항목 | 정의 |
|---|---|
| 구성 참조 | 원본의 머리색·헤어 구성·의상·문양·장비. 얼굴과 신체 비율은 이번 요청에 따라 재구성 |
| 화풍 참조 | GC9 v1.1 중 에델·브람·로난·미스트·라피스·리르 등 목적에 맞게 선택 |
| 정면 기준 | 새로 생성한 각 캐릭터의 정면 전신. 사선의 얼굴·체형·장비 기준으로 재사용 |
| 사선 | 예시처럼 약 35~45도 3/4 전신. 각도 수치는 제작 지시이며 사용자 실측값이 아님 |
| 성별별 인체 | 여성형 약 7.5등신, 남성형 약 8등신의 제작 출발값. 남성형은 더 큰 키와 넓은 어깨로 구분 |
| 배경 | 불투명 차콜. 투명 PNG와 구분 |
| 산출물 | 6종 × 정면·사선 = 12개 1024×1536 PNG |
| c05 | 사용자가 명시한 남성형 청색 망토·폐쇄 투구 기사 |
| c06 | 다운로드 (12)의 금발·흰금 갑옷·붉은 안감 기사. 외형에 따라 남성형 적용 |

복장과 장비의 큰 구성은 각도 사이에서 대응한다. 생성된 미세 문양의 픽셀 동일성이나 정확한 3D 모델 회전 결과를 정의하는 작업은 아니다.
