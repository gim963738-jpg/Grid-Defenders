# 정의 문서

| 항목 | 정의 |
|---|---|
| 캐릭터 | silver_staff_mage, 기존 은발 지팡이 SD 원화의 시범 자산 식별자 |
| 시점 | 오른쪽 정측면 |
| 손/장비 | 먼 인체 왼손에 지팡이, 가까운 오른팔 비움, 원통형 장비는 가까운 오른쪽 허리 |
| 시트 | 동작별 6×5, 1536×1280 RGBA, 30개의 256×256 고정 셀 |
| 순서 | 01~30 행 우선, 끝에서 01로 반복 |
| 걷기 | 1000ms/주기, 원본 229px 셀에 13/14px 여백 |
| 달리기 | 750ms/주기, A1~8/B2~8/C2~8/D1~5/F6~8 선택 |
| 표시 기준점 | (128,228), 피해/충돌과 별개 |
| 확대 | 공통 1~4배, 각 화면을 독립적으로 끌어 이동 |
| 2차 움직임 | 머리카락/로브 변형이 그림에 포함, 바람 파라미터 제어 없음 |
| 상태 | 실물 초안 저장/구조 검증 완료, 사용자 최종 판정·완성 자동 템플릿 아님 |

숫자 가이드와 근·원측 색은 계획 자료다. 생성된 그림이 가이드를 완전히 준수했다는 자동 판정 자료로 사용하지 않는다. 파일 해시와 브라우저 테스트는 발의 해부학적 자연스러움이나 사용자의 품질 만족을 대신 증명하지 않는다.
