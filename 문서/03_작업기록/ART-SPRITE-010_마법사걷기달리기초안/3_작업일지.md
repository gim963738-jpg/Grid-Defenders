# 작업 일지

2026-11-07.

1. 기존 SD 지팡이 캐릭터와 전사 걷기를 확인하고 정체성/스타일 참조를 분리했다.
2. 근·원측 다리, 지지 시간, 공중 구간을 구분한 걷기·달리기 30장 기하 가이드를 작성했다. 가이드는 최종 캐릭터 그림을 코드로 대신 그린 것이 아니다.
3. 내장 이미지 생성 8회. 걷기 첫 시트는 채택했다. 첫 달리기 전체 시트는 동작과 반복 연결 문제로 제외했다.
4. 달리기는 8장 구간 A~D로 재생성했다. 연결 시도 E는 제외하고, F의 6~8번만 골라 최종 28~30번 앞발 높이를 보정했다.
5. 달리기 전체 원본마다 동일한 최근접 축소를 적용하고, 선택 30장을 256px 고정 셀로 포장했다. 걷기는 축소 없이 여백만 넣었다. 번호 시트, APNG, 좌표 JSON과 출처 대응표를 저장했다.
6. 두 동작 비교 재생, 반복 켜기/끄기, 속도, 같은 번호 프레임 선택, 100~400% 확대, 휠·드래그·핀치, 발 확대, 시트 탭과 번호를 구현했다.
7. 파일/알파 검증과 실제 Edge 조작 검증을 수행했다. System.Drawing RGB 반올림 1/255와 알파 동일 여부를 구분했다. APNG는 Pillow와 브라우저에서 실제 30장·1000/750ms를 확인했다.
8. 채팅은 투명 WebP 축소 시 세부가 흐려져 밝은 배경 표시 사본으로 변경했다. 최종 채팅 표시도 256px 셀이다. 원본 PNG와 로컬 미리보기의 알파/배경 전환은 유지한다.

결과 파일의 제작기준.md에 남은 접지 높이 차이, 금테/머리 선의 변동, 공용 뼈대와 바람·피격 미구현을 기록했다. 게임 통합 검증은 해당 변경이 없어 수행하지 않았다.
