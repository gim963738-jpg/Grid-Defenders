# 노드 연결 이펙트 공방 — WEB-158

2026-11-06~07. 사용자 요청: 첨부한 이미지처럼 여러 노드를 곡선으로 연결해 효과를 구성하는 장치를 공방에 추가한다. 참조 이미지의 배치·포트 방식만 참고하여 기존 로컬 공방에 구현했다. 외부 사이트 소스나 PXF 포맷을 가져오지 않는다.

## 사용법

1. 공방 새로고침 → **노드** 탭. 직접 열기: `http://127.0.0.1:5182/effect-workshop.html#nodes`.
2. 처음 열면 현재 표시되는 기본 레이어와 그린 선으로 연결도를 구성한다. 그리기에서 기본 레이어 표시를 껐다면 해당 레이어는 처음 연결도에서 제외되며 **원본 추가**로 불러올 수 있다. 이전 작업은 원본·연결도 모두 자동 저장된다.
3. 노드 제목을 드래그해 옮긴다. 빈 바닥 드래그·휠로 화면 이동, 확대/축소 버튼·Ctrl+휠로 확대한다. **전체 보기**로 현재 노드를 함께 본다. 큰 연결도는 축소 한계에서 화면을 이동하며 편집한다.
4. 노드 오른쪽 출력 → 다른 노드 왼쪽 입력으로 끈다. 출력과 입력을 차례로 누르거나 아래 **연결 만들기** 선택창을 사용해도 된다. 작은 화면에서도 선택창·속성·연결 끊기는48px 조작 영역을 유지한다.
5. 보라색은 이미지, 노란색은 방향이다. **방향선 → 기본 효과/완성 모양의 이동 방향**, **이미지 → 색상 → 발광 → 최종 출력**으로 연결할 수 있다. 출력은 여러 노드에 분기할 수 있고 한 입력에는 한 출력만 연결한다. 이미 연결된 입력에 다른 출력을 넣으면 이전 연결을 교체한다.
6. **효과 추가**는 기본 레이어와 해당 소스 노드를 만든다. **원본 추가**는 아직 연결도에 없는 기존 레이어·그림을 불러온다. **처리 노드 추가**는 색상/투명도/변형/발광/페이드/합성/마스크를 만든다. 새 노드는 출력 흐름으로 연결해야 결과에 들어간다.
7. 노드를 선택해 오른쪽 속성을 수정한다. 기본 효과는 이름·색상·반경·투명도·회전을 직접 편집할 수 있다. 시작·종료 등 세부 레이어 값은 미리보기 화면에서, 선의 의미·그림·단계·지속시간은 그리기 화면에서 수정한다. 방향과 모양이 동시에 움직여야 한다면 두 선의 단계를 같이 지정한다.
8. 각 카드와 선택한 노드의 이미지에 현재 프레임 결과가 표시된다. 아래 타임라인에서 다른 프레임을 선택하거나 **결과 재생**으로 애니메이션을 확인한다. 첫/마지막 프레임처럼 투명한 시점에서는 카드도 비어 보일 수 있다.
9. 선택한 노드의 연결 목록에서 **끊기**, **노드 삭제**, 처리 노드 **복제**를 쓴다. 소스 노드를 지워도 레이어/그림 자체는 남아 원본 추가로 다시 불러올 수 있다. 방향 연결의 추가·해제는 그리기 화면의 연결할 방향선에도 반영된다. 삭제·연결·이동·속성·재구성은 실행 취소/다시 실행할 수 있다. 최종 출력 노드는 삭제할 수 없다.
10. **현재 작업으로 다시 구성**은 현재 원본의 표시/순서/방향 바인딩으로 기존 연결도를 바꾼다. 한 번의 실행 취소로 이전 연결도를 복원한다. **노드 사용**을 끄면 기존 레이어·그리기 합성으로 돌아가며 연결도는 보관된다.
11. 최종 출력이 미리보기/전체 프레임/실제 전장/투명 PNG 시트에 반영된다. **내보내기 → 수정 가능한 작업 JSON**으로 연결도까지 백업한다. **AI 작업 요청**에도 연결도와 편집 규칙이 포함된다.

## 노드 정의

| 종류 | 입력/출력과 동작 |
| --- | --- |
| 기본 효과 | 기존 절차적 레이어를 이미지로 출력. 방향 입력을 연결하면 중심이 해당 경로를 따라 이동 |
| 그린 선 | 방향 의미는 방향 출력, 완성 모양/경로 연출은 이미지 출력. 미지정·참고는 효과를 만들지 않음 |
| 색상 | RGB 색상과 적용 비율 조정, 원본 알파 유지 |
| 투명도 | 이미지의 알파 조정 |
| 크기·회전·이동 | 중심 기준 균일 배율/회전/정규화 좌표 이동 |
| 발광 | 원본 위에 블러 잔광 추가 |
| 구간·페이드 | 전체 재생 길이의 시작/종료 구간과 양 끝 감쇠 |
| 합성 | A 아래/B 위, 일반·빛 더하기·스크린·곱하기와 B 불투명도 |
| 마스크 | A의 이미지를 B의 알파로 잘라냄. 두 입력 필수 |
| 최종 출력 | 연결된 이미지 흐름을 공방 공통 렌더 결과로 사용 |

## 저장·렌더 계약

`gd.effect@1`의 선택 필드 `graph`를 확장했다. graph 없는 예전 JSON은 기존대로 열린다.

- `graph`: version1, enabled, nodes1~96개, links최대160개, view{x,y,zoom}. 노드 좌표와 화면 이동은 편집 전용이며 이펙트 위치를 변경하지 않는다.
- `node`: 고유 id, type, x/y, 소스 노드의 sourceId, params. params는 color/amount/scale/rotation/x/y/blur/mode/start/end를 모두 저장한다.
- `link`: from(출력 노드id), to(입력 노드id), port(대상 입력 이름). 이미지/방향 포트 종류, 하나의 입력당 하나의 연결, 하나의 최종 출력, 원본 참조, 순환 연결을 검사한다. 같은 원본은 한 소스 노드로 두고 출력을 분기한다.
- 그린 모양의 방향 연결과 `drawing.directionId`가 서로 다른 JSON은 오류로 알린다. UI에서 원본을 제거하거나 의미를 바꾸면 유효하지 않은 소스·연결만 정리한다. 외부 JSON은 조용히 복구하거나 실행하지 않는다.
- 프레임별 메모이제이션으로 같은 소스를 분기해도 한 번만 래스터화한다. 연결도 생성 시 일반/가산 레이어의 기존 합성 순서를 유지한다.
- 연결도 사용 중에는 최종 출력에 도달하는 흐름만 출력한다. 출력 미연결/빈 이미지에서 예전 효과로 자동 대체하지 않는다. PNG가 비어 있거나 경계에 닿으면 기존 출력 제한을 적용하며 작업 JSON은 백업 가능하다.
- 출력은 기존 투명 콘텐츠 → `SkillFrameSpec/createSkillFrame/SkillFrameArt` 계약을 사용한다.24px 투명 패딩, pivot, 표시 크기와 균일 배율을 유지한다. 시트 배치 JSON에도 graph를 함께 보관한다.

영웅·스킬·평타는 미배정이며 피해/사거리/타수/대상/쿨타임을 추가하거나 변경하지 않는다. 타격 프레임은 프레임 완료 표시이고 피해와 연결하지 않는다. 캐릭터 이동 metadata와 VFX 이미지도 분리한다. 이번 노드는2D 합성용이며 실시간3D 모델·임의 셰이더·외부 PXF 호환·자동 AI API·실제 게임 스킬 자동 적용은 범위에 포함하지 않았다.
