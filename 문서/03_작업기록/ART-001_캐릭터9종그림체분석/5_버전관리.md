# 그림체 자료 로컬 저장 상태

이번 변경은 `AGENTS.md`의 자료 경로 추가와 신규 GC9 원본·분석·보고서·프롬프트·입력 양식·작업 기록의 로컬 저장이다. 게임 코드와 task.md는 변경하지 않았다.

커밋·푸시는 수행하지 않았다. 원격에 이번 자료가 저장되었다고 주장하지 않는다. 별도 브라우저 검증 프로필과 화면 캡처, 인라인 보고서는 이 채팅의 scratch 폴더에 보관하며 프로젝트 원본 자료는 워크스페이스에 저장했다.

후속 저장 시 관련 경로만 대상으로 확인한다.

```powershell
git status --short
git diff --check
git diff -- AGENTS.md
```
