# 그림체 분석 작업 범위

사용자의 직접 요청에 따라 로컬 이미지 9장을 열어 분석하고 이후 제작에 필요한 참조·문서·입력 양식을 저장한다. 추가 승인 절차를 만들지 않는다.

대상:

- `자료/캐릭터그림체/GC9/`: 원본 9장, 출처·해시·개별 분석 JSON, 비교 보고서.
- `문서/02_세부기획/02_영웅/캐릭터그림체/`: 공통 그림체 기준, 생성 프롬프트, 새 캐릭터 입력 양식.
- `AGENTS.md`: 해당 그림체를 요청받을 때 위 자료를 먼저 읽도록 경로 연결.
- 이 작업 기록 5개와 채팅 비교 시각화.

완료 조건은 9장 개별 관찰, 공통·가변 요소 구분, 실제 원본을 함께 사용하는 프롬프트 준비, 재사용 가능한 경로와 원본 무결성 검증이다.

Downloads 원본·게임 코드·현재 UI·전투·스킬·기존 영웅 설정·task.md는 변경하지 않는다. 새 캐릭터 생성·게임 통합·가중치 추가 학습·커밋·푸시는 이번 범위에 포함하지 않는다.
