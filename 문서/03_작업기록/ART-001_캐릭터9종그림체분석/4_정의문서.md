# GC9 화풍 참조 정의

| 항목 | 정의와 상태 |
|---|---|
| GC9 | 이번 사용자 제공 원본 9장에 대한 로컬 화풍 참조 ID. 전 프로젝트의 모든 화풍을 강제하는 규칙이 아님 |
| M01~M05 | 미스트·하르페·지크하트·라스·로난. 사용자 지정 남성 그룹 5종 |
| F01~F04 | 에델·유로파·티아·리르. 사용자 지정 여성 그룹 4종 |
| 공통 화풍 | 깨끗한 가는 선·얼굴 생략·큰 형태 묶음·셀 명암·재질별 반사. 직접 관찰을 제작 기준으로 정리 |
| 정체성 | 새 인물의 얼굴·나이·체형·피부·종족·머리·의상·팔레트·장비. 화풍 참조와 분리 |
| 참조 조합 | 목적별 원본 2~3장의 권장 조합 8개. 신규 생성에서 검증한 최적 조합이라는 뜻은 아님 |
| 입력 양식 | 캐릭터 설정을 기록하는 JSON. 비어 있는 양식이며 생성 API 요청 형식이 아님 |
| 프롬프트 | 한국어·영어 공통 화풍 블록, 새 설정 블록, 피할 표현, 치환 예시 4개. 실제 생성 검증 전 |
| 원본 | 보관한 JFIF 9장. 흰 배경이며 알파 없음. 개별 출처와 해시는 참조목록에 기록 |
| 분석 보고서 | 원본 비교용 로컬 HTML. 게임 UI 또는 생성 결과물이 아님 |

입력 치환 예시는 게임 내 신규 캐릭터·직업·세계관·능력치의 확정이 아니다. 현재 문서는 제작 준비 완료이며 사용자 최종 화풍 확인 및 신규 생성물 검수와 구분한다.
