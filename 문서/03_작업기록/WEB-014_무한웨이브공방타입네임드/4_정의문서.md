# WEB-014 — 정의

## 공격·방어
- DamageType: physical(물리), magic(마법).
- DefenseType: normal(일반형), physical(물리 방어형), magic(마법 방어형).
- defenseMultiplier: 공격 계열과 방어 타입 일치0.75, 나머지1. armor/magicArmor 숫자는 현재 배율 계산에 사용하지 않음.
- mitigatedDamage: round(공격력 × 치명 배율 × 타입 배율). 체력 감소량은 남은 체력으로 제한, 피해 숫자와 로그에 같은 실제 감소량 표시.
- UnitDef.damageType: 보병/궁병/탱커/근접=물리, 마법병/원거리/힐러=마법.
- stats: physicalAttack/magicAttack(해당 계열에 공격값, 반대는0), physicalArmor/magicArmor. 기존 armor는 물리 방어와 동일한 호환 필드.
- 기존 공격력 아이템은 유닛 계열의 공격력 가산, 방어력 아이템은 물리 방어 가산. 별도 마법 방어 아이템 추가는 이번 범위 제외.

| 순환 괴물 | 일반형 |160|물리20|10|10|0.8|43|12|
| 철갑 괴물 | 물리 방어형 |180|물리25|60|10|0.7|40|12|
| 비전 괴물 | 마법 방어형 |160|마법25|10|60|0.8|43|12|

- 생성 시 HP/공격=기본값×(1+0.1×(소환 웨이브-1)), 반올림. 생존 개체는 다음 웨이브에 재성장·회복하지 않음.
- 몬스터 공격/공속/방어 숫자는 향후용 임시 데이터. 일반전 아군 일방 공격 규칙은 유지.
- 현상금은 기존 HP1600·기본100G/모루1 유지, 일반형 방어. 아군 처치 골드 증가 적용 유지.
- 일반은 붉은색·‘일반’, 물방은 푸른색·‘물방’, 마방은 보라색·‘마방’. 네임드는 큰 몸/금색 왕관/이름, 현상금은 금색/뿔.

## 무한 웨이브
- wave:1부터 무한 증가, waveTime:현재 웨이브의 경과 시간, waveSpawned:해당 웨이브 자동 생성 일반 수.
- 30초마다 전환, 일반10마리(시작1마리·2초 간격). 남은 일반은 처치/골드/모루 보상 없이 정리. 빨리 잡아도30초까지 대기.
- 네임드/현상금은 웨이브 전환 시 체력·ID 유지. 일반30마리 제한은 이 두 종류를 제외. 네임드가 누적되어도 시험 패배 처리 없음.
- 네임드:5웨이브마다1마리, 강철→비전 교대. 시험 소환과 별도로 자동 생성.
- pendingBounties:3웨이브마다1 증가·최대3. 버튼 클릭 시1 소모, 활성 현상금이 있으면 소비 없이 거부. 상한 초과분은 보관하지 않음.
- 이전50처치 조건/무제한 적립 규칙 폐기. normalKills는 통계용 일반 처치 수만 유지.
- spawnTestMonster: 개발 도구에서 정의5종 중1마리 수동 생성. 일반30 한도, 네임드는 별도.
- nextTestWave: 일반 정리 후 다음 웨이브 시작. 타이머 전환과 같은 규칙, 시간 대기만 생략.
- 정식40웨이브·보스·패배 기획을 확정 변경한 것이 아닌 임시 시험 모드.
