# Grid Defenders — 디펜스 전투 시험

PixiJS + TypeScript + Vite. WEB-002에서 순환 전투·선택 소환·장비·상점을 연결한 세로형 시험 버전이다.

## 조작
1. 소환·지휘에서 병사 또는 영웅 선택 → 전장 안쪽 빈 칸 터치.
2. 병사는 골드 차감, 영웅은 무료·최대 3명. 같은 영웅 중복은 시험 규칙상 제한.
3. 배치된 병사 선택 → 강화·판매. 영웅은 판매·교체 불가.
4. 상점·가방 → 구매. 선택한 장비는 영웅 장비창에서 사용.
5. 영웅 장비 → 영웅 선택 → 가방 장비 선택 → 장비칸 클릭 또는 드래그. 회전 후 빈 공간에 배치.
6. 장착 장비를 선택해 이동·회전·가방으로 해제·판매. 실패한 배치는 원래 상태 유지.
7. 상단 배속 버튼으로 1·2·3배 전환. 메뉴를 조작해도 전투 지속.

## 이동·범위 공격·격자 가방 (WEB-004)
- 유닛 드래그 → 빈 칸 이동, 다른 유닛 위에 놓기 → 자리교체. 영웅·병사의 모든 조합 허용, 무료.
- ID·레벨·강화 비용·장비·공격 대기시간 유지. 전장 밖에 놓으면 원래 위치 유지.
- 전장의 영웅 단순 클릭 → 해당 영웅 장비창 자동 전환. 드래그는 단순 클릭과 구분.
- 영웅의 선택 공격 범위는 진한 테두리와 내부 색으로 표시. 실제 사거리는 그대로.
- 보병: 주 대상을 향하는 90도 부채꼴 안의 모든 적 공격. 반경은 기존 사거리130 논리px.
- 마법병: 주 대상 중심48 논리px 원형 범위의 모든 적 공격. 궁병은 단일 공격 유지.
- 범위 이펙트와 실제 판정은 같은 기하 데이터 사용, 각 적에게 한 번씩 피해·보상·로그.
- 공용 가방도5열 테트리스 격자. 구매품은 빈 곳 자동 배치, 행은 필요에 따라 확장.
- 가방 블록 선택 시 상점에 머무름. ‘영웅에게 장착’ 버튼으로 장비창 전환.
- 공용 가방과 영웅 장비칸의 블록 더블클릭·두 번 탭 → 현재 자리에서90도 회전.
- 경계·다른 장비 때문에 회전할 수 없으면 기존 상태 유지. 버튼 회전도 같은 규칙.
- 블록 드래그 시 집은 칸을 유지. 영웅 장비와 공용 가방 사이 드래그·선택 후 빈 칸 배치 지원.

새로고침하면 시험 상태가 초기화된다. 저장·불러오기는 없다.

## 영웅 능력치 팝업·작은 카드 (WEB-005)
- 소환 전 영웅 카드를 클릭하면 기본 능력치 팝업과 소환 선택 표시. 빈 전장 칸에 놓아 소환.
- 배치된 영웅 클릭은 현재 장비 적용 능력치 팝업과 해당 영웅 장비창을 함께 연다.
- 이미 배치된 영웅의 소환 카드를 클릭해도 해당 영웅 선택·장비창으로 연결.
- 영웅 카드 약62px 높이로 축소. 이름·아이콘·무료/배치됨/정원 가득만 표시, 상세 수치는 팝업으로 이동.
- 영웅3명 정원이 가득해도 다른 영웅 기본 능력치는 확인 가능하나 소환 제한은 유지.
- 장비창의 영웅 선택 버튼과 능력치 줄 제거. 제목에 현재 영웅 이름·번호 표시.
- 팝업은 닫기·바깥 클릭·Escape·메뉴 전환으로 닫음. 전투를 멈추지 않는다.
- 최대 체력·공격력·방어력·공격속도·체력 재생·골드 획득만 표시. 미구현 치명타·회피 등은 추가하지 않음.
- 병사 정보·강화·판매는 기존 선택 정보 유지. 영웅은 별도의 큰 정보 카드 중복 표시 안 함.

## 임시 개발자 기록창 (WEB-003)
- 넓은 화면의 게임 왼쪽 여백에 표시. CSS viewport1080px 미만에서는 게임 아래로 이동.
- 피해: 공격자 이름·고유번호·배치 위치, 대상 몬스터 번호, 공격값·실제 체력 감소량·체력 전후.
- 처치: 처치자·몬스터·획득 골드·잔액 전후·골드 보너스.
- 경제: 소환·강화·구매·리롤·병사/장비 판매의 증감액과 잔액. 무료 영웅 소환은0G.
- 구역별 최근100건, 최신 위, 독립 스크롤. 시간을 배속이 반영된 전투 경과 분:초로 표기.
- 과거 기록을 스크롤해서 읽는 동안 새 기록이 생겨도 읽던 행을 유지(100건 범위 안에서).
- 실패한 행동에는 거래 기록 없음. 새로고침 시 기록 초기화.
- 게임 규칙이 아닌 개발 확인용 임시 화면. 기록 내보내기·영구 보존은 없음.

## 이번에 없는 기능
영웅 자동·수동 스킬, 웨이브·승패, 보스, 모루 정상 획득·오염·정화, 로비·영구 성장, 최종 아트.
아이템은 기본 수치형 9종만 연결했다. 쿨타임·고유 효과 아이템은 아직 상점에 나오지 않는다.
일반전은 아군이 피해를 받지 않으므로 체력·방어·재생은 능력치 정보로만 반영되며 생존 효과를 시험하지 않는다.

## 실행 (PowerShell)
```powershell
Set-Location -LiteralPath 'C:\Users\user\Desktop\Grid Defenders\게임'
npm.cmd ci
npm.cmd run dev
```
출력된 Local 주소를 브라우저에서 연다. 종료: 터미널에서 Ctrl+C.
PowerShell 실행 정책을 바꾸지 않도록 npm.cmd를 사용한다.

## 확인과 빌드
```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run preview
```
배포용 파일은 dist에 생성된다. index.html을 직접 더블클릭하지 말고 서버로 실행한다. 실제 호스팅·Google Play 배포는 이번 범위에 포함하지 않는다.

- REF-06의 상단 전장·하단 조작 구역 참고. 임시 도형이며 최종 아트가 아니다.

## WEB-006 현재 변경
- 병사 카드·전장 병사를 클릭하면 기본/강화 적용 능력치 팝업. 강화·판매 조작 유지.
- 오른쪽 개발 도구: 골드+10,000·모루+10·게임 리셋. 좁은 화면은 게임 아래, 패널 내부 스크롤.
- 조합 공식4종을 재료·결과 블록/이름/효과로 표시. 공식에서 재료 선택 또는 가방 아이템의 ‘조합 재료 선택’ 후 조합 실행.
- 철검2→정밀 검 / 수호 방패+활력의 수정→룬 방패 / 철검+가속 룬→질풍의 검 / 활력의 수정2→재생의 부적.
- 공용 가방 재료2개+모루1 소모, 결과 가방 자동 배치. 모루 초기0, 정상 획득은 미구현.
- 조합품 판매가는 누적 재료 구매가의 절반 버림.
- 영웅 장비는 겹침·경계 밖도 회전/배치 허용. 마지막 변경 장비를 비활성화하고 효과 전체 제외. 문제 해소 시 재활성.
- 비활성 장비는 빨간 표시와 목록의 이유·가방 회수 버튼으로 확인. 공용 가방의 기존 겹침/경계 제한은 유지.
- 이 절은 위 과거 조작 설명의 실패 유지·조합 제외·병사 정보 설명을 대체.

## WEB-007 현재 조작
- 아이템을 짚으면 조합 상대를 파란 점선으로 표시. 같은 가방에서 재료 블록의 변을 붙이면 노란 실선.
- 영웅 장비칸 오른쪽 조합 버튼은 현재 영웅+가방의 중복 없는 쌍을 일괄 조합. 실행 횟수만큼 모루 소비, 부족하면 전체 유지.
- 완성품은 조합 후 공용 가방에서 확인. 기존 공식 목록·결과 미리보기 제거, 도감은 별도 예정.
- 상점 상품을 공용 가방에 드래그해 놓으면 구매. 밖에 놓거나 골드가 부족하면 구매하지 않음. 드롭 칸이 막혔으면 빈 곳 자동 배치.
- 오른쪽 회전·해제 버튼은 조합 영역으로 교체. 더블클릭 회전·상세 회전·가방 드래그 해제 유지.
- 화면/가방 가장자리에서 드래그하면 스크롤. 위 WEB-006의 공식·재료 선택·미리보기 설명은 이 절로 대체.

## WEB-008 현재 수정
- 파란 점선은 누르는 동안만 표시. 놓거나 취소·창 전환하면 제거.
- 접촉 후보 중 실제 실행 대상은 노란 선, 재료 공유로 밀린 후보는 회색 선.
- 완성품은 같은 장비칸/가방에서 첫 재료 자리·방향 유지. 가방 공간 부족이면 전체 재료·모루 보존 후 공간 확보 안내. 영웅은 기존 겹침/경계 비활성 규칙 유지.
- 상점·가방 탭은 가방 위, 상점 아래. 위 과거 WEB-007 조작 중 점선·완성 위치 설명은 이 절로 대체.
