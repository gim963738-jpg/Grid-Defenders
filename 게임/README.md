# Grid Defenders — 디펜스 전투 시험

PixiJS + TypeScript + Vite. WEB-002에서 순환 전투·선택 소환·장비·상점을 연결한 세로형 시험 버전이다.

## 조작
1. 소환·지휘에서 병사 또는 영웅 선택 → 전장 안쪽 빈 칸 터치.
2. 병사는 골드 차감, 영웅은 무료·최대 3명. 같은 영웅 중복은 시험 규칙상 제한.
3. 배치된 병사 선택 → 강화·판매. 영웅은 판매·교체 불가.
4. 상점·가방 → 구매. 선택한 장비는 영웅 장비창에서 사용.
5. 영웅 장비 → 영웅 선택 → 가방 장비 선택 → 장비칸 클릭 또는 드래그. 회전 후 빈 공간에 배치.
6. 장착 장비를 선택해 이동·회전·가방으로 해제·판매. 실패한 배치는 원래 상태 유지.
7. 상단 배속 버튼으로 1·2·3배 전환. 메뉴를 조작해도 전투 지속.

새로고침하면 시험 상태가 초기화된다. 저장·불러오기는 없다.

## 이번에 없는 기능
영웅 자동·수동 스킬, 웨이브·승패, 보스, 조합·모루·오염·정화, 로비·영구 성장, 최종 아트.
아이템은 기본 수치형 9종만 연결했다. 쿨타임·고유 효과 아이템은 아직 상점에 나오지 않는다.
일반전은 아군이 피해를 받지 않으므로 체력·방어·재생은 능력치 정보로만 반영되며 생존 효과를 시험하지 않는다.

## 실행 (PowerShell)
```powershell
Set-Location -LiteralPath 'C:\Users\user\Desktop\Grid Defenders\게임'
npm.cmd ci
npm.cmd run dev
```
출력된 Local 주소를 브라우저에서 연다. 종료: 터미널에서 Ctrl+C.
PowerShell 실행 정책을 바꾸지 않도록 npm.cmd를 사용한다.

## 확인과 빌드
```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run preview
```
배포용 파일은 dist에 생성된다. index.html을 직접 더블클릭하지 말고 서버로 실행한다. 실제 호스팅·Google Play 배포는 이번 범위에 포함하지 않는다.
