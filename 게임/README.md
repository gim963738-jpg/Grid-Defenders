# 이펙트 부품 노드 (WEB-168)

공방 왼쪽 **공방 작품 갤러리**에서 기본 효과와 내 작업을 함께 비교합니다. **부품 보관함**은 불꽃·마법진·문양처럼 따로 꺼내 쓰는 구성 요소입니다. 현재 작품·내 부품·기본 부품·다른 저장 작품을 카테고리로 골라 움직이는 모습으로 확인하세요.

노드 선택 → **이 부분 보관** → 이름/카테고리 저장 → 다른 작품에서 **부품 보관함 → 내 부품 → 현재 작품에 넣기**. 원래 팔레트와 앞쪽 연결을 함께 복제하며 자동으로 최종 출력에 연결합니다. 실행 취소 한 번으로 추가를 되돌릴 수 있습니다. **마법진 화염 분출** 기본 예제에서 고리·문양·불꽃·불씨 네 노드를 확인할 수 있습니다.

부품 내부 움직임은 현재 작품의 전체 재생 길이에 맞춥니다. 부품 보관함 JSON은 별도 백업 가능하며, 작품 JSON에도 실제 부품 원본이 들어갑니다. 평면 PNG의 원래 레이어 복구 기능은 아니며 수집 PNG는 기존 무료 재료함에서 구간별로 조합합니다. 자세한 기능과 검사 범위는 `문서/03_작업기록/WEB-168_공방부품노드와사용성/2_사용법과검증.md`를 참고하세요.
