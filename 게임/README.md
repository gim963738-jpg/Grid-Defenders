# Grid Defenders — 디펜스 전투 시험

PixiJS + TypeScript + Vite. WEB-002에서 순환 전투·선택 소환·장비·상점을 연결한 세로형 시험 버전이다.

## 조작
1. 소환·지휘에서 병사 또는 영웅 선택 → 전장 안쪽 빈 칸 터치.
2. 병사는 골드 차감, 영웅은 무료·최대 3명. 같은 영웅 중복은 시험 규칙상 제한.
3. 배치된 병사 선택 → 강화·판매. 영웅은 판매·교체 불가.
4. 상점·가방 → 구매. 선택한 장비는 영웅 장비창에서 사용.
5. 영웅 장비 → 영웅 선택 → 가방 장비 선택 → 장비칸 클릭 또는 드래그. 회전 후 빈 공간에 배치.
6. 장착 장비를 선택해 이동·회전·가방으로 해제·판매. 실패한 배치는 원래 상태 유지.
7. 상단 배속 버튼으로 1·2·3배 전환. 메뉴를 조작해도 전투 지속.

## 이동·범위 공격·격자 가방 (WEB-004)
- 유닛 드래그 → 빈 칸 이동, 다른 유닛 위에 놓기 → 자리교체. 영웅·병사의 모든 조합 허용, 무료.
- ID·레벨·강화 비용·장비·공격 대기시간 유지. 전장 밖에 놓으면 원래 위치 유지.
- 전장의 영웅 단순 클릭 → 해당 영웅 장비창 자동 전환. 드래그는 단순 클릭과 구분.
- 영웅의 선택 공격 범위는 진한 테두리와 내부 색으로 표시. 실제 사거리는 그대로.
- 보병: 주 대상을 향하는 90도 부채꼴 안의 모든 적 공격. 반경은 기존 사거리130 논리px.
- 마법병: 주 대상 중심48 논리px 원형 범위의 모든 적 공격. 궁병은 단일 공격 유지.
- 범위 이펙트와 실제 판정은 같은 기하 데이터 사용, 각 적에게 한 번씩 피해·보상·로그.
- 공용 가방도5열 테트리스 격자. 구매품은 빈 곳 자동 배치, 행은 필요에 따라 확장.
- 가방 블록 선택 시 상점에 머무름. ‘영웅에게 장착’ 버튼으로 장비창 전환.
- 공용 가방과 영웅 장비칸의 블록 더블클릭·두 번 탭 → 현재 자리에서90도 회전.
- 경계·다른 장비 때문에 회전할 수 없으면 기존 상태 유지. 버튼 회전도 같은 규칙.
- 블록 드래그 시 집은 칸을 유지. 영웅 장비와 공용 가방 사이 드래그·선택 후 빈 칸 배치 지원.

새로고침하면 시험 상태가 초기화된다. 저장·불러오기는 없다.

## 임시 개발자 기록창 (WEB-003)
- 넓은 화면의 게임 왼쪽 여백에 표시. CSS viewport1080px 미만에서는 게임 아래로 이동.
- 피해: 공격자 이름·고유번호·배치 위치, 대상 몬스터 번호, 공격값·실제 체력 감소량·체력 전후.
- 처치: 처치자·몬스터·획득 골드·잔액 전후·골드 보너스.
- 경제: 소환·강화·구매·리롤·병사/장비 판매의 증감액과 잔액. 무료 영웅 소환은0G.
- 구역별 최근100건, 최신 위, 독립 스크롤. 시간을 배속이 반영된 전투 경과 분:초로 표기.
- 과거 기록을 스크롤해서 읽는 동안 새 기록이 생겨도 읽던 행을 유지(100건 범위 안에서).
- 실패한 행동에는 거래 기록 없음. 새로고침 시 기록 초기화.
- 게임 규칙이 아닌 개발 확인용 임시 화면. 기록 내보내기·영구 보존은 없음.

## 이번에 없는 기능
영웅 자동·수동 스킬, 웨이브·승패, 보스, 조합·모루·오염·정화, 로비·영구 성장, 최종 아트.
아이템은 기본 수치형 9종만 연결했다. 쿨타임·고유 효과 아이템은 아직 상점에 나오지 않는다.
일반전은 아군이 피해를 받지 않으므로 체력·방어·재생은 능력치 정보로만 반영되며 생존 효과를 시험하지 않는다.

## 실행 (PowerShell)
```powershell
Set-Location -LiteralPath 'C:\Users\user\Desktop\Grid Defenders\게임'
npm.cmd ci
npm.cmd run dev
```
출력된 Local 주소를 브라우저에서 연다. 종료: 터미널에서 Ctrl+C.
PowerShell 실행 정책을 바꾸지 않도록 npm.cmd를 사용한다.

## 확인과 빌드
```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run preview
```
배포용 파일은 dist에 생성된다. index.html을 직접 더블클릭하지 말고 서버로 실행한다. 실제 호스팅·Google Play 배포는 이번 범위에 포함하지 않는다.

- 전장 논리 크기 390×330, 페이지 최대 폭 430px, 하단 패널은 세로 스크롤.

- 정확한 패키지 버전은 package.json·package-lock.json 참조.
- 확인 환경: Windows Node.js 26.13.0, npm 11.20.0. 최소 요구 버전은 각 패키지의 engines를 확인한다.
