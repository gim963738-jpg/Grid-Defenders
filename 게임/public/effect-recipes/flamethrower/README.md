# 청염 화염방사

사용자가 제공한 영상의 주황색 분사구, 흰 중심, 넓은 푸른 외곽과 잔불을 참고한 공방용 재현 소스입니다. 영상에서 원본 화염을 추출한 파일은 아닙니다. 캐릭터·무기·피해 숫자·배경은 포함하지 않습니다.

공방 기본 효과 또는 갤러리에서 **청염 화염방사**를 검색해 **이 효과로 시작**을 누르세요. `.effect.json`을 공방의 JSON 가져오기로 열어도 됩니다.

- 편집 JSON: `blue-flamethrower.effect.json`, `gd.effect@1` 형식. 현재 공방의 `jet`(화염방사) 레이어를 사용합니다.
- 투명 PNG 시트: `blue-flamethrower.sheet.png`, 8열×8행, 64프레임.
- 배치 정보: `blue-flamethrower.sheet.json`, 모든 셀 좌표/기준점/표시 크기/프레임 시간을 포함합니다.
- 재생: 2.4초, 약26.667FPS. 점화 → 지속 분사 → 노즐 차단 → 푸른 잔불 소멸. 반복 재생 여부는 별도로 정할 수 있습니다.
- 콘텐츠: 256×256px, 사방24px 패딩, 셀304×304px. 실제 표시 크기는 콘텐츠 기준220px입니다.
- 기준점: 발이 아닌 **분사구(노즐)**입니다. 콘텐츠(.84,.52)=(215.04,133.12)px, 패딩 포함 셀(239.04,157.12)px. 무기의 분사구 위치에 맞춰 균일 배율로 배치하세요.

기본 방향은 영상처럼 **왼쪽**입니다. 오른쪽으로 사용할 때는 그림과 기준점을 함께 좌우 반전합니다. 반전 후 콘텐츠 기준점(.16,.52), 셀 기준점(64.96,157.12)px입니다. 공방에서는 레이어 회전/위치를 바꾸거나 노드 변환을 이용하고, 변경 후 밝은 배경의 전체 프레임에서 여백을 확인하세요.

팔레트는 외곽 불꽃 / 주황 분사구 / 밝은 중심 순서입니다. 화염방사 레이어에서 길이·두께·퍼짐·흐름 속도·입자 수·불투명도를 수정하고 FPS로 전체 시간을 바꿀 수 있습니다. 노즐은 먼저 꺼지고 이미 분사된 불꽃이 앞쪽에서 조금 더 남도록 구현했습니다.

피해·사거리·대상 수·쿨타임과 실제 게임 스킬은 연결하지 않았습니다. `impactFrame`은 프레임 완료 시각의 표시입니다. 출처 영상의 가려진 부분과 화면 밖으로 잘린 부분은 새로운 모양으로 구성했습니다.
