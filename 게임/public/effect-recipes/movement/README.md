# 달리기·이동 이펙트 소스 10종

Grid Defenders 개인 이펙트 공방용 절차적 원본입니다. 배경은 투명하며 캐릭터 그림은 포함하지 않습니다.

|---|---|---|
| run-soft | 가벼운 발먼지: 발걸음마다 작은 먼지 | 0.9초 |
| run-heavy | 묵직한 발구름: 흙먼지와 자갈 | 0.9초 |
| run-sand | 모래 질주: 길게 흐르는 고운 모래 | 1.2초 |

## 공방에서 사용

갤러리에서 **이동 소스**를 검색합니다. 카드의 **이 효과로 시작**을 누르면 기존 작업을 보존하고 새 편집 작업을 만듭니다. 공방의 **JSON 가져오기**로 `.effect.json` 파일을 열어도 됩니다.

팔레트, 레이어 위치·반경·입자 크기·퍼지는 각도·개수·속도·불투명도를 바꿀 수 있습니다. 프레임/FPS는 전체 연출 시간을 바꿉니다. 번개의 지그재그는 **그리기**에서 수정하며, 다른 레이어와 함께 **노드**로 조합할 수 있습니다. 수정한 결과는 공방의 **내보내기**에서 다시 받습니다.

`dust`(먼지 구름), `wind`(바람 띠), `splash`(물보라)는 이번 공방에 추가된 기본 도형입니다. 편집 JSON은 이 도형을 지원하는 현재 공방에서 사용합니다. PNG는 일반 투명 스프라이트 시트입니다.

## 파일과 배치

- `.effect.json`: 편집 원본 `gd.effect@1`.
- `.sheet.png`: 투명 PNG 시트. 8열, 192×192px 콘텐츠에 사방 24px 패딩을 더한 240×240px 셀.
- `.sheet.json`: 각 논리 프레임의 셀 좌표, 원본 영역, 기준점, 표시 크기, 시간.
- `manifest.json`: 10종 파일 목록.

기본은 **오른쪽 이동**이며 꼬리가 왼쪽으로 뻗습니다. 기준점은 발밑으로 콘텐츠 좌표 `(0.68, 0.68)` = `(130.56, 130.56)`px, 패딩 포함 셀 좌표 `(154.56, 154.56)`px입니다. 표시 크기는 콘텐츠 기준 132~166px이고 가로·세로 배율은 동일하게 적용합니다. 시트 마지막 행의 빈 셀은 프레임에 포함하지 않습니다.

왼쪽으로 사용할 때는 그림과 기준점을 함께 좌우 반전합니다. 반전된 콘텐츠 기준점은 `(0.32, 0.68)`, 패딩 포함 셀 기준점은 `(85.44, 154.56)`px입니다. 그림만 뒤집고 기존 기준점을 유지하면 발 위치가 어긋납니다.

일반 먼지는 각 발이 지면을 디딘 순간 그 발 위치에 한 번 재생하고, 남은 먼지는 그 자리에 두는 방식이 어울립니다. 바람·불꽃·번개는 이동 중인 캐릭터의 발 기준점을 따라 배치할 수 있습니다. 이 소스 묶음은 실제 캐릭터 이동 속도나 게임 스킬을 자동 연결하지 않습니다.

`impactFrame`은 공통 형식의 프레임 완료 표시만 유지하며 피해와 연결하지 않습니다. 피해·사거리·대상 수·쿨타임 값은 포함하지 않습니다. 표시 범위와 전투 판정은 별개입니다.
