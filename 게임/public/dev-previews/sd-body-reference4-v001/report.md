## 실제 생성과 사용량

내장 image_gen 2회, 기존 API 이미지 POST 2회 모두 성공했다. 실패·타임아웃·자동 재시도·추가 유료 보완·대체 모델 호출은 없었다. API는 gpt-image-2.6-sunburst / high / 1024×1536을 요청했다. 입력 4,264 / 출력 2,744 / 합계 7,008토큰이 보고됐다. 응답 모델명과 금액은 미보고이므로 미상이다. 내장 상세 모델과 사용량도 미보고이며 추정하지 않았다.

기존 requestImage/validateConfig 어댑터를 재사용했다. 키는 기존 파일에서 메모리로만 읽었고 명령 인자·출력·산출물에 넣지 않았다. secret-scan.json의 결과물 42파일 검사에서 키값이 검출되지 않았다. 기존 도구·env·서버·전역 환경은 변경하지 않았다.

## 검증과 남은 한계

네 파일 모두 반환된 1024×1536 RGBA 원본과 SHA가 같은 바이트 사본이다. 리샘플링·신체 변형·알파 정리·코드 재작화는 하지 않았다. 각 PNG와 밝고 어두운 전체 비교판을 직접 열었다. 격리 headless에서 네 이미지 로드, 확대 열기/닫기와 동일 본체 높이·발선의 CSS 등비 등록을 확인했다. 초기 확대용 빈 이미지의 decode 오류는 수정 후 재검증했다.

원본 안에 가려진 두상·몸은 추정해 새로 그린 것이며 정확한 알몸 복원이 아니다. 네 결과의 머리 비중·근육 명암·주름과 손발 세부에 차이가 있다. 특히 B 남성의 먼쪽 손가락과 일부 발가락 표현은 단순화되어 해부학적 완전성을 주장하지 않는다. 발끝도 다소 벌어져 있어 정밀한35도 투영과 구분한다.

배경에는 실제 alpha0이 있다. 내부 alpha 최댓값은 모두254로255는 아니며, 원본 바이트를 유지했다. 밝고 어두운 합성판에서 피부와 검은 옷의 경계를 확인했다. 한 성별당 한 샘플씩의 결과로 모델 일반 우열을 확정하지 않는다.

새18필독 ACK/start를 통과했고 반환 전 해시도 유효했다. 기존 A/B·코드 마네킹 등 검사한269파일은 불변이다. 리깅·영상·동작·게임 통합, 공통 규정·카탈로그·현재 창과 Git는 변경하지 않았다. 산출물과 실질5종기록은 로컬 작성 상태이며 커밋·푸시·원격 저장은 미실행이다. 후속은 사용자의 체형·작화 평가와 선택이다.
