비교 조건과 처리 설명

전장 800×360 CSS px를 축소하지 않습니다. 전사 기본 본체 72px / 터틀 기본 180px는 비교용 임시 배치입니다. PNG 전체 높이와 본체 높이는 다릅니다.

현재 표시는 원본을 Canvas 기본 보간으로 직접 축소합니다. 고품질은 알파를 고려하는 브라우저 Canvas의 high 보간과 단계 축소로 실제 DPR 표시 버퍼를 만듭니다. 경계 정리는 그 버퍼에서 바깥 투명 영역에 연결된 알파 1~8만 최대 1 낮추며 초록 계열은 보존합니다. 얼굴·검·발광을 다시 그리지 않습니다. 차이는 작을 수 있으며 어느 쪽이 나은지는 직접 비교하세요.

PNG는 800×360 CSS px 장면을 현재 DPR의 물리 해상도로 내보냅니다. 선택선·발점·확대는 출력에 포함되지 않습니다. 캐시는 24개/24MiB 한도, DPR은 실제값(최대3)입니다. 전체 구현·원본 SHA·발점 오차·검사는 보고에 기록합니다. 브라우저 자체 검사이며 실제 게임·실기기 검증 및 사용자 최종 합격은 별도입니다.
