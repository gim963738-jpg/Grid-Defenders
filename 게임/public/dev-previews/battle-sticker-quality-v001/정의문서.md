index.html, style.css, app.js, mobile-ui.css, assets/를 같은 상대경로로 복사하면 배포 가능하다. 외부 패키지/CDN/네트워크 요청은 없다. 일반 사용은 main01이 승인된 dev-previews 새 경로에 복사하여 기존 HTTP 경로에서 제공한다. 본 작업은 서버/포트를 열지 않았고 사용자 창·탭·패널을 조작하지 않았다. file URL은 브라우저의 이미지 픽셀 읽기 제한이 있으므로 일반 배포 경로는 HTTP다. 검사는 독립 headless에서 allow-file-access-from-files로만 수행했다.

전장은 800×360 CSSpx 고정이고 전체 transform/zoom을 사용하지 않는다. 스티커 좌표 x,y는 전장 내 발점이다. 크기 범위16~360 CSSpx, 최대50장이다. 전사 초기 발점280,280/72px, 터틀460,280/180px. 선택 목록, 직접 알파 hit test 클릭/탭, 드래그, 숫자/슬라이더, 복제/삭제/초기화가 있다. 복제체는 새 ID와 독립 좌표·크기를 갖는다. 빈곳 클릭/ESC는 선택을 해제한다. 입력칸 편집 중 삭제 단축키는 차단한다. 모바일에서는 ‘조작: 스티커 이동 / 전장 스크롤’ 버튼으로 제스처를 분리한다. 이동 모드에서는 전장 바깥을 쓸어 페이지를 스크롤한다. 스크롤 모드에서는 전장 안을 쓸어 가로/세로 스크롤한다.

전사 scale=본체CSSpx/1123. PNG 전체 크기1312×1199, hairTop42, foot470,1164이며 원 메타 추정 오차±10 nativepx를 유지한다. 72px일 때 전체PNG84.117542×76.872663 CSSpx, 원점은 발점에서30.133571,74.628673px를 뺀 위치다. 원 메타의 bodyHeight1123은 bounds의 exclusive 높이이며 hairTop42→footY1164 좌표 차1122를1123으로 재정의하지 않는다. 72는 이 메타 본체정의다. 검·투명여백을 본체로 재측정하지 않는다.

터틀 scale=본체CSSpx/748. PNG1536×1024, shell~foot body748/foot535,968은 수동±15px 추정값이다. 180px일 때 전체PNG369.625668×246.417112 CSSpx다. 큰 갑각·초록 발광·비대칭·원래 왼쪽앞3/4 방향을 보존하고 반전하지 않는다. 이는 디자인합격 v02/main03 출처이며 사용자가 main2라고 부른 호칭으로 바꾸지 않는다. 크기는 게임밸런스 확정값이 아니다.

배경은 원본1194×1317을 기존 구도대로1600×1766로 표시하고800×360에서 x=-400,y=-843.6(center 60%)로 그린다. 재생성하지 않는다. 본체 크기/발점/보이는 PNG 범위는 피해판정과 관계없다.

현재표시: 원본 native 이미지→전장 Canvas로 직접 drawImage. imageSmoothingEnabled=true, 기본 보간 수준인 low(기본값)다. nearest 열화나 샤프닝을 넣지 않는다.

고품질축소: 동일 native→가로/세로가 목표의2배보다 클 동안 각 축ceil(절반) 중간Canvas→최종 ceil(PNG CSS폭×DPR),ceil(PNG CSS높이×DPR) 버퍼. 모든 축소는 Canvas imageSmoothingQuality=high, 기본 premultiplied-alpha 보간·합성을 사용한다. 자체 Lanczos·선형광 계산이라고 주장하지 않는다. 최종 버퍼를 원래 소수 CSS크기로 그려 발점과 본체크기를 유지한다. 예: 전사72는 DPR1의85×77, DPR2의169×154 버퍼이며 ‘본체’는 각각72/144 물리픽셀 기준이다. DPR은 실제 window.devicePixelRatio로 읽되3을 상한으로 한다. 3초과는 내부해상도가 제한되므로 실제DPR과 차이가 날 수 있다.

축소+경계정리: 위와 완전히 같은 축소를 한 후 가장자리에서4방향 flood fill하여 알파0~8인 외부 연결 영역만 찾는다. 그 중 a1~8의 비초록 픽셀만 알파를1/255 낮춘다. RGB를 재색칠하지 않는다. g>1.15r 및 g>1.1b인 초록 계열은 그대로 보존한다. a>8인 표면/얼굴/검/갑각과 내부 구멍은 수정하지 않는다. 실제 발광의 의미를 완벽히 분류하는 알고리즘이 아니므로 매우 낮은 알파의 비초록 발광/윤곽에 소실 위험이 남는다. 효과는 작게 제한했다. 원본 바이트를 변경하지 않고 파생Canvas/캐시에만 적용한다.

캐시는 asset+본체높이+DPR+mode 키의 LRU24개/24MiB 한도다. 이동은 좌표만 바꾸고 texture를 재사용한다. pointermove마다 native 전체를 처리하지 않는다. 숫자/빠른slider의 마지막 유효값만 RAF에서 렌더링한다. 최대크기360,DPR3의 보스단일버퍼는 약8.75MiB이고 중간Canvas는 생성범위 내 임시 객체다. DPR3·최대50체 장시간 메모리는 실측하지 않았다.

PNG는 뷰포트스크린샷이 아닌800×360 장면 전체를 현재 유효DPR로 합성한다. DPR1=800×360, DPR2=1600×720이며 표시 라벨/파일명으로 알린다. 선택선·발점표시·확대는 제외한다. 선택 확대는4CSS배로 별도스크롤하며 확대에서만 nearest를 써 실제 표시 샘플을 관찰한다. 전장의 현재표시에는 nearest를 쓰지 않는다.
