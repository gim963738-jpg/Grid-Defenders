# 남녀 공통 이동 뼈대 / 별도 체형 데이터

rig.json은 공통 계층·좌표축·카메라를, bodies.json은 두 체형별 길이/폭/관절을, motions.json은 하나의 공통 움직임을 정의한다. 전방x·높이y·좌우z의 수학 좌표를 우측 앞35도 정사영으로 Canvas에 그린다. 모든 형태는 코드 도형이며 원본 이미지를 탈의 편집하지 않았다.

Root→Pelvis→Torso→Chest→Neck→Head와 좌우 UpperArm→Forearm→Hand / Thigh→Shin→Foot를 둔다. 전신 루트는 전방으로 적분하고 카메라는 루트를 따라간다. 지지발 월드 목표는 고정하고 골반 높이를 도달 범위 안으로 내린 뒤 2본 IK로 무릎을 푼다. 팔은 다리와 역상으로 스윙한다. 숨은 두상·골반 위치는 추정이다.

초안의 팔/다리가 원본 관계보다 길게 보인 것을 내부 대조에서 발견해 history-proportion-draft에 보존했다. 원본 근측 어깨(548,429)·팔꿈치(492,562)·손목(455,653)·손(473,708), 추정 골반(650,775)과 무릎/발목을 대조해 팔/다리를 줄이고 몸통/목 간격을 늘렸다. ±25~35px의 추정 오차이며 정확한 해부 계측으로 주장하지 않는다. 머리카락끝17과 추정두상110~턱335를 구분한다.

남성체: 어깨반폭112·골반68·허리78, 위팔130/전완95, 대퇴205/하퇴195, 몸통310/목70. 여성체: 어깨96·골반80·허리63, 위팔126/전완92, 몸통300/목70이며 다리는 동일하다. 골반 형상도 별도 반경104(남성93)다. 전체 가로압축·색만 변경하지 않았다. 신체 비율은 사용자 평가용 초안으로 공통 표준을 바꾸지 않는다.

Start는1.2초 가속, Walk→Run은0.8초 혼합, 일반 정지는0.85초 감속한다. 임의 정지 버튼은 현재 시점에서0.65초 감속하고 진행 중인 공중발은 착지한 뒤 한 발씩 짧게 정리한다. 지지발을 갑자기 기본 위치로 옮기지 않는다. 본/무기나 옷 파츠 연결·공격·게임 통합은 이번 대상이 아니다.
