# 공개 기술 자료 조사와 적용

조사일: 2026-11-10. 이번에는 공식 기술 문서를 읽었다. 실제 게임 영상 관찰이라고 보고하지 않으며 영상 시간 구간은 해당 없다. 기존 팔 공격 참고를 걷기 자료로 재사용하지 않았다.

- [Unity Inverse Kinematics](https://docs.unity.com/en-us/engine/6000.6/manual/animation-section/animation-mecanim/avatar-creationand-setup/inverse-kinematics): 목표 위치에서 관절을 역산하는 원리를 확인해 지면의 발 목표를 고정하는 2본 IK에 적용했다. Unity 설치/연동을 뜻하지 않는다.
- [Epic Locomotion Based Blending](https://dev.epicgames.com/documentation/en-us/unreal-engine/locomotion-based-blending-in-unreal-engine): 속도/방향 기반 걷기·달리기 혼합을 확인했다. 이번에는 공통 위상을 유지하고 속도/접지율/발 높이/팔 각도를 부드럽게 바꾼다.
- [Godot AnimationTree](https://docs.godotengine.org/en/stable/tutorials/animation/animation_tree.html): 상태 전환/혼합/동기화 원리를 확인했다. 단순 루프 끝 대기와 즉시 전환을 구분해 현재 발 상태를 이어받는 감속 정지를 만들었다.

제작 판단: 걷기는 접지율0.62로 지지발이 이어지고 달리기는0.40으로 짧은 체공이 생긴다. 주기는 각각1.05/0.70초이며 보폭·회수높이·골반 압축·상체 기울기·팔꿈치 굽힘도 바뀐다. 이 수치들은 시제품 임시 설계값이며 사용자 확정값이나 공식 문서의 권장값이 아니다. 각 체형은 같은 동작 프로필을 사용한다.

Adobe 걷기 문서404, Unity RootMotion 리디렉션500은 확인하지 못한 자료로 남기고 근거에서 제외했다.
