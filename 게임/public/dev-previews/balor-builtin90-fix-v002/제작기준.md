# 차수2 작품 제작기준

사용자 “이 내용으로 진행”에 따른 내장90 한장 국소편집이다. 입력1의 방패 뒷면/갈색 손잡이·전완·왼손 연결/직립방패/3층 견장/90도 자세를 우선 보존한다. 입력2는 이미 존재하는2.6 PNG를 몸통과 시선만 참조하며 신규2.6 허가가 아니다. 입력3의 v9정면은 검 디자인 확인용이다.

검 전체를 몸의 측면 평면에 자연스럽게 회전한 뒤 손목/손을 연결한다. 날–가드보석–청색 그립–은폼멜은 한 강체 중심축이며 손에 가려진 꺾임도 미달이다. 전체 가로압축/원본 수학변형/검을 코드로 다시 그리는 방법은 사용하지 않는다. 수직 방향은 이번 생성 결과이며 사용자 지정 각도 규정으로 확정하지 않는다.

내장 편집 최대3회, 후보/도구 반환 PNG바이트 보존. 비교용 crop·합성·CSS등비 등록만 허용. 유료/API/env열람0. 기존6칸·2.6원본·공통규정·게임·사용자화면·Git은 보존한다. SD/리깅은 포함하지 않는다. 기술검수와 사용자 미적합격을 구분한다.
