| 항목 | 관찰 및 판정 |
|---|---|
| 검 중심축 | 새 검은 몸 옆으로 내려진 직선 강체로 읽힘. 파란 그립과 붉은 보석, 날/폼멜이 같은 투영축으로 이어짐. 기준점 x약450, 육안오차±4px. 숫자만으로 통과하지 않고 전체검/손잡이 대조. |
| 손·그립 | 오른손 손가락이 청색 그립을 둘러싸고 손목에서 이어짐. 은폼멜이 손 위로 식별됨. 가려진 손바닥 내부의 모든 손가락 구조를 검증했다고 주장하지 않음. |
| 길이·방향 | 이전 사선검을 거의 수직 방향으로 전체 회전. 날길이 육안 약535px 전후, 유사 길이 유지. 끝은 발바닥보다 위에 있고 바닥 관통/잘림 없음. 정확한3D투영 검증은 아님. |
| 방패 | 평평한 회색 뒷면/갈색 핸들/스트랩과 잡은 왼손 유지. 2.6의 문장 앞면을 가져오지 않음. 자연가림의 반대편 전완 전체는 미확인. |
| 견장 | 분리된3층 판금, 가장자리 굴곡, 중간 음영과 원형핀 유지. 세부 선/광택은 생성 편집으로 미세 달라짐. 픽셀동일 보존 아님. |
| 몸통·시선 | 흉곽~허리 흐름을 약간 정돈하고 화면오른쪽으로 시선. 전신 가로압축/얼굴축소 없음. 개선 정도와 미적 적절성은 사용자 판정. |
| 인물·90도 | 갈색 헤어/청회눈/한눈과 코옆선/옆몸통/갑주/망토/입상 유지. 최종 알파보완에서 입·눈선과 갑주 세부가 미세 재묘사됨. |
| 알파·가장자리 | 후보2는 alpha32외곽이 전캔버스에 닿아 미달. 후보3에서 배경 제거, alpha32 bounds=[152,97,696,1460], 캔버스1024×1536. maxAlpha254이며 낮은알파 유색 미세 가장자리 가능성은 잔여기술한계. 밝고어두운 비교에서 큰 배경판/잘림은 관찰되지 않음. 자동키잉·알파수정 없음. |
| 표시/발선 | 실제모발끝97~발바닥1459, 본체1363px 추정. foot(550,1459), 오차별도 manifest. CSS본체720·57·72 등록, 같은 발선. 57/72에서 손가락/보석 형태 판독 한계. 실게임/실기기 검증 아님. |

내장3회: 후보1은 폼멜미식별, 후보2는 배경알파미달, 후보3 선택. 핵심 검축의 기존 꺾임은 새 결과에서 관찰되지 않았다. 완벽한 국소 픽셀보존이나 사용자 합격을 의미하지 않는다. 기존v001의 실패보고·API2회 이력은 그대로 보존하며 이번 API는0회다.
