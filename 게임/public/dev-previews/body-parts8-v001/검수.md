위 bind0는 별도 visible 재질 변형/가림 마스크를 명시한 개별 PNG 합성이다. 무가림 완전 파츠만으로 같은 수치를 달성한 것이 아니다. 각 joint ±30px ROI에서 부모와 정지 겹침이 있으며 양수는 회전 가능성 합격을 의미하지 않는다. 원시 가시 소유는 누락/중복0, 비영 알파 RGBA 정확 일치다. 저알파254 등 원본 합성의 정수 반올림/중첩으로 미세 차이가 남는다.

밝고 어두운 전체 브라우저 비교, 개별 원본/보완전후/노출 비교, 57/72 CSS px 표시를 확인했다. 작은 표시는 갤러리 관찰이며 실기기/실게임 검증이 아니다. browser-evidence.json: 8카드,64파츠 다운로드 참조, 모든 이미지 로드, 양 성별/양 시점 필터 각4카드, 확대 열기/닫기, 예외0. 전체 원본 손발 잘림은 없고 파츠 캡/클립은 원시 반환과 구분된다.

기술 관찰 통과는 파일 존재·실제 열람·가시 추출·완전 외곽 복구·정지 바인드 비교에 한정한다. 무가림 형상 정합/회전 연결 및 사용자 미적 선택은 미확정이다.
