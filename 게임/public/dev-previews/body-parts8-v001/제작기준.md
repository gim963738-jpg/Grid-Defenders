# 작품별 제작기준

사용자 선택 A 남녀35도 원본을 유일 화풍/비율/얼굴·복장 마스터로 사용한다. 35도 전신은 바이트 보존,90도 전신은 각 성별 원본 참조로 실제 생성한다. 총8개는 4전신+4펼침판이며 개별64파트는 부속이다. 민머리/불투명 검은 반팔·짧은 반바지/맨발/무장비/자연 양발 입상을 유지한다.

원본 가시 추출, AI 추정 완전 복원, 바인드 화면 가림을 별개로 저장한다. 완전 PNG에 가림을 bake해 파편을 만들지 않는다. 숨은 L부위를 거짓으로 관찰했다고 하지 않으며 실제 독립 donor와 관절 캡을 보존한다. 35/90/인체좌우를 라벨 교체나 반전으로 대신하지 않는다.

호출은 사용자 지정 기존 GPT Image2.6/high adapter만, 최초6회+필요국소보완 최대2회 내부 한도이며 사용자 금액예산이 아니다. 실패/타임아웃 자동재시도·대체 모델·추가결제·키출력 금지. 완성 형상/원본 재질/표시 마스크를 혼동하지 않는 명세와 실제 노출 합성 비교를 남긴다. 이번은 정지 분리 자료이며 리깅/걷기/게임 적용은 하지 않는다.
