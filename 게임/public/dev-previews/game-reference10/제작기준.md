사용자 재확인 뒤 진행: 실제 게임10종을 연구하여 같은 금발 쌍수전사의 같은 오른쪽앞3/4 전투준비 자세로 총10장을 생성한다. 비율 변경을 허용한다. 이전20매체×2모델 제작은 중단된 별도 이력이다. A/B는 자세·정체성 입력이며 두비율을 각각10개 만드는 요청이 아니다.

정체성/장비좌우/양발전투준비/두무기/화면오른쪽앞3/4는 고정한다. 비율은 게임별 시각적 관찰 범위에 따라 신규 생성으로 변경한다. 머리포함 대략 등신은 작업설계 추정이며 원작 공식규격이나 승인 수치가 아니다. 숨은두개골 정수리는 직접 실측값으로 주장하지 않는다.

첫3종(벽람·가디언·오딘)을 개별 생성·실제 열람 검수 후 잔여7종 진행. 투명PNG 원본 바이트/크기/알파 보존. 캐릭터를 수학적으로 늘이거나 축소해 생성 대신 제출하지 않는다. 비교만 CSS 등비표시/실측 발선 등록. 57/72CSSpx는 갤러리 관찰이며 실게임/실기기 검증 아님.
