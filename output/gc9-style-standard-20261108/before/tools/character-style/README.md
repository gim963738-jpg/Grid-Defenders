# GC9 작화 입력 점검

`자료/캐릭터그림체/GC9/작화고정기준.json`이 좋은 평가를 받은 실제 결과와 출처를 지정한다. 발로르는 C6 전체 작화, 일반 기준은 C4 전체 작화다. 재질 보조 자료가 전체 기준을 대체하지 않는다.

```text
node tools/character-style/preflight.mjs output/characters/gc9_balor/style_recovery_20261108/recovery-plan.json
node tools/character-style/verify-recovery.mjs
```

두 명령은 이미지 생성/API 호출을 하지 않는다. 현재 계획은 입력 검증만 통과하며 생성은 중단 상태다. 도구 호출 전에 계획·실제 첨부 경로·실행 프롬프트를 함께 대조한다. 이 도구는 내장 이미지 도구를 가로채거나 화풍을 자동 합격시키는 기능이 아니다.

v10의 실제 금속 부분 수정, 전체 참조의 재질 전용 축소, 실패본 마스터 사용을 회귀 사례로 검사한다. 파일·해시 검증을 그림체 성공으로 기록하지 않는다. 제작 재개 후에도 기존 시안 승인 순서를 유지하고 전체 작화가 맞지 않는 결과를 다음 방향의 기준으로 쓰지 않는다.
