## 앞선 진단에서 바로잡은 점

- **고정 블록 누락만으로 설명할 수 없다.** 잘된 C6는 맞춤 프롬프트였다. 반대로 v09·v10은 고정 블록을 그대로 포함했지만 실패했다. 블록 사용은 문서 준수 항목이고, 결과 작화 일치의 증명은 아니다.
- **텍스트만 생성한 것도 아니다.** 최초 발로르에도 실제 참조가 있었다. 문제는 어떤 이미지를 어떤 권한과 역할로 썼는지, 그리고 출력의 전체 작화를 확인했는지다.
- **대화 모델 변경 하나가 원인이라는 근거도 없다.** C6와 최초 발로르는 모두 `gpt-6.1-sol`이었다. `gpt-6-astra`로 바뀐 기록은 11/8 02:01:08 KST로, 최초 발로르보다 뒤다. 이미지 생성 엔진의 내부 모델명·버전은 기록에 없어 변경 여부를 판정할 수 없다.
- **SD 이미지가 GC9에 들어갔다고 단정하지 않는다.** 확인된 문제 구간의 실제 참조에서 그 근거를 찾지 못했다. SD 스타일 선택과 GC9 작화 판정은 별개로 유지한다.
- 파일·해시·알파·갤러리 검사는 저장과 화면 동작 검사다. 그 성공을 얼굴·선·명암·전체 인상이 맞는다는 근거로 제시한 것은 부적절했다.
