저장된 8개 프롬프트를 원대화의 실제 호출 인자와 대조했다. **문자열 8개 모두 일치**, 참조 순서도 일치했다. 당시 폴더가 5x2에서 6x2로 바뀐 부분만 경로를 정규화했다. 8장의 원본 PNG 해시도 기록과 일치한다. 원본은 모두 1024×1536이며 이미지·실행 프롬프트·원 생성기록을 덮어쓰지 않았다.

## 실제 성공 입력의 차이와 공통점

| 대상 | 정면 입력 순서 | 사선 입력 순서 |
|---|---|---|
| C3 갈색 머리·청록 궁수 | 구성 → Edel 주 작화 → Lire 재질·활 보조 → 정면 구도 | C3 정면 → 구성 → 사선 구도 → Edel 작화 |
| C4 은발·은빛 갑옷 궁수 | 구성 → Edel 주 작화 → Bram 판금 보조 → 정면 구도 | C4 정면 → 구성 → 사선 구도 → Edel 작화 |
| C5 은빛 투구·청색 망토 기사 | 구성 → Bram 작화·판금 → Ronan 선·남성형·셀 명암 → 정면 구도 | C5 정면 → 구성 → 사선 구도 → Ronan 작화 |
| C6 금발·흰 갑옷 기사 | 구성 → Myst 주 작화 → Bram 재질 보조 → 정면 구도 | C6 정면 → 구성 → 사선 구도 → Myst 작화 |

서로 다른 조합에서도 성공한 공통 구조는 **구성 참조가 그림체를 지배하지 않도록 하고, 얼굴·선·머리·인체·명암·재질을 통일된 작화로 다시 그리는 지시**다. 정면이 완성되면 그 결과의 인물 정체성과 작화를 다음 방향에 함께 유지했다. 단일 문구나 특정 참조 이름 하나가 성공 원인이라고 증명된 것은 아니다.

**C5는 Bram·Ronan으로 성공했다.** 따라서 이 조합을 썼다는 사실만으로 발로르가 실패했다고 단정했던 이전 해석은 근거가 부족하다. C6의 Myst·Bram 경로도 유효한 성공 사례지만 전체 GC9를 대표하는 유일한 조합은 아니다.

이번에 완성본 8장을 향후 참조 집합으로 고정한 것과 당시 실행은 구분한다. 당시 정면 프롬프트가 미래의 완성본 8장을 이미 참조한 것처럼 기록하지 않는다. 원문 프롬프트는 목록의 `source_entry_verbatim`에 그대로 보존하고 새 재사용 양식은 별도로 관리한다.

## 앞으로 유지할 작화 기준

| 축 | 기준 | 이탈로 판단할 사례 |
|---|---|---|
| 전체 인상 | 얼굴·선·형태·명암이 한 작화로 연결됨 | 금속만 비슷하고 얼굴·선·몸 묘사는 다른 작화 |
| 얼굴 | C4 우선. 정돈된 윗눈꺼풀, 간결한 코·입, 깨끗한 턱과 제한된 피부 명암 | 실사 콧방울·두꺼운 입술·인형 피부 광택. C4 여성 얼굴을 남성에게 복제 |
| 선화 | 외곽·겹침은 분명하고 내부·얼굴선은 가늘며 끝을 정돈 | 균일한 두꺼운 선, 구조를 가리는 무작위 잔선 |
| 머리·모피 | 큰 묶음과 흐름, 뾰족한 끝, 선택적인 내부선 | 낱가닥 사실 묘사·광택 덩어리·촘촘한 털 텍스처 |
| 인체 | 머리·몸통·관절이 이어지는 정돈된 2D 인체 | 원본 실사·SD 비율 고정, 여백 확보를 위한 체형 왜곡 |
| 명암 | 큰 기본색·주 그림자 면, 또렷한 겹침, 필요한 면 안의 제한된 완만한 변화 | 전면 에어브러시, 입체 렌더 같은 표면, 전체 재질의 동일한 광택 |
| 금속 | C3 우선. 면 방향·두께·겹침과 선택적 반사 | 부푼 금테, 뭉친 문양·관절, 전면 반짝임으로 구조를 대체 |
| 재질 범위 | C3 금장, C4 은빛, C5 복잡한 판금, C6 옅은 흰 판금의 차이를 허용 | 모든 금속을 같은 색·고대비로 통일하거나 참조 복장 자체를 복제 |

C5는 얼굴이 가려져 있으므로 얼굴 기준으로 사용하지 않는다. 새 인물의 성별·나이·종족·체격·머리·복장·무기는 새 설정을 따른다. 과거 제작의 여성형 약 7.5등신·남성형 약 8등신은 당시 프롬프트의 출발값이며 모든 캐릭터에 강제하는 사용자 확정 수치가 아니다.

당시 차콜 배경·1024×1536·인물 점유율·발선은 역사적 출력 조건이다. 이후 요청한 장비 잘림 방지 여백, 실제 투명도, 반환 원본 크기와 바이트 보존 규칙을 우선 적용한다. 장비를 분리하거나 개별 축소해 여백을 맞추지 않는다. SD 체형·키 기준은 별도로 유지한다.

## 오류 누적에 대한 정정

확인된 문제는 전체 작화가 다른 결과를 계속 편집 원본으로 사용하고, v10에서 기존 얼굴·몸 묘사를 고정한 채 금속만 수정했던 흐름이다. 이 방식은 나머지 작화 차이를 그대로 남긴다. “C4 얼굴 + C3 금속”이라는 축약도 전체 작화 기준을 충분히 전달하지 못했다. 다만 각 입력 변경이 실패에 기여한 정도까지 분리해 입증한 것은 아니다.

초기 발로르는 텍스트만으로 생성한 것이 아니며 실제 참조가 있었다. 고정 문구의 유무나 대화 모델 이름만으로 원인을 확정할 근거도 부족하다. 11월 6일의 JPEG 축소 미리보기 문제와 이후 발로르 원본의 작화 차이는 별개다.

후속 금발 전사·장검·단검은 파생 제작의 연속성을 점검하는 자료로 남긴다. 최근 작업이라는 이유로 이번 8장 원기준을 대체하지 않는다. 실패한 발로르와 미검증 v11을 새 기준으로 승격하지 않았다.
