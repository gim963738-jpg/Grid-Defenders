## 구성 확인

t14는 검은 머리·민소매 검은 각진 갑옷·가슴 앞과 팔의 보라색 발광·쌍단검을 유지했다. 가슴 앞의 큰 발광 문양을 등에 복제하지 않았고, 잘린 하체는 검은 바지·정강이 갑옷·부츠로 이어 제작했다. 정측면에서 먼 쪽 손과 단검은 자연스럽게 겹쳐 가려질 수 있다.

t15는 픽셀·SD의 큰 머리와 짧은 신체 비율을 성인 여성형으로 바꿨다. 긴 분홍 웨이브 머리·큰 검은 천 리본·흑백 복장·낮은 검은 신발을 유지했다. 작은 흰 하의 블록은 검은 테두리의 흰 짧은 하의로 해석했다. 후면의 머리끝 길이가 정면·측면보다 짧아 보이는 부분만 1회 추가 수정했다. 수정 전 후보는 `variants/`에 보관하고 ZIP에서는 제외했다.

두 캐릭터 모두 정측면과 사선이 구분되고, 후면에 얼굴·앞 가슴 문양이 나타나지 않는 것을 확인했다. 같은 인물의 큰 구성은 대응하지만 미세 문양·주름·형상이 정확한 3D 회전처럼 픽셀 단위로 일치하는 산출물은 아니다. 최종 화풍과 구성 일관성에 대한 사용자 판단은 별도다.

## 실제 파일과 검증

- 선택본 8장 모두 실제 **1024×1536 RGBA PNG**다. 완전 투명 픽셀과 알파 240 이상 가시 영역을 확인하고 통계를 기록했다.
- 내장 `image_gen`으로 총 9회 생성했다. 기본 8장과 여성 후면 길이 수정 1회이며, 최종 선택본은 8장이다.
- 입력 보관본 2개와 원본의 SHA-256이 일치한다. 생성 도구 원본과 프로젝트 복사본의 해시·바이트 크기도 일치한다.
- ZIP은 선택 PNG 8장만 포함하며 CRC와 개별 해시 검증을 통과했다.
- 브라우저에서 두 캐릭터·8개 원본 PNG를 로드하고 캐릭터·방향·영역 전환 및 배경 변경을 확인했다. 100% 상세 이미지의 실제 너비와 CSS 표시 너비가 모두 1024이며 JPEG 축소본을 사용하지 않는다.
- 두 캐릭터 각각 흰색·차콜 배경 캡처를 열어 전체 프레임·투명 가장자리·구성 대응을 확인했다. 390px 화면에서 가로 넘침이 없다.

알파 240 이상 실루엣 기준으로 남성형의 상단은 y=9~15, 하단은 y=1499~1522이며 여성형의 리본 포함 상단은 y=26~66, 하단은 y=1484~1496이다. 생성 원본을 보존했으며 픽셀 기준선 정규화나 업스케일은 하지 않았다.
