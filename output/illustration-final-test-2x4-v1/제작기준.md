# 일러스트 마지막 테스트 2종과 4방향

사용자가 제공한 다운로드 (14)·(15)를 기존 그림체와 성별별 전신 비율로 재구성한다. 직전 확정한 정면·정측면·후면·3/4 사선 규칙을 각 캐릭터에 적용해 총 8개 PNG를 제작한다.

## 원본 구성과 전환

| ID | 원본 | 체형 | 유지할 구성 |
|---|---|---|---|
| t14 | 다운로드 (14).jfif | 남성형 | 검은 머리·보라 눈, 검은 민소매 각진 갑옷·노출된 위팔, 가슴 앞과 팔의 보라 발광, 검은 장갑·허리 판금, 한 손당 짧은 단검 1개씩 |
| t15 | 다운로드 (15).jfif | 여성형 | 긴 분홍 웨이브 머리·큰 검은 천 리본, 흰 칼라·십자 문양·소매 끝과 흑백 상의, 작은 흰 하의·검은 허리 디테일, 맨손·밝은 다리·낮은 검은 신발 |

t14는 잘려 있는 하체를 같은 검은 갑옷·바지·부츠 언어로 보수적으로 이어 완성한다. 원본 뒤쪽 구도는 없어 앞 갑옷 구조와 좁은 발광 선을 이어 구성하되 가슴의 큰 십자 발광을 등에 새로 복제하지 않는다. 주변 효과를 거대한 실체 날개·추가 팔로 바꾸지 않는다.

t15는 픽셀·SD 그림을 성인 여성형으로 옮긴다. 아기형 얼굴·큰 머리·짧은 체형은 보존하지 않는다. 작은 픽셀의 흰 하의 블록은 검은 테두리의 흰 짧은 하의로 해석했다. 검은 머리 장식은 천 리본으로 해석하며 동물 귀·뿔을 추가하지 않는다. 원본에 없는 무기·갑옷·장식·높은 구두는 넣지 않는다.

## 화풍과 방향

C4 생성 결과의 정돈된 얼굴선·눈꺼풀·작은 코와 입을 성별에 맞춰 적용한다. C3의 금속 면·두께·반사광은 t14의 검은 금속에 적용하고 t15에 불필요한 금속 갑옷을 추가하지 않는다. 남성형은 약 8등신, 여성형은 약 7.5등신을 제작 출발값으로 삼는다. 이는 사용자 실측값이 아닌 기존 제작 기준이다.

- 01 front: 정면 0도.
- 02 side: 화면 오른쪽을 보는 정확한 정측면 90도.
- 03 back: 후면 180도. 얼굴·앞 가슴 문양을 등에 그리지 않는다.
- 04 threequarter: 화면 오른쪽을 보는 약 45도 사선.

정면을 먼저 만들고 정측면·후면의 기준으로 쓴다. 사선은 새 정면·정측면·후면을 함께 참조한다. 같은 사람의 체형·복장·장비를 유지하고, 먼 쪽 손·단검이 가려지는 것은 자연스러운 각도 차이로 처리한다.

## 출력과 검수

내장 `image_gen`을 사용한다. 앞선 4방향 작업과 같이 투명 배경 PNG를 요청한다. 입력 JFIF 자체는 투명 이미지가 아니다. 실제 반환 해상도·알파 통계·출처·해시·정확한 프롬프트와 참조 순서를 생성 기록에 보관한다.

검수는 실제 PNG의 전체 프레임과 100% 얼굴·장비를 사용한다. 원본 PNG를 직접 읽는 비교 화면과 PNG 8장 ZIP을 제공한다. JPEG 축소본 확대를 원본 검수로 사용하지 않는다. 게임 코드·이전 산출물·Downloads 원본은 변경하지 않는다.
