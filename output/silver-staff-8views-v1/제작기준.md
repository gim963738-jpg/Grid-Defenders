# 은발·날개 지팡이 캐릭터 8방향 입상

사용자 제공 측면 PNG를 기반으로 같은 캐릭터의 45도 간격 8방향 전신을 제작한다. 최신 요청에 따라 **모든 방향은 양발을 딛고 서 있는 자세**다. 원본의 걷는 보폭과 휘날림은 중립 입상에 맞게 정리한다.

## 이번 작업의 우선 기준

사용자가 이 견본을 원하는 기준으로 지정했으므로 **원본의 픽셀 표현·큰 머리와 짧은 게임 캐릭터 비율**을 유지한다. 이전 GC9 전신 제작의 긴 성인형 비율을 이번 견본에 자동 적용하지 않는다. 이 선택은 이번 8방향 작업에 적용하며 기존 GC9 규칙을 덮어쓰지 않는다.

은발 장발·푸른 눈·청색과 금색의 어깨 덮개와 망토·흰 겹옷·짙은 바지와 장화·파란 보석·금색 날개와 청색 곡선 장식의 긴 지팡이를 유지한다. 정식 이름·직업·스킬은 확정하지 않는다.

화면 오른쪽을 향한 원본에서는 인체 오른쪽 팔이 가까이 보인다. 이 팔은 비어 내려와 있고, 반대쪽 왼팔이 지팡이를 쥐고 있다. 따라서 지팡이는 인체 왼손, 원통형 허리 장비는 인체 오른쪽으로 고정한다. 정면에서 지팡이는 화면 오른쪽, 후면에서는 화면 왼쪽에 온다. 반대 방향을 단순 좌우 반전해 만들지 않는다. 초기 세 장은 이 좌우를 반대로 잡아 variants에 보관하고 수정본을 제작한다.

## 방향과 입상

| 번호 | 각도 | 화면에서 보는 방향 |
|---|---|---|
| 01 | 0도 | 정면 |
| 02 | 45도 | 화면 오른쪽을 향한 앞 사선 |
| 03 | 90도 | 화면 오른쪽 정측면 |
| 04 | 135도 | 화면 오른쪽을 향한 뒤 사선 |
| 05 | 180도 | 정후면 |
| 06 | 225도 | 화면 왼쪽을 향한 뒤 사선 |
| 07 | 270도 | 화면 왼쪽 정측면 |
| 08 | 315도 | 화면 왼쪽을 향한 앞 사선 |

두 발은 어깨보다 좁게 자연스럽게 벌리고 같은 바닥에 둔다. 무릎과 몸통을 편안하게 세우고, 왼손으로 지팡이를 옆에 세우며 오른팔은 내린다. 발·몸통·머리가 같은 방향으로 돌아가야 한다. 걷기·달리기·전진 발·공격·점프 자세를 만들지 않는다.

## 참조와 출력

원본은 [source/reference.png](source/reference.png), 855×919 RGB PNG로 검은 배경이 포함되어 있다. 생성물은 배경이 실제 알파인 개별 PNG 8장으로 요청한다. 정면 생성 결과를 디자인 기준으로 쓰고, 후면 기준을 만든 뒤 사선의 앞뒤 연결에 함께 사용한다. 원본에서 보이지 않는 뒷면은 보이는 재료·머리 길이·망토·장식으로 최소 보완한다.

서로 같은 정사각형 캔버스·바닥 높이·캐릭터 크기를 요청하며 실제 반환 파일의 크기와 알파를 확인한다. 인위적 확대를 고해상도 생성으로 기록하지 않는다. 얼굴·손·지팡이 끝·장화와 망토가 잘리지 않아야 한다.

완성물은 수작업 픽셀 정규화나 게임 내 애니메이션 통합을 완료한 스프라이트 시트와 구분한다. 이번 범위는 8방향 입상 이미지와 비교 자료다.

## 저장 결과와 확인

선택본은 `images/`의 PNG 8장, 각 1254×1254다. 내장 image_gen을 11회 사용했고 장비 좌우 수정 전 초안 3장은 `variants/`에 보존했다. 처음에는 1024×1024를 문구로 요청했으나 실제 반환은 1254×1254였고, 후속 요청은 그 정면 기준 크기에 맞췄다. 저장 과정에서 확대·축소·리샘플링하지 않았다.

8장 모두 실제 투명 픽셀과 불투명에 가까운 피사체 픽셀이 있고, 가시 외곽이 캔버스 가장자리에 닿지 않는다. 발과 지팡이를 포함한 가시 외곽의 하단 위치는 y=1178~1189로 11픽셀 차이가 있다. 픽셀 단위 정규화 전 생성본이라는 범위를 유지한다.
