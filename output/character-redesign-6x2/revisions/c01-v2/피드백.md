# 사용자 평가와 C1 수정 기준

사용자는 C2·C3·C4·C5·C6의 정면과 사선을 잘된 편으로 평가했다. 특히 C4가 독보적으로 좋은 전체·얼굴 표현 사례이며 C3가 그다음이다. 금속은 C4도 잘됐지만 C3가 가장 좋은 사례다. C1은 특유의 AI 느낌이 남고 금속 표현이 아쉬워 재구성을 요청했다.

이 평가는 사용자의 판단이다. 아래 수정 방법은 그 평가를 그림의 구체적인 요소로 옮긴 작업 기준이며, 수정본에 대한 사용자 확인을 대신하지 않는다.

## 수정 범위

C1의 정면·사선만 새 버전으로 제작한다. 은발과 땋은 머리, 별·원형 머리핀, 별 귀걸이, 흰금 갑옷, 가슴 별 문양, 검·새 문양 방패, 허리 장식·기도문 띠, 여성형 비율과 전신 구도는 유지한다. C2~C6와 이전 C1 파일은 보존한다.

## 관찰과 적용

| 축 | 기존 C1에서 정리할 부분 | 기준과 적용 |
|---|---|---|
| 얼굴 | 입술·피부의 부드러운 광택과 둥근 인형 같은 볼륨 | C4의 간결한 눈꺼풀·코·입·피부 명암. 회색 눈과 C1 헤어는 유지 |
| 금테 | 부푼 관처럼 읽히는 연속적인 둥근 음영 | C3처럼 밝고 어두운 면, 두께·모서리·빛 방향을 구분 |
| 흰 판금 | 금테와 비슷한 부드러운 광택으로 재질 구분이 약함 | 흰 도장 금속의 옅은 차가운 면, 판 사이 겹침과 틈을 명확히 표현 |
| 방패·장식 | 작은 선과 겹친 장식이 확대 시 뭉쳐 보임 | 새 문양의 큰 형태·깃 배열·금속 테두리를 정돈, 무작위 선을 줄임 |
| 체인·손·머리 | 작은 연결부와 땋은 머리의 앞뒤 구조 | 닫힌 고리·고정점·손잡이·손가락·땋은 교차가 읽히도록 정리 |

장식을 많이 추가하거나 전체 반짝임을 높여 디테일을 대신하지 않는다. 주요 문양은 유지하면서 반복되는 작은 형태와 경계를 의도적으로 그린다.

## 생성과 검수

정면에는 기존 C1 정면 + C4 정면(얼굴 표현) + C3 정면(금속)을 사용한다. 사선에는 새 C1 정면 + 이전 C1 사선(구도) + C4 사선(얼굴) + C3 사선(금속)을 사용한다.

원본 PNG의 실제 픽셀 크기와 전체 프레임을 확인하고, 얼굴·흉갑·방패·손을 100% 원본 배율로 비교한다. 200% 보기는 픽셀을 확대하는 관찰 도구이며 해상도 증가로 간주하지 않는다. JPEG 축소본은 품질 판단에 사용하지 않는다.

정면 생성에는 2048×3072를 요청했지만 실제 반환 파일은 1024×1536이다. 크기를 인위적으로 늘리거나 고해상도로 완성했다고 주장하지 않는다. 사선도 실제 반환 해상도를 기록한다. 이번 목표는 같은 픽셀 크기에서 선·형태·재질의 가독성을 개선하는 것이다.

내장 `image_gen`을 사용하며 정확한 프롬프트와 참조 순서는 `생성기록.json`에 저장한다. 새 결과는 `c1-1_v2.png`, `c1-2_v2.png`로 보관한다.
