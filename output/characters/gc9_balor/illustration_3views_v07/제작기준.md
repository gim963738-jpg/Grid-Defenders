# 발로르 · 오른쪽 정측면·후면 방패 각도 수정

최신 지시는 **방패 각도만 수정**하는 것이다. 사용자가 표시한 빨강은 방패 뒤 손잡이·팔걸이, 파랑은 전완, 노랑은 손이다. 기존 팔·손·손가락·자세·검·얼굴·갑주·망토를 기준으로 유지하고 방패 본체와 부착물의 투영 각도를 조절했다. 표시를 최종 이미지에 그리지 않는다.

대상은 이전 v05 오른쪽 정측면과 후면 두 장이다. 정면 v06은 그대로 유지한다. 초기 정면 yaw 프롬프트는 사용자 정정 전에 준비한 초안이며 **실행하지 않았다**. 후속 요청을 추가 정면 생성으로 해석하지 않는다.

이번 작업은 각도만 수정하는 범위이므로 기존 두 방향의 1024×1536 프레이밍을 유지했다. 정면 v06의 1254×1254 여백 규격으로 측면·후면까지 새로 통일한 작업이 아니다. 반환된 PNG의 크기·알파·바이트를 보존하며 임의 축소·확대하지 않는다.

내장 image_gen으로 방향별 각도 수정 1회와 새로 생긴 검은 배경 잔여물 제거 1회씩, 총 4회 실행했다. 각도 수정 중간본은 variants의 `_initial_v07.png`로 보존한다. 최종 각도·배경 정리 프롬프트와 실제 원본 경로는 상위 생성 기록에 연결한다. 밝은 배경에서 전신·장비 연결과 외곽을 확인하며 이번 수정본에 대한 사용자 통과는 미정이다.
