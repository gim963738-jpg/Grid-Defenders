# 발로르 기존 SD·새 SD 정면 비교

**2026-11-08 결정: 기존 SD 디자인 채택, 새 SD 폐기.** 이 폴더는 비교 이력이며 기존 SD 정면만 디자인 선택본으로 유지한다. 향후 본체 크기·체형은 은발·날개 지팡이 기준을 적용한다.

사용자의 정정에 따라 GC9 일러스트와 SD 비교가 아닌 **기존 SD와 새 SD**의 정면 2장을 제작한다. 둘 다 같은 발로르이며 서대륙 소속·장비·성격 설정은 바꾸지 않는다.

- 기존 SD: 앞서 제작한 금발 전사와 은발 지팡이 8방향의 실제 원본을 화풍·등신·픽셀 표현 기준으로 사용한다. 발로르 일러스트 v05는 구성·색·인물 참조다.
- 새 SD: 직전 새 SD 발로르와 사용자 SD 견본을 기준으로 같은 인물을 정면으로 회전한다.
- 공통: 투구 미착용·갈색 머리·부드러운 인상·청은 갑주·사자 흉갑·용 망토·대형 날개/십자가 방패·오른손 검과 확정 그립을 유지한다.
- 방향: 양쪽 모두 정면 0도 입상이며 사선 머리·몸통·보행 동작을 넣지 않는다.

비교용 2장 요청은 해당 정면 제작의 승인이다. 특정 SD 스타일의 최종 통과로 해석하거나 후속 방향 세트로 확대하지 않는다. 원본은 도구가 실제 반환한 크기·알파·바이트로 저장한다. 비교 화면의 표시 크기 조정과 원본 파일 저장을 구분한다.
