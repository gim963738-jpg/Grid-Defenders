# 발로르 SD 새 디자인 시안 v01

**현재 상태: 2026-11-08 사용자 결정으로 새 SD 스타일 폐기.** 아래는 시험 당시 제작 기록이다. 생성물과 입력 견본은 향후 제작 참조에서 제외하고 원본 이력으로 보관한다. 현재 선택은 기존 SD이며 [은발 공통 기준](../../../../문서/02_세부기획/02_영웅/SD_공통제작기준.md)을 적용한다.

사용자가 새로 제공한 SD 견본 3장의 비율·카메라·픽셀 표현을 적용하는 시안 1장이다. 발로르 일러스트 v05를 정체성 기준으로 사용하고, 일러스트의 긴 신체 비율은 새 SD 비율로 전환한다. 기존 GC9 일러스트 화풍 기준과 이번 SD 화풍 시험을 구분한다.

## 견본에서 가져올 특징

- 머리·머리카락이 전신 높이의 약 1/3을 차지하는 약 3~3.5등신, 짧은 몸통·다리와 분명한 부츠.
- 얼굴 위·어깨·발 윗면이 읽히는 약간 높은 카메라와 앞 사선 방향의 안정된 입상.
- 짙은 유채색 외곽, 작은 색 덩어리로 나눈 머리·옷 주름, 선택적인 금속 하이라이트와 계단형 윤곽.
- 의상마다 큰 색 면과 실루엣으로 직업을 구분하며 장식은 작은 크기에서도 읽히는 대표 문양으로 단순화.

## 발로르의 유지 요소

짧은 짙은 갈색 머리·부드러운 성인 남성 인상·청색과 은색 갑주·사자 흉갑·용 문양의 갈라진 청색 망토·고정핀을 유지한다. 연결 끈과 투구는 없다. 오른손은 붉은 보석과 파란 손잡이의 은색 양날검을 확정 그립으로 쥐며 왼손은 은색 바탕에 검은 날개와 십자가가 있는 대형 카이트실드를 든다. 방패의 보호 면적은 SD 전신 높이의 약 2/3로 유지한다.

이번 시안은 오른쪽 앞 사선과 약간 높은 카메라를 적용하며 걷지 않고 양발로 선다. 견본의 다른 인물·머리색·복장·배경·큰 바닥 그림자와 자세 가이드의 빨강·파랑 선은 옮기지 않는다.

## 제작 범위와 보존

내장 image_gen으로 SD 시안 1장만 생성하고 실제 반환 원본 크기·알파·바이트를 보존한다. 시안은 사용자 확인 대기 상태이며 정면·오른쪽 정측면·후면 3방향 세트는 시안 통과 후 별도로 제작한다. 게임용 저해상도 프레임·공유 팔레트·애니메이션을 검증한 결과로 표기하지 않는다.
