# 발로르 제작 기준

서대륙 발트레인 왕국 친왕파의 인간 남성 기사이며 왕국 제3 기사단장이다. 28세·183cm·다부진 체격을 유지한다. 원소 속성은 무이며 제국 검술과 방패술을 배웠다.

뒤에 지정한 필수 유지 요소를 우선해 청색·은색 판금과 청색 망토를 사용한다. 최신 사용자 선택에 따라 **투구를 벗은 모습이 주 제작본**이다. 짧은 짙은 갈색 머리·회청색 눈·부드러운 눈매와 옅은 미소를 유지한다. 오른손 검·왼손 은색 카이트실드의 인체 좌우를 고정한다. 방패 문양은 검은 날개와 십자가, 망토에는 용 문양과 점무늬를 둔다.

GC9 원본 M05·A04와 C3 금속 표현을 실제 첨부해 판금·천의 공통 디자인을 만들었다. 얼굴 제안에는 남성 얼굴 참조와 C4 얼굴 표현을 적용했고, 선택된 얼굴을 후속 방향의 기준으로 사용한다. 성기사 스타일만으로 대교회 소속·빛 속성·성스러운 마법 효과를 추가하지 않는다.

현재 정면은 `illustration_3views_v06/front.png`의 **GC9 얼굴·여백 보정본**이다. 이전 완성 세트인 `illustration_3views_v05`의 정면·오른쪽 정측면·후면 3장은 이력으로 보존한다. v06 측면·후면은 제작하지 않았으며 후속 방패 각도 수정은 아래 v07을 따른다. 최초 승인용 시안과 투구 착용본·그립 수정 중간본도 보관한다.

원본은 생성 도구가 반환한 실제 PNG 크기·알파·바이트로 저장한다. 그립과 투구 탈착 선택은 사용자 확정으로 기록하고, 이번 완성 3장에 대한 별도 사용자 평가를 임의로 통과 처리하지 않는다.

## 후속 사용자 수정

디자인 수정 필요 선택 직후 잘못 눌렀다는 정정을 받아 기존 디자인 통과로 진행했다. 이어 요청한 망토 고정핀의 연결 끈만 제거하고 원형 핀은 유지했다. 수정한 정면을 정측면·후면의 공통 디자인 기준으로 사용했다.

투구를 벗은 정면은 처음에는 별도 얼굴 제안이었으며, 이후 사용자가 “투구벗음 버전으로 정리해서 진행”이라고 선택해 현재 주 제작본으로 전환했다. 기존 폐쇄형 날개 투구 이미지는 이력으로 보존한다.

검·도·몽둥이 등 한손 무기의 그립은 사용자가 표시한 팔·손목·다섯 손가락 연결을 공통 기준으로 고정했다. [공통 기준](../../../문서/02_세부기획/02_영웅/한손무기그립기준.md)의 원본 자세·손가락 참조를 사용한다. 정면의 오른손은 손잡이를 감싸고 검은 화면 왼쪽 위 폼멜에서 오른쪽 아래 가드·날로 이어져 몸 앞을 가로지른다. 정측면·후면은 같은 소유 손과 물리적 자세를 회전해 투영한다. 후면의 검날은 망토에 자연스럽게 가려진다.

v01~v05 일러스트 원본은 1024×1536 RGBA PNG이며 v06 정면은 1254×1254 RGBA PNG다. 원본 크기와 바이트를 보존하며 `balor_illustration_3views_v05.zip`에는 이전 v05 3장을 보관한다. 얼굴 제안·투구 착용본·연결 끈 제거 전 시안은 이전 버전으로 보관한다.

## v05 사용자 보정

방패는 원문 3/2를 문맥상 인물 높이 약 2/3로 해석해 세 방향에 확대했다. 어깨·윗가슴부터 아래 정강이까지 보호하는 은색 카이트실드로 검은 날개·십자가와 비대칭 소유 손을 유지한다. 측면 검은 단단한 하나의 검으로 손잡이·가드·곧은 칼날을 연결한다. 후면 오른손은 손바닥 가죽면·엄지두덩·손가락 안쪽을 보이고 손등 판금이 정면을 향하지 않게 한다. 배경 검은 잔여물은 실제 알파와 밝은 바탕에서 확인한다. v04 3방향과 v05 측면 중간본은 이전 버전으로 보존한다.

## 후속 SD 디자인 시험

사용자가 새로운 SD 견본 3장을 제공해 [SD 시안 1장](sd_style_test_v01/제작기준.md)을 별도로 제작했다. 이후 **기존 SD 채택·새 SD 폐기**로 선택이 완료됐다. 기존 SD 정면 선택과 은발·날개 지팡이 기준의 후속 크기 적용 상태를 별도로 유지한다.

## v06 정면 · 얼굴과 장비 포함 여백

M02·M05 원본과 C4를 다시 대조했다. 제작 당시에도 M02·C4를 참조했으나 v05에는 코의 입체감·입과 턱 주변 묘사가 GC9보다 사실적으로 남아 있었다. 부드러운 28세 남성·갈색 머리·회청색 눈을 유지하면서 눈꺼풀·코·입선과 피부 명암을 간결하게 보정했다.

여백은 장비 돌출로 인한 잘림을 방지하는 목적이다. 검과 방패를 손에 들고 망토를 착용한 연결 상태·상대 크기를 유지해 전체만 균일하게 줄였다. 장비를 별도 배치하거나 개별 축소하지 않는다. 첫 생성본은 위·좌우 여백이 부족해 중간본으로 보관하고, 빈 정사각 배치 안내도를 보조 참조로 사용해 다시 생성했다.

현재 정면은 1254×1254 생성 원본이며 알파 32 이상 전체 외곽 기준 위 21.2%·왼쪽 25.1%·오른쪽 25.2%·아래 8.9%의 여백이다. 장비 끝까지 초기 안전 영역 안에 들어온다. [원본과 얼굴 비교](illustration_3views_v06/review.html)에서 밝은 배경·원본 배율의 얼굴·오른손을 확인한다. 이번 수정본의 사용자 통과는 별도로 미정 상태다.


## v07 · 정측면·후면 방패 각도만 수정

사용자가 표시한 방패 뒤 손잡이·팔걸이(빨강), 전완(파랑), 손(노랑)을 물리적 참고로 삼아 오른쪽 정측면과 후면의 방패 각도를 조절했다. 팔·손·자세·검·얼굴·갑주·망토는 기존 모습을 기준으로 유지한다. 현재 정면 v06은 유지하고 두 방향만 v07로 표시한다. 최신 요청이 각도만 수정하는 범위이므로 두 PNG는 기존 1024×1536 프레이밍을 유지한다.

[방패 각도 비교](illustration_3views_v07/review.html)에서 이전 v05와 비교한다. 초기 각도 수정 출력의 검은 배경 잔여물을 별도 편집으로 제거했으며 실제 생성 원본의 바이트·해상도·알파를 유지했다. 정면 yaw 초안은 실행하지 않았다. 사용자 수정본 통과는 미정이다.
