# 금발 바람 엘프 v04 — 개선됐으나 합격선 미달

**이전 총평: “개선되긴했으나 합격선까지는 아니야”.** v04는 v03보다 개선된 수정 중 시안이며 전체 작화는 합격선 미달이다. 최신 세부 평가는 위의 정정 사항을 따른다. 이번 분석은 추가 이미지 생성 없이 v03·v04·C4·C3 원본과 실제 호출 입력을 대조했다. v04도 편집·화풍 마스터에서 제외하고 원본·프롬프트는 그대로 보존한다.

> **최신 세부 평가 반영:** 사용자는 이후 얼굴·머리카락도 미세 조정이 필요하다고 정정했다. 금속은 거의 합격선이며 미세 보완, 옷 표현은 최우선 보완 대상이다. 기본 인상과 헤어 구성을 유지하면서 얼굴·머리 표현을 미세 조정한다. 아래의 전면적 작화 이탈 분석보다 이 세부 판정을 우선한다.

## 핵심 결론

현재 방법은 GC9 전체 작화를 안정적으로 재현한다는 검증을 통과하지 못했다. **참조 역할을 문장으로 정하고 큰 셀 면을 늘리는 것만으로 실제 작화의 일관성을 확보하지 못했다.** 앞선 실패 분석의 입력 길이·참조 중첩 가설을 해결책처럼 기대하고 변경했지만, 사용자는 이번 결과의 개선을 인정했다. 다만 어느 입력 변경이 얼마나 기여했는지와 재현의 안정성은 아직 확인되지 않았다.

모델 내부에서 어느 입력을 얼마나 반영했는지는 확인할 수 없다. 특정 참조·단어·배경 하나를 확정 원인으로 지목하거나 다음 문구 변경으로 해결된다고 말할 근거가 없다.

## v03에서 바뀐 것과 바뀌지 않은 것

|---|---|---|---|
| 문장 길이 | 981단어 | 526단어 | 짧게 했지만 불합격. 길이 하나로 원인 설명 불가 |
| 실제 이미지 수 | 4장 | 5장 | 참조 수를 줄인 재시도가 아니었음 |

C3를 제외하고 Edel을 주 참조로 명시한 사실은 맞다. 다만 C4 전체 작화와 Bram·구도 이미지도 실제로 함께 전달했다. 그 역할명은 모델의 반영 범위를 물리적으로 차단하는 기능이 아니다. 그렇다고 이5장 조합 자체가 원인이라고 확정할 수도 없다. 과거 C4도 여러 실제 이미지를 사용해 성공했기 때문이다.

## 출력에서 확인되는 작화 차이

- **큰 셀 면의 존재와 C4 작화의 재현은 다르다.** v04는 머리와 천의 면을 크게 나눴지만, 머리의 반복적인 밝은 조각과 상의의 분절된 명암이 두드러진다. C4·C3에서 보이는 큰 형태·겹침·재질별 명암의 위계가 같은 방식으로 묶이지 않았다.
- **선과 명암을 따로 강화한 것으로는 전체 마감이 이어지지 않았다.** 얼굴·머리·옷을 정리하는 선의 선택과 명암 경계가 목표의 한 작화로 연결되지 않았다. 이 차이를 금속이나 눈 크기 하나로 축소하지 않는다.
- **얼굴 설정과 그림체를 구분한다.** 황록색 눈·엘프 귀·표정의 개별 차이는 허용되는 설정이다. C4의 얼굴을 그대로 복제해야 한다는 뜻이 아니며, 눈 하나만 바꾸면 전체 작화가 맞는다고 판단하지 않는다.
- **체형은 성인형2D다.** 이번 결과를 SD화·실사화·3D화로 설명할 근거는 없다. 원래 의상의 각진 구성이나 금발이라는 색 자체도 실패 원인이 아니다.

## 확실히 확인한 별도 제작 실패

주 실루엣의 상단 여백은 **7.8125%**, 하단은 **5.729%**로 요청 기본값20%·6%를 충족하지 못했다. 프롬프트에 수치를 적고 입력 검사를 통과했어도 실제 출력에서 이탈했다. 이 사실은 지시가 적혀 있다는 것과 결과가 지켜진다는 것이 다름을 보여준다.

주변의 낮은 알파 잔여색도 남았다. 이는 어두운 배경에서 후광처럼 보이는 투명 가장자리 품질 문제다. 여백·알파 문제를 해결하면 그림체까지 맞는다고 연결하지 않는다.

PNG가1024×1536이고 원본 바이트를 보존했다는 것은 저장 검사다. 같은 원본100% 배율로 봐도 v03과v04의 인물 크기가 같지는 않다. 알파32 실루엣 기준19.1% 증가가 있어 더 선명해 보이는 것을 작화 개선의 증거로 쓰면 안 된다. 같은 인물·머리 표시 크기 비교와 원본 픽셀 검수를 구분해야 한다.

## 앞선 설명에서 바로잡을 점

1. 장문이나 참조 중첩은 가설이었다. 문장 단축·주 참조 표기를 검증된 해결법처럼 기대한 해석을 철회한다. 이번에는 여러 조건이 동시에 바뀌어 해당 가설을 완전히 반증한 것도 아니다.
2. “성공한 C4 구조를 따른 변형”이라고는 기록할 수 있지만 실제 성공 입력의 동일 재실행이나 검증된 재현 방식은 아니었다.
3. “큰 명암 면이 늘었다”는 부분 관찰로 전체 화풍의 개선을 대신 설명하지 않는다. 전체 마감이 맞지 않는다면 부분 변화는 합격 근거가 아니다.
4. 결과를 사용자에게 합격으로 보고한 적은 없지만, 내부 검수는 여백 실패와 구성 보존에 비해 전체 작화 이탈을 충분히 설명하지 못했다.

## 처리와 검증 범위

v03·v04를 모두 그림체 실패 이력으로 유지한다. 카탈로그는 v04를 **개선됨·합격선 미달**로 표시하며, 내부 여백 실패 표기가 사용자 불합격 판정을 덮어쓰지 않게 수정했다. C3~C6의 기존8장 기준과 캐릭터 구성·배치 보류는 유지한다.

이 분석으로 해결된 것은 실패 기록과 진단의 정확성이다. 전체 화풍을 고정하는 기술이 검증된 것은 아니다. 새 조합이나 문구만으로 재시도 성공을 보장하지 않으며 이번 요청에서는 이미지를 생성하지 않는다.
