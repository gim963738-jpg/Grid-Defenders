# 금발 바람 엘프 v03 실패 분석

이번 출력은 사용자 판정에 따라 **GC9 전체 작화 미통과**로 기록한다. 원본·실행 프롬프트는 보존하고 편집·화풍 마스터에서 제외한다. 이 분석에서 추가 이미지 생성은 하지 않았다.

## 결론

확인된 제작상의 오류는 **규약에 맞는 참조를 첨부한 것과 성공한 제작 경로의 재현을 혼동하고, 결과에서 보이는 전체 작화 차이를 내부 검수에서 구체적으로 지적하지 못한 것**이다. 성공한 C4의 입력과 다른 신규 조합을 사용했다. 이 조합의 재현력은 검증되지 않았으며 이번 결과는 그 시험에 실패했다.

참조 변경·문장 길이·여백 각각이 결과에 끼친 영향은 한 번의 호출로 분리해 확정할 수 없다. 참조 수를 줄이거나 특정 문구를 바꾸면 반드시 해결된다고 주장하지 않는다. 기준 집합 C3~C6 8장의 사용자 평가는 그대로 유지한다.

## 실제 그림에서 달라진 점

| 축 | C4·C3 기준과 비교한 관찰 | 해석의 범위 |
|---|---|---|
| 얼굴 | 둥글고 크게 열린 눈, 볼·턱·미소의 부드러운 처리로 C4의 절제된 얼굴선 인상과 달라짐 | 새로운 인물의 눈 모양·표정 차이는 허용한다. 그 차이 하나가 아니라 선·머리·명암을 함께 보고 전체 작화 이탈로 판단 |
| 머리 | 가는 금발 잔선·작은 점광택이 늘고 큰 묶음·명암 띠의 위계가 약해짐 | 밝은 금발이라는 색 설정 자체를 실패 원인으로 보지 않음 |
| 천·명암 | 좁고 긴 중간톤 주름이 많고 면 안의 음영 변화가 늘어 넓은 셀 면 정리가 약해짐 | 실사나 3D로 바뀌었다고 부르기보다 같은 2D 안의 작화 차이로 설명 |
| 선 | 얼굴·머리 외곽과 겹침이 내부선보다 확실히 강하게 읽히지 않음 | 모든 선을 검고 두껍게 만들라는 뜻이 아님 |
| 인체 | 성인형의 긴 팔다리는 유지됨 | SD화로 단정하지 않으며 여백에 따른 표시 크기 차이를 화풍 차이와 구분 |
| 금속 | 얇은 금테 중심이라 C3의 큰 판금과 같은 조건으로 비교할 부분이 적음 | 금속 표현 하나로 이번 전체 실패를 설명하지 않음 |
| 알파 | 인물 주변에 낮은 알파의 잔여색이 있어 어두운 바탕에서 후광으로 보임 | 별도의 가장자리 품질 문제이며 얼굴·선·명암 차이의 원인은 아님 |

## 실제 입력 비교

| 항목 | 성공한 C4 | 이번 v03 |
|---|---|---|
| 입력 순서 | 구성 원본 → Edel 주 작화 → Bram 재질 → 정면 구도 | 구성 원본 → C4 주 작화 → C3 전체 작화 보조 → Edel 작화 보조 |
| 프롬프트 | 2,969자 / 440단어 | 6,803자 / 981단어 (실제 호출의 끝 개행 제외) |
| 화면 점유율 지시 | 인물 높이 약82%, 발선95% | 인물 높이 약70%, 추가 여백 포함 |
| 배경 | 차콜 단색 | 실제 투명 RGBA |

**새롭게 바꾼 입력 조합이라는 점은 사실이다.** 두 완성본과 원본 작화 보조를 한 번에 넣어 각 참조의 표현이 섞일 가능성이 생겼다. 구성 보존·제외 항목·숫자 여백 지시도 늘었다. 주 작화의 우선순위가 충분히 전달되지 않았을 가능성은 있으나 이미지 모델이 어떤 참조에 얼마만큼 영향을 받았는지는 도구가 공개하지 않는다.

문장이 길면 실패한다거나, C3/C4를 함께 넣으면 반드시 실패한다는 증거는 없다. 과거 성공 프롬프트에도 soft skin·cel planes 같은 표현이 있으므로 특정 일반 단어 하나에 원인을 돌리지 않는다. 텍스트만으로 생성한 것도 아니다. 실제 참조4장·순서는 저장된 요청과 일치한다.

## 여백과 투명도 검수의 한계

주 실루엣의 알파32 경계는 x=206~809, y=317~1432로 요청 안전 영역 안이다. 같은 해상도에서 과거82%보다70% 크기로 그리라는 지시는 인물에 쓸 수 있는 픽셀을 줄인다. 이는 세부 가독성에 영향을 줄 수 있지만 **여백 요구가 잘못됐다는 뜻도, 전체 그림체 차이를 설명한다는 뜻도 아니다**. 파일을 축소해 저장한 사실은 없고 반환 원본1024×1536·바이트를 그대로 보존했다.

알파1 경계는 x=0~1004, y=53~1536까지 퍼져 있다. 주 실루엣 경계 밖의 알파가0보다 큰 픽셀은18,397개, 최대 알파18이다. 매우 옅은 잔여색이므로 어두운 바탕에서 과장되어 보일 수 있다. 알파 채널이 존재한다는 검사만으로 깨끗한 컷아웃이라고 판정할 수 없다. 알파 최대값254라는 사실만으로 인물이 잘못 투명해졌다고 단정하지 않는다.

## 검수에서 놓친 부분과 기록 정정

이전 visual-review는 RGBA·여백·설정 보존을 상세히 확인하면서 얼굴·머리·선·명암의 이탈을 구체적으로 적지 않았다. 사용자 승인 대기 상태로 표기했더라도 내부에서 발견할 수 있는 작화 차이를 먼저 설명했어야 했다. 파일 검사와 참조 역할 검사는 전체 작화 검수를 대신하지 못했다.

v03은 실패 이력으로 분류하고 향후 화풍·편집 참조에서 제외했다. 다음 방향과 자동 재생성은 진행하지 않는다. 기존8장 기준과 캐릭터 구성은 유지한다. 재개가 요청되면 주 작화의 권한을 명확히 한 입력을 준비하되, 그 준비를 재현 성공이라고 표현하지 않는다. 생성 후 같은 표시 크기와 원본100%에서 얼굴·머리 묶음·선 위계·명암 면을 먼저 확인한다.
