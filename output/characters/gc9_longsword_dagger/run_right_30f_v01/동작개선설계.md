# 금발 전사 동작·바람·표정 개선 설계

2026-11-07. 상태: **줌 기능은 구현, 아래 애니메이션 개선은 제안**. 현재 스프라이트 그림이나 게임의 전투 규칙을 수정한 문서가 아니다. 프레임 번호는 모두 1부터 시작한다. 시간·변위 수치는 첫 제작을 위한 제안값이며 확정된 게임 규칙이 아니다.

## 1. 현재 결과에서 확인한 문제

`motion-review.png`는 현재 15/16번과 30/01번의 하체를 동일 좌표·배율로 비교한다. 원본 시각 검토에 근거한 지적이며 자동 인체 추적 결과는 아니다.

| 구간/대상 | 보이는 문제 | 필요한 수정 |
| --- | --- | --- |
| 15→16 | 뒤에 있던 파란 발이 앞쪽 지지 위치로 급하게 바뀐다. 반대 무릎이 몸 아래를 지나 앞으로 나오는 과정이 부족하다. | 파란 다리의 접기→앞으로 통과→펴기→내려놓기를 연속된 자세로 제작한다. |
| 30→01 | 뒤쪽 파란 발의 벌어짐과 높이가 급하게 달라진다. | 마지막 자세에서 첫 자세까지의 발·무릎 이동량도 다른 인접 프레임처럼 이어지도록 수정한다. |
| 지지/공중 구간 | 발바닥이 어느 시점에 땅을 짚고 몸을 밀어내는지 명확하지 않다. | 접지·압축·밀기·공중 구간을 먼저 지정한다. 접지한 발과 공중의 발은 다른 궤적을 사용한다. |
| 무릎·장비·상체 | 같은 인물이어도 프레임마다 관절 위치와 모양이 조금씩 다시 그려졌다. | 뼈 길이·골반·목·장비 부착점을 고정하고 허용한 부위만 변화시킨다. |

기존 검사는 30장 존재, 알파, 잘림, APNG 디코딩, 재생 버튼 검사가 중심이었다. 이 검사가 자연스러운 달리기를 증명하지는 않는다. 이번에는 실제 자세 연결을 별도로 검토한다.

## 2. 달리기 수정: 핵심 8자세 + 중간 22장

최종 결과는 요청한 30프레임을 유지한다. 먼저 양쪽 다리가 한 번씩 지지하는 핵심 8자세를 잡고, 자세별 연결을 확인한 뒤 중간 22장을 채운다. 아래 번호는 **새로 수정할 동작의 배치안**이다. 현재 프레임이 이미 이 동작을 충족한다는 뜻은 아니다.

| 핵심 프레임 | 몸과 다리 | 확인할 점 |
| --- | --- | --- |
| 01 | 가까운 은색 오른발 착지, 파란 왼다리는 뒤에서 회수 시작 | 은색 발의 접지점과 골반의 관계 |
| 05 | 오른발로 체중을 받으며 무릎 굽힘 | 몸이 조금 낮아지고 반대 발이 끌리지 않는지 |
| 09 | 오른발이 뒤로 밀어내고 왼무릎이 앞으로 통과 | 파란 발이 몸 아래에서 자연스럽게 앞으로 나오는지 |
| 13 | 양발 공중, 파란 왼발을 앞으로 펴서 착지 준비 | 발을 뻗는 방향과 이동 거리, 몸이 올라가는 양 |
| 16 | 먼 파란 왼발 착지, 은색 오른다리는 뒤에서 회수 시작 | 01번과 지지 다리가 실제로 바뀌었는지 |
| 20 | 왼발로 체중을 받으며 무릎 굽힘 | 은색 발의 회수와 골반 하강 |
| 24 | 왼발이 뒤로 밀어내고 오른무릎이 앞으로 통과 | 은색 발이 갑자기 앞으로 나타나지 않는지 |
| 28 | 양발 공중, 은색 오른발을 앞으로 펴서 착지 준비 | 29→30→01까지 같은 궤적과 속도로 이어지는지 |

제자리로 달리는 시트에서는 지지한 발이 캐릭터 기준으로 뒤쪽, 즉 화면 왼쪽으로 움직인다. 실제 게임에서 캐릭터가 오른쪽으로 이동하면 두 이동량이 상쇄돼 지면에 붙어 보인다. 지지한 발을 모든 프레임에서 화면의 같은 x에 두면 실제 이동 시 미끄러진다. 반대로 공중의 발은 무릎을 접어 회수한 뒤 앞으로 펴는 곡선을 따라야 한다.

제작 절차:

1. 확정 원화에서 골반·양 무릎·발목·발끝·목·양 손의 위치를 표시한다. 허벅지/종아리 길이, 발 크기와 검 길이를 기준으로 기록한다.
2. 원화의 가까운 다리는 은색, 먼 다리는 파란색으로 고정한 포즈 가이드를 만든다. 장검은 오른손, 단검은 왼손을 유지한다.
3. 01/16의 반대쪽 접지, 05/20의 눌림, 09/24의 통과, 13/28의 공중 자세를 먼저 검토한다.
4. 각 핵심 자세 사이의 무릎·발목 좌표를 이어 중간 자세를 만든다. 다리 길이와 굽힘 방향을 고정한다. 이미지 편집은 이 가이드와 확정 원화를 함께 사용해 틀린 자세만 보완한다.
5. 전체 그림을 중첩하거나 복제해 장수만 채우지 않는다. 단순 영상 보간도 다리와 칼날을 휘게 할 수 있으므로 관절 궤적을 확인한다.
6. 발이 땅에 닿은 프레임만 공통 지면에 맞춘다. 공중 자세까지 발바닥 기준으로 재정렬하지 않는다. 이미 그려진 상하 움직임에 게임 코드가 다시 상하 이동을 더하지 않는다.
7. 자세가 맞은 뒤 1초와 약 0.67~0.8초 주기를 비교한다. 최종 장수는 30장으로 유지한다. 재생 속도를 높여 잘못된 다리 교대를 숨기지 않는다.

실제 게임에서는 이동 거리로 달리기 주기를 진행시키는 방식을 권장한다. `주기 진행량 = 이번 이동 거리 / 한 주기의 보폭`으로 계산하면 이동 속도가 달라져도 지지하는 발이 덜 미끄러진다. 이동이 멈추면 자연스러운 지지 자세에서 대기로 전환한다. 같은 시각 앵커와 몸 크기를 모든 동작에 사용한다.

## 3. 부위 분리와 부착점

현재 PNG는 머리카락·얼굴·갑옷·천이 한 장으로 합쳐져 있다. 이 상태에서는 바람에 머리카락만 움직이거나 피격 때 눈·입만 바꾸기 어렵다. 먼저 **편집 가능한 부위별 원화**를 만들어야 한다. 가려진 두피·목·어깨를 보완하고 기존 눈·입이 남아 이중으로 보이지 않도록 표정 없는 얼굴 바탕도 준비한다.

| 부위 | 고정할 위치 | 허용할 움직임 |
| --- | --- | --- |
| 몸통·골반·갑옷 | 몸의 기준점과 관절 연결 | 달리기 기울기와 하중 변화, 갑옷은 단단하게 유지 |
| 먼/가까운 다리 | 골반·무릎·발목 | 규정한 관절 길이와 발 궤적 |
| 먼/가까운 팔 | 어깨·팔꿈치·손목 | 몸의 반작용, 무기를 쥔 손 고정 |
| 머리 바탕 | 목 부착점 | 작은 회전과 상하 움직임 |
| 표정 | 머리의 눈·입 위치 | 눈썹·눈·입 상태 교체 |
| 뒤 머리카락·앞머리·옆 머리 | 두피의 각 뿌리 | 끝부분만 뒤늦게 따라오기 |
| 스카프·허리 천 | 목 매듭·허리 봉제선 | 자유로운 끝부분의 흔들림 |
| 장검·단검 | 각 손의 그립 위치 | 손을 따라가는 회전, 칼날과 가드는 변형하지 않음 |
| 발밑 그림자 | 지면의 캐릭터 위치 | 높이에 따른 농도 변화 |

기본 표시 순서는 뒤 머리카락/뒤 천 → 먼 다리·먼 팔/단검 → 몸통 → 가까운 다리 → 머리/표정 → 앞머리 → 가까운 팔/장검으로 설계하되, 실제 포즈에 필요한 앞뒤 순서는 프레임별로 기록한다. 목·소매·머리 뿌리는 작은 겹침 영역을 두어 움직일 때 틈이 드러나지 않게 한다.

일반 달리기처럼 반복되는 큰 몸동작은 검토한 프레임으로 고정하고, 얼굴과 작은 머리카락·천 반응은 별도 레이어로 합성하는 방식을 권장한다. 복잡한 공격이나 큰 피격처럼 머리 각도가 크게 바뀌는 동작은 전용 자세를 만들어 표정이 붙을 위치를 따로 지정한다.

## 4. 머리카락과 바람

머리카락 전체를 좌우로 옮기지 않는다. 뿌리는 두피를 정확히 따라가고 끝만 늦게 따라온다. 이 캐릭터는 짧은 금발이므로 긴 머리처럼 크게 휘면 원래 디자인이 바뀐다.

입력은 세 가지다: 주변 바람, 캐릭터 이동으로 생기는 상대 바람, 몸의 가속·급정지·충격. 오른쪽으로 달릴 때 기본적인 상대 바람은 왼쪽이며, 실제 바람이 더 강하면 반응 방향도 달라진다. 계산은 `상대 바람 = 장면 바람 − 캐릭터 속도`를 캐릭터가 바라보는 방향으로 변환한 값으로 한다.

제안 시작값은 **256px 셀 기준**이다. 실제 게임의 57~65px 표시에서 다시 조정한다.

| 상황 | 머리카락 끝 | 스카프·허리 천 |
| --- | --- | --- |
| 대기/약한 바람 | 1~2px의 작은 변화 | 2~4px의 천천한 흔들림 |
| 보통 달리기 | 뒤쪽으로 2~4px, 몸보다 약 1~2프레임 늦음 | 4~8px, 몸보다 약 2~3프레임 늦음 |
| 강한 바람/급정지 | 상한 4~6px, 한 번 지나쳤다가 안정 | 6~10px 이내에서 늦게 흔들리고 점차 멈춤 |
| 피격 | 머리 회전 직후 끝부분이 조금 늦게 따라옴 | 충격 방향으로 밀린 뒤 감쇠 |

위 숫자는 자연 법칙이나 검사 결과가 아니라 첫 시안의 조절 범위다. 덩어리별 지연과 진폭을 다르게 하되 매 프레임 무작위로 흔들지 않는다. 세 덩어리의 끝 모양을 3~4단계로 그려 바꿔 보여주거나, 제작 도구에서 작은 뼈대 움직임을 만든 뒤 고정 픽셀 프레임으로 내보낸다. 원본의 실루엣과 금발 명암 덩어리는 유지한다.

반복 애니메이션에 포함시킨 흔들림은 30→01에서 위치와 진행 방향이 이어져야 한다. 게임의 실시간 바람은 별도 상태로 유지해 달리기→대기 전환 때 흔들림이 갑자기 0으로 돌아가지 않게 한다. 바람 세기 변화는 약 0.15~0.3초에 걸쳐 부드럽게 반영한다. 사용자 일시정지와 배속에는 프로젝트의 공통 게임 시간을 따른다.

## 5. 표정과 피격 반응

처음 필요한 표정은 기본, 집중, 눈깜박임, 약한 피격, 강한 피격, 회복의 여섯 상태다. 얼굴 윤곽·눈 위치·갈색 눈동자와 머리 크기를 유지하고 눈썹·눈꺼풀·입만 바꾼다. 측면은 보이는 한쪽 눈 중심으로 읽혀야 한다. 뒤를 보는 방향에는 얼굴 레이어를 표시하지 않는다.

| 상태 | 얼굴 표현 | 동작과 연결 |
| --- | --- | --- |
| 기본 | 원래의 편안한 눈과 입 | 대기 기본 상태 |
| 집중 | 눈썹을 조금 낮추고 입을 다묾 | 달리기·공격 준비 |
| 깜박임 | 열린 눈→반쯤 감음→감음→다시 열림 | 대기 중 약 2~4초 간격, 약 100~150ms; 피격 중에는 중단 |
| 약한 피격 | 순간적으로 눈을 좁히고 입에 힘을 줌 | 몸동작을 크게 끊지 않고 머리·어깨 반응 |
| 강한 피격 | 눈을 짧게 감고 이를 악문 작은 입 | 전용 피격 자세와 연결 |
| 회복 | 감은 눈을 다시 열고 집중 표정으로 복귀 | 달리기/공격/대기의 현재 상태로 자연스럽게 돌아감 |

약한 피격의 제안 타임라인:

| 실제 명중 후 | 표정·몸·부가 움직임 |
| --- | --- |
| 0~40ms | 표정을 피격 상태로 바꾸고 머리·어깨가 충격 반대쪽으로 조금 반응. 필요한 경우 짧은 국소 밝기 강조. |
| 40~100ms | 반응이 가장 큰 자세. 머리카락·천의 끝부분이 뒤늦게 따라감. |
| 100~180ms | 몸의 변위를 줄이고 눈을 다시 뜸. |
| 180~300ms | 기본 동작의 현재 진행 상태로 복귀. 천과 머리카락이 안정됨. |

강한 피격은 6~8개의 전용 자세를 만들고 약 250~400ms 안에서 검토한다. 표정만 바꾼 채 몸이 그대로면 충격이 읽히지 않으므로 머리·어깨·골반의 작은 반응을 함께 준다. 시각적인 밀림은 원본 256px 셀에서 약 4~10px를 첫 후보로 삼되, 실제 게임 위치나 충돌 판정을 자동으로 옮기지 않는다.

표정 우선순위는 사망 → 강한 피격 → 약한 피격 → 공격/집중 → 깜박임 → 기본으로 제안한다. 이것은 **표현의 우선순위**이며 공격 취소·스턴·무적을 새로 만드는 규칙이 아니다. 연속 피격 시 약한 반응을 매번 처음부터 재생하면 떨림이 심해지므로 짧은 간격의 반응은 갱신·합치고 강한 반응은 약한 반응으로 덮어쓰지 않는다. 피해 계산은 그와 관계없이 실제 명중마다 처리한다.

## 6. 함께 처리할 요소

| 요소 | 구체적인 처리 |
| --- | --- |
| 갑옷·장비 | 금속 판 자체는 휘지 않는다. 관절 부위만 회전하고 버클·초승달 문양은 위치를 유지한다. |
| 무기 | 손목/그립 부착점을 기준으로 따라간다. 장검·단검 길이와 가드 형태를 고정한다. 무기가 지나가는 앞뒤 순서를 포즈에 맞춘다. |
| 호흡 | 대기에서 가슴·어깨만 아주 작게 움직인다. 캐릭터 전체나 머리를 늘였다 줄이지 않는다. |
| 눈·시선 | 기본 시선은 이동/공격 방향을 향한다. 작은 측면 캐릭터에서는 눈동자를 매 프레임 흔들기보다 눈썹·눈꺼풀 변화로 표현한다. |
| 발소리·흙먼지 | 접지 이벤트에서 한 번만 발생한다. 공중 프레임이나 같은 프레임을 다시 그렸다는 이유로 재발생시키지 않는다. |
| 그림자 | 지면 기준점을 유지하며 공중 높이에 따라 농도를 조절한다. 발에 붙여 같이 떠오르게 하지 않는다. |
| 타격 섬광·숫자 | 캐릭터와 별도 레이어로 처리한다. 확정 명중 위치를 사용하고 얼굴을 계속 가리지 않는다. |
| 방향 전환 | 오른손 장검·왼손 단검·은색/파란 다리가 비대칭이므로 수평 반전으로 모든 방향을 대체하지 않는다. 기존 8방향 원화를 사용하고 방향별 목/손 부착점을 기록한다. |

## 7. 현재 게임 코드와 연결하는 방법

확인한 현재 구조는 `게임/package.json`의 Pixi 8.22.0, `게임/src/defenseView.ts`의 Pixi 스프라이트, `게임/src/bossBattleView.ts`의 DOM/SVG 표시다. `heroArt.ts`는 주로 통짜 프레임을 반환하고, 웨이브 화면의 기본 영웅 높이는 57px다. 보스 전투는 `BossBattle.hits`를 일정 시간 유지한다. 아래는 이 구조에 맞춘 추가 설계이며 아직 구현하지 않았다.

1. `characterMotion.ts`에 방향·동작·프레임 시간·달리기 위상·접지 이벤트를 관리하는 공통 재생 상태를 둔다. 렌더 횟수가 아닌 게임 시간/이동 거리로 진행한다.
2. `characterPresentation.ts`에 표정 우선순위, 피격 반응 시간, 머리카락·천 지연, 시각적 밀림을 둔다. 게임 모델의 체력·공격력·사거리·쿨타임을 여기서 바꾸지 않는다.
3. `characterArt.ts`에 부위별 텍스처, 공통 크기, 목/두피/손 부착점, 레이어 순서를 캐시한다. 매 프레임 Canvas를 새로 만들거나 PNG를 다시 인코딩하지 않는다.
4. Pixi 화면은 캐릭터 Container 안의 필요한 Sprite에 공통 상태를 반영한다. 보스 화면도 동일한 상태에서 이미지와 위치를 얻는다. 두 화면이 별도 타이머로 표정을 추측하지 않게 한다.
5. 이미 존재하는 피해 확정 지점에서 `hitId`, 대상, 명중 방향, 강도, 시각을 가진 표현 이벤트를 한 번 만든다. `hits` 배열에 남아 있다는 이유로 매 렌더마다 피격을 재시작하지 않는다. 전투/웨이브 번호를 포함한 고유 키로 중복을 막는다.
6. 피해는 기존 규약대로 지정 타격 프레임이 끝난 순간 확정한다. 피해 프레임·쿨타임·취소 규칙을 얼굴이나 애니메이션 종료 콜백으로 결정하지 않는다.
7. 첫 단계의 충격 강조는 짧은 피격 포즈 유지와 시각 변위로 처리한다. 게임 전체 시간을 정지시키는 히트스톱, 실제 넉백, 스턴은 별도 전투 규칙에 정의된 경우에 연결한다. 배속/일시정지/새 전투에서 표현 상태도 함께 정리한다.

큰 동작과 미세 반응을 모두 통짜 이미지 조합으로 만들면 자산 수가 급증한다. 예를 들어 30프레임×8방향×6표정×3바람 상태는 4,320장이다. 몸동작·표정·바람 반응을 분리하면 없는 조합을 매번 다시 생성할 필요가 줄어든다. 성능이나 이음새가 문제가 되는 동작만 검토한 레이어 결과를 미리 한 장으로 합쳐 내보낸다.

엄격한 픽셀 표현에서는 머리카락을 런타임에 소수 픽셀로 회전시키면 외곽이 떨릴 수 있다. 제작 단계의 뼈대/곡선 계산 결과를 고정한 픽셀 프레임으로 내보내거나 소수의 끝 모양을 전환한다. 전체 캐릭터의 마지막 표시 위치에서 한 번만 픽셀 정렬하며, 부위를 각각 따로 반올림해 틈을 만들지 않는다.

## 8. 제작 순서와 합격 기준

권장 순서는 **오른쪽 달리기 8핵심 자세 → 중간 보완으로 30장 → 기본 머리/천 반응 → 약한 피격/표정 → 강한 피격과 방향 확장**이다. 발 동작이 틀린 상태에서 머리카락 흔들림을 먼저 늘리지 않는다. Grok를 다시 연결하지 않아도 내장 이미지 편집과 부위별 원화·포즈 가이드로 진행할 수 있지만, 통짜 시트를 한 번 더 생성하는 것만으로 연속성이 보장되지는 않는다.

합격 기준은 다음 제작 때 적용할 목표다.

- 은색/파란 지지 다리가 반주기마다 교대하고 한 주기 안에 각 다리의 회수·통과·전방 뻗기·착지가 보인다.
- 접지 구간의 발바닥 높이는 256px 셀 기준 약 ±1px 안에서 유지하는 것을 목표로 한다. 공중 구간은 별도로 확인한다.
- 골반·목·손의 부착점과 뼈 길이, 얼굴 크기, 무기 길이가 의도 없이 변하지 않는다.
- 15→16, 30→01을 포함한 전체 연결을 5fps와 기본 속도에서 확인한다. 수치 차이는 검토할 구간을 찾는 보조 수단이며 동작 품질 합격 판정으로 사용하지 않는다.
- 머리카락 뿌리가 두피에서 떨어지거나 얼굴에 구멍이 생기지 않는다. 바람 방향·달리기/정지·연속 피격에서 반응이 이어진다.
- 실제 게임 높이 57~65px와 확대 화면 모두에서 표정이 읽히고 무기가 뒤바뀌지 않는다.
- 밝은 회색/초록과 어두운 배경, 전장 상단/중앙, 320/390px 화면에서 투명 여백·잘림·다른 유닛 가림을 확인한다.
- 0.25×/1×/5×와 일시정지에서 피해·표정·부가 반응의 시간 관계, 연속 명중 중복, 새 전투 초기화를 확인한다.
