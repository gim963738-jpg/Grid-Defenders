# 오른발 천천히 내리기 · 새 30프레임

사용자가 기존 시트에서 선택한 순서는 **1→2→3→4→5→9→10→11→13→14→15→16→21→22→23**이다. ‘왼발을 짚고 오른발을 들어 올려 접은 상태에서 천천히 내리는 시트를 다시 생성하고, 연결 순서는 사용자가 정한다’는 후속 요청을 적용했다.

## 동작과 참조

가까운 은색 판금 다리는 인체 오른발, 먼 청색 천 장화는 왼발이다. 왼발로 지탱하고 접힌 오른쪽 무릎을 펴면서 장화를 내려놓는 한 구간을 생성했다. 머리·상체·장검·단검·방향·장비는 기존 디자인을 따른다.

기존 23번을 연결 후보의 외형 참조, 22·21번을 오른발을 접어 올린 동작 참조, 원본 오른쪽 정측면을 장비 구분 참조로 내장 image_gen에 전달했다. 파일은 `references/`에 사본을 보존했다. 전체 생성 프롬프트는 `generation-prompt.txt`에 있다.

## 파일과 번호

| 파일 | 내용 |
|---|---|
| right-foot-lower-30f.png | 투명 PNG, 1536×1280px, 6열×5행 |
| right-foot-lower-30f-numbered.png | **새 01~30번**이 표시된 확인용 시트 |
| frames/right-foot-lower-01.png ~ 30.png | 각 256×256px, 개별 프레임 30장 |
| right-foot-lower-30f.json | 셀 위치·표시 기준점·순서·재생 정보 |
| right-foot-lower-animated.png | APNG, 15fps·2초·한 번 재생 후 정지 |
| preview.html | 재생·속도 변경·새 번호 선택·밝은/어두운 배경 |
| order.html | 번호 표시용 HTML. 캐릭터 PNG 위에 별도 번호 레이어 표시 |
| connection-plan.json | 사용자가 지정한 기존 15개 번호와 연결 상태 |
| generation-prompt.txt / generation-record.json | 내장 생성 프롬프트와 원본 경로 |

번호는 왼쪽→오른쪽, 위→아래다. 새 시트의 번호는 기존 번호와 별개다. 사용자가 후속 연결을 고르므로 기존 15장을 새 시트에 임의로 합치거나 새 30번에서 01번으로 순환시키지 않았다.

생성 원본은 1374×1145px, 229px 셀 6×5다. 각 셀을 자른 후 투명 여백을 왼쪽/위 13px, 오른쪽/아래 14px 더했다. 최종 PNG는 크기 변경 없이 포장했다. 표시 기준점은 (128,234)이며 피해·충돌 영역과 분리한다. 채팅용 WebP만 절반 크기로 축소·압축했다.

## 확인

서로 다른 PNG 30장, 모든 프레임의 알파·불투명 내용과 셀 경계 가시 픽셀 없음(알파16 이상)을 확인했다. 밝은 배경의 번호 표시 시트를 확인했다. Edge에서 밝은/어두운 배경 전환·프레임 선택·마지막 프레임 정지·390px 가로 넘침 없음·48px 조작 영역을 검사했다. 브라우저로 APNG 30장을 디코딩하고 256×256 크기와 총 2000ms, 한 번 재생을 확인했다.

프레임을 고르는 단계의 새 후보 자산이다. 기존 23번과의 최종 연결 선택과 연결 후 시각 확인은 사용자 선택 이후 진행한다. 기존 시트·게임 코드 수정, 커밋·푸시는 수행하지 않았다.
