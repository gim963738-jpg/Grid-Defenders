## 참고1: 비율 관찰

205×182의 게임 화면 캡처이며 약한 위에서 내려다보는 시점이다. 사용자 빨간 선은 머리 외곽과 몸통·팔·다리 경계 주석으로 보고 출력에 옮기지 않는다. 머리와 발의 가시 외곽은 비교적 읽히지만 목도리·재킷·머리카락이 해부학적 경계를 가린다. 아래 좌표는 원본 캡처에서 수동 판독한 근사 범위이며 신체 실측이나 정사영 수치가 아니다.

모발 포함 머리 단위는 약 42~45px, 본체는 약 140px로 **약 3.1~3.4 머리 단위**다. 얼굴 두개부만의 머리 단위는 모발 덩어리보다 짧아 약 3.8~4.4등신으로 추정되지만, 이마·두개골이 가려져 직접 실측할 수 없다. 기존 금발 SD는 모발끝~턱 약 350px / 본체1215px로 약3.5 머리 단위지만 머리 폭·부푼 바지·두꺼운 장화가 전반적인 덩어리를 크게 만든다. 등신 하나만 바꾸기보다 어깨·허리·다리·손발의 폭과 관절 위치를 함께 조정해야 한다.

참고1은 머리 폭 약36~40px, 어깨 폭 약35~42px로 머리와 어깨가 비슷하고, 골반 폭은 약24~29px다. 손은 작은 밝은 덩어리 약7~9px, 신발은 약15~19px로 보인다. 몸통(어깨~골반) 약40px, 다리(골반~발) 약48~54px, 팔(어깨~손끝) 약45~48px다. 어깨~손은 몸통보다 조금 길고, 가랑이 아래 다리에서 무릎 아래 장화가 큰 비중을 차지한다. 발 벌림·원근·모발 돌출 때문에 폭 수치는 최대 수 px 오차가 있다.

공통 설계 목표는 약3.3 머리 단위, 모발끝 대비 턱 약.30, 어깨 .34, 골반 .65, 무릎 .82, 발1.00이다. 짧은 몸통·정리된 상완과 전완·길게 읽히는 아래 다리, 머리 폭에 가까운 기본 어깨폭으로 조정한다. 장비 폭은 본체와 따로 판단한다. 신규 네 안은 같은 본체 전시 높이로 비교한다. 생성 원본의 높이 오차를 숨기지 않고 HTML 표시에서만 등비 등록한다.

장면 전체는 어두운 외곽선과 제한된 중간톤, 금속의 밝은 작은 면, 천의 큰 명암 덩어리를 사용한다. 화면이 작아 실제 선 두께나 개별 눈썹 픽셀을 확정하기 어렵다. 눈썹·눈·턱은 얼굴이 정면에 가까운 중앙 보라 머리에서만 제한적으로 읽힌다. 이를 ‘남성 짧은 머리/여성 긴 머리’로 축약하지 않고 어깨·허리·옷의 상하 비중·장화·소품·명암의 묶음으로 해석했다.

## 네 안 적용

1. **원형 계승**: 부드러운 갈색 눈과 옅은 미소, 기존 앞머리를 가장 가깝게 유지한다. 견갑 층과 흉갑을 큰 2~3면으로 정리하고 허리 주머니/벨트를 읽기 쉽게 묶는다.
2. **민첩한 쌍수 전사**: 낮고 좁은 견갑, 잘록한 허리, 간결한 바지와 가는 장화선, 뒤로 흐르는 금발의 리듬으로 가벼움을 만든다. 방어구와 고정 장식은 삭제하지 않는다.
3. **단단한 전위 전사**: 같은 본체 높이에서 어깨·흉갑 폭, 견갑의 판금 중첩과 각진 눈썹을 강화한다. 허리·무릎은 공통 위치를 유지하고 머리·전신을 확대하지 않는다.
4. **개성 강조 모험 전사**: 금발의 비대칭 뾰족 덩어리, 한쪽 눈썹이 살짝 올라간 자신감 있는 옅은 미소, 청색 목도리의 짧은 끝과 허리 천의 비대칭을 강조한다. 긴 망토·새 소품을 추가하지 않는다.

전안 고정: 청년 남성 인상, 금발·갈색 눈, 청색 목도리/내려진 후드, 은갑옷, 청색 허리 천, 갈색 벨트/바지, 오른손 장검·왼손 단검, 오른 견갑 초승달, 오른 판금 정강이/왼 청색 천 장화와 금속 보호대, 장검 청색 사선·날개 가드·고리 보호대, 단검 짧은 각진 날. 정면에서 인체 오른쪽은 화면 왼쪽이다.

## 기존 기준과의 한정 차이

은발 공통 체형을 이번 참고1의 비율 분석 목표로 한정 대체한다. 새 비율을 SD 공통 규정에 확정하지 않는다. 일러스트부터/1장 승인 절차는 최신 승인된 SD4안 요청을 따른다. 기존 원본과 생성 원본은 바이트를 보존하고 비교 화면에서만 등비 표시를 조정한다. 방향 세트·애니메이션·세계관 배치·카탈로그·게임 통합은 제외한다.

## 실제 생성 결과와 목표의 차이

내장 image_gen 1차4회 후 머리가 작고 길쭉한 결과를 확인해, 같은 원본 입력으로 머리 비중을 강조한 2차4회를 실행했다. 1차는 이력이며 최종 비교는 `variant-1-final.png`~`variant-4-final.png`다. 2차도 수학적으로 변형하지 않은 새 생성이다. 실제 최종 머리 단위는 수동 판독상 약3.02 / 3.01 / 3.18 / 3.17로, 목표3.3보다 조금 더 큰 머리다. 본체 높이의 약31~33%가 모발끝~턱이고 몸통·팔다리 부피가 줄어 짧은 SD 인상을 만든다. 각 안의 정확한 비율이 동일하다고 주장하지 않는다. 얼굴/어깨/골반의 해부학 경계는 옷에 가려져 좌표에 수 px~수십 px 판독 오차가 있다.

생성 요청의 상단20% 여백과 본체74% 점유는 반환 결과에서 그대로 실현되지 않았다. 실제 머리끝은 y91~126, 발선은 y1169~1195 부근이고 본체 높이는1056~1104px다. 원본은 유지하고, 비교 화면에서만 본체680 CSS px/발선760 CSS px로 등비 등록했다. 이는 공통 SD 프레이밍 합격 판정이 아니다. 작은 원본 캡처의 관찰 한계를 감안해 이번 자료는 사용자 선택용 시안으로 제출한다.
