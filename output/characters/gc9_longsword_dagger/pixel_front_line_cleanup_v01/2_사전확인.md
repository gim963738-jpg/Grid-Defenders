# 정면 v01 복구·선 정리 사전확인

사용자 직접 지시: “금발 장검·단검 · SD 픽셀 · 정면 v01 이때로 돌아가서 선정리 진행”. 원본은 pixel_8views_v01/images/01_front_000.png이며 실제 view_image로 확인했다. 이 그림을 유일한 편집 입력으로 사용해 당시 비율·얼굴·색·장비·자세를 유지하고 선 겹침/연결·유색 알파 잔여만 정리한 정면1장을 내장 image_gen으로 만든다. 새2안 비율/공통기준을 이번 선 정리에 덮어씌우지 않는다.

최신 사용자 직접 지정이 일반 SD 비율 규정보다 이번 편집에서 우선한다. 장검은 원본의 바깥 아래 각도를 유지하며 일반 대각선 그립을 이유로 자세를 바꾸지 않는다. 신규 폴더에서 편집결과와 원본 사본/프롬프트/기록만 보관한다. 기존PNG/공통기준/카탈로그/게임/사용자화면/다른방향을 바꾸지 않는다. 원본 및 반환PNG 바이트/해상도/알파 보존, 밝고어두운배경과 몸/얼굴/무기/손/잘림 검수. 별도 커밋·푸시 없음.

이번은 종결된 감독작업 이후 이 창의 새 직접 요청이다. 과거 Task/Dispatch/ACK를 재사용하지 않으며 활성 감독Dispatch가 없음을 확인했다. 작업방법의 직접작업 방식으로 필독/적용 근거를 이 폴더에 남긴다. 새 사용자 승인을 추가 요구하지 않는다.
