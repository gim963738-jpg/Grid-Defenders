# 금발 장검·단검 캐릭터 GC9 시안

사용자 제공 다운로드 (22)는 복장, 다운로드 (23)은 머리, 첨부 스케치는 장검과 단검의 형태 참조다. 각 이미지의 역할을 분리해 GC9 v1.1의 성인 남성형 전신 시안 1장을 제작한다. 정식 이름·직업·능력은 확정하지 않는다.

- 복장: 청색 목도리와 내려진 후드, 은빛 흉갑·견갑·팔 갑옷·장갑, 청색 허리 천, 갈색 가죽 벨트·주머니·바지. 원본의 다리 장비 비대칭을 이어 오른다리는 판금 장화, 왼다리는 청색 천과 작은 금속 보호대로 구성한다.
- 머리: 23번의 짧고 층진 금발과 옆으로 흐르는 앞머리. 해당 이미지의 흰금 코트·무기는 옮기지 않는다.
- 무기: 오른손 장검 1자루·왼손 단검 1자루. 장검의 청색 사선 장식, 날개처럼 뻗은 가드와 고리형 손 보호대, 단검의 짧고 각진 날·가드를 스케치에서 해석한다.
- 표현: C4 얼굴선·선화, C3 금속 면, GC9 성인 남성형 비율을 적용한다. M05 원본은 사전 분석으로 참고하고, 도구에는 복장·머리·스케치·C4·C3의 5장을 전달한다. 각 화풍 참조의 인물 정체성·머리·복장은 옮기지 않는다.
- 구도: 양발을 딛고 서 있는 완만한 앞 사선 전신. 두 무기가 겹치지 않고 끝까지 보이도록 배치한다. 이번 요청은 캐릭터 메인 시안 1장으로 제작한다.
- 출력: 실제 알파 PNG를 요청하고 실제 반환 크기를 기록한다. 해상도 확대·JPEG 재저장으로 품질을 대체하지 않는다.

내장 image_gen을 사용한다. 정확한 프롬프트는 `images/main_threequarter_v01.prompt.txt`, 입력 순서와 출력 정보는 `generation-records.json`에 저장한다. 생성 후 얼굴·손·무기 개수·가드 형태·장비 연결과 잘림을 확인한다.

## 저장 결과

메인 시안은 [main_threequarter_v01.png](images/main_threequarter_v01.png), 실제 1024×1536 RGBA PNG다. 1536×2304를 문구로 요청했으나 실제 반환 크기는 이보다 작으며, 저장 과정에서 확대하거나 재인코딩하지 않았다. 참조 6장 요청은 도구의 5장 한도로 사전 거절되었고, 5장으로 수정한 호출에서 실제 이미지 1장을 생성했다.

투명 픽셀 1,071,663개와 알파 240 이상 피사체 픽셀 439,915개를 확인했다. 가시 외곽은 x=24~873, y=8~1486이며 캔버스 가장자리에 닿지 않는다. 밝은 배경과 어두운 배경에서 두 무기·손·복장·머리·발을 확인했다. 원본 PNG 100% 표시와 화면 맞춤 보기도 확인했다.

기존 제작 모음의 ‘테스트 마무리 시안’에 제작본, ‘첨부자료’에 새 입력 3장을 연결했다. 화면 카테고리는 기존 6개를 유지한다. 결과는 신규 캐릭터 첫 시안이며 사용자 최종 승인 여부는 별도다.
