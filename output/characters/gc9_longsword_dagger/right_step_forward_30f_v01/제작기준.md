# 오른발 앞으로 내딛기 · 새 30프레임

사용자는 기존 시트의 **1→2→3→4→5→9→10→11→13→14→15→16→21→22→23** 이후, 들고 있는 오른다리 무릎을 앞으로 보내 한 발 앞에 내딛는 시트로 다시 제작해 달라고 요청했다.

이전 `right_foot_lower_30f_v01`은 발을 아래로 내려놓는 후보였다. 이번 요청을 우선해 **오른무릎 앞으로 이동 → 오른쪽 정강이 펴기 → 왼발 앞을 지나 오른발 뻗기 → 뒤꿈치 접촉 → 앞발바닥 내려 착지**하는 새 후보를 생성했다. 오른발이 지지하는 왼발보다 화면 오른쪽으로 앞서 나간 상태로 끝난다.

## 참조와 고정 구성

내장 image_gen에 기존 23번을 연결 후보 외형, 22번을 접힌 오른다리 동작, 원본 오른쪽 정측면을 장비 구분 참조로 전달했다. 참조 3장의 사본은 `references/`, 전체 프롬프트는 `generation-prompt.txt`에 있다.

가까운 인체 오른다리의 은색 판금 장화가 앞으로 움직이고, 먼 왼다리의 청색 천 장화가 지지한다. 금발·청색 목도리·은색 갑옷·갈색 바지와 벨트·오른손 장검·왼손 단검을 유지한다. 화면 오른쪽을 바라보며 한 번 내딛는 구간이다.

새 번호는 기존 시트 번호와 별개이며 왼쪽→오른쪽, 위→아래 순서다. 사용자가 연결할 프레임을 정하므로 기존 선택 15장을 임의로 합치지 않았다. 30번 이후 첫 자세로 돌아가지 않고 마지막 자세를 유지한다.

생성 원본은 1374×1145px, 229px 셀 6×5다. 각 고정 셀을 자른 후 왼쪽/위 13px, 오른쪽/아래 14px의 투명 여백만 더해 256px로 포장했다. 최종 PNG의 확대·축소, 프레임별 자동 자르기와 위치 재정렬은 없다. 표시 기준점 (128,234)는 피해·충돌 영역과 독립적이다. 채팅용 WebP만 표시를 위해 절반 크기로 축소·압축했다.

## 검증과 상태

서로 다른 PNG 30장, 각 프레임의 실제 알파/불투명 내용, 셀 경계의 가시 픽셀 없음(알파16 이상)을 확인했다. 밝은 배경의 전체 번호 시트에서 오른쪽 은색 장화의 전방 이동과 착지를 확인했다. Edge에서 이미지 로드·프레임 선택·밝은/어두운 배경 전환·마지막 자세 정지·390px 가로 넘침 없음·48px 조작 영역을 검사했다. APNG 30장을 브라우저로 디코딩하여 256px 크기, 2000ms, 한 번 재생을 확인했다.

이번 파일은 전방 내딛기 연결 후보의 로컬 저장이다. 기존 시트·이전 내리기 후보·게임 코드는 유지했다. 최종 연결 프레임 선택과 연결 후 시각 확인, 커밋·푸시는 수행하지 않았다.
