# 선택 연결본 · 20프레임

사용자 지정 순서로 아래 두 구간을 연결했다.

1. 기존 `walk_right_30f_v01`: **1→2→3→4→5→9→10→11→13→14→15→16→21→22→23** (15장).
2. 다시 만든 전방 내딛기 `right_step_forward_30f_v01`: **9→10→11→18→30** (5장).

연결 번호 01~15는 앞 구간, 16~20은 새 구간이다. 접합부는 **연결 15(앞 23)→16(새 09)**. 각 셀에 연결 번호와 원본 출처 번호를 함께 표시했다.

총 20장, 기본 15fps·약 1.33초·한 번 재생 후 마지막 자세 정지다. HTML에서 30/15/10/5fps와 연결부부터 재생을 선택할 수 있다. APNG는 밀리초 단위로 1333ms다.

후속 요청으로 HTML 미리보기에 **무한 재생** 버튼을 추가했다. 켜면 재생을 시작하고 20→01로 반복하며, 끄면 진행 중인 회차의 마지막 자세에서 멈춘다. 반복 중에도 일시 정지와 재개를 할 수 있다. 기본값은 꺼짐이다. 다운로드용 APNG는 기존 단발 버전을 유지한다.

- `connected-walk-20f.png`: 투명 PNG, 1280×1024px, 5열×4행, 256px 셀.
- `connected-walk-20f-numbered.png`: 연결 번호와 원본 번호 표시 시트.
- `connected-walk-animated.png`: 움직이는 PNG.
- `preview.html`: 전체·연결부 재생과 프레임 확인.
- `sequence.json`: 정확한 20개 원본 번호·경로·SHA-256.
- `connected-walk-20f.json`: 시트 프레임 좌표와 재생 정보.
- `frames/`: 원본과 바이트가 같은 PNG 사본 20장.

원본 프레임의 위치·크기·픽셀을 유지해 연결했다. 개별 사본의 SHA-256 일치와 연결 순서를 검사했다. 브라우저에서 APNG 20장 전체 디코딩, 256px 크기·1333ms·단발 재생, 15→16 출처 표시, 연결부 재생, 마지막 자세 정지·배경 전환을 확인했다. 밝은 배경의 번호 시트를 시각 확인했다.

이전 45프레임 연결본과 원본 시트는 유지했다. 현재 작업 폴더에 로컬 저장했으며 게임 연결·커밋·푸시는 수행하지 않았다.
