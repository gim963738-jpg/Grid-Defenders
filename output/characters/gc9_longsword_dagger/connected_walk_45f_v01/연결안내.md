# 앞 구간 + 오른발 내딛기 연결본

사용자 요청으로 기존 앞 구간 15장과 최신 전방 내딛기 30장을 순서대로 연결했다.

- 연결 01~15: 기존 `walk_right_30f_v01`의 **1→2→3→4→5→9→10→11→13→14→15→16→21→22→23**.
- 연결 16~45: 최신 `right_step_forward_30f_v01`의 **01~30 전체**.
- 접합부: **연결 15번(앞 23) → 연결 16번(새 01)**.
- 총 45프레임, 기본 15fps·3초·한 번 재생 후 마지막 자세 정지. HTML에서 30/15/10/5fps를 선택할 수 있다.

## 파일

| 파일 | 내용 |
|---|---|
| preview.html | 전체 재생, 프레임 선택, 원래 출처 번호 표시, 연결부부터 재생 |
| connected-walk-animated.png | 256×256px APNG, 45장·3초·한 번 재생 |
| connected-walk-45f.png | 실제 알파 PNG, 2304×1280px, 9열×5행 |
| connected-walk-45f-numbered.png | 연결 번호 01~45와 출처 번호 ‘앞/새’를 표시한 확인용 시트 |
| connected-walk-45f.json | 시트 좌표·순서·표시 기준점·시간 |
| sequence.json | 45장 각각의 원본 경로·원본 번호·SHA-256 |
| frames/connected-walk-01.png ~ 45.png | 원본과 바이트가 같은 개별 PNG 사본 |
| verification.json / browser-verification.json | 복사 일치와 브라우저 재생 검사 결과 |

기존 256px 프레임을 그대로 복사하고, 크기 변경·회전·프레임별 이동 없이 고정 셀에 포장했다. 새 그림이나 중간 동작을 생성하지 않았다. 따라서 이번 결과는 지정한 프레임들을 연결해 확인하는 버전이며, 접합부의 자세·디자인을 추가로 보간한 버전은 아니다. 표시 기준점 (128,234)은 피해·충돌 영역과 독립적이다.

모든 개별 사본의 원본 SHA-256 일치, 연결 15→16의 출처, 연결부부터 재생 버튼, 마지막 자세 정지를 확인했다. APNG 45장의 브라우저 디코딩과 256px 크기·3000ms·한 번 재생을 확인했다. 밝은 배경의 전체 번호 시트를 시각 확인했고 브라우저 배경 전환·390px 가로 넘침 없음·48px 조작 영역도 검사했다.

현재 작업 폴더에 로컬 저장했다. 원본 두 자산 폴더와 게임 코드는 유지했으며 커밋·푸시는 수행하지 않았다.
