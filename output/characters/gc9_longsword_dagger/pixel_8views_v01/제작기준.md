# 금발 장검·단검 8방향 SD 픽셀 입상

대상은 기존 `금발 장검·단검 · 오른쪽 앞 사선 시안 v01`이다. 원본 GC9 메인 PNG는 유지하고, 같은 디자인을 큰 머리·짧은 몸의 SD 픽셀 표현으로 다시 그린다. 기존 은발 지팡이 픽셀 견본의 표현·비율·카메라 높이를 참고하며 그 인물의 의상과 장비는 옮기지 않는다.

## 고정 구성과 좌우

- 금발·갈색 눈·청색 목도리와 내려진 후드·은빛 흉갑/견갑/팔 갑옷/장갑·청색 허리 천·갈색 벨트와 바지를 유지한다.
- 인체 오른손은 장검, 왼손은 단검이다. 장검의 청색 사선 장식·날개 가드·고리형 손 보호대, 단검의 짧고 각진 날과 작은 가드를 유지한다.
- 인체 오른다리는 판금 정강이·장화, 왼다리는 청색 천 장화와 작은 금속 보호대다. 초승달 문양은 오른쪽 견갑이다.
- 후면은 짧은 내려진 후드·은빛 등판·갈색 허리띠로 이어 보완한다. 긴 망토를 새로 붙이지 않는다.

## 자세와 방향

양발을 딛고 서서 장검과 단검을 아래로 드는 대기 자세다. 몸·머리·발을 함께 회전하며 무기를 반대손으로 옮기지 않는다. 반대쪽 옆모습을 좌우 반전으로 대신하지 않는다.

| 파일 | 각도·방향 |
|---|---|
| 01_front_000 | 정면 0도 |
| 02_front_right_045 | 오른쪽 앞 사선 45도 |
| 03_right_090 | 오른쪽 정측면 90도 |
| 04_back_right_135 | 오른쪽 뒤 사선 135도 |
| 05_back_180 | 후면 180도 |
| 06_back_left_225 | 왼쪽 뒤 사선 225도 |
| 07_left_270 | 왼쪽 정측면 270도 |
| 08_front_left_315 | 왼쪽 앞 사선 315도 |

## 생성과 저장

내장 image_gen으로 방향별 PNG 8장을 개별 생성한다. 정면 SD 픽셀을 먼저 만든 뒤 정측면과 후면을 기준으로 사선과 반대 측면의 일관성을 맞춘다. 원본 실제 픽셀 크기·알파·잘림·무기 개수·좌우를 확인하고, 밝고 어두운 배경에서 본다. 저장 시 리샘플링하지 않는다.

각 프롬프트는 `images/*.prompt.txt`, 참조 순서와 출력 정보는 `generation-records.json`에 보관한다. 수작업 픽셀 격자·발 기준점 정규화와 게임 내 애니메이션 통합은 이번 정지 이미지 제작과 구분한다.

## 후속 제작의 공통 크기 · 2026-11-08

이전 PNG와 당시 프롬프트는 이력으로 보존한다. 사용자 결정에 따라 이후 SD는 은발·날개 지팡이의 인물 크기와 체형을 공통 기준으로 적용한다. 현재 금발 정면의 실측 본체는 1215px로 은발의 926px보다 크게 프레이밍되어 있으며 다음 제작부터 [공통 기준](../../../../문서/02_세부기획/02_영웅/SD_공통제작기준.md)을 적용한다.
