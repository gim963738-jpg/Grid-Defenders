# 캐릭터 제작 모음 정리 기준

주 탐색은 **출신 대륙 → 클래스**다. 상단 전체 클래스에서는 대륙과 관계없이 해당 클래스 캐릭터를 본다. 기본 화면은 캐릭터별 묶음이며 이미지별 보기로 바꾸면 각 방향·형식 파일을 개별 카드로 볼 수 있다.

## 출신과 클래스

왼쪽에는 전체 대륙·중앙대륙·서대륙·남대륙·동대륙·북대륙·출신 미지정을 둔다. 첨부자료와 모든 이전 작업물은 배치를 보류한다. 기존 아르케리온 수석 빛 마법사 시안도 출신·소속 미지정으로 보관하고 신규 캐릭터부터 출신·소속을 지정한다.

오른쪽 클래스 버튼은 선택한 대륙 안에서 필터링한다. 상단 전체 클래스 버튼은 대륙·검색·이전 제작 묶음 조건을 해제해 해당 클래스 전체를 연다. 숫자는 최근 정리본이 있는 캐릭터 수다.

클래스는 기존 명칭·문서·확인한 외형을 바탕으로 정리하며 정식 직업명과 별도로 보관한다. 소속 국가나 배운 공격 학파는 확인된 설정만 기록한다.

## 설명과 태그

카드에는 이름과 특징을 표시하고 소속·클래스·직업·무기 종류·배운 공격 계열을 태그로 표시한다. 미정 항목은 미지정으로 표시한다. [캐릭터 목록](../../../자료/캐릭터설정/캐릭터목록.json)이 분류 정보의 원본이다.

개인 이름이 없는 자료는 특징을 나타내는 표시 이름을 사용한다. 원래 제목·파일명·제작 출처도 검색과 상세 보기에 유지한다. 원본 참조는 새 세계관의 인물 소속으로 재해석하지 않는다.

이전 작업물의 표시 이름에 도시나 세력 이름이 남아 있어도 현재 세계관 배치로 해석하지 않는다. placement_status:deferred인 기존 프로필은 출신 unassigned와 빈 affiliation_ids를 유지한다. 클래스·특징·장비·원본 분류는 보관한다.

## 이전 자료와 원본

기존 7개 분류는 검색 필터의 “기존 제작 묶음”에 보관한다.

발로르부터 시작한 실제 신규 제작은 통합 “신규 캐릭터” 묶음에 둔다. 과거 7개 보관 분류와 구분하며 캐릭터마다 별도 카테고리를 늘리지 않는다. 주 탐색은 계속 대륙·클래스다.

- 은발 지팡이 · 픽셀 8방향
- 금발 전사
- 테스트 마무리 시안
- 테스트 과정 작업물
- 첨부자료
- GC9 그림체 참조
- SP13 스플래시 참조

금발 전사의 이미지별 보관 분류에서는 SD 8방향을 먼저, GC9 일러스트와 오른쪽 걷기 시트를 이어 표시한다. 기존 #blondWarrior·#staff8 주소도 이 이미지별 보기를 연다.

원래 세부 제작 묶음은 source_group으로 남긴다. 이미지·프롬프트·인계 스냅샷의 경로와 바이트를 보존하고 동일 SHA-256 사본은 한 번 표시하며 모든 보관 경로를 연결한다.

원본 100% 보기와 저장은 실제 파일을 사용한다. 미리보기는 표시 크기만 맞춘다. 실제 알파 여부·원본 폭과 높이·SHA-256은 [이미지 메타데이터](image-metadata.json)에 있다.

## 제작과 갱신

[캐릭터 제작 규약](../../../문서/02_세부기획/02_영웅/캐릭터제작규약.md)의 순서는 **일러스트 시안 승인 → 4방향 제작 → SD 시안 승인 → 3방향 제작**이다. 승인용 시안은 최종 방향 세트와 구분한다.

분류 정보는 자료/캐릭터설정/캐릭터목록.json, 순서는 제작순서.json에서 관리한다. 새 폴더는 스캔과 분류 규칙에도 함께 등록한다.

```powershell
node tools/character-catalog/build.mjs
node tools/character-catalog/verify-files.mjs
```

메타데이터가 이미 최신이고 이미지가 바뀌지 않았다면 빌드에 --skip-scan을 사용할 수 있다. build.mjs와 gallery.template.html에서 JSON·HTML을 함께 갱신한다.

구조 변경 전 HTML·JSON·템플릿은 snapshots의 before-origin-class-20261107 사본에 보관했다.
