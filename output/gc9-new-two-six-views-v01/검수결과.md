# 제작자 자체 검수 결과

작업 MAIN03-20261109-5F7D5052 / 차수1.
실제 개별PNG6장 후보의 제작·보존·파일 검사를 완료했다. 사용자 시각 합격과 독립 테스터 검수는 대기다.

## 생성 및 파일 검사

내장 image_gen.imagegen9회: 최초 정면2회, 정면 구도 보완2회, 방향4회, 남성 사선 얼굴 방향 국소 보완1회.
최종6장과 이전 후보3장의 실제 바이트를 모두 보존했다. 모든 호출의 실행 프롬프트·참조 순서/역할/해시·도구 반환·출력 경로가 generation-record.json에 있다.

6장 모두1024×1536 RGB PNG, 고유 SHA256이며 생성 원본과 제출 파일 바이트가 동일하다. ZIP6항목을 재독해 원본 PNG 해시와 일치함을 확인했다. 실제 입력2장/GC9 기준8장 해시와 현재 필독17문서 해시를 확인했다. 기존4명12장도 차수1 manifest 해시 그대로 보존됨을 확인했다.

## 여백·배율·발선

밝은 전체 프레임에서 머리·발·뿔·옷자락·무기·풍선 잘림을 발견하지 않았다. RGB 대비 경계(min<180 또는 채널 색차>45) 기준으로 상단20/좌우15/하단6%를6/6장 충족한다. 옅은 경계는 자동 측정에서 누락될 수 있어 시각 확인을 병행했다.

N01 발선 경계 y1327~1332, 최대5px(캔버스 높이의 약0.33%) 차이이며 전체 경계 높이929~937px로8px 차이다. N02 발선 y1324~1326, 최대2px(약0.13%) 차이이며 풍선 포함 전체 경계 높이911~914px로3px 차이다. 정확히 동일한 픽셀 기준선이라고 선언하지 않고 생성기의 작은 잔여 편차로 남긴다. 전체 경계에는 머리/풍선/소품이 포함되어 해부학적 키 실측은 아니다. 후처리로 위치/크기를 맞추지 않았다.

## 시각 검사

원본2장과 최종6장 전체를 직접 표시했다. inspect.html의 원본2배 CSS 확대 화면에서 얼굴·천·양손과 장비/줄을 확인하고 Orca 브라우저 캡처를 evidence에 보존했다. 남성 사선의 얼굴이 처음에는 측면에 치우쳐 국소 방향을 보완했으며 보완본은 두 눈이 보이는 사선, 측면은 한 눈과 겹친 어깨로 구분된다. 각 방향의 몸통·골반·무릎·발도 함께 회전한다. 각도는 시각 근사이며3D로45/90도를 계측한 결과가 아니다.

N01 남성·N02 어린 인상 여성의 구분, 안경 미추가, 입을 다문 중립 표정, 양발 기립·팔 내림을 확인했다. 여성 사선은 무릎이 약간 이완된 자연스러운 서기이며 양발 접지는 유지한다. 소품을 잡는 팔/손목만 최소 굽힘이 있고 턱괴기·주머니손·액션은 없다. 장식 얼굴의 작은 미소는 풍선/동반 소품 디자인이며 인물 표정과 구분한다.

머리색/가르마·큰 묶음·흐름과 가는 선 표현이 유지된다. 천은 큰 겹침과 구조를 따르는 셀 명암이며 몸을 감싸는 전투 잔상이나 인쇄된 얼룩 같은 그래픽을 추가하지 않았다. N01 검은 천에도 접힌 면과 일부 각진 그림자는 남아 있으며 이를 사용자 합격으로 단정하지 않는다. 금속 장식의 문양과 팔 장비 인레이는 원래 디자인 요소로 구분한다.

손은 소품/무기 손잡이와 연결된다. 다만 작은 화면의 겹친 손가락과 측면의 먼 손 일부는 가려져 모든 손가락의 해부학 합격을 보장하지 않는다. N01 빈손의 가는 손가락과 쌍날 고리형 그립, N02 사탕·풍선줄 손잡이는 최종 사용자 검토 항목으로 남긴다.

## 추정과 남은 판정

N02 픽셀 소품을 사탕 모양·해파리형 옆 주머니·작은 귀 장식으로 해석하고 끈/부착부·옅은 다리 의상의 어두운 옆선·뒷면 옷과 풍선줄 손 연결을 최소 보완했다. N01 팔 장비/쌍날 및 뒷옷 구조도 SD 소스에서 전신으로 해석했다. 이는 원본 해석이며 사용자 확정 세부 설정으로 승격하지 않는다.

GC9 전체 작화 일치, 중립 인상, 손과 소품 디자인의 최종 미적 합격은 사용자에게 남아 있다. 독립 테스터와 실제 전장 검증, 게임 적용은 수행하지 않았다. 기존 규정/다른 작품 중단 기록/앞선 잘못된 C01 해석을 새 캐릭터 승인으로 사용하지 않았다.
