# GC9 신규 남녀2명6장 제작기준 v01

MAIN03-20261109-5F7D5052 / 차수1 / main03 / splash.
사용자 확정 범위는 “새 2명만 제작: 총 6장”이다. 기존 C01~C04 수정/재생성은 제외하며 이전 차수2 취소를 이번 승인과 혼동하지 않는다.

N01은 메이플스토리 참조의 남성으로, 갈흑 장발·보라눈·검은 동양풍 겹옷과 긴 옷자락·회색 교차깃·금색 허리띠/둥근 장식·붉은 띠와 술·부츠·원본 팔 장비/쌍날 특징을 보존한다. 대형 청록 전투불꽃과 몸 주변 궤적은 지시대로 억제하고 팔 장비의 실제 청록 인레이는 보존한다.

N02는 리본 파일 참조의 어린 인상 여성으로, 은백/연분홍 장발·붉은 눈·분홍 뿔형 머리장식·분홍/흰 의상·신발·분홍 작은 소품과 동반 장식·동물형 풍선을 보존한다. SD와 픽셀 렌더링은 GC9 작화 마스터가 아니며, 성인화/성적 과장 없이 일반 전신 일러스트 비율로 옮긴다.

입을 다문 중립 표정, 편안한 눈썹, 양발로 지면을 지지하는 자연스러운 기립, 팔을 몸 옆으로 편안히 내린 자세를6장에 적용한다. 소품을 잡는 손의 최소 굽힘은 허용한다. 턱괴기·주머니손·한발들기·도약·캐스팅·전투 포즈는 제외한다.

정면, 화면 오른쪽45도 전신, 화면 오른쪽90도 전신을 각각 별도 생성한다. GC9 C3~C6 정면/사선8장 전체가 비교 기준이며 C4 전체/얼굴을 우선, 남성에는 C6를 보조, 여성 최초에는 C3를 보조했다. 실제 호출별 전체작화1~2장과 디자인/편집대상/정면 기준의 역할을 분리하고 총4참조 이하로 실행했다.

큰 머리 묶음·정돈된 가는 선·선택적 하이라이트를 유지하며 낱가닥 노이즈·붓결을 피한다. 의상은 무광 천과 구조/장력에 맞는 큰 셀 명암으로 표현하고 그래픽·얼룩·잔상처럼 보이는 불필요한 파편 명암을 배제한다. 실제 장식과 주름을 제거하지 않는다. 앞선 불만의 원인이 무엇이었다고 확정하지 않는다.

밝은 단색 계열 배경, 상단20%·좌우15%·하단6% 기본 여백, 공통 배율/발선을 지시한다. 원본 생성 단계에서 구도를 확보하고 반환 PNG 바이트를 그대로 보존한다. 수치 미세편차를 맞추려고 무한 재생성하거나 자동 축소·분해·재조립하지 않는다. 눈 방향처럼 국소 구조 문제에만 부분 보완을 사용한다.

N02 낮은 해상도에서 모호한 소품은 사탕/막대 소품, 해파리형 옆 주머니와 끈, 작은 귀 장식으로 해석했다. 옅은 다리 의상에 어두운 옆선을 적용했고 풍선줄을 낮게 내린 손과 연결했다. 보이지 않는 뒷옷 구조와 이 연결은 최소 추정이며 사용자 확정 디자인이라고 주장하지 않는다.

내장 image_gen.imagegen만 사용한다. 스프라이트60프레임·전장 반영은 이번 독립 정지 일러스트 범위 밖이다. 기존4명/타팀/게임코드/카탈로그/공통규정은 변경하지 않으며 커밋·푸시도 하지 않는다. 생성/파일 검사 완료와 사용자 미적 합격은 구분한다.
