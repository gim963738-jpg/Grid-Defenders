## 확인한 구성

붉은 머리와 높은 붉은 깃, 내려둔 짙은 후드, 붉은 코트·망토, 크림색 셔츠·접은 소매, 양어깨 은색 판금, 오른팔 완갑과 오른무릎 보호판, 허리 주머니 두 개, 헐렁한 짙은 바지, 갈색 끈 부츠·붉은 매듭을 유지했다. 얼굴과 인체는 기존 남성형 기준으로 재구성했다. 원본에 없는 무기를 추가하지 않았다.

정측면은 한쪽 눈과 옆을 향한 몸통·무릎·발이 보이는 구도다. 후면에는 얼굴·앞 단추·가슴 고정쇠·앞 부츠 끈이 나타나지 않으며, 오른팔 완갑은 화면 오른쪽에 있다. 3/4에서는 앞면과 옆면 및 두 눈이 함께 읽힌다.

네 전체 프레임을 직접 확인하고 흰색·차콜 배경의 브라우저 화면 캡처를 열어 투명 가장자리와 구성 대응을 비교했다. 얼굴과 금속 표현은 C4·C3의 사용자 평가를 제작에 적용했다. 최종 화풍과 모델 일관성에 대한 사용자 판단은 별도다.

## 파일과 화면 검증

- 원본 4개 모두 1024×1536 PNG이며, 완전 투명 픽셀과 알파 240 이상 가시 영역이 있다. 실제 알파 통계는 생성 기록에 보관했다.
- 원본 입력 보관본과 Downloads 파일의 SHA-256이 일치한다. 생성 도구 원본과 프로젝트 복사본의 SHA-256도 모두 일치한다.
- ZIP은 위 4개 PNG만 포함하며 CRC와 해시 검사를 통과했다.
- 원본 PNG를 직접 사용하는 비교 화면에서 4장 모두 로드된다. 방향·상세 영역 전환과 배경 변경을 확인했다. 100% 검수 이미지의 실제 너비·CSS 표시 너비가 모두 1024이며 JPEG 축소본을 사용하지 않는다.
- 390px 화면에서 가로 넘침이 없다. 원본 배율 상세 창의 스크롤은 의도된 기능이다.

같은 캔버스와 비율을 요청했지만, 생성 원본의 알파 240 이상 실루엣 상단은 y=14~22, 하단은 y=1503~1521 범위다. 픽셀 단위로 완전히 같은 기준선에 정규화한 파일이나 정확한 3D 모델 회전 산출물은 아니다. 생성 원본을 임의 확대·축소하지 않고 보존했다.

게임 적용·공격 판정·앵커 설정·커밋·푸시는 이번 작업에 포함하지 않았다.
