# 붉은 머리 모험가 리모델링과 4방향

사용자가 제공한 붉은 머리 모험가 삼면도의 머리색·복장·장비 구성을 유지하고, 기존 분석 화풍과 성인 남성형 비율로 재구성한다. 같은 캐릭터를 정면·정측면·후면·3/4 사선의 개별 PNG 4장으로 제작한다.

## 참조와 구성

원본은 `inputs/source-threeviews.png`에 변경 없이 보관했다. 실제 크기 1774×887, 투명 알파가 있는 PNG다. 새 산출물도 투명 배경을 요청하고 실제 파일의 알파를 확인한다.

- 머리: 짧고 헝클어진 붉은 머리와 위로 뻗는 가닥. 원본의 개별 얼굴·짧은 비율 대신 약 8등신의 기존 남성형 제작 기준을 적용한다.
- 의상: 붉은 높은 깃 코트와 각진 앞자락·망토, 목 뒤에 내려둔 짙은 후드, 크림색 단추 셔츠와 접은 소매, 짙은 목 안감, 붉은 천의 옅은 이중 테두리.
- 금속: 양어깨의 겹친 은색 판금, 해부학적 오른팔의 긴 은색 완갑, 오른무릎 앞쪽의 은색 보호판. 왼팔·왼무릎까지 대칭으로 추가하지 않는다.
- 가죽: 어두운 갈색 손가락 없는 장갑, 직사각 은색 버클의 벨트, 좌우 허리 주머니 2개, 앞면에 끈이 있는 긴 갈색 부츠와 붉은 윗단 매듭.
- 바지: 짙은 헐렁한 바지. 원본에 없는 검·활·방패·배낭 등은 추가하지 않는다.

C4 생성 결과의 얼굴선과 완성도, C3 결과의 금속 면·두께·반사광을 우선 참조한다. 여성형 얼굴·체형이나 금색·청록 팔레트는 복사하지 않는다. 남성형 인체와 기본 선화는 GC9의 라스 참조도 함께 사용한다.

## 네 방향

| 파일 | 방향 | 확인할 점 |
|---|---|---|
| images/01_front.png | 정면 0도 | 가슴·골반·무릎이 정면, 오른팔·오른무릎 판금은 화면 왼쪽 |
| images/02_side.png | 정측면 90도 | 화면 오른쪽을 향한 정확한 옆모습, 한쪽 눈만 보이며 가슴도 옆을 향함 |
| images/03_back.png | 후면 180도 | 얼굴·앞 단추·앞 버클이 보이지 않음, 오른팔 판금은 화면 오른쪽, 부츠 뒤에 앞 끈을 그리지 않음 |
| images/04_threequarter.png | 3/4 사선 약 45도 | 화면 오른쪽으로 돌아선 몸, 두 눈과 앞면·옆면이 함께 읽힘 |

정면을 먼저 완성하고 나머지 방향의 인체·얼굴·복장 기준으로 사용한다. 사선에는 앞서 제작한 정면·정측면·후면을 함께 첨부한다. 머리 크기·어깨·허리·무릎·발 위치와 표시 배율을 가능한 한 맞추고, 각도에 따른 겹침만 자연스럽게 바꾼다. 정확한 3D 모델 회전 이미지와는 구분한다.

## 산출물과 검수

내장 `image_gen`으로 별도 이미지별 생성한다. 실제 반환 크기·알파·해시·정확한 프롬프트와 참조 순서는 생성 기록에 저장한다. 원본을 JPEG로 축소해 확대 검수하지 않는다. 투명 이미지의 전체 프레임과 얼굴·금속·장비를 밝은 배경 및 어두운 배경에서 확인한다.

네 PNG와 전달용 ZIP, 원본 PNG를 직접 읽는 4방향 비교 HTML을 작업 폴더에 보관한다. 게임 코드·UI·전투·이전 캐릭터 산출물은 변경하지 않는다.
