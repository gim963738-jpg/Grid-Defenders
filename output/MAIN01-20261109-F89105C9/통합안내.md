# MAIN01-20261109-F89105C9 차수1 통합 안내

main01 검토용이며 루트/UI 제품 파일은 편집하지 않았다. 통합.patch는 최신 루트 게임/src/main.ts에만 import, 인스턴스 선언, refreshRunControls의 sync, createRangeDummy 직후 초기화, HMR dispose를 추가한다. landscape-entry.ts는 이미 main.ts를 동적으로 import하고 같은 liveBattle/전장 DOM을 사용하므로 별도 연결 변경이 필요 없다. 통합 전 source-comparison.json의 루트 SHA-256을 대조한다. main.ts.before는 원본 바이트 백업, main.ts.after는 검증 사본이며 전체 덮어쓰기용이 아니다.

복사 대상은 게임/src/devImageCompare.ts, devImageCompareArt.ts, devImageCompare.css, 게임/public/assets/dev-image-compare/이다. 새 파일만 복사 후 통합.patch를 적용한다. QA는 output 아래의 별도 qa-game에 최신 루트 src/HTML을 복제하고 main.ts.after 및 새 모듈/CSS만 얹었다. gameplay 제품 main.ts/landscape-entry.ts는 검증용으로도 수정하지 않았다. 기존 미커밋 파일과 UI 작업 원본은 그대로다.

사용: 기존 개발자 도구 마지막의 이미지 대조 → 원본/1~4안 카드 → 전장 터치 또는 카드 드래그 → 배치된 그림 터치/드래그 → 선택 크기 슬라이더/숫자 50~200%,100% 복원. 카드 줄은 가로 스크롤이다. 배치 모드 해제는 빈 전장 입력을 게임에 돌려주며 그림 선택은 유지한다. 닫기는 모든 미리보기 입력을 해제하고 그림만 남긴다. 다시 열어 개별/전체 삭제한다. 전장 전환/비활성화는 자동 정리한다. ESC도 닫기다.

방향 추가 API: createDevImageCompare(...) 반환값의 setAssets(CompareArt[])에 도착한 방향 메타데이터를 넣는다. CompareArt={variant:0~4,direction:'front'|'right45'|'right90',file:'directions_v02/파일.png',label:'원본 또는 N안',width,height,bodyHeight,footX,footY}. file은 assets/dev-image-compare/ 기준 상대 PNG경로다. 실제 PNG와 검수된 방향별 몸 높이/발 좌표를 함께 복사한 뒤 호출한다. 선택 방향 교체는 동일 variant 메타데이터를 찾으며 배치 좌표와 percent를 보존한다. 아직 없는 방향은 제작 대기 표시/카드 비활성화이며 선택된 그림을 임의 대체하지 않는다. 메타데이터 없는 생성 이미지를 반전하거나 프레이밍 추정으로 합격 처리하지 않았다.

최종: directions_v02의15개 PNG와asset-manifest.json이도착해 SHA-256/알파경계를대조하고바이트복사했다. devImageCompareArt.ts가15개측정명세를기본으로내보내므로추가setAssets호출없이정면/45/90이동작한다. 초기정면5개파일도요청대로그대로보존한다. 측정manifest의최신정면값도함께사용한다. 몸과발Y는alpha>=32 ROI측정이며footX는지지중심추정(원본±20px),발Y±3px오차표시를유지했다. main01은모듈3파일과assets하위전체를복사하고기존통합.patch만적용하면된다.
