# 차수2 최소 통합

대상은 files/게임/ 아래8파일이다. src/devImageCompare.ts·devImageCompareArt.ts·devImageCompare.css는루트기준검토패치 통합.patch로적용한다. public/assets/dev-image-compare/scalp_face_v03/의신규4PNG와asset-manifest.json은그대로복사한다. 기존15PNG/main.ts/전투/재화/일반저장/그외UI를변경하지않는다. before/after SHA와원본출처는변경manifest.json,착수시기준은base-hashes.json.

main01이UI작업공간에3파일패치/자산만적용한뒤root에동일바이트로반영하는범위다. 실제적용전현재3파일이beforeSha256과같은지확인한다. git apply --check는이번제출시root에서통과했다. qa-game전체나브라우저프로필/node_modules/dist는통합대상이아니다. main.ts import/init/sync/dispose추가는필요없다.

사용법: 이미지대조를열면기본신규4안묶음. 카드를눌러전장에배치하거나드래그한다. 가로스크롤로4안모두접근한다. 기존5종묶음에는원본+기존1~4안이있고각3방향을유지한다. 신규안은정면만지원하며이전90도선택상태에서도신규카드를누르면명시적으로정면을선택한다. 배치된신규안선택중45/90은비활성. 기존안카드를다시선택하면45/90이복구된다. 기존크기/이동/삭제/닫기/전환동작은유지한다.

카탈로그ID0~4는기존세트,5~8은신규세트다. 카드순번으로자산ID를추정하지않고실제variant를사용한다. setAssets허용범위도등록된front카탈로그ID로검사하며기존5개도착수하드코딩을제거했다. 렌더링은각이미지의width/height/bodyHeight/footX/footY를사용한다.
