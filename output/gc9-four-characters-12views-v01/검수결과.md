# 제작자 자체 검수
실제 생성·보존된 제출 후보는12장이다. 의뢰 전체 기술 검수는 **미달**이며 사용자 시각 합격은 대기다.

## 파일과 여백
12장 모두1024×1536 RGB PNG이고 서로 다른 SHA256을 가진다. 생성 원본과 제출 PNG 바이트가 동일하다. ZIP12개 항목은 재독하여 PNG 해시와 모두 일치함을 확인했다. 실제 바이트/해시/해상도는 manifest.json에 전부 기록했다.

밝은 배경에서 전체 프레임의 머리·발·뿔·옷자락·새를 확인했고 의도하지 않은 캔버스 잘림을 발견하지 않았다. 대비 마스크(min RGB<180 또는 색차>45)의 경계 측정으로 안전 여백은12/12 충족한다. 옅은 경계는 자동 측정에서 빠질 수 있어 시각 확인을 병행했다. 원본 배경에는 미세한 밝기 변화가 있어 완전히 균일한 단색이라고 보장하지 않는다.

## 남은 필수 문제
캐릭터별 공통 배율·발 기준선은 충족하지 못했다. 최종 후보의 발선 경계 범위는 C01 y1263~1426(163px 차이), C02 y1311~1442(131px), C03 y1300~1430(130px), C04 y1322~1443(121px)이다. 사선 보완본이 정면·측면보다 작고 발선이 높다. 공통 배율 복구를 시도한 C01 추가 후보는 과도하게 확대되어 여백까지 회귀했으므로 폐기 후보로 보존했고 마스터로 사용하지 않았다. 자세한 수치는 evidence/set-consistency.json에 있다.

## 얼굴·손·의상·방향
원본과 생성 결과를 직접 표시하고 inspect.html의 원본2배 CSS 확대 화면으로 얼굴·손/소매 연결을 확인했다. 주요 얼굴·헤어·의상 색과 종족 특징이 유지되고, 각 방향에서 머리·몸통·골반·무릎·발이 함께 회전한다. C01 안경과 새, C02 뿔/귀와 앞치마, C03 가르마와 미소, C04 터틀넥/열린 재킷을 확인했다. 측면의 먼 눈·팔·귀·뿔이 가려지는 것은 방향에 따른 가림으로 구분한다.

C01 노출된 손가락이 길고 각진 편이고, C02 사선 손은 일부 손가락이 겹쳐 분리 판정이 제한된다. C03 턱 근처 손의 접촉과 주머니 속 손은 일부 가려져 모든 손가락의 해부학 합격을 주장하지 않는다. C04 양손은 주머니에 있어 손가락 검증 불가다. C04 사선·측면에서 뒤쪽 큰 칼라가 후드처럼 읽히며 원본에 보이지 않던 뒤 구조이므로 미확정 보완으로 기록한다.

선과 셀 명암은 확인되나 특히 C02 얼굴의 둥근 비율, 각진 천 그림자, 머리 하이라이트의 GC9 일치 여부는 사용자 판정이 필요하다. AI 검수를 사용자 합격이나 새 스타일 마스터 승인으로 대체하지 않는다.

## 도구 및 증거
내장 image_gen.imagegen24회 실제 호출: 최초/비율 보완13회, 여백 보완8회, 발선 보완2회, 공통 배율 보완 실패1회. 생성기록에 모든 실행 프롬프트·참조 순서/역할/해시·출력 경로와 반환 결과를 보존했다. API/유료 외주/임의 모델 변경/CLI 생성 우회/하위 위임은 사용하지 않았다.

Orca 브라우저에서 확대 검수 화면을 열었다. 캡처 도구가 가로·세로 반복 타일을 반환하는 현상을 관찰해 전체화면 캡처를 검수 완료의 단독 증거로 삼지 않았다. 원본 이미지 직접 관찰·확대 페이지·수치 검사와 함께 판단했다. 게임 전장과 독립 테스터 검수는 수행하지 않았으며 이번 독립 일러스트 후보 범위 밖이다.
