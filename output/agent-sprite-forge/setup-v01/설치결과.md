# Agent Sprite Forge 설치와 Grok 계정 연결

2026-11-07 사용자 요청으로 설치하고, 사용자가 선택한 **Grok 계정 로그인** 방식으로 연결했다. 기기 인증 로그인 명령이 성공으로 종료된 것을 확인했다. 계정 이메일·인증 토큰·API 키는 이 기록이나 프로젝트에 저장하지 않았다. 로그인 자격 증명은 Grok CLI가 사용자 설정 위치에서 관리한다.

## 설치

| 구성 | 설치 결과 |
|---|---|
| Agent Sprite Forge | `0x0funky/agent-sprite-forge`, 커밋 `6b3da5c444363378e20f3fce130ebecc22f343dd` |
| 스킬 | `generate2dsprite`, `video2dsprite`, `generate2dmedia` |
| 스킬 위치 | `C:/Users/user/.codex/skills/` |
| Python | 3.11.9, 독립 환경 `C:/Users/user/.local/share/agent-sprite-forge/venv` |
| Python 패키지 | numpy 2.4.6, Pillow 13.0.0, scipy 1.17.1 |
| FFmpeg / ffprobe | 9.0.1 Essentials, WinGet 사용자 범위 설치 |
| Grok CLI | 공식 npm `@xai-official/grok` 1.0.77 |
| 영상 생성 경로 | `local:grok-acp`, Grok 계정 로그인 |
| 프로젝트 실행 도구 | `tools/forge.py` |

스킬 설치는 기본 제공 `skill-installer`의 GitHub 설치 도구를 사용했다. 스프라이트·영상 작업에 필요한 세 스킬을 같은 커밋에서 가져왔다. 지도 제작과 코드로 그리는 대체 경로는 이번 설치에 포함하지 않았다. `Agent-Sprite-Forge-LICENSE.txt`에 원본 MIT 라이선스를 보존했다.

## 연결과 점검

- Grok 기기 인증 로그인 성공을 확인했다.
- 사용자 설정 `%APPDATA%/agent-sprite-forge/config.json`에 영상 경로를 `grok-acp` 우선으로 등록했다. 이 파일에는 경로 선호도만 저장했다.
- 영상 경로 조회가 `local:grok-acp`를 선택한다.
- FFmpeg로 VP9 알파 투명 영상의 인코딩/디코딩과 H.264 인코딩을 검사했다. PNG·WebM·packed 영상 처리가 가능하다.
- 설치 후 진단에서 실패는 0개다. 한글/공백 경로, 다른 기본 Python, 미설치 지도·코드아트 스킬에 대한 안내는 남는다. 프로젝트 실행 도구는 독립 Python 환경, `PYTHONUTF8=1`, 사용자 PATH를 적용한다.
- 실제 생성 요청과 구독 할당량을 쓰는 시험 생성은 실행하지 않았다. 영상 생성 권한·할당량·모델 도구 노출은 첫 실제 생성 시 확인할 항목이다.

`doctor-final.json`은 설치·경로 점검, `video-doctor.json`은 영상 처리 기능 점검, `install-manifest.json`은 설치 버전과 로그인 성공 관찰 기록이다. 진단 도구는 Grok의 로그인 상태를 읽는 기능이 없으므로 진단의 `PRESENT` 등급과 이번 실제 로그인 성공 관찰을 구분했다.

## 사용

프로젝트 폴더에서 실행한다. 실행 도구는 인자로 받은 스크립트 명령을 실행하며, 입력하지 않은 생성 작업을 자동 실행하지 않는다.

```powershell
python tools/forge.py doctor --host-tools image_gen
python tools/forge.py video doctor
python tools/forge.py media resolve --kind video
python tools/forge.py master --help
python tools/forge.py set --help
```

로그인이 만료되면 `python tools/forge.py login`으로 기기 인증을 다시 시작할 수 있다. 비밀번호나 키를 채팅에 보낼 필요가 없다.

새 스킬은 다음 메시지부터 사용할 수 있다. 기존 금발 캐릭터 PNG를 기준 원화로 준비하고, 오른쪽 걷기 영상 생성과 프레임 추출을 진행할 수 있는 설치 상태다. 현재 게임 코드나 기존 스프라이트 시트는 수정하지 않았다.
